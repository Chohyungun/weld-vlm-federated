# 영상에서 생성할 수 있는 정보와 판정의 한계

이번 과업은 결함 종류·위치와 기준 설명문의 생성이다. 실제 용접부의 합격·불합격을 자동으로 판정하는 과업으로 정의하지 않는다.

## 자료에 있는 정보

라벨에는 결함 종류와 픽셀 좌표의 폴리곤이 있다. 폴리곤으로 바운딩박스와 픽셀 단위 면적을 계산할 수 있다. 명목 재질 정보도 있으나 실물과 일치하는지는 별도 검증이 필요하다.

## 자료에 없는 정보

판 두께, 화소당 길이, 결함의 실치수, 전문가가 확인한 합부 판정과 조치 지침이 일관된 정답으로 제공되지 않는다. 픽셀 단위 길이·면적을 mm·mm²로 변환할 근거가 없다. 일부 정상 파노라마에 보이는 납글자 정보도 대부분의 결함 크롭과 연결할 식별자가 없어 전체 과업의 정답으로 사용할 수 없다.

## 학습 응답과 평가

모델은 결함 코드·원본 좌표 박스·판정 상태·인용 조항을 구조화한 JSON과 기준 설명문을 생성한다. 치수 기준 합부는 판단 불가 상태로 두며 허용치 표에 대응한 조항과 라벨에서 만든 기준 설명문을 학습한다. 기준 설명문은 검사 전문가가 영상을 직접 판독한 소견과 다르다. 이 허용치 표는 연구용 기준이며 원천 규정의 적용 타당성을 전문가가 검수한 정답과 구분한다.

조항 일치율은 허용치 표 기준의 일치성을 나타낸다. 설명문 자동 검사에는 알려진 오탐·미검출이 있어 정확한 판독·안전한 판단·규정 준수를 증명하는 점수로 사용하지 않는다. 평가 결과는 검출 성능, 구조화된 출력 실패, 조항 일치성, 설명문 검사로 나누어 보고한다.

실제 결과와 각 지표의 분모는 [결과표](paper/결과표_템플릿.md), 학습 응답의 범위는 [본문](paper/본문_초안.md)에 정리하였다.
