# 데이터셋 현황

이 문서는 연구에 사용한 이미지와 조사한 후보 자료를 한곳에서 안내한다. 자료를 받았다는 사실, 내용을 검증했다는 사실, 학습·평가에 사용했다는 사실은 서로 다르다. 아래 수치는 기존 확보·검증 기록을 정리한 것이며, 이번 문서 개정에서 데이터를 다시 세거나 배포처 접근 상태를 재조회하지는 않았다.

수치는 **실측**(파일을 직접 확인한 값), **기재**(배포처·논문이 발표한 값), **미확인**으로 구분한다. 이미지 장수와 라벨·중복 사본을 포함한 파일 수도 따로 적는다. 현재 실험 결과와 해석은 [사전실험 보고](사전실험_보고.md), 데이터 처리 방식은 [구현설계](구현설계.md)를 함께 본다.

## 1. 현재 사용한 자료와 확보한 자료

주 자료는 AI허브 71761의 용접 방사선 검사(RT) 이미지다. 배포분에서 확인한 RT 62,998장과, 2026-08-31에 분할 목록을 동결한 실험 자료 62,308장은 집계 단계가 다르다. 현재 공통 평가셋 12,461장의 결과는 탐색적으로 해석한다. 분할 사이 중복 의심이 남아 있어 독립적인 현장 일반화 성능으로 단정할 수 없다.

| 자료 | 확보·검증된 규모 | 현재 역할과 제한 |
|---|---|---|
| 창원 AI허브 71761 | 이미지 129,613장, 라벨 JSON 129,613개(실측) | RT를 주 실험에 사용. VT는 주 실험 제외 |
| 창원 RT 배포분 | 62,998장: 명목 ST 54,053 / 명목 AL 8,945(실측) | 실험 전 자료 규모. 아래 동결 분할과 구분 |
| 창원 VT 배포분 | 66,615장(실측) | RT와 결함 종류가 달라 주 실험에 섞지 않음 |
| RIAWELC | 고유 이미지 21,964장 / 파일 24,407개(실측) | 분류용 외부 자료 후보. 위치 정답이 없고 저자 테스트 분할은 중복 |
| LoHi-WELD | 고유 이미지 3,022장 / 파일 34,489개(실측) | 가시광 확장 후보. 주 RT 실험 및 공통 클래스 비교에서 제외 |
| AI허브 104. LNG탱크 품질 검사 | 공유 저장공간의 폴더 존재 확인, 장수 미확인 | 용접 결함 검사와의 관련성부터 확인 필요 |
| AI허브 42. 용접로봇 행동 생성 | 공유 저장공간의 폴더 존재 확인, 장수 미확인 | 결함 검사 자료인지 미확인 |

현재 동결 분할은 평가 12,461장(결함 7,086 / 정상 5,375), 학습 풀 49,847장(train 44,846 / val 5,001)이다. 학습 풀은 C1 26,451장, C2 16,253장, C3 7,143장으로 나뉜다. C1·C2·C3는 한 장비에서 구성한 참여자 역할이며 실제 세 회사가 제공한 자료가 아니다.

ST·AL은 데이터셋에 적힌 명목 구분이다. 후속 표본 확인에서 명목 AL 파노라마에 강 계열 규격이 보였고, 결함 크롭의 재질은 확인하지 못했다. 두 집단의 차이를 실제 강재·알루미늄의 물리적 차이로 해석하지 않는다.

## 2. 창원 자료에서 확인한 내용

AI허브 식별자는 `dataSetSn=71761`이다. 라벨 JSON 전수 확인에서 파싱 실패는 0건이었고, 22키 스키마와 288,097개 폴리곤을 확인했다. 좌표는 정규화 값이 아닌 절대 픽셀 정수다. 원천 이미지와 라벨은 30개 아카이브별 개수 대조에서 1:1로 맞았다. 전체 원천 용량은 약 40.5 GB, RT는 약 7.6 GB였다.

| RT 클래스 | 명목 ST | 명목 AL | 합계 |
|---|---:|---:|---:|
| 정상 | 23,696 | 4,698 | 28,394 |
| 기공 | 24,345 | 2,621 | 26,966 |
| 융합불량 | 2,928 | 300 | 3,228 |
| 균열 | 2,054 | 294 | 2,348 |
| 슬래그혼입 | 1,030 | 1,032 | 2,062 |
| 합계 | 54,053 | 8,945 | 62,998 |

배포처의 전체 구축량 144,019장(기재)에는 비공개 테스트 자료가 포함된다. 실제 확보한 공개분은 129,613장으로 기재값의 90.0%다. 학습·검증·테스트를 8:1:1로 나누고 테스트 10%를 공개하지 않는다는 배포처 설명과 부합한다. 파일 목록에는 확보한 수량을 사용한다.

검증 과정에서 다음 문제가 드러났다. 처리 방침과 상세 근거는 [AI허브 전수확인](데이터셋_AI허브_전수확인.md)에 있다.

- 결함은 주로 1280×720 크롭이고 정상은 파노라마다. RT/ST에서는 이미지 크기만 이용한 규칙으로 결함·정상을 96.1% 정확도로 구분할 수 있었다. 이 값은 모델 성능이 아니라 데이터의 편향을 나타낸다.
- 저자 Training/Validation을 가로지르는 연속 ID 묶음은 6,874개(53.1%), 해당 이미지는 99,888장(77.1%)이었다. ID 묶음은 실제 용접부를 확인한 식별자가 아닌 대용 기준이다.
- RT에 용입부족 2건, VT에 균열 6건이 섞였다. 이미지 경계 밖 좌표값 9,562개, 음수 좌표를 포함한 파일 1,280개, 꼭짓점이 3개 미만인 폴리곤 30개도 확인했다.
- 정상 폴리곤 60,890개는 결함 검출의 객체 정답과 구분해야 한다. 이미지 해상도는 9,767종이며 비트깊이 전수 확인은 미완료다.

## 3. 보조 이미지 자료

### RIAWELC

[공식 저장소](https://github.com/stefyste/RIAWELC)에서 2026-08-18 취득했다. 파일 24,407개를 전수 판독한 규격은 **227×227, 8bit grayscale PNG**다. README의 224×224와 다르다. `testing` 2,443장은 모두 `training`의 바이트 동일 사본이며, 고유 이미지는 21,964장이다. 저자 테스트 분할을 독립 평가에 사용하지 않는다.

클래스 매핑은 `Difetto1=CR(균열)`, `Difetto2=PO(기공)`, `Difetto4=LP(용입불량)`, `NoDifetto=ND(정상)`이다. 위치 라벨이 없어 mAP와 BBox-IoU를 산출할 수 없다. 원판에서 잘라낸 타일이므로 원판별로 묶어 분할해야 한다. 후속 파일명 전수 확인에서 원판 접두사 479개를 확인했으며, 이전 509개 집계의 차이는 ` - Copia` 접미 30건 처리에서 생겼다.

명시적 LICENSE 파일은 없고 README에 공개 배포 문구와 인용 요구가 있다. 상업 이용·재배포 가능 여부는 별도 확인 사항이다. 인용 대상은 Totino 외(2022, ICMECE)와 Perri 외(*Manufacturing Letters*) 두 편이다.

### LoHi-WELD

[공식 저장소](https://github.com/SylvioBlock/LoHi-Weld)에서 2026-08-18 취득했다. 원본은 저해상 2,000장과 고해상 1,022장이다. 34,489개 파일에는 원본·어노테이션·저자 5-fold 사본·캐시·스크립트가 함께 들어 있다. 원본 폴더 두 곳만 자료 규모에 포함하며 `kfold_low`·`kfold_high`의 25,420개 파생 파일은 추가 표본으로 세지 않는다.

22,412개 bbox를 YOLO 정규화 좌표와 LabelMe 절대 픽셀 좌표로 제공한다. 클래스는 `pore`, `deposit`, `discontinuity`, `stain`이다. 저해상 77장의 빈 라벨이 정상인지 누락인지는 미확인이다. 크기도 저해상 85~215 × 30~56, 고해상 755~827 × 164~280으로 가변이다.

네 클래스 중 세 개를 창원·RIAWELC의 결함 체계에 대응시키기 어려워 공통 클래스 비교에서 제외했다. LICENSE 파일은 없으며, 논문의 공개 데이터셋 설명만으로 사용권 전 범위를 확정하지 않는다. 인용 대상은 Block 외(2024), *IEEE Access* 12, 77442–77453이다. 확보 절차와 검증 근거는 [실물 확보 보고](데이터셋_실물확보.md)를 본다.

## 5. 규정·텍스트 자료가 맡는 역할

창원 라벨에는 두께, 픽셀-mm 스케일, 적용 규격, 등급, 합부 판정, 조치 지침, 검사 소견이 없다. 이미지에서 얻은 결함의 종류·위치·명목 재질에 합성 조건을 붙일 수는 있지만 이를 실측 판정 정답이라고 부를 수 없다. 근거와 평가 범위는 [판정문 생성 가능성](데이터셋_판정생성_가능성.md)에 정리했다.

문서 후보 34건(PDF 33 + DOCX 1, 91MB)을 조사하고 바이트 중복을 제외한 32건을 추출했다. 추출 성공이 학습·검색 투입 허용을 뜻하지는 않는다. API 1104의 유료 표준 수치를 옮긴 제3자 요약본은 사용 대상에서 제외했고, 출처·권리가 미확인인 자료도 참고용으로 제한한다. 규정 자료는 파일럿 범위이며 원문 수치 대조와 사람 정답 검증이 남아 있다. 상세는 [corpus 후보 판정](corpus_후보_판정.md)을 본다.

공개 QA 텍스트는 저작권과 순환 평가 우려로 2026-08-16에 코퍼스에서 제외했다. 조사 규모는 Obsismc/deepeval-QA-20k 28,070행, Welding-Handbook-QA 16,389행, deepeval-QA 7,313행(영어), welding_iwe 5,163행·radiographic-testing-zh 4,549행(중국어), KoDongkyun/Gemma4_Welding 599행(한국어)이다. 조사 기록상 모두 LLM 생성물이며, 전문가 정답으로 취급하지 않는다.

[WeldLLM 코드](https://github.com/ucassqs/WeldLLM)는 MIT 라이선스로 공개돼 있으며 데이터 확보와 별개의 자산이다. 검출망 설정, 150+ 템플릿의 어노테이션 생성기, YOLO-Qwen 정렬 모듈을 조사했다. bbox를 템플릿에 넣어 만든 설명문은 전문가가 작성한 독립 정답과 구분한다.

## 6. 보관과 공개 범위

확보 기록의 저장 위치는 `<공유 드라이브>/<프로젝트 폴더>/`처럼 자리표시자로 표시한다. 실제 경로, 원본 이미지·원문, 항목별 식별자 목록은 이 안내에 싣지 않는다. RIAWELC·LoHi-WELD는 2026-08-22에 공유 드라이브로 이전한 기록이 있다. AI허브 자료의 공유 저장 이력과 국내 장비 이용 규약 사이에는 확인이 필요한 부분이 있으므로, 폴더가 존재한다는 사실을 보관·반출 조건 준수의 증명으로 해석하지 않는다.

새 자료를 추가할 때는 [메타데이터 설계](메타데이터_설계.md)에 따라 출처·사용 조건·확보 상태·검증 근거를 먼저 기록한다. 확보, 활용 적합성, 사용권, 사람 검토는 각각 확인해야 한다.
