# 데이터 구성과 사용 범위

본실험은 AI Hub 창원 용접 데이터셋(71761)의 방사선 검사 영상을 사용했다. 아래 수량은 저장소에 보존한 원자료 확인 기록을 기준으로 하며 현재 제공처의 배포 수량을 새로 조사한 값은 아니다.

| 자료 | 확인 수량 | 이번 본실험에서의 역할 |
|---|---:|---|
| AI Hub 71761 RT | 62,998장 | 정제·분할 전 원자료 |
| AI Hub 71761 VT | 66,615장 | 촬영 방식·라벨 차이로 제외 |
| RIAWELC | 고유 영상 21,964장 | 보조 자료 조사, 이번 결과에는 미사용 |
| LoHi-WELD | 고유 영상 3,022장 | 보조 자료 조사, 이번 결과에는 미사용 |

## 원자료와 실험 자료의 차이

RT 원자료에 제외 규칙을 적용한 62,308장을 분할 대상으로 동결했다. 평가셋은 12,461장이다. 남은 49,847장은 참여자별 학습·검증 자료를 구성하는 풀로, 실제 한 번의 학습에 투입한 행 수와 다르다. 이번 실행은 약 1/4 학습량을 누적 단위에 맞춰 선택한 11,224개 영상·응답 쌍을 사용했다. 평가 결과는 동결 평가셋의 층화 표본 1,059장에 해당한다.

## 자료에서 확인한 것과 확인하지 못한 것

원자료에는 결함 종류와 위치를 나타내는 폴리곤이 있다. 이를 공통 코드와 원본 픽셀 좌표의 바운딩박스로 변환한다. 명목 재질 ST·AL이 있으나 실물 재질을 확인한 정보로 간주하지 않는다. 회사·설비·촬영일에 따른 독립 참여자 분할을 구성할 일관된 필드가 없어 하나의 AI Hub 자료를 세 참여자로 나누어 모사했다.

판 두께와 화소당 실치수가 없어 결함 길이·면적을 mm 또는 mm²로 확정하지 못한다. 합격·불합격과 조치 지침도 검사 전문가가 검수한 정답으로 제공되지 않는다. 일부 정상 파노라마의 납글자 관측을 모든 결함 영상의 측정 정보로 확대하지 않는다.

연속 식별자와 중복 신호를 이용한 묶음은 실제 용접부 ID가 아니다. 학습·평가 사이 유사 영상 의심 사례가 남아 있어 독립 촬영 자료에 대한 일반화 성능을 주장하지 않는다.

자세한 원자료 확인은 [AI Hub 전수 확인](데이터셋_AI허브_전수확인.md), 보조 자료의 중복·라벨 문제는 [실물 확보 기록](데이터셋_실물확보.md), 참여자 분할의 해석은 [연합 설계 적합성](데이터셋_연합설계_적합성.md)을 참조한다.
