# 주요 데이터셋

## 창원 — AI허브 71761 (주 데이터)

| 항목 | 값 |
|---|---|
| 링크 | aihub.or.kr `dataSetSn=71761` |
| 고유 이미지 | 129,613 【실측】 (RT 62,998 + VT 66,615) |
| 문서 기재 | 144,019 【기재】 |
| 차이 | 실측이 기재의 90.0% — 클래스별로도 88.6~91.2%로 균일 |
| 라벨 | JSON, 22키 고정 스키마, 파싱 실패 0 【실측】 |
| 이미지 | `jpg`, 해상도 9,767종 【실측】. 비트깊이 【전수 측정값 없음】 |
| 원천 용량 | 약 40.5 GB (RT만 7.6 GB) 【실측】 |

규모 차이의 이유: 배포처가 훈련·검증만 개방하고 테스트 10%는 비개방임을 명시한다
(자주찾는질문 · 데이터셋 소개의 8:1:1 분할). 144,019 × 0.9 = 129,617, 실측 129,613.
분포가 보존돼 있어 분할 구조는 유지하고 규모만 줄이면 된다.
매니페스트의 전체 규모는 공개분 실측값 129,613장이다.

데이터 품질과 분할상의 위험은 [전수 확인 결과](데이터셋_AI허브_전수확인.md)에 있다.

1. 규격 지름길: 결함=1280×720 크롭 / 정상=파노라마. 이미지 크기만으로 96.1% 분류 가능. 모든 학습 조건에 공통으로 나타날 수 있다.
2. 저자 분할이 연속 촬영 묶음의 53.1%를 쪼갠다 (영향 이미지 77.1%)
3. 라벨 공간 교차 오염 8건: RT에 `incomplete penetration` 2, VT에 `crack` 6
4. 경계 밖 좌표 9,562개(음수 포함 파일 1,280개) / 정상 폴리곤 60,890개 / 퇴화 폴리곤 30개

연합 적합성: 자연 분할 축은 재질뿐(ST/AL). 회사·설비·촬영일 필드는 없다 【실측】.
분포 분석은 [연합설계 적합성](데이터셋_연합설계_적합성.md).

 규격이 224×224가 아니다. 공식 README를 포함해 여러 문서가 224라고 적었으나
전수 판독 결과 예외 없이 227×227이다.

 클래스 매핑, 순서대로 짝지으면 균열과 용입불량이 뒤바뀐다 【실측 확정】

```
Difetto1 = CR 균열      Difetto2 = PO 기공
Difetto4 = LP 용입불량   NoDifetto = ND 정상
```

인용 의무 2편: Totino et al. (2022) ICMECE / Perri et al., *Manufacturing Letters*

# 판정문에 필요한 정보

라벨 129,613개 전수 스캔 결과다. 상세는 [판정생성 가능성](데이터셋_판정생성_가능성.md).

- 두께·픽셀-mm 스케일·촬영조건 필드가 0건이다 【실측】. 정규식을 키·값 양쪽에 걸어 히트 0.
- 픽셀→mm 변환 불가. 파노라마 필름 픽셀에는 납글자로 두께·ASTM 규격·촬영일이 있으나,
  결함 이미지 68,879장 중 파노라마는 17장(0.025%)이고 크롭에서 잘려 나갔다.
- 폴리곤 면적은 계산되지만 단위가 px²다. mm²가 아니다. 해상도 9,767종이라 균일 스케일
  가정도 성립하지 않는다. 판정 라벨·조치 지침·자유 기술 필드도 전부 없다.

→ D4 이미지-판정문 페어는 전량 합성이다. 실물 축은 `{결함 종류, 폴리곤 위치, 재질}` 셋뿐이다.
