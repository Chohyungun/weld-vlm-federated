# R3 판정 — 잔존 수용

총괄 · 2026-08-31

## 판정

**출처 지름길의 잔존을 수용하고 현행 매니페스트로 분할을 동결한다.**

사다리 R0~R3 은 사전 확정된 것이고, R3 은 그 마지막 단이었다. 세 단을 다 밟았고
통과선에 닿지 못했다. 사다리는 여기서 끝난다.

| 단계 | 조치 | 결과 |
|---|---|---|
| R1 | 폐색 규명 | 건너뜀 — AUC 0.997 로 적용 구간 초과 |
| R2-a | 테두리 마스킹 8% | 불합격 0.9972 → 0.9906 |
| R2-b | τ 상향 | 불가 — 밴드 205px 대 타일 720px |
| — | 어두운 쪽 클램프 | 기각 — 결함 p25 = 배경 p75 = 104 |
| **R3** | **히스토그램 정합** | **불합격 → 0.9802** |

## 무엇이 닫혔고 무엇이 남았나

정합은 실패한 조치가 아니다. **겨냥한 채널은 닫았다.**

| 채널 | 조치 | 결과 |
|---|---|---|
| 절대 규격·화소수·종횡비 | 타일링 | 구성적 0비트. 닫힘 |
| 테두리 국소 무늬 | R2-a 마스킹 | shuffle 0.9852 → 0.8476. 유의 감쇠 |
| 전역 밝기 주변 분포 | R3 정합 | 1백분위 0.8801 → **0.5901**. 닫힘 |
| **밝기의 공간 배치** | 없음 | **잔존.** 블록 통계 단독 0.8085 |
| 패치 내부 질감 | 없음 | 잔존. shuffle 0.8646 |

정합 후 두 출처의 평균 밝기는 125.3 대 128.6 으로 사실상 같다. 남은 것은
"어떤 밝기값이 나오는가"가 아니라 **"그 값이 어디에 있는가"** 다. 히스토그램 정합은
전역 단조 픽셀 사상이므로 공간 배치는 구성상 건드리지 못한다.

**전처리로 더 좁힐 여지가 원리적으로 없다.** 공간 배치를 지우려면 픽셀을 옮기거나
지역별로 다른 사상을 써야 하는데, 전자는 결함 위치 정보를 파괴해 검출 과제 자체를
무너뜨리고 후자는 결함의 국소 대비를 왜곡한다.

## 검토했으나 지금은 채택하지 않은 것 — 정상을 원본 크롭으로 한정

실측에서 **결함은 전량 N-crop** 이라는 것이 확인됐다(학습 24,781 / 검증 2,720 /
평가 7,086, N-tile 0장). 출처 차이는 정상 쪽에만 있다. 정상을 N-crop 으로 한정하면
두 클래스가 같은 출처가 되어 지름길이 **구성적으로** 사라진다.

| 항목 | 현행 | 크롭 한정 | 감소 |
|---|---|---|---|
| 학습 풀 | 49,847 | 30,076 | 39.7% |
| C1 | 26,451 | 19,698 | 25.5% |
| C2 | 16,253 | 6,079 | **62.6%** |
| C3 | 7,143 | 4,299 | 39.8% |
| 평가 정상 | 5,375 | 654 | 87.8% |

**채택하지 않은 이유는 비용이 아니라 순서다.** C2 가 62.6% 빠지면 설계한 강재
2/3 대 1/3 이 3.24:1 로 깨져 재층화가 필요하고, 평가셋 20% 층화도 다시 잡아야 한다.
분할을 다시 뜨고 다시 동결하는 작업이다.

그 비용을 치를지는 **검출기가 실제로 출처를 이용하는지**에 달려 있는데, 지금은 그
증거가 없다. 프로브가 잰 것은 ResNet-18 이 정상 이미지들 사이에서 출처를 맞힐 수
있다는 것이고, 우리 헤드라인 축(검출·위치·판정)에서 그것이 성능을 부풀리는지는
아직 재지 않았다. **증거 없이 데이터의 40% 를 버리지 않는다.**

## 그래서 파일럿에서 무엇을 재는가

**P9 교차 출처 오탐(TOST δ=0.10)을 파일럿 필수 산출물로 승격한다.** 배관은 D 에
준비돼 있다.

- 검출기의 오탐이 출처별로 쏠리는가. N-tile 정상에서의 FP 율과 N-crop 정상에서의
  FP 율이 동등성 구간 안에 드는가.
- 쏠린다 → 크롭 한정본을 본실험 구성으로 승격한다. 그때는 근거가 있다.
- 안 쏠린다 → 잔존은 논문의 한계 문단이지 위협이 아니다.

**어느 쪽이든 다섯 칸에 동일하게 적용한다.** 구성을 바꾸면 다섯 칸 전부 재실행이다.

## 논문에 싣는 것

1. 출처 판별 AUC 를 **그대로** 싣는다. 0.9972 → 0.9906 → 0.9802 의 3단 대조와
   채널 분해표를 함께 싣는다. 무엇을 시도했고 무엇이 닫혔고 무엇이 남았는지가
   그 표에 다 있다.
2. **어느 문장에서도 "지름길이 죽었다"고 쓰지 않는다.** 사다리 문서의 규칙이다.
3. 출처별 오탐 분해(P9)를 결과에 넣는다.
4. 지름길 무력 부표 — 정상을 원본 크롭으로 한정한 보조 결과표를 부록에 붙인다.
