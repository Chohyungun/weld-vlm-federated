## 어디까지 왔나

```
8/25  전처리 규격 확정 게이트         ✅ 통과
8/26  타일링 · 매니페스트 v1 · 최종 분할  ✅ 완료
8/27  동결 전 프로브 → 불합격 → 사다리 R2-a → 재불합격 → R3  ← 여기서 멈춤
8/29  분할 동결 (하루 슬립 확정)      ⏸ 대기
8/30~ 축소 파일럿 = 첫 한 사이클      ⏸ 대기
```

**아직 한 사이클은 돌지 않았다.** 다섯 칸 학습은 한 번도 실행되지 않았다.
지금까지 GPU 를 쓴 것은 셋뿐이다 — corpus 축소본 400건, Ray 메모리 프로브,
지름길 프로브(ResNet-18).

## 막혀 있는 것 — 출처 지름길

**결함/정상이 이미지 출처로 판별된다.** 클래스를 정상 하나로 고정해도 AUC 0.99 다.
클래스 불균형이 아니라 픽셀 통계 문제이므로 증강·다운샘플링·비중 조정은 듣지 않는다.

| 축 | 값 |
|---|---|
| 1백분위 밝기 단독 AUC | **0.8801** (N-crop 108.6 / N-tile 48.1) |
| 99백분위 | 0.5046 (차이 없음) |

원인 추정: RT 파노라마를 타일링한 이미지에는 필름 가장자리·배경의 어두운 영역이
들어오고, 검사원이 결함을 겨냥해 자른 크롭에는 들어오지 않는다.

### 사다리 진행

| 단계 | 결과 |
|---|---|
| R1 폐색 규명 | 건너뜀 (AUC 0.997 로 적용 구간 초과) |
| R2-a 테두리 마스킹 8% | **불합격** 0.9972 → 0.9906. shuffle 만 0.985 → 0.848 |
| 어두운 쪽 클램프 | **기각** — 결함 p25 = 배경 p75 = 104, 분포 겹침 |
| R2-b τ 상향 | **불가** — 밴드 205px 대 타일 720px |
| R3 히스토그램 정합 | **중단 시점에 착수, 미완** |

## 재개 시 첫 할 일

1. `wt/A` 에 히스토그램 정합 진행분이 커밋돼 있는지 확인. 있으면 이어서, 없으면 재착수
2. 결과에 따라 R3 확정:
   - 채널이 닫히면 → 정합본으로 동결
   - 안 닫히면 → **잔존 수용**. 출처 판별 AUC 를 논문에 싣고, 출처별 FP 분해 +
     지름길 무력 부표(정상을 원본 크롭으로 한정한 보조 결과표)를 붙인다
3. 동결 게이트 → 축소 파일럿

## 총괄이 답을 기다리는 것

**필름 표본 육안 확인.** 출처 차이의 물리적 원인이 "파노라마 타일 대 검사원 크롭"
이라는 것은 통계에서 나온 추론이다. 실제 필름 20~30장을 사람이 보면 그 추론이
맞는지, 다른 원인이 있는지 확인된다. R3 판단의 근거를 바꿀 수 있는 유일한 외부 입력이다.

## 별개로 살아 있는 문제

**클래스 불균형은 여전히 유효한 과제다.** C1 이 균열 33장·융합불량 31장뿐이라
로컬 단독 칸의 소수 클래스 성능이 바닥일 수 있다. 다만 전처리는 다섯 칸 공통 고정
항목이라 증강·재샘플링을 넣으면 다섯 칸 전부에 동일하게 넣어야 한다.
파일럿에서 실제로 어떻게 나오는지 보고 판단한다.
