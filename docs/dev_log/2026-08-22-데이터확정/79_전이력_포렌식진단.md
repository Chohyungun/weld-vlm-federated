작성 2026-09-01. 대상은 저장소 개설(8/21)부터 현재까지의 전 이력이다.
git 이력, 머지 50건 전량, dev_log 보고서 전부, 그리고 디스크의 산출물을 직접 열어서 대조했다.
문서는 근거가 아니라 검증 대상으로만 다뤘다. 저장소는 1바이트도 고치지 않았다.

## 1. 한 줄 진단

**데이터 실물은 믿을 수 있다. 그 위에 얹힌 "검증했다"는 절차는 믿을 수 없다.**

동결 스냅샷(62,308장), 재인코딩·마스킹·정합 세 벌의 타일, 분할, 파일럿 다섯 칸 학습,
프로브 산출물은 전부 디스크에 실재하고 보고서 수치와 맞는다. 조작이나 날조는 한 건도 찾지 못했다.
불리한 결과(P2·P3 세 차례 불합격, 검증기 교체로 통과율 반토막, 임베딩 변별 불가, ⑤ 판정부 전건 공전)를
숨긴 흔적도 없다. 이 부분은 신뢰해도 된다.

무너지는 것은 셋이다.

1. **머지 게이트가 6주간 절반만 돌았다.** 규약이 요구한 두 조건 중 "전체 테스트 통과"는
   자기신고로만 존재했고, "원저자가 아닌 트랙의 독립 검수"는 50건 전부 한 번도 없었다.
2. **사전 확정한 정지 규칙 셋이 발동 조건을 채우고도 발동하지 않았다.** 후퇴 사다리의 종착 의무,
   축소 파일럿 게이트, 사전등록 상수 재현 검사가 전부 그렇다. 그리고 사다리는 이름표가 바뀌었다.
3. **매 세션 로드되는 정본 문서(`docs/개발규약.md`)가 두 세대 낡았고 자기 레드라인과 충돌한다.**

영향도를 가를 기준 하나를 먼저 세운다. **파일럿 성능 수치는 논문에 싣지 않기로 이미 확정됐다.**
따라서 LoRA 시드·conf 임계·토큰 예산 같은 파일럿 결함은 "논문 오염"이 아니라 "본실험 착수 전 처방"이다.
반대로 동결 스냅샷·사전등록 상수·사다리 서사·이질성 수치는 논문에 직접 실린다. 여기가 급하다.

## 3. 신뢰할 수 있는 것

실물로 확인한 것만 적는다. 문서가 그렇다고 해서 넣은 것은 없다.

### 3-1. 데이터 동결

- **SNAPSHOT 무결.** `data/interim/manifest_v1/` 네 멤버의 sha256을 재계산해 `SNAPSHOT.sha256`
  기재값과 전부 일치. 논문에 실을 digest `1f80e98b151372e3fa44c754d0c5ab2cf06bd731d3dfdb8f2515d05383834899`를
  실제 파일 순서(manifest→annotations→data_capabilities→tiles)로 역산해 재현했다.
  파일럿 표본 `c0a254a8…`, D4 페어 `63fc6b6e…`, 어블레이션 두 팔도 같은 방식으로 검증된다.
- **매니페스트가 실물과 맞는다.** 62,308행에서 무작위 250행을 뽑아 rel_path 결측 0건·sha256 불일치 0건.
  전 행이 `tiles_v1_histmatch`를 가리키고(마스킹본 잔존 0), width/height 고유값은 (1280,720) 하나뿐이다.
  세 타일 트리(원본·마스킹·정합)가 각각 ST 53,379 + AL 8,929 = 62,308장으로 정확히 차 있다.
- **분할 불변조건이 데이터에서 성립한다.** 묶음 6,232개, split을 가로지르는 묶음 0건,
  train 44,846 / val 5,001 / eval 12,461, C1 26,451 / C2 16,253 / C3 7,143.
  58번 표를 독립 재산출해 한 자리도 어긋나지 않았다. eval 비율 19.999%.
- **타일링 회계가 닫힌다.** passthrough 37,816 + tiled 24,398 + oversized_band_cropped 94 = 62,308,
  거기에 폐기 688을 더하면 62,996 = 62,998 − 용입부족 2. 네 경로가 독립적으로 같은 수에 도달한다.
- **D4 페어의 평가셋 격리를 직접 확인했다.** `pairs.jsonl`의 image_id 2,625개(중복 0)와
  파일럿 eval 653장의 교집합 0건, 동결 글로벌 eval 12,461행과의 교집합도 0건.
  불변조건 1-4는 보고서 문장이 아니라 실물에서 지켜졌다.
- **처리 단계별로 바뀐 컬럼이 rel_path·sha256 둘뿐**임을 62,308행 전량 정렬 대조로 확인했다
  (pre_mask→masked, masked→histmatch 두 구간 모두).

### 3-3. 파일럿 학습

- **R×E=N 등가가 회계로 선다.** 검출: sep_local 3,828+1,968+1,026 = 6,822 = sep_central = sep_fed.
  통합형: uni_central 432 = uni_fed 432. 토큰 회계도 독립으로 일치한다
  (⑦ 클라이언트별 244,918+69,094+34,490 = 348,502 ×3라운드 = 1,045,506 = ⑥ supervised_tokens).
  다만 ⑦은 명목만 성립한다 — 4-C4를 함께 읽어야 한다.
- **조기 종료·best 금지가 검출 경로에서 코드로 강제된다.** `detection/round_runner.py` patience=10000,
  `detection/fed_trainer.py` final_eval no-op(best.pt 로드 경로 제거), 그 값을 assert하는 시험 2건.
  저장소에 best 체크포인트가 없고 `runs/*/weights`가 비어 있다.
  ⑥ 학습 곡선도 6 epoch 엄격 단조 하강(0.5557→0.4085)이다.
- 파일럿 다섯 칸이 우회 없이 완주했고 산출물이 전부 실재한다(라운드별 글로벌 체크포인트 포함).

## 4. 신뢰할 수 없는 것

### Critical

**C1. 사전 확정한 사다리의 종착 의무 둘이 이행되지 않았고, 사다리 이름표가 바뀌었다.**

40번 원문(8/24)의 사다리는 이렇다.

| 단 | 40번이 정한 내용 |
|---|---|
| R1 | 0.60 < AUC ≤ 0.70 → **폐색 실험(테두리 마스킹 / 히스토그램 정합 / 저역통과)**으로 규명 |
| R2-a | AUC > 0.70 → RT 전량 테두리 마스킹 |
| R2-b | 여전히 초과 → τ 상향 + 타일 후보 재생성 |
| R3 | 여전히 초과 → **총괄 판단 요청. 잔존 AUC를 논문에 싣고 헤드라인 주장 범위를 축소** |

같은 문서 §5-3은 "**P2가 R2-b 이후에도 0.70 초과면 분할 확정(불변조건 1-2 잠금)을 보류한다**"고 못박았다.

## 5. 확인이 불가능한 것

원리적으로 판별할 수 없는 것들이다. 의심으로 적는 게 아니라 "여기는 못 본다"는 표시다.

- **머지 시점에 실제로 시험을 돌렸는가.** 오늘 재실행으로 50건 전부 통과는 확정했지만,
  당시에 누가 언제 돌렸는지는 CI 로그·아티팩트·훅 기록이 하나도 없어 판별 불가다. 커밋 메시지 자기신고가 유일한 기록이다.
- **커밋 저자 식별.** commit-msg 훅이 모든 커밋에서 도구 트레일러를 제거하고 author·committer가 전부 동일 인물이다.
  "감독이 머지했다"는 first-parent 구조로만 방증된다.
- **채팅·구두 검수의 존재.** 규약이 검수 산출물의 형식·보관을 정하지 않아, 세션 대화로만 오간 검수가 있었다면 흔적이 없다.
  확인한 것은 "저장소 안에 검수 산출물이 없다"와 "검수 시간이 물리적으로 없었다"까지다.
- **`ray_mem_probe.json`이 지워진 것인지 애초에 없던 것인지.** outputs/가 통째로 미추적이라 삭제 흔적이 남지 않는다.

   (지금은 소관 트랙이 없어서 아무도 안 고친다).

### 본실험 착수 전

8. **게이트 구조를 고친다.** 독립 검수 산출물의 형식과 보관 위치를 정하고, 머지 결과 트리에서
   extras 포함으로 시험을 돌리는 pre-merge 훅 또는 CI를 건다. dispatch를 추적으로 돌리거나
   최소한 지시 요약을 추적 문서에 남긴다. PR 경로를 열면 셋이 한꺼번에 해결된다.
9. **재현성 자산을 추적으로 돌린다.** `.gitignore`가 자기 주석과 반대로 동작하고 있다.
   매니페스트·SNAPSHOT·핵심 산출물 해시만이라도 추적한다.
10. **채점 경로를 정본화한다.** fp16/fp32 중 하나로 통일하고, 정상 이미지를 mAP 모집단에 되돌린다(M9).
    conf 임계를 configs로 올리고 통합형 대응 규칙을 정한다. 본실험 R·E를 configs에 고정한다.
11. **격리 위반을 닫는다.** `configs/rag.yaml`의 max_new_tokens를 train+val 재산출본으로 교체한다.
12. **논문에 실릴 값의 산출 코드를 만든다.** 채널 분해표(0.8801/0.5901/0.8085 등)가 지금 재현 불가다.
    P5·P0·P1′도 코드와 산출물을 갖추거나, 못 하면 40번에서 공식 철회한다.
13. **문서 정정 웨이브를 한 번 더 돈다.** 실험설계 §3-4, 데이터셋_연합설계_적합성, 그림_명세와 F1 SVG,
    구현설계(3B), 논문 §3.2 TVD·슬래그비 재산출, 결과표 각주의 회사 명명.
14. **시드 정책 충돌을 판정한다.** 통합형 1시드면 회복률 분모 규칙을 어떻게 적용할지 함께 정한다.
15. **21번을 정리한다.** `make_riawelc_fixture.py`가 지금 첫 줄에서 죽는다. 고치거나 지운다.
    그리고 21번이 근거였던 threshold_cap 96을 다시 확인한다.
