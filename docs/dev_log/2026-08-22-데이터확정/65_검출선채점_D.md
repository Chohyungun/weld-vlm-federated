   모델 하나씩 계산하도록 고쳤고, 중복 레코드는 조용히 덮지 않고 거부한다. 회귀 시험 2건.

   규칙 준수). mAP 는 `evaluation/metrics/localization.py` 의 `coco_map` 으로 산출
