## 4. 잠금 방식과 되돌리는 절차

**실질 잠금은 `verify_snapshot` 이다.** 학습·평가 코드는 `load_snapshot`(기본 verify=True)
으로만 읽으므로, 파일이 1바이트라도 바뀌면 로드 자체가 실패한다. 여기에 OS 읽기 전용
속성을 이중 안전장치로 부여했다(manifest.csv · annotations.csv · tiles.csv ·
data_capabilities.yaml · SNAPSHOT.sha256).

**되돌리는 절차** (불가피한 경우 한정, 총괄 승인 필수):

1. 총괄 승인을 의사결정로그에 먼저 기록한다 — 해시가 바뀌면 실험 결과가 바뀐 것이다.
2. `attrib -R data\interim\manifest_v1\*` (또는 PowerShell `IsReadOnly=$false`)로 속성 해제.
3. 수정 후 `scripts/freeze_snapshot.py` 재실행 — 새 digest 가 나온다. **옛 digest 를
   인용한 문서·논문 초안을 전부 갱신**하고, 새 digest 를 의사결정로그에 남긴다.
4. 이미 돌린 실험이 있으면 무효다. 스냅샷 digest 가 다른 실험은 비교 불가로 처리한다.
