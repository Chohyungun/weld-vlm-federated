# 규격 지름길 대응 — 4관점 적대 검증 종합 판정

작성 2026-08-23 · 감독(CTO) 종합 · 근거 `docs/데이터셋_AI허브_전수확인.md` 4-4 / `docs/개발규약.md`

> **결론 한 줄.** 정상 파노라마를 **이미지 1장당 타일 1장(k=1)** 으로 내려 RT 전량을
> 1280×720 단일 규격으로 만들고(트랙 A), 그것이 실제로 지름길을 죽였는지는
> **평가 설계 관점의 사전등록 상수·프로브**로 증명한다(트랙 D). 표본 선택과
> 온더플라이 창 샘플링은 채택하지 않는다.

# 1. 문제 요약

## 1-1. 실측 사실

RT 62,998장(ST 54,053 + AL 8,945)에서 결함과 정상이 **이미지 규격으로 갈린다.**

| 촬영/재질 | 클래스 | 1280×720 | 대형(폭>2500) | 그 외 | 1280×720 비율 |
|---|---|---|---|---|---|
| RT/ST | 균열 2,054 / 기공 24,345 / 융합불량 2,928 / 슬래그 1,030 | 전량 | 0 | 0 | **100.0%** |
| RT/ST | 정상 23,696 | 2,090 | 19,371 | 2,235 | **8.8%** |
| RT/AL | 정상 4,698 | 1,139 | 3,552 | 7 | **24.2%** |

평균 화소수도 결함 0.92 MP 고정 대 정상 RT/ST 3.01 MP(최대 36.17)로 갈린다.
결함 이미지 중 파노라마는 68,879장 중 **17장(0.025%)** 뿐이다.

## 1-2. 지름길의 정확한 크기 — 헤드라인 지표 위에서 다시 잰다

**여기가 이번 판정에서 가장 먼저 바로잡아야 할 지점이다.** 네 관점과 여덟 건의 적대 검증이
각각 다른 클래스 집합 위에서 게이트 수치를 계산했다. 실제 계약은 이미 확정돼 있다.

`evaluation/metrics/detection.py` 모듈 독스트링(계약 #4, 게이트 #11 확정):

> **"정상"은 클래스가 아니다.** 결함 4종이 전부 음성인 상태로 표현한다. 정상을 5번째
> 클래스로 두면 다수 클래스가 하나 더 들어가 Macro-F1 이 낙관적으로 부풀려진다.

즉 헤드라인은 **이미지 수준 다중라벨 4결함 Macro-F1**이고, 정상 이미지는 **평가 모집단에
그대로 남아 오탐(FP) 원천으로만 계산에 들어간다.** `score_detection()` 의 `gold` 는
"정상 이미지는 빈 집합"이고 macro 는 support>0 클래스만 평균한다.

이 정의 위에서 상수 예측기 두 개를 계산하면 이렇게 된다 (RT 모집단 카운트 기준,
동결 평가셋에서 재산출해 대조한다).

| 예측기 | 산식 | 4결함 Macro-F1 |
|---|---|---|
| 전량양성 (규격 무시, 모든 이미지에 4코드 주장) | `F1_c = 2n_c/(N+n_c)`, N=62,998 | **0.2081** |
| 규격전용 최적 (1280×720 에만 4코드 주장) | 예측 양성 = 37,814 | **0.3025** |
| **규격 지름길의 순 기여** | | **+0.0944** |

클래스별 값 — 전량양성: 균열 0.0719 / 기공 0.5995 / 융합불량 0.0975 / 슬래그 0.0634.
규격전용: 0.1169 / 0.8325 / 0.1573 / 0.1034.

참고로 "1280×720이면 결함" 이진 규칙의 정확도(SDS)는 **RT/ST 0.9613 · RT 전체 0.9484 ·
RT/AL 약 0.871**(AL 은 2-8의 최빈 60.0% 반올림에서 유도한 값이라 M0 로 확정한다)이다.
4-4가 인용한 96.1%는 RT/ST 이진 값이고, 헤드라인 값이 아니다.

**따라서 이번 처방의 게이트는 전부 `0.2081 → 0.3025` 축 위에 놓는다.**
적대 검증이 제시한 `0.9603 → 0.3596`(이진)과 `0.3622 → 0.1242`(5클래스)는 둘 다
계약 #4가 채점하지 않는 과제의 숫자다. 그대로 게이트에 쓰면 **미처리 원본이 게이트를
통과하는 사고**(적대 검증 tiling/validity 조건 1이 지적한 그것)가 여기서도 재발한다.

## 1-3. 왜 급한가

- 다섯 칸 전부에 똑같이 실려 **어느 칸도 이상치로 드러나지 않는다.**
- 회복률 = (연합−로컬)/(중앙−로컬) 의 분자·분모가 모두 오염되므로 헤드라인 숫자가
  결함을 잰 것인지 이미지 크기를 잰 것인지 사후에 분리할 수 없다.
- **비용이 지금은 거의 0이고, 학습 착수 후에는 무한대다.** `data/raw`·`interim`·`processed`
  가 비어 있고 실 매니페스트는 mock 뿐이다. 분할이 동결되면 불변조건 1-2에 따라
  되돌리는 값이 다섯 칸 전량 재실행이 된다.

# 3. 적대 검증 판정

## 3-1. 판정 요약

| 관점 | 실험 타당성 | 실행 가능성 | 종합 |
|---|---|---|---|
| **tiling** | 조건부 (조건 6건) | 조건부 (조건 5건) | **생존 — 채택 골격** |
| subset | **기각(치명)** | **기각(치명)** | 폐기 |
| invariance | **기각(치명)** | **기각(치명)** | 폐기 |
| measure | 조건부 (조건 4건) | 조건부이나 **단독 채택은 치명** | **보완 채택 — 증명 장치** |

## 3-2. subset 이 죽은 이유 (요지)

두 검증이 독립적으로 같은 곳을 짚었다. **선택이 헤드라인에 기여하는 값이 0이다.**
RT/ST 결함 4종은 선택 **전에도 이미 전부 100.0% 1280×720** 이므로, 결함 지지집합 안에서
width·height 는 이미 상수다. 실제로 4결함 Macro-F1 의 전량양성 하한은 선택 전 0.2081,
선택 후 0.2081로 **차이가 0.0000** 이다.

그리고 버려지는 25,184장 중 25,165장(99.92%)이 정상 한 클래스다. 이것은 규격 선택이
아니라 **정상 클래스 88.6% 삭제**이며, 규격 지름길이 실제로 작동하는 유일한 축인
결함/정상 판별을 재는 표본을 없앤다. 선택이 필요한 곳에서는 표본을 없애고, 표본이
남은 곳에서는 선택이 불필요하다 — 두 조치가 서로를 무효화한다.

부수적으로 RQ2도 성립하지 않는다. 오탐을 채점하지 않는 지표에서는 "항상 결함"이라고
답하는 통합형이 감점되지 않는다.

## 3-3. invariance 가 죽은 이유 (요지)

전처리 논리는 옳았다. 무너진 것은 **평가 집계**다. 계약 #4는 `image_id` 당 예측 1건이고
`evaluation/schema.py` 가 그 스키마를 강제한다. 그런데 파노라마 1장을 결정적 슬라이딩
창 약 12개로 쪼개면 창 단위 출력을 이미지 단위로 접는 규칙이 반드시 필요하고, 어떤
규칙을 써도 **창 수 K 의존이 남는다.** OR 집계면 이미지 오탐률 = 1−(1−p)^K 로 K에 단조증가,
평균·투표면 단조감소다. K는 원본 폭의 함수다. 텐서에서 0비트로 죽인 규격 채널이 채점기에서
부활한다.

더 나쁜 것은 통합형 평가가 GPU 1장에서 불가능해 "통합형만 3,000장 부분표본"으로
갈라진다는 점이다. 전처리를 공통 고정하겠다는 안이 평가 프로토콜을 칸별로 갈라놓았다
(규약 3-3·3-7 정면 위반).

추가로 배율 지터 [0.85, 1.18]은 결함 크롭(정확히 1280×720)에서 s<1.0 을 물리적으로 실현할
수 없어, **리샘플링 배율의 지지집합 자체가 원본 크기의 결정론적 함수**가 된다. 죽이겠다던
채널을 설계가 다시 만든다.

## 3-4. measure 가 단독으로는 죽는 이유

R1W 의 산술은 옳다 — 유효 N = 34,585 + 3,229×8.7934 ≈ 62,979 이므로 F1 식이 전량양성과
같아져 규격전용의 순 기여가 정확히 0.0000이 된다. 재계산해 재현했다.

죽는 이유는 **학습에 지름길이 100% 남는데, 그것이 드러나는 시점이 되돌릴 수 없는 때**라는
것이다. Ultralytics imgsz=640 레터박스에서 3445×943 파노라마는 640×175(회색 73%)로,
1280×720은 640×360(회색 44%)으로 눌린다. 회색띠 두께가 그대로 학습 신호다. 모델이 보는
진짜 음성 크롭은 학습분 약 2,583장뿐이고 결함 크롭 27,683장 대비 10.7:1이다. 다섯 칸 전부
R1W 에서 자명하한 0.2081 근처로 붙으면 (중앙−로컬)이 0에 수렴해 **회복률이 산출 불가**가
되고, 그 시점(10월 중순)에는 재학습 예산이 없다.

**따라서 measure 는 데이터 측 조치와 결합될 때만 값이 있다.** 결합되면 값이 매우 크다 —
타일링 후에는 R1 이 사실상 전체가 되어 R1W ≡ full 이 되고, R1W 는 "타일링이 실제로
지름길을 죽였는지"를 재는 **검증 계기**로 역할이 바뀐다.

## 3-5. tiling 이 생존한 이유와 붙는 조건

생존 이유는 하나로 요약된다. **k=1 이 계약 4종을 하나도 열지 않는다.**

- 이미지 수·묶음 크기·재질×클래스 비가 보존되어 R×E=N 등가가 그대로다.
- 타일이 원본 `group_id` 를 상속하므로 묶음 12,956개 구조와 클래스 교차 묶음 9.1% 보호가
  유지된다.
- 계약 #4의 "이미지 1장 = 예측 1건"이 깨지지 않는다 → 집계 규칙이 아예 필요 없다.
- `annotations.csv` 는 손대지 않는다. 정상 폴리곤 60,890개는 어차피 폐기 대상이고
  (전수확인 5장 A-3), 결함 크롭은 잘리지 않으므로 bbox·area·major_axis 전부 불변이다.
- 부수 이득: 처리 후 전 이미지가 1280×720 이므로 **Ultralytics 기본 레터박스의 패딩량이
  상수가 된다.** 커스텀 Dataset 교체가 불필요해져 함정 구간 1(Ultralytics×Flower)의
  접촉면이 늘지 않는다. VLM 시각 토큰 수도 자동으로 상수가 된다(함정 구간 4 완화).

붙는 조건(양쪽 검증에서 취합, 아래 4장에서 전부 처방에 반영):

1. 게이트 수치를 **헤드라인 과제(4결함 Macro-F1)** 위에서 재유도할 것 → 1-2절에서 완료.
2. 프로브를 **평가셋 밖**으로 뺄 것 (전처리 규칙이 평가셋에 적합되는 루프 차단).
3. 폐기 회계를 **재질×클래스 셀별 사전 상한 + 재질 간 폐기율 차 상한**까지 규격에 못박을 것.
4. 데이터 동일성을 문서가 아니라 **파이프라인이 보증**할 것 (`tiles.csv` 를 스냅샷 안으로).
5. "중앙 사전확률은 헤드라인을 오염시키지 않는다"는 단정을 철회하고 측정할 것.
6. **P2 실패 시 후퇴 사다리**를 사전에 확정할 것.
7. 트랙 F 의 RT 원천 해제를 **선행 작업으로 분리 발주**할 것 (I/O 비용이 0으로 잡혀 있었다).
8. 인코딩 통일 파라미터에 **색심도·채널수**를 넣을 것 (8bpp/24bpp 혼재 실측).
9. M4(납글자 제외구역) **폴백을 미리 확정**할 것 (RT/ST 해상도 9,635종에서 절대좌표 규칙은
   성립 가능성이 낮다).
10. `configs/base.yaml` 을 먼저 만들 것 (현재 없다).

## 3-6. 감독이 직접 정정한 사항 3건

적대 검증이 놓쳤거나 잘못 짚은 것을 실물 근거로 교정한다.

**(가) M3(포함·배율 검사)의 대상은 1,183개가 아니라 10개다.**
tiling 안은 "클래스를 가로지르는 묶음 1,183개 중 RT 몫"에 다중배율 NCC 를 돌리자고 했고,
실행 가능성 검증은 그 비용을 "CPU 1~2시간, 이 안의 유일한 비용 항목"으로 잡았다.
그런데 `docs/데이터셋_판정생성_가능성.md` 2-3의 실측은 다르다 —
**연속 id 묶음 12,956개 중 파노라마와 크롭이 함께 든 묶음은 10개(145장)뿐이다.**
나머지는 크롭끼리(7,115) 또는 파노라마끼리(3,079)로 모여 있다. 즉 M3 는 145장 대상이고
**CPU 수 분**이다. 동시에 실행 가능성 검증의 지적도 그대로 유효해진다 — 10개 묶음에서
"포함 0건"이 나와도 그것은 깨끗하다는 증거가 아니라 **연결 키가 없다는 증거**다.
P6 문구를 "교차 묶음 범위에서 미검출"로 좁힌다.

**(나) 계약 #4 클래스 집합은 이미 4결함으로 확정돼 있다.** 1-2절 참조.
subset 안의 "헤드라인 재정의"는 신규 기여가 아니라 현상 유지이고, 그 안이 치명적이었던
부분(정상을 평가 모집단에서 제거)만 남는다. tiling/validity 가 요구한 5클래스 재계산
(0.3622 → 0.1242)은 채점기가 채점하지 않는 과제이므로 채택하지 않는다.

**(다) 납글자 제외구역은 절대좌표 규칙으로 성립할 수 없다.** RT/ST 해상도가 9,635종이고,
게다가 배포 측이 납글자 영역을 **회색 바로 마스킹한 필름이 섞여 있으며 마스킹이 일관되지
않다**(판정생성_가능성 2-3, 확인 3장 중 2장). 절대좌표는 물론이고 상대좌표 규칙도 위험하다.
따라서 M4 는 "제외구역을 좌표로 못박는다"가 아니라 **"밴드 ROI 내부 제한(τ)으로
구조적으로 배제되는지 표본 육안 확인"** 으로 강등하고, 실패 시 τ=1.0 폴백으로 간다.

# 4. 채택 처방

## 4-0. 권고

**정상 파노라마 k=1 타일링(트랙 A) + 사전등록 상수·프로브 기반 증명(트랙 D)을 결합해 채택한다.**
표본 선택과 온더플라이 창 샘플링은 채택하지 않는다.

차선안과 그 조건은 4-9에 둔다.

## 4-1. 실행 순서 — 분할을 먼저 하고 타일링을 뒤에 한다

**이것이 두 생존안을 합칠 때 새로 생기는 상호작용이고, 순서를 이렇게 잡아야 조건 2가 닫힌다.**

```
① 매니페스트 v0 생성 (라벨 JSON 전수, 규격은 헤더 판독)
② 예비 분할 (묶음 단위, 재질×클래스 층화 20%, 시드 고정)   ← 잠그지 않는다
③ 학습 풀에서만 τ·타일 규칙 캘리브레이션 (M1·M4·M6)
④ 타일링 + RT 전량 재인코딩 → data/interim/tiles_v1/
⑤ 매니페스트 v1 (rel_path·sha256·width_px·height_px 갱신, 폐기분 제거)
⑥ 최종 분할 (동일 시드로 1회) + eval fold 수용 검사
⑦ SNAPSHOT.sha256 잠금 → 이후 읽기 전용
```

- **②를 ③보다 앞에 두는 이유**: 전처리 상수가 평가셋 픽셀 통계에서 유도되면 불변조건 1-4가
  실질에서 깨진다. ②의 학습 풀에서만 캘리브레이션한다.
- **타일 선택 함수는 split 을 입력으로 받지 않는다.** `sha256(image_id + seed) mod N_cand`
  결정론적 균일 선택이고, 평가셋에도 동일 규칙·동일 시드를 예외 없이 적용한다. 평가셋 정상이
  파노라마로 남으면 헤드라인이 여전히 크기를 잰다.
- **내용 기반 선택 금지.** 중앙 선택도, 밝기·대비 기준 "좋은 타일" 선택도 쓰지 않는다.
  정상 쪽에만 걸리는 편향이라 새 교란이다.
- ②와 ⑥의 모집단은 폐기분만큼 다르다. 두 분할의 묶음 배정 일치율을 SplitMeta 에 기록하고,
  캘리브레이션이 라벨 비의존 기하 통계에서만 나왔다는 사실을 함께 적는다.

## 4-2. 선행 측정 (M0~M6) — 전부 착수 전 필수

| # | 측정 | 재료 | 비용 | 무엇을 결정하는가 |
|---|---|---|---|---|
| **M0** | RT/AL 결함 4종의 해상도 분해 | 라벨 JSON (F 파싱 완료분) | 수 분 | 비-R1 결함 19장의 클래스 분포. 단일 클래스에 10% 이상 몰리면 감독 회부 |
| **M1** | 정상 폴리곤 기하 — bbox 폭·높이, 면적비, 종횡비, 중심 분포 | 라벨 JSON | 수 분 | **이 폴리곤이 용접부 밴드인가.** 밴드 높이 중앙값 ≥ 720 이면 τ=1.0 가능 |
| **M2** | JPEG 헤더 전수 스캔 (SOF·DQT) — 채널수·비트깊이·양자화표 해시·추정 품질 | RT 62,998 JPEG 헤더 | ~15분 | 색심도 지름길 크기, 재인코딩 목표 품질(양 모집단 중 낮은 쪽에 맞춘다) |
| **M3** | 포함·배율 검사 — 다중배율 NCC | **파노라마+크롭 공존 묶음 10개(145장)** | 수 분 | 파노라마 정상이 결함이 잘려나간 원본인가 / 결함 크롭이 리사이즈본인가 |
| **M4** | 납글자·필름 여백 위치 (표본 200장 육안 + 밝기 블롭) | 정상 파노라마 표본 | 반나절 | τ 규칙만으로 구조적 배제가 되는지 확인. **좌표 규칙은 만들지 않는다**(3-6 다) |
| **M5** | 결함 크롭 구도 편향 — 결함 폴리곤 중심의 (cx/W, cy/H) 분포, 레터박스·균일 테두리 유무 | 라벨 JSON + 표본 | 수십 분 | 중앙 사전확률의 크기. mAP 해석과 D의 중앙 사전확률 베이스라인에 직결 |
| **M6** | 정상의 묶음(run) 크기 분포 — 크롭 출신·타일 출신 각각 | 라벨 JSON | 수 분 | 오탐 지표의 유효 표본(묶음 수). 두 적대 검증이 공통으로 살리라고 한 항목 |

M0·M1·M5·M6 은 라벨 JSON 만으로 되므로 **원천 해제를 기다리지 않고 오늘 착수 가능하다.**
M2·M3·M4 는 픽셀이 필요하다 → 4-7의 선행 작업.

**M5 를 "결함·정상 통계를 대비해 겹치지 않는 구간을 임계로 삼는" 형태로 쓰지 않는다.**
그것은 라벨로 판별 임계를 적합해 전처리에 넣는 것이고 규약 1-4 위반이다. 전처리 상수는
**라벨 비의존 기하 통계에서만** 유도한다.

## 4-3. 타일 생성 규칙 (`configs/base.yaml` → `preprocess.tile`)

```yaml
preprocess:
  tile:
    rule_version: "v1"
    tile_size:   [1280, 720]      # 결함 크롭과 동일
    k:           1                 # 원본 1장당 타일 1장 — 사전 고정, 실험 중 변경 금지
    stride_x:    640               # 후보 격자 (50% 중첩)
    vertical_anchor: band_center   # 정상 폴리곤(밴드) 세로 중심 정렬
    tau:         <M1 로 확정>      # 타일 ∩ 밴드폴리곤 면적비 하한. 폴백 1.0
    align8:      true              # x0, y0 를 8의 배수로 강제 (JPEG 블록 격자 정렬)
    padding:     forbidden         # 경계 초과 타일은 전량 기각. 검은 띠가 그 자체로 지름길
    selection:   "sha256(image_id + seed) mod N_cand"
    seed:        <고정>
    encode:
      mode:        "L"             # 그레이스케일 강제 (M2 결과에 따라 확정)
      quality:     <M2 의 양 모집단 최저치>
      progressive: false
      optimize:    false
      strip_exif:  true
    scope: "RT only"               # VT 는 주 실험 밖 (라벨 공간 불일치)
```

**전처리는 다섯 칸 공통 고정 항목이므로 칸별 override 를 로더 수준에서 금지한다.**
확정 후 블록의 sha256 을 의사결정로그에 남긴다.

### 라벨 승계 규칙

타일이 **정상**으로 승계되는 것은 아래 세 조건을 **전부** 만족할 때만이다.

1. 타일 ∩ 정상폴리곤 면적비 ≥ τ
2. 원본 이미지가 M3 포함 검사에서 미검출
3. 이미지 경계 무초과 (패딩 금지)

하나라도 실패하면 **재생성 없이 폐기**하고 사유별 건수를 기록한다(규약 3-6과 같은 취지).
**정상 폴리곤 바깥은 "정상"이 아니라 "미검사"다.** 정상으로 승계하지 않는다.

### 정상 폴리곤 폐기 결정(A-3)과의 관계 — 뒤집지 않는다

정상 폴리곤 60,890개는 **학습·채점 라벨로는 여전히 전량 폐기한다.** 전처리 단계에서
밴드 ROI 좌표로만 읽고 `annotations.csv` 에는 넣지 않는다. 트랙 A·D 의 기존 결정을
되돌리는 것이 아니다.

### 비-R1 결함 19장

**폐기한다.** 좌표 재계산 경로를 만들지 않는다(함정 구간 4의 접촉면을 늘리지 않는다).
34,604장 중 19장(0.055%)이다. 단 M0 에서 단일 클래스에 10% 이상 몰리면 감독 회부.

### 인코딩 지문 통일

타일만 재인코딩하면 양자화표가 정상 쪽에만 달라져 지름길이 그대로 이사한다.
**결함 크롭 34,585장을 포함한 RT 전량을 동일 인코더 설정으로 새 경로에 다시 쓴다.**
`data/raw/` 는 건드리지 않는다(불변조건 1-1).

압축 세대 차이는 재인코딩으로 완전히 지워지지 않는다. 그래서 (a) x0·y0 를 8의 배수로 맞춰
블록 격자 불일치 아티팩트를 줄이고, (b) M2 에서 양 모집단의 원본 추정 품질계수를 비교해
**낮은 쪽에 맞춰 전량 재인코딩**하며, (c) 잔존량은 P2·P3 로 **측정해 보고하고 0으로
단정하지 않는다.**

## 4-4. 폐기 회계와 사전 상한 — RQ3 오염을 막는 게이트

tiling/validity 가 찾아낸 가장 중요한 구멍이다. 기존 프로브 어느 것도 폐기 비대칭을 잡지
못한다(P1·P4 는 규격만, P2·P3 는 결함/정상만 본다). 아래를 규격에 못박는다.

| 상한 | 값 | 위반 시 |
|---|---|---|
| 정상 셀(재질별) 폐기율 | ≤ **5%** | 감독 게이트, 진행 보류 |
| 결함 셀(재질×클래스) 폐기 | ≤ **30장 또는 2%** 중 큰 값 | 감독 게이트 |
| **재질 간 정상 폐기율 차** `\|AL − ST\|` | ≤ **5%p** | 감독 게이트 — RQ3 직결 |
| 클라이언트별 (재질×클래스) 구성비 변화 | 타일링 전 대비 ≤ **2%p** | 감독 게이트 |

상한을 넘으면 **결정론적 다운샘플로 비를 복원**한다(같은 재질 내 보완 셀을 해시 순서로
seeded 다운샘플, `tiles.csv` 에 기록). 복원 여부와 규모를 논문 부록에 싣는다.

**이유.** AL 은 필름 종수가 332종으로 ST 의 9,635종보다 훨씬 적어 규격이 균질하다.
τ·경계 규칙이 AL 파노라마 집단에 통째로 걸리거나 통째로 비껴갈 가능성이 크다. AL 정상
폐기율이 40% 나오면 C3 의 결함:정상이 0.90:1 → 1.30:1 로 이동하고, RQ3 의 "AL 회사가
연합 참여로 얻는 이득"의 분모(로컬 성능)가 재질이 아니라 폐기 때문에 낮아진다. 이미
"재질↔어노테이션 시기 교락"이 미해결 상태(의사결정로그 미정)라 축이 하나 더 섞이면 사후
분리가 불가능하다.

## 4-5. P2 실패 시 후퇴 사다리 (사전 확정)

이 작업이 매니페스트 잠금을 막고 있으므로 후퇴안 없이 게이트를 세우면 파이프라인이 멈춘다.

| 단계 | 조치 | 비용 |
|---|---|---|
| **R0** | AUC ≤ 0.60 → 통과. 값을 논문에 싣는다 | — |
| **R1** | 0.60 < AUC ≤ 0.70 → 폐색 실험(테두리 각 변 128px 마스킹 / 히스토그램 정합 / 저역통과)으로 무엇을 봤는지 규명. 잔존량을 수치로 싣고 감독 판단 | GPU 1 h |
| **R2-a** | AUC > 0.70 → **RT 전량에 동일 상대 테두리 마스킹**(각 변 8%). 대칭 조치라 새 비대칭을 만들지 않는다. 재인코딩 1회 왕복 | CPU 10분 + 프로브 재실행 |
| **R2-b** | 여전히 초과 → τ 상향(밴드 내부로 더 좁힘) + 타일 후보 재생성 | CPU 20분 |
| **R3** | 여전히 초과 → **감독 회부.** 잔존 AUC 를 논문 본문에 싣고 "이 프로브군으로는 제거되지 않았다"로 서술. 헤드라인 주장 범위를 축소 | — |

**어느 단계에서도 "지름길이 죽었다"고 쓰지 않는다.** 출처 판별 AUC 측정값이 비어 있으면
그 문장을 쓰지 않는다는 규칙을 서술 규율로 고정한다.

## 4-6. 축소 파일럿 게이트 — 본실험 착수 전 필수

measure/feasibility 가 남긴 가장 값진 조건이다. **다섯 칸이 전부 자명하한 근처로 붕괴하는
사태를 본실험 전에 잡는다.**

- 조건: 분리·중앙 1시드, 학습 풀 20% 서브샘플, epoch 1/3. **1~2 GPU일 (9주 예산의 약 2%).**
- 통과 기준 3개 동시 충족:
  1. 4결함 Macro-F1 이 **0.2081 을 유의하게 초과**(묶음 단위 클러스터 부트스트랩 CI 하한 기준)
  2. **FAR@정상 < 0.5** (정상 이미지에서 결함을 1건 이상 주장한 비율)
  3. `|FPR(크롭 출신 정상) − FPR(타일 출신 정상)|` 관측값과 CI 를 보고 (이 시점에서는 판정하지
     않고 값만 기록)
- 미달 시: 본실험 착수를 중지하고 감독 회부. 4-9 차선안으로 분기한다.

## 4-7. 선행 작업 — 트랙 F 에 분리 발주 (I/O 비용이 0으로 잡혀 있었다)

`data/raw`·`data/interim`·`data/processed` 가 전부 비어 있고 RT 원천은 공유 드라이브의
zip 안에 있다(RT 약 7.6 GB / 62,998 파일). tiling 안의 "본 처리 총 10분"은 로컬 SSD 가정이다.

**처방: 공유 드라이브에서 zip 을 로컬 E: 로 1회 복사한 뒤 로컬에서 해제한다.**
드라이브 폴더 위에서 직접 해제하지 않는다(실물확보 7-5 실측: 2.09 GB/58,919 파일 약 2시간).
타일 산출물(약 9~10 GB)은 분할 동결 후 1회만 공유 드라이브에 올린다.

## 4-8. 일정 — 8/25 "데이터 확정"의 정의를 쪼갠다

푸는 쪽이 비교할 수 없이 비싸다.

## 4-9. 차선안과 그것을 택해야 하는 조건

| 조건 | 차선안 |
|---|---|
| **M1 에서 정상 폴리곤이 밴드가 아니거나 밴드 높이 중앙값 < 720** | **밴드 규격 타일링.** 타일 규격을 (1280×720) 대신 M1 이 준 밴드 높이 분위수 기반 단일 규격 `(w_t × h_t)` 으로 낮추고, **결함 크롭도 같은 규격으로 중앙 크롭**한다. 네이티브 배율을 유지하면서 단일 규격을 얻는다. 결함 폴리곤 절단율을 M5 로 재고 3% 초과 시 감독 회부 |
| **M3 에서 결함 크롭이 리사이즈본으로 나옴 (최적 배율 중앙값이 1.00±0.02 밖)** | 네이티브 배율 정합이 원리적으로 불가능하다. **타일링 포기 → measure 단독 + 4-6 파일럿 게이트**로 가고, 헤드라인을 "규격 통제 조건"으로 한정 서술한다. 이 가지의 검정력 한계(정상 유효 표본 약 65 묶음)를 논문 본문에 명시한다 |
| **4-4 폐기 상한을 어떤 τ 설정으로도 못 맞춤** | 폐기 비를 결정론적 다운샘플로 복원하고 복원 규모를 부록에 싣는다. 그래도 못 맞추면 C3 를 AL 결함 중심으로 재정의할지 감독 판단 |
| **P2 가 R2-b 이후에도 AUC > 0.70** | 4-5 의 R3. 지름길 잔존을 수치로 싣고 헤드라인 주장 범위를 축소한다 |

**채택하지 않는 것을 명시한다.** 표본 선택(`sel_geom` 필터로 40% 삭제)과 온더플라이 창
샘플링(평가 K창)은 어떤 조건에서도 차선안이 아니다. 전자는 오탐 측정을 없애고 후자는
계약 #4를 깬다.

# 5. 지름길 사망 증명 절차

**원칙 세 가지.**
- 처리 **전**과 **후** 를 같은 스크립트로 돌려 **쌍(pair)으로 보고**한다. 전 단계 수치가 없으면
  "죽었다"가 아니라 "낮다"밖에 못 쓴다.
- 모든 게이트를 **헤드라인 과제(4결함 이미지수준 Macro-F1)** 위에서 판정한다.
- **프로브는 학습 풀 내부의 프로브 전용 홀드아웃에서 학습·채점**한다. 평가셋에는 최종 확정
  규칙으로 결정론적 검사(P1·P4)만 한 번 건다. 생성 측(A)이 아니라 **D가 프로브를 소유**한다
  (규약 3-5 취지).

## 5-1. 사전등록 상수 — 모든 결과표의 머리행에 박는다

학습 착수 전에 `docs/의사결정로그.md` 에 커밋한다. 이후 수정 금지.

| 상수 | 값 | 산출 근거 |
|---|---|---|
| 전량양성 자명하한 (4결함 Macro-F1) | **0.2081** | `2n_c/(N+n_c)`, N=62,998 |
| 규격전용 최적 (처리 전) | **0.3025** | 예측 양성 = R1 37,814 |
| 규격 지름길 순 기여 (처리 전) | **+0.0944** | 위 둘의 차 |
| 규격 결정력 SDS (이진 정확도) | RT **0.9484** / ST **0.9613** / AL **≈0.871** | "1280×720 → 결함" 규칙 |

동결 평가셋에서 재산출해 위 표를 재현해야 계측이 옳음이 확인된다.

## 5-2. 프로브 P0~P9

## 5-3. 게이트 규칙

- **P1·P4·P5 는 결정론적이다. 100% 아니면 머지 금지.**
- **P2 가 R2-b 이후에도 0.70 초과면 분할 확정(불변조건 1-2 잠금)을 보류한다.**
- **P7·P8 의 상한 위반은 감독 게이트다.** 표에 숫자만 찍고 넘어가지 않는다.
- **P9 는 본실험 후 판정이며, 불합격이면 "판정 불가"로 보고한다.** 검정력 재계산 전에는
  "해당 칸 수치를 논문에 싣지 않는다"는 규칙을 걸지 않는다 — 검정력이 낮을수록 통과가 쉬워지는
  역인센티브를 만들지 않기 위해 CI 겹침이 아니라 TOST 를 쓴다.

## 5-4. 회복률 분모 규칙 (사전등록, 연합 결과 산출 전)

지름길이 죽으면 다섯 칸 모두 절대 성능이 내려간다. 분모 D=(중앙−로컬)이 좁아지면 회복률
추정의 분산이 폭증한다. 델타법 근사로 SE_d=0.010·D=0.08 이면 95% CI 반폭 약 31pp,
D=0.05 면 약 50pp 다.

- **D 를 95% CI(묶음 단위 클러스터 부트스트랩 2,000회)와 반드시 병기한다.**
- **D < 3 × 시드 sd 이면 회복률을 산출하지 않고 세 절대값만 CI 와 함께 보고한다.**
- 이 규칙은 어떤 지름길 대응안을 채택하든 유효하며, **연합 결과가 나오기 전에** 커밋한다.

## 5-5. 보고 형식

P0~P9 를 전/후 2열 표 한 장으로 묶는다. 헤드라인 문장의 형태를 고정한다.

> "RT 규격전용 최적 예측기의 4결함 Macro-F1 **0.3025 → 0.2081**(자명하한과 동일),
> 출처 판별 AUC **{측정값}**, 교차 출처 오탐률 차 **{측정값}** [TOST δ=0.10 {판정}]."

출처 판별 AUC 값이 비어 있으면 지름길이 죽었다고 쓰지 않는다.
논문 본문에는 다음 문장을 넣는다 — **"프로브 통과는 잔여 신호가 없다는 증명이 아니라,
우리가 세운 프로브로는 찾지 못했다는 기록이다."**

## 5-6. 이 처방으로 **죽지 않는 것** (정직하게 적는다)

| 채널 | 상태 |
|---|---|
| 절대 규격 W·H, 화소수, 종횡비, 시야, VLM 토큰 수 | **구성적으로 0비트.** 상수 입력에서 클래스를 가르는 함수는 존재하지 않는다. 항등식이며 P1 로 검증 |
| 색심도(8bpp/24bpp) | 그레이스케일 강제 후 채널 간 분산 상수 0. M2 가 원래 크기를 계량 |
| 레터박스 회색띠 두께 | 전 이미지 동일 규격이므로 상수. C-2 로 확인 |
| 압축 세대·그레인 통계 | **감쇠하되 잔존.** 양자화표는 P4 로 1종 강제 가능하나 세대 차이 블록 통계는 남을 수 있다. P2·P3 가 측정 |
| 납글자·필름 여백 | **감쇠하되 잔존.** 마스킹이 비일관적이라 규칙 기반 완전성 보장이 없다. τ 로 구조적 배제, 잔존량은 P2 로 정량화 |
| **결함 크롭의 중앙 사전확률** | **죽지 않는다.** 이 처방의 사정거리 밖이다. mAP·IoU 에 걸리고 RQ2 의 분리형 검출 해석을 흔든다. C-1 로 측정해 한계 절에 싣는다 |
| **k=1 이 버리는 정상 픽셀** | 전량 타일링 대비 정상 시각 다양성이 준다. k 는 다섯 칸 공통 고정이라 한 칸만 못 바꾸고 민감도 분석은 9주에 안 들어간다. **"고정값이며 민감도 미검증"으로 부록에 적는다.** 전처리 시드도 1벌 고정이라 "타일 선택의 우연"이 학습 시드 3세트 분산에 포함되지 않는다는 점도 함께 적는다 |
| 외적 타당도 | 주장 범위가 "1280×720 크롭·타일 단위 결함 판정"으로 좁아진다. 파노라마 전장 필름 배포 성능은 주장하지 않는다. 한계 절에 명시 |

## 7-2. 분할 파이프라인 — 층화 축은 건드리지 않는다

- **`strata_keys()` 변경 없음.** 층화는 `{material}|{묶음 대표 클래스}` 2축 그대로다
  (게이트 #6 결정 D 유지).
  - 이유: 축을 3축으로 늘리면 층이 희소해져 `_first_fold()` 의 `except ValueError` 경로가
    **경고 없이 층화를 통째로 포기**하고, `sample_judgment_groups()` 의 `k = max(1, ...)` 때문에
    판정 채점 표본이 층 수에 비례해 부푼다. 규격 확보하려다 재질×클래스 층화를 잃는다.
  - 그리고 **타일링 후에는 규격이 상수라 층화 축이 될 수 없다.** 필요 자체가 사라진다.
- **추가하는 것은 수용 검사 하나뿐.** 평가 fold 추첨 후 "크롭 출신 정상 묶음 ≥ N_min"
  (권장 ST ≥ 35, AL ≥ 15) 을 확인하고 미달이면 `seed+1` 로 재추첨한다.
  `data/split/dirichlet.py` 의 `partition_with_acceptance()` 수용-재추첨 관용구를 재사용하고
  재추첨 횟수를 `SplitMeta` 에 기록한다.
- **Dirichlet 에서 정상 클래스를 제외하자는 제안은 채택하지 않는다.** `assign_clients()` 는
  `group_id → client` 매핑이고 배정은 묶음 단위다. 이미지·클래스 단위 배정 경로가 없고,
  혼합 run(전체의 9.1%)에서는 정상이 결함을 따라간다. 근거로 제시된 시뮬레이션 수치도
  정상을 독립 배정 가능한 것으로 가정한 계산이라 대상 자체가 틀렸다.
