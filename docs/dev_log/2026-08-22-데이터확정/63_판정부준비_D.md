## 과제 1 — 색인 구축 + 검색 경로 (`rag/index.py`)

- 진입점 `build_index()`: `chunk_meta.jsonl` → 색인. 변환은 기존 `chunk_from_meta`
  한 지점이고, 조항 ID 중복이면 거부한다(조항 단위 청킹 위반 신호).
- 검색 설정은 **`configs/rag.yaml` 단일 소스** (top-k=3, 반구간, 무검색 출력).
  문서는 링크만 한다. `configs/` 는 데이터 파이프라인 소관 폴더라 기존 `base.yaml` 을
  건드리지 않고 별도 파일로 추가했다 — 소유 판단이 다르면 이관한다.
- **후보 0~1개 경로는 임베딩 모델 없이 돈다.** 후보 복수인데 모델 미선정이면 사전순
  폴백으로 조용히 넘기지 않고 `MissingEmbeddingModel` 로 명시적으로 실패한다.
  폴백으로 낸 top-1 이 실측처럼 읽히면 선정 절차가 무의미해지기 때문이다.
- `snapshot_digest()`: 색인 내용의 결정론적 해시 — 스냅샷 고정(불변조건 1-6) 재료.
- `corpus/derived/chunk_meta.jsonl` 은 아직 main 에 없다. 계약(`derive_chunk_meta` 의
  반환 형식)에 맞춰 시험 픽스처를 짰고, **B 산출물이 오르면 실물 1회 확인**한다.

## 과제 2 — 임베딩 실측 하네스 (`rag/embedding_trial.py`)

- 후보: **BGE-M3 대 Qwen3-Embedding-4B** (의사결정로그 미정 항목 그대로).
- 질의 100건: `queries_from_gold_rows()` — 정답 조항 행의 구조화 키에서 두께를 구간
  `[min, max)` 안 격자로 뽑는다. **시드 20260825 고정, 완전 결정론** (시험으로 고정).
  경계 사례 20%(상한 직전)를 섞는다. **한국어 평가셋 599행은 관여하지 않는다.**
- 정답 조인: `derive_gold_clauses` 산출물(gold_clauses.csv) 행을 그대로 받는다.
- **격리 위반이 아닌 근거**: `13_spec_D` §5-4 가 "gold_clauses.csv 에서 질의 100건 추출
  → 후보별 top-1 측정 → 채택 후 고정"을 임베딩 선정 절차로 **사전 등록**했고,
  의사결정로그 미정 항목이 같은 절차를 가리킨다. 격리가 금지하는 것은 평가 자산의
  **학습 투입**이며, 이 사용은 사전 등록된 검색기 구성 절차다. 선정 후 재선정하지 않는다.
- `run_trial()` 은 후보 0~1개 질의(임베딩 무관)를 **따로 센다** — 그 몫이 크면 임베딩
  선택이 최종 성능에 미치는 영향 자체가 작다는 뜻이고, 그것도 보고 대상이다.
- 임베더는 주입식(`Embedder` 콜러블). 하네스 시험은 스텁 임베더로 통과했다.

## 과제 3 — 판정부 생성 배선 (`rag/judge.py`)

- 경로: 검출 출력(계약 #4 defects) + 검색 결과 → 프롬프트 → 생성 → 분리형 원시 출력
  (`verdicts.jsonl` 행: image_id / retrieved / verdict / cited / parse_ok).
- 파일럿 판정 축은 좁혔다: **조항 검색 + 기준 서술.** 프롬프트가 합부를 내지 말라고
  명시한다. `rag/prompts/verdict_pilot_v1.txt` 파일 고정 + sha256 이 실행 보고에
  들어간다(`prompt_sha256` 태그 재료).
- **greedy 1회, 재시도·재프롬프트 금지** — 시험이 생성 호출 횟수를 직접 센다.
  스키마 위반은 오답 처리 + 사유별 실패율 집계(P9 러너와 같은 원칙).
- **검색 0건 경로**: 생성을 호출하지 않고 `해당 조항 없음` + `판정불가` 를 결정론적으로
  낸다. 후보가 없는데 모델에게 물어보는 것 자체가 환각을 청하는 일이다. 시험으로 고정.
- 추출은 관대하게(코드펜스 벗김), 검증은 엄격하게(enum 위반 오답, 값 보정 없음).
  제시 밖 조항 인용은 지우지 않는다 — 무근거 인용률이 재야 할 신호다.
- 체크포인트: `configs/rag.yaml` `judge.checkpoint: null`. **C 의 ⑥ 확정을 기다린다**
  (통합형·판정부 동일 체크포인트 공유). 생성 함수는 주입식이라 배선 시험은 스텁으로 돌았다.
