# 공개 문서 검수 방침

총괄 · 2026-08-24 · **모든 트랙 공통. 자기 소관 파일에만 적용한다.**

## 0. 전제

> 저장소와 노션은 **우리도 보지만 모르는 사람이 본다.**
> 쓸데없는 과거 이력과 대조는 지양한다. 꼭 필요하면 유지하되 아니면 지운다.

읽는 사람은 우리 팀이 아니라 **이 연구를 처음 보는 사람**이다.
그 사람에게 필요 없는 것은 지운다. 판단 기준은 "이 문장이 없으면 독자가 무엇을 못 하는가"다.

## 1. 지운다

| 대상 | 예 |
|---|---|
| **문서 머리의 트랙·브랜치 표기** | `작성 2026-08-21 · 트랙 A · 브랜치 wt/A` → `작성 2026-08-21` |
| **소관·분업 규칙 서술** | "내 소관이 아니라 손대지 않았고 보고한다 (소유권 규칙)" |
| **1인칭 진행 보고** | "내가 고치지 않았다", "~에 배분 필요하다", "~에 회부한다" |
| **내부 절차 번호** | `게이트 #7`, `회부 5`, `판정 14` → 내용으로 풀어 쓰거나 삭제 |
| **과거값 대조 문장** | "종전은 X였는데 Y로 정정했다" → **현재값 Y만 남긴다** |
| **다른 트랙 지시·요청** | "트랙 A에 배분 필요", "D의 P2 몫으로 넘긴다" |

## 2. 바꾼다

| 옛 표기 | 새 표기 |
|---|---|
| 감독 / CTO | 총괄 |
| 트랙 A·B·C… | 삭제하거나 담당 이름. 문맥상 필요하면 "데이터 담당" 같은 역할어 |
| 게이트 통과 / 반려 | 검토 완료 / 재작업 |
| 지시·디스패치 | 삭제 |

## 3. 남긴다 — 지우지 마라

- **`docs/의사결정로그.md`** — 결정 이력이 문서의 목적이다. 다만 표현은 2절을 따른다.
- **불일치 기록** — "문서 기재 A, 실측 B" 는 **연구 재료다.** 어느 쪽이 정본인지 명시하고 남긴다.
- **폐기·기각 기록** — 무엇을 왜 안 했는지는 방법론의 일부다. 다만 "누가 반려했다"가 아니라
  "왜 성립하지 않는다"로 쓴다.
- **수치·날짜·고유명사·인용** — 손대지 마라.

## 4. 옛 수치 정정 — 전수 확인 대상

아래는 실측으로 바뀐 값이다. **자기 소관 파일에서 전수 grep 하고 고쳐라.**

| 옛 값 | 현재 |
|---|---|
| AI허브 `144,019장` | 라벨 전수 **129,613** (RT **62,998** / VT 66,615) |
| `RT 70,000` | **RT 62,998** → 평가셋 12,600 / 학습 풀 50,398 |
| RIAWELC `24,407장` | 파일 24,407 / **고유 21,964** / 규격 **227×227** (224 아님) |
| LoHi `3,022장` | 3,022 **맞다.** 파일 34,489 는 저자 5-fold 사본 포함 |
| AI허브 `승인 대기` | **확보 완료.** 현재 병목은 GPU |
| `앵커 조선소` · `협력사` | **삭제.** 데이터에 회사 구분이 없다. "재질 기반 자연 분할" |
| 숨은 기본값 `6건` | **8건** |

**"파일 총수"와 "고유 이미지 장수"를 항상 분리해 적어라.**

## 5. AI 티 제거

문체는 아래를 피한다.

- em dash(`—`)를 부연 연결에 쓰는 것. 콜론·마침표·괄호로 바꾼다
- `특히`, `~것이다`, `~라는 점에서`
- 문장의 힘을 볼드로 대신하는 것. 볼드는 **한 문서에서 한 가지 용법**으로만
- 대구·경구로 문단을 닫는 습관 ("A가 아니라 B다" 류가 반복되면 덜어낸다)
- 같은 종결어미가 5문장 이상 연속되는 구간

**의미를 바꾸지 마라.** 수치·주장·인용은 그대로 두고 표현만 고친다.
