# 3시드에서 회복률 분모 규칙의 검정력: 실측과 처방

작성 2026-08-24 · 대상 `40_규격지름길_대응판정.md` §5-4
재현: `scripts/probe/seed3_power.py` (몬테카를로 20만 회, 시드 고정)

## 요지

사전등록된 `D ≥ 3 × 시드sd` 규칙은 시드 3세트에서 검정력이 낮다. 규칙 자체가 틀린 것은
아니고, 자유도 2 의 표본 표준편차를 참 σ 처럼 쓰는 데서 문제가 생긴다. 규칙을 바꾸지 않고
CI 기반 보조 판정을 병기하는 쪽을 제안한다.

## 1. 자유도 2 의 표본 sd 는 어느 정도로 불안정한가

σ=1 로 두고 3표본 sd 를 20만 회 뽑았다.

| 항목 | 값 |
|---|---|
| 이론 보정계수 c4 | 0.8862. 평균적으로 σ 를 11.4% 과소추정한다 |
| 변동계수 CV | **0.523** |
| s 의 5·50·95 백분위 | 0.226 / 0.830 / 1.729 |
| **P(s < 0.5σ)** | **0.223** |

마지막 줄을 보면, 다섯 번에 한 번꼴로 통과선 `3s` 가 `1.5σ` 아래로 내려간다.
그때는 막아야 할 분모가 통과한다.

## 2. 규칙의 실제 통과확률

`D` 를 참값으로 고정하고 `D ≥ 3s` 의 통과확률을 계산했다.

| 참 D/σ | P(통과) | 있어야 할 판정 |
|---|---|---|
| 1 | 0.105 | 차단 |
| 2 | 0.360 | 차단해야 하는데 36% 가 통과한다 |
| 3 | 0.633 | 경계 |
| 4 | 0.833 | 경계 |
| 5 | 0.938 | 통과 |
| 6 | 0.982 | 통과 |
| 8 | 0.999 | 통과 |

D 도 3시드 추정량으로 두면(중앙 3 + 로컬 3) 더 나빠진다: D/σ=2 에서 0.274, D/σ=5 에서 0.947.

임계가 서 있지 않다. 차단해야 할 구간에서 3분의 1이 통과하고, 통과해야 할 구간에서
6%가 막힌다. 두 방향 모두 오차가 크다.

## 3. 원인: 규칙이 두 가지를 섞고 있다

`D ≥ 3σ` 는 두 질문을 한 식으로 묻는다.

1. D 가 0 과 구별되는가 (유의성)
2. D 가 충분히 넓어 회복률의 분산이 감당 가능한가 (정밀도)

1번은 3시드로도 t 검정으로 답할 수 있다(D/σ=3 에서 검정력 0.78). 2번은 애초에 σ 를 알아야
하는데 3시드로는 못 안다.

## 4. 제안: 규칙을 바꾸지 않고 보조 판정을 병기한다

사전등록 규칙은 트립와이어로 그대로 둔다. 값을 사후에 바꾸면 그 자체가 사후 합리화가 된다.
대신 §5-4 가 이미 요구한 **묶음 클러스터 부트스트랩 CI** 를 판정에 정식 편입한다.

| 판정 | 근거 | 추정 안정성 |
|---|---|---|
| 트립와이어 (사전등록) | `D ≥ 3 × 시드sd` | 낮음 (n=3) |
| **보조 (신설)** | **회복률 자체의 95% CI 반폭 ≤ 0.25** | 높음. 평가셋 12,600장과 수백 개 묶음에서 추정한다 |

둘 중 하나라도 불합격이면 회복률을 헤드라인으로 싣지 않는다. 보조 판정은 반대 방향으로도
작동한다. 시드 sd 가 우연히 작게 나와 트립와이어를 통과하더라도, 회복률 CI 가 넓으면
그 비율은 쓸 수 없다.

시드 sd 를 보고할 때는 그 자체의 CI 를 병기한다. 세 시드에서 나온 sd 는 카이제곱 기준
95% CI 상한이 점추정의 3배를 넘는다. 점추정만 실으면 독자가 그 값을 σ 로 읽는다.

구현: `evaluation/stats.py` 의 `recovery_denominator_verdict()` · `seed_sd_diagnostic()`.
`MAX_RECOVERY_HALF_WIDTH = 0.25` 는 §5-4 가 든 예(D=0.08 → 반폭 31pp)에서 "못 쓰는
구간"의 경계로 잡았다. 이 값은 아직 사전등록되지 않았다. 확정이 필요하다.

## 5. 확정이 필요한 것

1. `MAX_RECOVERY_HALF_WIDTH = 0.25` 를 사전등록 상수로 확정할지, 다른 값으로 할지.
2. 시드를 3세트로 유지할지. 분산 추정만 놓고 보면 3은 부족하다. 다만 시드를 늘리는
   비용이 GPU-일로 직결되므로, "분산을 추정하지 않고 CI 로 간다"는 지금 제안이 현실적이다.
3. 이 문서를 §5-4 의 부속으로 `docs/의사결정로그.md` 에 함께 사전등록할지.
