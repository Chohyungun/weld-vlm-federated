# 한 사이클 파일럿 — 로컬 GPU 로 다섯 칸을 끝까지 통과시킨다

총괄 · 2026-08-24

## 0. 방침 전환

GPU 미확보를 이유로 미뤄 온 항목들이 있다. **방침을 바꾼다.**

> 성능도 중요하지만 지금은 **한 사이클 돌리는 것**이 더 중요하다.

로컬 RTX 5060 Ti 16GB 로 **다섯 칸을 전부, 끝까지** 통과시킨다.
목표는 좋은 수치가 아니라 **파이프라인이 끊기는 지점을 전부 찾아내는 것**이다.

파일럿 수치는 논문에 싣지 않는다. **찾아낸 고장과 그 처방을 싣는다.**

## 1. 실측 확인 — 필요한 것은 전부 돈다

```
NVIDIA GeForce RTX 5060 Ti / sm_120 / 15.9 GB
torch 2.11.0+cu128 / CUDA 12.8
```

| 항목 | 상태 | 근거 |
|---|---|---|
| bitsandbytes QLoRA 4bit | **동작** | NF4 + LoRA r16 backward + AdamW, peak 0.59GB |
| ultralytics 학습 | **동작** | 학습·검증·AMP 전 구간 sm_120 |
| Flower + Ray 라운드 반복 | **동작** | 3라운드 프로브에서 메모리 단조 증가 없음 |
| flash-attn | 불가 → **SDPA 폴백** | 휠 부재 |
| **vLLM** | **불가** | cu128 과 충돌(torch 2.8.0 강등 요구), Windows 미지원 |

**vLLM 불가가 막는 것은 없다.** 우리는 greedy 1회 고정이라 `transformers.generate` 와
출력이 같다. 손해는 배치 처리량뿐이고, 파일럿 규모에서는 문제가 되지 않는다.
`docs/개발규약.md` 스택 절의 "vLLM 서빙" 표기를 **"로컬 추론(transformers, vLLM 은
Linux GPU 확보 시)"** 으로 고친다.

## 2. 축소 규칙 — 무엇을 줄이고 무엇을 줄이지 않는가

**줄인다**

| 항목 | 본실험 | 파일럿 |
|---|---|---|
| 데이터 | RT 62,998 | **묶음 단위 층화 표본 ~3,000** |
| 검출 모델 | YOLO11s | **YOLO11n** |
| 통합형·판정부 | Qwen3.5-4B QLoRA | **Qwen3.5 최소 크기 QLoRA 4bit** (실물 확인 후 확정) |
| 이미지 크기 | 640 | **416** |
| 배치 | 프로파일값 | **1~2 + grad accum 으로 유효 배치 유지** |
| 라운드 × epoch | R=10, E=10 | **R=3, E=2** (등가 유지) |
| 시드 | 3세트 | **1세트** |
| 합성 corpus | QA 2만 / 판정 1만 | **각 200건** |

**줄이지 않는다 — 줄이면 파일럿의 의미가 없다**

- **다섯 칸 전부 돈다.** 한 칸이라도 빼면 비교 경로가 검증되지 않는다
- `R × E = N` 등가 유지. 조기 종료 없음. **last 채점**
- 평가셋 선분리 → 묶음 단위 분할 순서
- **단일 채점기.** 다섯 칸 출력을 공통 스키마로 변환 후 채점
- 좌표 규약 통과 (`vlm/coords.py`)
- 실패 검사 (`WeldFedAvg`), 회계 매트릭스, 원자 로그
- **사전등록 상수 대조** (`evaluation/prereg.py`) — 축소 표본이라 `relative` 옵션을 쓴다

## 3. 목표는 수치가 아니라 고장 목록이다

파일럿의 산출물은 아래다.

1. **다섯 칸이 끝까지 도는가.** 안 돌면 어디서 멈추는가
2. **끊기는 지점 전수** — OOM, 좌표 붕괴, 스키마 위반, 직렬화 불일치, 회계 빈 셀
3. **16GB 실측 프로파일** — 칸별 peak VRAM, 1 step 시간, 라운드 시간, 총 소요
4. **본실험 소요 추정** — 파일럿 실측에서 외삽. **9주 안에 되는지 여기서 판정한다**
5. **`configs/gpu/` 16GB 프로파일 확정** — 추정이 아니라 실측으로

**수치는 보고하되 결론으로 쓰지 않는다.** 표본 3,000 에 시드 1세트다.

## 4. 순서 — 앞이 막히면 뒤로 못 간다

```
① 축소 표본 매니페스트 (묶음 단위 층화, 평가셋 선분리 유지)
② 분리·로컬  — 검출만. 가장 단순한 경로부터 뚫는다
③ 분리·중앙  — ② 와 같은 코드에 R=1, E=N
④ 분리·연합  — Flower 3라운드. 여기서 직렬화·회계·실패검사가 처음 실전에 걸린다
⑤ 판정부     — RAG + 판정 생성. transformers.generate greedy 1회.
              판정 축은 좁혀서 돌린다(원인·조치 또는 조항 검색 + 기준 서술).
              본실험 정의는 현행 유지가 총괄 확정이고, 파일럿만 좁힌다
⑥ 통합·중앙  — VLM QLoRA. 좌표 규약 첫 실전 검증
⑦ 통합·연합  — LoRA 어댑터 집계. 함정 #3 첫 실전
⑧ 단일 채점기로 다섯 칸 일괄 채점 + 지표 산출
```

**각 단계에서 막히면 멈추고 보고하라.** 우회해서 다음으로 넘어가지 마라.
무엇이 막혔는지가 이 파일럿의 산출물이다.

## 5. 배분

| 트랙 | 몫 |
|---|---|
| **A** | ① 축소 표본 매니페스트. 타일링 규칙 적용 후 3,000장 층화 표본 |
| **C** | ②③④⑥⑦ 학습 전 구간. 16GB 프로파일 실측 |
| **B** | ⑤ 판정부 입력이 될 합성 corpus 축소본 각 200건 |
| **D** | ⑧ 일괄 채점 + 지표. 프로브 P2·P3 를 파일럿 산출물로 돌린다 |

## 6. 일정

**8/28 분할 동결 뒤 착수한다.** 동결 전에 돌리면 매니페스트가 바뀌어 다시 돌려야 한다.
다만 **각 트랙은 지금부터 자기 구간의 스크립트와 설정을 준비**한다.

목표는 **9/1까지 ⑧ 완주**다. 그 결과로 9/2 G1 판정을 대체하거나 보강한다.

## 7. 하지 말 것

- 파일럿 수치를 논문 결과로 쓰지 마라. **표본 3,000·시드 1세트다**
- 막힌 것을 우회하고 넘어가지 마라. 우회는 본실험에서 같은 자리에서 다시 터진다
- 파일럿이라고 규칙을 풀지 마라. 조기 종료·best 채점·재시도는 여전히 금지다
- 모델 크기를 줄이면서 **좌표 규약과 프롬프트를 함께 바꾸지 마라.** 바꾸면 본실험과
  다른 것을 검증하게 된다
