## 과제 2 — 기전 확인: 정합은 자기가 하겠다고 한 일을 했다

정합본에서 단일 통계량 AUC 를 재측정했다(표본 800, 시드 0 — 직전 진단과 동일 조건).

| 통계량 | 마스킹 전 | **정합 후** | 정합 후 crop / tile |
|---|---|---|---|
| **1백분위 밝기** | 0.8801 | **0.5901** | 48.4 / 21.9 |
| 평균 밝기 | 0.8177 | **0.6432** | 125.3 / 128.6 |
| 99백분위 밝기 | 0.5046 | 0.6282 | 229.5 / 228.9 |
| 파일 크기 | 0.6955 | 0.5742 | 50,663 / 55,717 |
| 표준편차 | 0.7488 | **0.7505** | 43.8 / 53.3 |

1백분위가 0.8801 → 0.5901 로 떨어졌고 평균도 두 출처가 사실상 같아졌다(125.3 대 128.6).
**주변 분포 채널은 실제로 닫혔다.** 정합이 작동하지 않은 것이 아니다.

## 그런데 raw 가 높게 남았다 — 채널이 하나가 아니었다

지시서의 첫 번째 분기에 해당한다. 남은 것을 공간 통계로 짚었다(같은 표본 800).

| 통계량 (정합 후) | 단독 AUC | crop / tile |
|---|---|---|
| **8×8 블록 평균의 표준편차** (밝기의 공간 배치 불균일성) | **0.8085** | 31.6 / 40.6 |
| 전체 표준편차 | 0.7505 | 43.8 / 53.3 |
| 상하 절반 평균차 | 0.6487 | 24.5 / 17.5 |
| 행 프로파일 범위 | 0.5948 | 132.7 / 114.1 |

**남은 채널은 밝기의 공간 배치다.** 히스토그램 정합은 전역 단조 픽셀 사상이라
"어떤 밝기값이 나오는가"는 강제하지만 **"그 값이 어디에 있는가"는 건드리지 못한다** —
구성상 그렇다. 파노라마 타일은 프레임 안 밝기 배치가 불균일하고(블록 평균 표준편차
40.6), 원본 크롭은 균일하다(31.6). 이 차이는 정합 전에도 있었고 정합이 지울 수 없는
종류다.

세 조건의 상대 크기가 이 해석과 정합한다.

- `lowres` 0.9934: 32×32 축소는 **저주파 공간 배치를 정확히 보존**한다. 거의 안 내려간
  이유다.
- `shuffle` 0.8646: 패치 셔플은 공간 배치를 파괴한다. 그래서 raw 보다 낮다. 남은 0.86 은
  패치 내부의 국소 대비·질감이다.
- shuffle 이 마스킹 후(0.8476)보다 오히려 소폭 올랐다. 정합이 대비를 늘린 것
  (전체 표준편차 crop 12.3→43.8, tile 24.4→53.3, 마스킹본 내부 대비)과 방향이 맞다.
  단정하지 않고 수치만 적는다.

## 사다리 요약 (원본 → R2-a → R3)

| 채널 | 대응 | 결과 |
|---|---|---|
| 절대 규격·화소수·종횡비 | 타일링 (P1·P4) | **구성적 0비트. 닫힘** |
| 테두리 국소 무늬 (납글자·필름 가장자리) | R2-a 마스킹 | shuffle 0.985→0.848. 유의하게 감쇠 |
| 전역 밝기 주변 분포 | R3 히스토그램 정합 | 1백분위 0.880→0.590. **닫힘** |
| **밝기의 공간 배치** | (대응 없음) | **잔존. 블록 통계 단독 0.81, 학습 프로브 0.98** |
| 패치 내부 질감·국소 대비 | (대응 없음) | 잔존. shuffle 조건 0.86 |

공간 배치를 지우려면 픽셀을 옮기거나 지역별로 다른 사상을 적용해야 하는데, 전자는
결함의 위치 정보를 파괴하고(검출 과제 자체가 무너진다) 후자는 결함의 국소 대비를
왜곡한다. 전처리로 더 좁힐 여지가 원리적으로 크지 않다는 뜻이며, 이것이 사전 확정된
귀결(잔존 수용)이 놓인 자리다.
