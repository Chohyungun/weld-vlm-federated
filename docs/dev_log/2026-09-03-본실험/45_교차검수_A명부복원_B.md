## 3. 시험의 이빨

### 3-1. A 의 시험 — 변이 6종 (임시 clone)

기준 → 변이 → 원복을 매번 확인했고, 변이 뒤 clone `git status` 는 0줄이다.

| A 의 시험 | 변이 | 결과 |
|---|---|---|
| `…pilot3000_계열_3개는_A_소유_restored_로…` | `crop_only` 상태를 `lost` 로 | 통과 → **실패** → 통과 |
| 〃 | `scale_control` 근거에서 "8자 접두" 제거 | 통과 → **실패** → 통과 |
| `test_restored_자리에_실물과_계약서가_있다` | 세 자리를 가짜 봉인본으로 만든 뒤 하나의 계약서 삭제 | 통과 → **실패** → 통과 |
| 〃 | 세 자리 중 **하나를 통째로 없앰** | 통과 → **skip** → 통과 ← **I-1** |
| `test_B_명부와_어긋나지_않는다` | B 판에서 **B 소유** `pairs_pilot_v2` 를 `lost → restored` | 통과 → **실패** → 통과 |
| 〃 | A 판에서 B 소유 `cycle_pilot` 상태를 바꿈 | 통과 → **실패** → 통과 |

완화된 정합 시험은 의도대로 좁다 — A 소유의 `lost → restored` 만 허용하고 B 소유 항목의 변경은 여전히 잡는다.

**I-1.** 새 실물 시험의 `skipif` 조건이 `not all((REPO_ROOT / k).is_dir() for k in PILOT3000_KEYS)` 다.
정션이 없는 clone 에서 건너뛰려는 뜻이지만, 정션이 **있는** 트리에서 복원 자리 **하나**가 사라져도 같은
조건에 걸려 skip 한다. 30번 §8-4 와 B 시험 주석("옛 판정은 디렉터리가 없으면 그냥 건너뛰었다 — 09-11
소실이 그렇게 초록으로 지나갔다")이 경계한 바로 그 모양이다. B 의 `FROZEN_REAL` 은 B 네 곳만 채점하므로,
이 커밋만으로는 복원 자리 하나가 사라져도 스위트 전체가 초록이다.

권고(A, 선택): skip 조건을 **저장 뿌리** 기준으로 — `not (REPO_ROOT / "data/processed").is_dir()` 이면 skip,
뿌리가 있으면 세 자리 전부를 단언. B 의 대조기가 `absent_tree` 와 `missing_contract` 를 가르는 기준과 같다.

### 3-2. B 쪽 보강 — 실물 명부 전체 대조 시험

B 의 import 전환 커밋에 `test_실물_트리에서_명부_전체_대조가_실패_0이다` 를 넣었다. `check_registry()` 로

남긴다. 가짜 뿌리에서 이빨을 확인했다(이 커밋의 명부를 그대로 적재):

| 가짜 트리 | 결과 |
|---|---|
| 있어야 할 자리 전부 봉인 | 통과 |
| `…_crop_only` 하나를 통째로 없앰(뿌리는 있음) | **실패** — `missing_contract` |

**백업 계획이 다시 커진다.** 복원 3곳이 `restored` 로 목록에 든다(41번 I-1 수정이 이것을 위한 것이다).

| 명부 | 파일 | 바이트 | git 밖(★) |
|---|---|---|---|
| main 현재(B 자체 명부, 전환 전) | 24 | 3,452,666 | 15 / 3,425,333 B |
| + `manifest_v1` (62f660b, 전환 뒤) | 29 | 50,769,661 | 20 / 50,742,328 B |

41번·B 보고에서 "50.6 MB" 라고 적은 것은 십진 MB 로 어림한 값이다. `plan` 출력의 "MB" 는 2^20 단위라
같은 29개가 **48.42 MB** 로 찍힌다. 바이트로 적는다 — 29개 50,769,661 B, 44개 57,267,748 B(≈ 54.6 MiB).

**순서.** B 의 실물 명부 시험은 이 명부가 있어야 통과한다 — `lost` 명부에서는 실물이 돌아온 세 자리가
`lost_but_present` 로 실패한다. 그래서 순서는 `9595cbe` 머지 → B 가 main 을 받아 전환 커밋 → B 게이트다.
그 사이(9595cbe 머지 뒤 B 전환 전) main 의 B 대조기 CLI 는 B 자체 명부(`lost`)를 읽어 여전히 exit 1 이다.
시험 스위트는 A 의 완화된 정합 시험이 이 차이를 허용하므로 초록이다.
