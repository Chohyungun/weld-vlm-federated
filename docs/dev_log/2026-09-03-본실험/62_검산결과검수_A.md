## 6. "독립 확인 아님" 두 항목 (과제 6)

**D9 정답 순서.** 모듈의 `iou_ties` 는 탐욕 매칭 중 한 검출에 대해 아직 잡히지 않은 정답 둘 이상이 같은 최대 IoU(≥ 0.5)를 가질 때 센다
(`map_independent.py` 197–200행, 같으면 뒤쪽으로 갱신 = pycocotools #10). 정답 순서가 값에 닿는 경로는 이 사건뿐이다 — 무시 정렬은
안정 정렬이고 `ignored_gt` 가 0 이며, 정답 수·클래스 집계는 순서와 무관하다. 동률이 한 번도 없으면 매 검출의 최대 정답이 유일해 잡힌 집합의
진화가 순서와 무관하다(귀납). 15칸 합계 **0** 이므로 어떤 순서로 읽어도 같은 매칭이다. 경계 쌍(|IoU − 0.5| < 1e−9) 0 은 `≥` 규칙 쪽도
발동하지 않았음을 더한다. D 의 판단에 **동의한다.**

**R-paths 레코드 경로.** 경로 규칙이 문서가 아닌 데서 생기는 위험은 둘이다. (가) v3 가 채점한 것과 다른 파일을 읽는다 — 30개 해시 전후 대조와
I 보고 해시 = v3 = 디스크(15/15)로 닫힌다. (나) v3 가 애초에 그 칸의 하한 레코드를 잘못 골랐다 — I 모드가 파일 **안** 헤더(cell/client/seed, D3 문서
규약)·좌표계 `ABS_ORIG`·레코드 수 12,461·`_raw_s` 이름을 확인하므로, 남는 것은 "경로 문자열을 문서로부터 다시 도출하지 않았다" 뿐이고 값에는
닿지 않는다. D 의 "경로·해시는 v3 `input_records` 에서 고정" 은 이 잔여를 정확히 적은 것이다. **동의한다.**
