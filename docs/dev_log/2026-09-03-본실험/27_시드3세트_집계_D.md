## 1-0. 이 집계가 읽은 것과, 그것으로 확인되는 것

집계기는 시드별 본채점 산출물 세 개만 읽는다. 채점을 다시 하지 않는다.

| 시드 | 입력 파일 | sha256 (앞 16자리) |
|---|---|---|
| 1 | `outputs/main_d/seed1/score_cells_v1.json` | `69dc57c6ff63b230…` |
| 2 | `outputs/main_d/seed2/score_cells_v1.json` | `188e2667d0aa7d79…` |
| 3 | `outputs/main_d/seed3/score_cells_v1.json` | `f8f4aaa775830fbb…` |

**확인되는 것:** 세 산출물의 채점 파라미터 15종(`profile`·`model_cfg`·`imgsz`·`predict_chunk`·
`max_det`·`conf`·`conf_floor`·`conf_sweep`(격자 14점)·`conf_sweep_source`·`class_names`·
`coord_space`·게이트 상수 3종·`imgsz_source`)이 **전부 같다.** 차이 0건.

**확인되지 않는 것:** 세 산출물이 **같은 채점기 코드**로 나왔는지. 산출물에 코드 해시가 없다.
`scorer` 필드가 `evaluation.score.score_records (단일)` 이라는 문자열을 담을 뿐이다.
집계 산출물의 `provenance.not_verified_here` 가 같은 말을 한다. 이후 시드에서 이 구분을
없애려면 채점기가 자기 코드 해시를 산출물에 남겨야 한다 — 별건으로 올린다(§12).

### 3-1. 분모 규칙 (사전등록 §5-4 `D ≥ 3·시드 sd`) — 판정을 셋으로 갈라 적는다

**모델별 시드 sd 를 먼저 싣는다** (`mAP@50`, 시드 3개 · 자유도 2).

| 칸 | 시드 sd | 시드별 값 |
|---|---|---|
| `sep_central` | 0.00444 | 0.4926 / 0.4916 / 0.4997 |
| `sep_local_C1` | 0.00247 | 0.3584 / 0.3577 / 0.3623 |
| `sep_local_C2` | 0.00189 | 0.1358 / 0.1321 / 0.1338 |
| `sep_local_C3` | 0.00473 | 0.0932 / 0.1025 / 0.0995 |
| **`sep_fed`** | **0.00971** | 0.2820 / 0.2639 / 0.2668 |

사전등록 문면이 "시드 sd" 의 정의를 정하지 않았으므로 **세 정의로 각각** 판정한다.

| 정의 | sd | 3·sd | D = 0.2974 | 판정 |
|---|---|---|---|---|
| **칸별 최대** (가정 없음, 가장 보수적) | 0.00971 | 0.02912 | D / 3·sd = 10.2 | **충족** |
| 다섯 칸 풀링 (자유도 10) | 0.00541 · σ 95% CI [0.0038, 0.0095] | 0.01622 | 18.3 | 충족 |
| 분모 D 자체의 시드 sd (자유도 2) | 0.00357 | 0.01070 | 27.8 | 충족 |

**풀링은 보조 요약이다.** 다섯 칸의 시드 간 분산이 같다는 가정에서만 성립하고, 칸마다 성능
수준이 다르므로 그 가정은 검증된 것이 아니다(연합 0.0097 대 C2 0.0019, 5배 차). 그래서
가정이 들어가지 않는 **칸별 최대** 정의를 표의 첫 줄에 두었다. 세 정의 중 가장 엄한 것으로도
D 가 3·sd 의 10배를 넘으므로 정의 선택이 판정을 가르지 않는다.

#### 판정 세 줄 — 종합 검증 통과가 아니다

| # | 항목 | 상태 |
|---|---|---|
| ① | 사전등록 트립와이어 `D ≥ 3·시드 sd` | **충족** (세 정의 전부) |
| ② | 회복률 95% CI 반폭 ≤ 0.25 (41번 보조 판정) | **미산출.** 본채점이 이 축의 묶음 클러스터 부트스트랩 CI 를 내지 않는다(COCO mAP 재표집 비용). **통과가 아니라 판정 자체가 없다** |
| ③ | 대표 지표 채택 | **미결.** 총괄 판정 사항이다(22번 §6-2-3). 분모 규칙 충족은 채택의 필요조건이지 충분조건이 아니다 |

①만으로 "회복률 검증 통과" 로 읽으면 안 된다. 41번이 트립와이어 단독의 검정력 부족을 실측했고
(D/σ=2 에서 36% 오통과) 그래서 CI 보조 판정을 처방했는데, 그 판정이 이 축에는 아직 없다.
집계 산출물의 `denominator_gate.verdict` 가 같은 세 줄을 담는다. 하위 필드
`denominator_sd_df2.recovery_reportable` 이 `true` 인 것은 **트립와이어 한 줄의 결과**이며
(CI 가 없으면 통과로 계산된다) 그 단서를 `field_caveat` 에 달았다.

②를 채우려면 mAP 의 묶음 부트스트랩이 필요하다 — 별건으로 올린다(§12).
`recovery_denominator` 게이트는 본채점 산출물에서 "시드 sd 없음 — 기록" 이었고, 이 집계가
①의 자리를 채운다.

## 5. 판별력 — 선별 한 문장과 후보 판단 재료

### 5-1. Δ (운용점, 선별용)

**다섯 칸 × 세 시드 = 15개 값 전부 CI 하한이 0 위다.** 이 문장이 이 지표가 낼 수 있는 전부이고
순위·비율로 읽지 않는다(22번 §6-2-4). 값은 산출물에 있다(중앙 0.3756 · C1 0.2893 · C2 0.4518 ·
C3 0.3689 · 연합 0.4239, 3세트 평균).

### 8-2. 로컬 모델 대비 연합 모델 — 공통 평가셋에서의 성능 변화

**이 수가 재는 것을 먼저 적는다.** 분모·분자가 모두 동결 글로벌 평가셋 12,461장에서 나온
값이다. 즉 **공통 기준에서 두 모델을 맞댄 것**이지, 참여자 c 가 연합에 참여해 얻는 편익이
아니다. 두 진술은 실제로 갈린다 — C3 가 그 예다.

    공통 = (연합 − 로컬_c) ÷ 로컬_c              [평가셋 전량 12,461장]
    명목 자기 재질 = (연합 − 로컬_c) ÷ 로컬_c     [그 클라이언트 재질 부분집합만]

| 로컬 모델 | 공통 시드 1 | 시드 2 | 시드 3 | **공통 평균** | **명목 자기 재질 평균** |
|---|---|---|---|---|---|
| **C1** (강재, 최대 참여자) | −21.3 % | −26.2 % | −26.4 % | **−24.63 %** | 분리 불가 (ST = C1 ∪ C2) |
| C2 (강재) | +107.6 % | +99.9 % | +99.4 % | **+102.29 %** | 분리 불가 (ST = C1 ∪ C2) |
| **C3** (알루미늄) | +202.5 % | +157.5 % | +168.2 % | **+176.09 %** | **AL −52.73 %** (−48.7 / −55.4 / −54.0) |
| 공통 최악 | C1 | C1 | C1 | 3 / 3 시드에서 C1 | — |
| 공통 편차 (최대 − 최소) | 223.8 pp | 183.7 pp | 194.6 pp | 200.7 pp | — |

**두 가지가 확인된다.**

첫째, 공통 평가셋에서 **C1 은 세 시드 모두 연합 모델이 자기 로컬 모델보다 낮다**
(−21 ~ −26 %). 데이터가 가장 많은 참여자다. C2·C3 의 세 자릿수 상승이 평균 +37.4 %(§8-1)를
만들고 C1 의 하락을 덮는다.

둘째, **C3 는 부호가 갈린다.** 공통 평가셋에서는 +176.09 % 인데 자기 재질(AL)에서는
**−52.73 %** 다. 공통 평가셋의 86 %가 강재라, C3 의 로컬 모델은 공통 기준에서 애초에 매우
낮고(mAP@50 0.0984) 연합이 그것을 크게 웃돈다. 그러나 C3 가 실제로 검사하는 알루미늄에서는
자기 로컬이 0.4802 로 강하고 연합은 0.2267 이다. **"C3 가 연합으로 176 % 좋아진다" 는 문장은
이 표에서 나오지 않는다.**

명목 자기 재질 값도 참여자 편익의 **대용**일 뿐이다. 평가셋은 회사별 분할보다 먼저 뗐고
이미지에 클라이언트 열이 없어(불변조건 1-3) 재질이 유일한 귀속 축이다(17번 §14-1).
ST 는 C1 과 C2 에 걸려 있어 두 참여자의 몫을 분리할 수 없다 — 그래서 두 칸은 빈칸이다.
집계 산출물이 같은 구분을 `measures` · `does_not_measure` · `own_material_unresolvable` ·
`clients_with_sign_disagreement` 필드로 담는다.

검산: 시드 1 의 C2 +107.6 / C3 +202.5 는 총괄 지시의 +107.7 / +202.6 과 소수 첫째 자리에서
다른데, 지시 값은 4자리 반올림 수(0.2820·0.1358·0.0932)로 계산한 것이고 내 값은 반올림 전
수로 계산한 것이다 — 같은 값이다.

## 9. 감사 회신 조건 — 분산의 해석

세 시드의 분산은 **기존 난수 정책 아래의 변동**이다. 이 실험의 학습은 라운드마다 같은 첫 두
epoch 순열을 쓴다(감사 F01). 그래서 시드 간 sd(칸당 ≤ 0.01)는 초기화·집계 경로의 변동이지
**데이터 순서·증강 다양성을 바꾼 분산이 아니다.** 이 표의 어느 sd 도 "순서 다양성이 충분히
반영된 분산"으로 서술하지 않는다. 시드 3세트가 완성됐다는 사실이 F06 의 메타데이터 교락
반례를 없애지도 않는다(codex_reply Q1·Q2). 집계 산출물의 `variance_interpretation` 필드에 같은
문장을 넣었다.
