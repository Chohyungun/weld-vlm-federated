# 57. 총괄 게이트 — 53번 미니스펙 `map_50` 독립 구현 검산 (2026-09-17)

대상: D 53번(`wt/D` `c7c0a1d`). 대표 수치 채택(의사결정로그 09-16)에 남은 조건이 이 검산이다.

## 판정: 조건부 통과

정의표(§3, 17항)와 판정 기준(§4)은 그대로 받는다. 구현 범위와 담당을 아래처럼 바꾼다.

| # | 게이트 항목(53번 §8) | 판정 |
|---|---|---|
| 1 | 추천안 | **A 직접 구현 수용.** ultralytics `ap_per_class` 참고치도 수용(판정에 쓰지 않고 크기만 보고) |
| 2 | 구현 트랙 | **C 가 구현한다.** D 는 정의표·실행기·입력 대조를 맡는다. 검수는 A |

| 5 | 교차 검수·정의표 선대조 | **A** 가 구현 전에 §3 정의표를 설치본 소스와 따로 대조한다(#5·#9·#10·#11·#16 우선). 구현 뒤 모듈·시험·실행기를 검수한다 |

## 바꾸는 것 — 입력 규약도 따로 읽는다

53번 §1 은 레코드 파싱·정답 적재·클래스 목록·xyxy→xywh 변환을 기존 코드와 **공유**하고, 공유 부분은 박스 수로만 대조한다.
박스 수 대조는 좌표 순서가 뒤바뀌거나 박스가 다른 이미지·클래스에 붙는 오류를 잡지 못한다. 채점 파이프라인에서 결함이
숨기 쉬운 곳이 바로 이 입력 규약이다. 알고리즘만 다시 짜서는 대표 수치의 근거를 독립으로 확인했다고 말하기 어렵다.

그래서 두 모드로 돌린다.

| 모드 | 입력 | 목적 | 채택 조건을 닫는가 |
|---|---|---|---|
| **S(공유 입력)** | 기존 `read_records`·`read_gold`·`to_coco_xywh` 결과 | 차이가 나면 알고리즘(①~④) 문제로 좁힌다 | 아니오(진단) |
| **I(독립 입력)** | 새 모듈이 파일 형식 문서만 보고 jsonl·`annotations.csv`·동결 매니페스트를 직접 읽고, 좌표를 직접 변환한다. `evaluation.score`·`evaluation.metrics.localization`·`scripts.probe.*` 를 import 하지 않는다 | 입력 규약까지 포함한 끝에서 끝 검산 | **예** |

- I 모드가 기대하는 값도 S 모드와 같다(같은 데이터, 같은 정의). 허용 차는 똑같이 1e−12 다.
- I 모드에서 값이 갈리고 S 모드에서 같으면 입력 규약 쪽 차이다. 그때도 어느 쪽이 맞다고 적기 전에 원인을 좁혀 보고한다.
- 파일 형식의 근거는 스키마 문서·매니페스트 계약이다. 문서에 없는 규약(좌표 원점, 클래스 문자열 표기, 이미지 id 형식)을
  기존 코드에서 읽어 와야 한다면 그 항목을 목록으로 남긴다. 그 항목들은 독립 확인이 아니므로 결과 보고에 따로 적는다.

## 담당과 순서

1. **A — 정의표 선대조**(구현 전). pycocotools 2.0.11 설치본 소스로 53번 §3 을 따로 확인한다. 결과는 58번.
2. **C — 모듈 구현.** `evaluation/metrics/map_independent.py`(총괄 배분 — D 소관 경로에 새 파일 하나만)와 시험.
   pycocotools·`evaluation.recovery_ci`·`evaluation.score`·`evaluation.metrics.localization` 을 import 하지 않는다(시험으로 고정).
   S·I 두 모드 입력을 받는 함수를 둔다. 손계산 픽스처(53번 §5 시험 1)와 합성 무작위 대조(시험 2, 시험 안에서만 pycocotools).
3. **D — 실행기와 입력 대조.** `scripts/probe/map50_independent.py`: 판 번호·덮어쓰기 거부·입력 해시 30개 전후 대조·두 모드 실행·
   판정·출력(`map50_independent_v3.json`). ultralytics 참고치(선택).
4. **A — 구현 검수**(모듈·시험·실행기, 변이 표본). 그 뒤 총괄 게이트.
5. **D — 실행**(게이트와 겹치지 않게, 계획 한 줄 먼저). 보고 59번. 판정은 총괄.

C 와 D 는 같은 파일을 동시에 고치지 않는다. 함수 서명(입력·출력 형태)은 C 가 먼저 적어 D 에 넘긴다.
