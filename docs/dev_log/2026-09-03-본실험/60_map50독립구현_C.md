## 2. 모듈 — 정의표 17항 + A 58번 보강의 구현 위치

입구는 셋이다.

- `evaluate_map50(gold, pred, classes)`: 알고리즘, 두 모드 공통.
- `map50_shared(...)`: S 모드, 진단용.
- `read_gold_independent(...)` · `read_pred_independent(...)` · `map50_independent(...)`: I 모드.

입력은 `image_id → [(iso_code, xywh[, score])]` 순서 있는 목록이고, 결과는 `Map50Result` 다.
- 두 평균: `map_50`(pycocotools 순서), `map_50_class_mean`
- `ap_by_class`, `precision`(101 × K)
- `counts`: 절단 · 동률 · 경계 쌍 · 버림 · 빈 쌍 · 무시 0 단언

| # | 정의 | 구현 |
|---|---|---|
| 1·2 | `linspace(0,1,101)` 격자, `searchsorted(left)`, 범위 밖 0 | `REC_THRS`(같은 `linspace` 식) · 첫 범위 밖에서 멈춤(오름차순이라 뒤도 0) |
| 3 | 뒤에서부터 포락선 | 파이썬 목록에서 `if pr[i] > pr[i−1]` 그대로 |
| 4 | `tp/(fp+tp+ε)` | `EPS = np.spacing(1)`. 완벽 매칭 AP 가 1.0 이 아님을 시험이 고정 |
| 5 | 이미지 × 카테고리 상위 100 | 한 번 정렬 후 `order[:100]`. 세 곳의 같은 절단을 한 번으로 합쳤다(결과 동일 — 같은 안정 정렬, 같은 목록) |
| 6·7 | 안정 정렬(이미지 안, 전체) | 이미지 안은 파이썬 정렬(Timsort, 안정), 전체는 `argsort(kind="mergesort")` |
| 8 | 이미지 순서 = 문자열 정렬, 목록은 정답 키 **전체** | `sorted(gold)` — 정상 이미지 포함(A §5-e) |
| 9·10 | 문턱 이상 미매칭 정답 중 **IoU 최대**, 같음은 매칭, 동률은 뒤쪽(A §5-a) | `if v < best: continue` 후 갱신. 동률 발생 수를 센다 |
| 11 | xywh 면적식, `x+w` 재계산, `+1` 없음 | `_iou_matrix` — `min(dw+dx, gw+gx) − max(dx, gx)`, 합집합 `(da+ga) − i`. `maskUtils.iou` 와 비트 대조 시험 |
| 12·13 | 'all', 무시 없음 | 범위 밖 박스가 있으면 멈춘다(무시 경로는 짜지 않았다). `ignored_*` 는 0 |
| 14·15 | 정답 없는 카테고리 −1 제외, 검출 없는 카테고리 0 포함 | `npig == 0` 이면 −1 그대로 · 검출 0 이면 격자 0 |
| 16 | 평탄 평균 + 카테고리 평균 둘 다 | `precision[precision > -1]`(C 순서) 한 번에 평균 · 카테고리별 101점 평균의 평균 |
| 17 | 목록 밖 버림, 빈 (이미지, 카테고리) 건너뜀 | `dropped_class_*` · `pairs_empty` 계수. 점수 None 은 알고리즘 입구에서 거부(치환은 호출자·I 모드 정책) |
| **18**(A 추가) | id 는 1 부터 — pycocotools 는 id 진릿값으로 매칭을 기록 | **id 를 쓰지 않고 불 배열로 매칭을 기록**한다. 시험의 pycocotools 기준 픽스처는 이미지·정답·카테고리 id 를 1 부터 매긴다 |
