# 50. 공개 검수기 픽스처의 로컬 경로 교체 — 트랙 B (2026-09-16)

지시: `dispatch_B_픽스처경로_20260916.md` (총괄 21:15; 보고 번호는 총괄 정정으로 50번).
F 46번 §4 가 올린 ④ 후보 — `tests/corpus/test_release_and_backup.py` 의 `test_로컬_절대경로를_잡는다` 입력이
이 저장소의 **실제 위치 형태**(작업 드라이브 + 저장소 폴더)였다. 이 보고와 커밋 메시지에는 그 문자열을 옮기지 않는다.

## 1. 교체

입력을 **존재하지 않는 가짜 경로**로 바꿨다 — `Q:` 드라이브(이 컴퓨터의 드라이브는 C·E·G 뿐이다) +
`Users\example_user\sample_project\corpus`. 드라이브도 폴더 이름도 이 저장소·사용자와 무관하다.
시험의 뜻(검수기가 로컬 절대경로를 `local_path` 로 잡는다)은 그대로이고, 왜 가짜인지를 독스트링에 적었다.

**`Users` 갈래로 시험하는 이유 — 규칙이 폴더 이름 목록에 기대고 있다(보고).**
`screen_public_release.LOCAL_PATH` 는

```
[A-Za-z]:[\\/](?:Users|Fedvlm|Program Files)|/(?:home|Users)/[A-Za-z]
```

이다. Windows 쪽은 드라이브 다음 **첫 폴더가 `Users`·`Program Files`·이 저장소 이름의 접두**일 때만 잡는다.
옛 픽스처는 그중 **저장소 이름 갈래**를 탔다 — 즉 시험이 이 저장소 이름에 기대고 있었다. 가짜 경로로는
그 갈래를 시험할 수 없으므로(저장소 이름을 쓰면 다시 실제 형태가 된다) 어느 저장소에나 있는 `Users` 갈래로 옮겼다.

가짜 입력으로 규칙을 찔러 본 결과(시험 아님, 직접 호출):

| 입력 형태 (전부 가짜) | `local_path` |
|---|---|
| `Q:` + `\Users\example_user\…` (픽스처) | 잡음 |
| `Q:` + `/Users/…` · `Q:` + `\Program Files\…` · `/home/example_user/…` | 잡음 |
| 드라이브 없이 `\Users\example_user\…` | **놓침** (이빨 변이의 근거 — §3) |
| `Q:` + `\sample_project\…` (첫 폴더가 목록 밖) | **놓침** |
| `Q:` + `\공유 드라이브\…` · `Q:` + `\내 드라이브\…` | **놓침** |
| `Q:` + `\\Users\\…` (**JSON 이스케이프**, 역슬래시 2개) | **놓침** |

**규칙 자체는 넓히지 않았다(지시 — 별건, 보고만).** 다만 마지막 줄은 검수기의 실제 용도에 걸린다. 검수 대상
(`TARGET_DIRS` = `cycle_pilot`·`cycle_pilot_v2` 의 미추적 구성원)은 JSON/JSONL 이고, JSON 은 Windows 경로의
역슬래시를 두 개로 적는다. 그 안의 경로는 이 규칙에 **안 잡힌다** — 09-13 위생 정규식이 이스케이프된 경로를
놓친 것(30번 부록 G)과 같은 모양이다. 공유 드라이브·내 드라이브 형태도 총괄·F 의 위생 grep 패턴은 잡지만 이
규칙은 못 잡는다. 넓힌다면 `[\\/]{1,2}` 와 그 두 폴더 이름을 더하고, 저장소 이름 갈래는 빼는 것을 제안한다.

**위생 grep 과의 관계.** 가짜 경로도 `Users` 로 시작하므로 총괄·F 의 위생 패턴
(`[A-Za-z]:[\\/]{1,2}(Users|…)`)에는 이 줄이 **계속 걸린다.** 검수기가 잡는 형태여야 시험이 서므로 피할 수 없다.
다음 정리 목록에서는 "가짜 경로 픽스처(`Q:`·`example_user`)" 로 분류하면 된다.

그 밖에 `tests/corpus` 에 실제 경로 형태는 없다. 교체 뒤 같은 검색에서 저장소 이름은 0건이다.

## 3. 이빨 — 변이 1개 (스크래치 사본)

`git archive HEAD` 사본에 교체한 시험 파일을 얹고, 입력에서 **드라이브(`Q:`)만 뺀** 변이를 걸었다.

| 단계 | `test_로컬_절대경로를_잡는다` |
|---|---|
| 기준(교체한 가짜 경로) | 통과 |
| 변이 — 드라이브 `Q:` 제거 | **실패** (`local_path` 가 안 나온다) |
| 원복 | 통과 |

시험은 여전히 규칙의 드라이브 부분을 문다. 사본은 스크래치에만 있고 wt_B 는 건드리지 않았다.
