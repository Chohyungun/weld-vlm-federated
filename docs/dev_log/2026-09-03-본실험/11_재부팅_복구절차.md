# 11. 재부팅 복구 절차 — 시드 1 ④ 재기동 (A1+A2)

2026-09-05 · 총괄 작성 · 근거: 10번 §7 (사인 = 커밋 고갈), 의사결정로그 09-05 판정

## 재부팅 전 (사용자, 관리자 권한)

1. **페이지파일 고정 (A1).** 시스템 속성 → 고급 → 성능 설정 → 고급 → 가상 메모리:
   "모든 드라이브 자동 관리" 해제 → **C: 사용자 지정 40960/40960 MB** +
   **E: 사용자 지정 32768/32768 MB** (합 72 GB, 커밋 한도 ≈ 103.6 GB).
   C: 여유가 걱정되면 C: 24576 + E: 49152 로 조정해도 무방 (합 ≥ 64 GB 유지).
   관리자 PowerShell (실제 통한 방식 — `New-CimInstance` 는 항목을 지운 뒤 생성에 실패해
   설정이 비는 사고가 있었다. 09-06 실측):
   ```powershell
   Set-CimInstance -Query "SELECT * FROM Win32_ComputerSystem" -Property @{AutomaticManagedPagefile=$false}
   Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management' -Name PagingFiles -Type MultiString -Value @('C:\pagefile.sys 40960 40960','E:\pagefile.sys 32768 32768')
   Get-CimInstance Win32_PageFileSetting   # 두 항목이 40960/40960, 32768/32768 로 보여야 한다
   ```
   재부팅 전에 `Win32_PageFileSetting` 이 **비어 있지 않은지** 반드시 확인한다 — 비어 있으면
   재부팅 후 페이지파일 없이 부팅되어 한도가 RAM 31.6 GB 로 떨어진다.
2. 재부팅.

## 재부팅 후 (사용자 → 총괄 → C 순)

   OneDrive·브라우저는 필요 시 허용.

   않는다. 단 ④ chain_s1 기동은 외부 GPU 프로세스(게임) 종료 후에만 — `docs/의사결정로그.md` 09-06 항목.)*
2. herdr 기동 → 각 worktree 에서 세션 재개 (경로 고정, 모델은 `CLAUDE.md` 의 검토 등급 정책):

   | 총괄·A·B·C·D·E·F | 세션 식별자와 경로는 **미추적 파일**에 있다 — 같은 폴더의 `dispatch_LOCAL_세션재개표.md` |
