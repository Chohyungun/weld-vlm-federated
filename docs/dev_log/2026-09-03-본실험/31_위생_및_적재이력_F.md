### 1-2. 7-2 기술 경고 보존

원문은 드라이브 문자가 붙은 두 경로를 예로 들어 "한글이 든 경로를 스크립트 파일에 그대로 쓰면 깨진다"고 했다.
예시를 **경로가 아니라 폴더 이름**으로 바꿨다. 경고는 그대로 성립한다.

- Drive for desktop 마운트 아래 개인·공유 드라이브 루트가 `내 드라이브`·`공유 드라이브` 라는 한글(공백 포함)
  폴더이고, `<프로젝트 폴더>` 이름도 한글이다. 그래서 적재 경로에는 한글이 거의 늘 들어간다.
- 그런 경로를 스크립트에 그대로 쓰면 PowerShell 5.1 이 `.ps1` 을 ANSI 로 읽어 `Illegal characters in path` 로 죽는다.
- 처방 코드(코드포인트 조립)는 그대로 두고 마운트 문자만 `<DRIVE>` 로 바꿨다. `<프로젝트 폴더>` 도 같은 방식으로
  조립하라는 한 줄을 붙였다.

인과는 원문대로 **한글**로 한정했다. 지시문은 "한글 + 공백"이라 했지만 08-22 실측 서술은 한글이 원인이고,
공백이 원인이라는 실측은 없어서 원인으로 올리지 않았다.

B 의 코드는 실행하지 않았다. 계약 해시는 전 구성원 일치다.

물리 디스크는 C: 가 NVMe SSD, E: 가 SATA HDD 1 TB 다. **PC 밖 사본은 하나도 없다.**
C: 쪽 두 벌은 `%TEMP%` 라 청소 한 번에 사라지므로 영속 사본으로 칠 수 없다. 영속 사본만 세면 셋 다

**B 에게 넘길 곁가지 사실.** `cycle_pilot` 추적분 3개(`_phi_report.json` · `cycle_corpus_report.json` · `judge_agreement.json`)의
**git 블롭은 LF 로 정규화돼 계약 해시와 다르다.** wt_B 실물은 CRLF 라 계약과 맞고, 블롭을 LF→CRLF 로 되돌리면 3/3 일치한다.
git 은 이 3개의 복구원이긴 하지만 줄바꿈 변환을 거쳐야 한다. plan 은 이들을 ㆍ(git 에도 있음)로 찍는다.

### 2-3. 국내 리전 — 확인 수단을 찾지 못했다

- 클라이언트의 로컬 설정·메타데이터 캐시에 리전이나 데이터 위치 필드가 없다. 속성 키 13개(`driveway_account`·`teamdrive_cache` 등)와
  항목 스키마를 봤다.

**이 세션에서 리전을 확인할 수단이 없다.** 드라이브를 소유한 조직 쪽 관리 정보가 필요해 보이지만, 그 경로도 검증하지 않았다.
판단은 사용자 몫이다.

**판단 재료 하나.** 리전 질문은 백업만의 문제가 아니다. **AI허브 71761 원천 zip 60개 44.11 GiB(RT·VT, 원천 + 라벨)가 08-21 부터
바로 이 공유 드라이브에 있다**(2-4). 09-08 의 "국내" 전제가 틀리면 백업 이전에 원천 적재부터 규약 2-1 과 부딪힌다.
국내로 확인되면 백업 목적지로도 쓸 수 있다. 어느 쪽이든 적재 지시보다 이 확인이 먼저다.

### 2-4. 원천 데이터 — raw 는 드라이브에 동일본이 있다, interim 은 대부분 로컬 단일

다른 공유 드라이브나 내 드라이브에 AI허브 zip 사본은 없다. 휴지통에 같은 폴더 출신 zip 21개(크기 0 기록)가 있는데 경위는 확인하지 않았다.

  다만 그 드라이브가 2-3 의 리전 미확인 대상이다.
- `data/interim` 7.26 GiB 중 드라이브에 있는 것은 라벨 zip 32 MB 뿐이다. **나머지 7.22 GiB 는 E: HDD 로컬 단일**이다.

  `SNAPSHOT.sha256` 이 든 동결 폴더다(규약 1-2 단일 진실, 1-6 재생성 금지). **`verify_backup` 백업 계획 20개에 들어 있지 않다.**

## 3. 한 것과 하지 않은 것

- 목록·크기·해시·이름 탐색만 했다. **복사·이동·삭제 0건.** 봉인 자산과 원천은 읽기만 했다. 워크트리는 지우지 않았다. GPU 는 쓰지 않았다.
- Drive 메타데이터 DB 는 `mode=ro` 로만 열었고 복사본을 만들지 않았다. 로그 zip 은 메모리에서만 풀었다.
- 다른 트랙 코드(`verify_backup` 포함)는 실행하지 않았다. 같은 규칙으로 독립 계산했다.
- 탐색 스크립트는 세션 스크래치에 있고 커밋하지 않았다.
- 커밋은 wt/F 에만 한다. 이 브랜치는 main 보다 111 커밋 뒤지만 데이터셋 문서 3개는 main 과 차이가 없다.
