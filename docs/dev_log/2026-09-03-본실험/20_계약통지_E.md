## 2. 결과표 골격 변경 (`docs/paper/결과표_템플릿.md`)

- 표기 규약 +3: 회계 셀 인용 규칙 / 재개 run 등가 전제 / 속도 축 표본·플래그 규칙.
- T6: 분리·연합 행에 ^k^(표본·플래그) ^l^(오버헤드 분해) 각주. `T_train`(④) = progress.jsonl 세그먼트 wall 합
  (기동 오버헤드 포함, 14번 §R-5 iv). 시드 3세트 평균±sd 는 채점 run(B on) 사이에서만.
- **T6-a 신설** — ④ 라운드별 벽시계 부속표. 열 = 표본 · 시드 · 라운드 · wall · 이음매 · 외부 GPU 점유 ·
  `val_loader_workers` · 격리 세그먼트. 요약 2행(플래그 제외 평균 / 전체 평균), 표본별.
- **T7 신설** — 실험 조건 표(시드 × 조건). 열 = 코드 커밋 · FAB 해시 · 호스트 구성(OMP) · `val_loader_workers` ·
  세그먼트 수·이음매 라운드 · 하트비트 허용치 · 등가 검증 기록. 부록 권고.
- 채움 절차: 1-a 회계·감사 산출물의 읽기 계약(accounting.csv 는 `measured` 행만, audit.json 키 4종 + 값 집합 검증,
  progress.jsonl 세그먼트 행), 1-b 속도 표본 분리·요약 평균 2종, 3 수기 허용 범위를 T7 조건 기록과 ^l^ 분해값로
  넓히되 출처 경로 병기.
