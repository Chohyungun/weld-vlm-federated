## 1. `evaluation/recovery_ci.py` — 매칭 캐시 + 중복도 집계

### 1-1. pycocotools `accumulate` 와 같은가 — 코드 대조

pycocotools 2.x `accumulate` 를 한 줄씩 맞대 보았다. 모두 같다.
- 이미지 순서로 검출을 잇고 `-score` 안정 정렬(mergesort)을 한다.
- `npig == 0` 이면 그 카테고리를 건너뛴다(-1). 검출이 0 이면 정밀도 행이 0 이다.
- 우측 포락선은 `pr[i-1] = max(pr[i-1], pr[i])` 와 같다.
- 101점 보간은 `searchsorted(left)` 로 하고, 인덱스를 넘는 칸은 pycocotools 의 `except: pass` 와 같게 0 이다.
- `(T, R, K)` 격자를 C 순서로 펴서 한 번에 평균한다(`_summarize` 와 같은 순서). 그래서 항등 검사의 허용 오차 0 이 성립한다.

**가장 위험한 가정은 캐시의 이미지 순서다.** `EvalCache.image_ids = sorted(gold)` 인데 `evalImgs` 의 i 번째가 그 이미지여야 한다. `build_cocoeval` 이 `sorted(gold)` 순서로 정수 id 1..N 을 매기고 pycocotools 가 `np.unique(imgIds)` 로 정렬하므로 일치한다. 무시 플래그(`dtIgnore`)는 이 구축에서 생기지 않는다(`iscrowd=0`, 면적 범위 `[0, 1e10]`).

## 4. `24a1224` — CI 입력 결속과 규칙 재판정

### 4-1. 설계 대조

외부 지적(codex_reply §18)과 총괄 요구 1~6 을 코드에 대조했다.
- **결속**: 판 번호·산출물 이름·시드 목록·시드별 {원시 sha256, 시드값, 지문 combined·rule·newline_normalized}, CI 실행 지문 = 채점 지문, `stable=true`.

### 9-1. I-1 — 신뢰수준·구간 방식

### 9-3. m-6 — 재표집 루프 이동의 비트 동일성(지시 3항)

- **방법.** 두 코드는 같은 캐시에서 출발했다. 캐시는 1차 CI 재실행 때 스크래치에 만든 15벌이다(`9f01b31` `build_cache`, 공유 원시 레코드). `build_cache`·`weighted_map`·`group_weights`·`recovery_from` 은 두 커밋 사이에 한 줄도 바뀌지 않았다(`recovery_ci.py` 의 차이는 import 2줄과 파일 끝 추가뿐이다).
  - 각 커밋의 `recovery_bootstrap.py` 에서 "`# ---- 짝지은 재표집`" 부터 "`# ---- 점추정`" 앞까지 **원문을 잘라** 그 커밋의 모듈로 실행했다. 난수는 `default_rng(20260825)`, 추첨은 20회다.
  - 두 커밋의 모듈 이름이 같아서 프로세스를 나눠 npz 로 저장하고, `float64` 비트(`view(uint64)`)로 맞댔다.
- **결과.** R̄ 1 · R_s 3 · D_s 3 · 칸별 map_50 15, 모두 **22배열 × 20회가 비트 일치**한다. R̄ 첫 세 값은 0.2259312386…, 0.2375461726…, 0.2410467653… 이다.
- **대조군(변이 사본의 `paired_bootstrap`).**
  - 추첨을 시드 루프 안으로 옮기면 22/22 배열이 갈린다. 비교가 순서 변화를 잡는다.
  - `np.mean(rs)` → `sum(rs)/len(rs)`, `np.nanmean` 두 변이는 **이 20회에서 같다.** 원소가 3개라 합산 순서가 같고, 20회에 미정의 추첨이 없어서다(`n_nan = 0`). 미정의 전파는 실데이터 20회로는 확인되지 않는다. D 의 합성 시험(`분모가_0_이하인_재표집은_nan…`)과 D 변이(`nanmean` 잡힘)가 덮는다.
- 이 결과와 §9-4 를 합치면 **`01b7f4d` 생성기는 같은 캐시에서 기존 v2 CI 와 같은 비트를 낸다.** 49번의 v2↔v3 CI 대조에서 차이가 나면 원인은 루프가 아니라 입력(레코드·캐시·채점값)에 있다.
