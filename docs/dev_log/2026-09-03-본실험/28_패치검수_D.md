`None` 을 "아무거나" 로 기대한다.

부수 사실: `Query.to_text` 가 `재질=`·`품질규격=` 을 새로 넣어(`:81,84`) dense 보조 검색의 질의

## 4. F12 — 항목별 bbox 폐기

### 4-1. 내 경로 — HEAD 판과 패치 판을 같은 입력에

| 퇴화 박스(x1 ≥ x2) 1개 + 정상 1개 | ok 2 (퇴화가 통과) | ok 1 (bad 1) |
