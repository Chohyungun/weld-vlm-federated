## 2. 차단 보고 — 시드 2·3 값이 어디에도 등록돼 있지 않다

지시서는 "시드 3세트 (등록된 시드 세트 그대로)"라고 했으나, **등록된 세트가 없다.**

- `configs/base.yaml` 에 시드 세트 블록 없음 (A 의 R·E 등록 지시에도 시드는 없다)
- 실험설계 §6-4 는 "3시드" 정책만, 값 없음
- `round_runner` 독스트링의 "base_seed 3세트는 불변이고 파생 공식과 함께 configs 에
  기록한다"는 선언만 있고 이행된 적이 없다

**시드 1 = 20260828 은 모호하지 않다** — 파일럿·초기 가중치·LoRA 초기화·§4-6 게이트가
전부 이 상수 위에 있다. 그래서 시드 1 체인은 즉시 착수했다.

**시드 2·3 은 값을 지어내지 않고 거부하게 해 뒀다**(`main_det.py` 가 `experiment.seeds`
등록을 읽을 때까지). 여기서 트랙이 임의로 고르면 "결과를 본 뒤 시드를 고르는" 경로가
열린다 — 사전등록 상수 계열 사고(80번 D2)와 같은 부류다. 시드 1 완주까지 ~3.2일이므로
등록이 그 안에 landing 하면 일정 손실이 없다.

**요청:** A 에게 `configs/base.yaml` `experiment.seeds: [20260828, s2, s3]` 등록 배분
(R·E 등록 지시에 한 줄 추가). 파생 규칙 제안 — 자의성 제거를 위해
`[20260828, 20260829, 20260830]` 같은 기계적 파생을 권한다. 값 선택은 총괄 몫이다.

## 3. preflight 실측 (2026-09-03)

- `cudnn_deterministic=true` · `cudnn_benchmark=false` (실효값, 선언 아님)
- `flwr run . local-sim --run-config 'cell="smoke" …'` → 스모크 칸 R=2 완주, 회계 ok
- 이 과정에서 **프레임워크 결함 2건**을 잡아 배선에 반영했다:
  1. flwr 가 `--run-config` 의 키를 `[tool.flwr.app.config]` 기본값과 대조해 없는 키를
     거부한다 → `resume-root`·`smoke-fail-at` 기본값 선언 추가
  2. flwr 의 FAB 설치가 `pyproject.toml` 을 인코딩 지정 없이 읽어 **Windows cp949 에서
     한글 주석에 UnicodeDecodeError(exit 700)** — 하위 프로세스에 `PYTHONUTF8=1` 강제.
     단, 상주 SuperLink 데몬이 cp949 환경에서 이미 떠 있으면 그 자식이 다시 죽으므로,
     **정확히 이 시그니처에 한해** 데몬 재기동 후 1회 재시도하는 가드를 뒀다
     (다른 실패는 재시도 없이 멈춘다 — 우회 금지)

## 4. detections.jsonl 계약 (13_spec_D §2-3) — C 가 낸다

시드·칸 완주마다 `outputs/main_c/seed{k}/predictions/{tag}.detections.jsonl`:

- `{image_id, boxes:[{cls, xyxy_px, conf}], coord_space:"ABS_ORIG", coord_cfg_hash}`
- 추론 진입점은 D 의 `load_yolo_from_npz` **하나** (fp32, `model_cfg="yolo11s.yaml"` —
  파일럿의 `.half()` 사본을 만들지 않는다, D17)
- `conf = 0.01(CONF_FLOOR)` 하한 추론 — D 가 어떤 임계로든 걸러 쓰고, 채점 임계를
  C 가 선점하지 않는다 (D-1 처방과 정합)
- **CPU 고정** + 부속 meta(checkpoint sha256·imgsz·conf·max_det·device·precision) —
  74번 M11(같은 설정 명목인데 ±2박스)의 재발을 조건 기록으로 막는다
- 대상: `sep_local_c0..2` · `sep_central` · `sep_fed`(=`global_r050`).
  ④의 라운드별 글로벌 50벌은 npz 로 전부 보존된다(RQ3 궤적) — 라운드별 detections 는
  비용(라운드×17분 CPU)이 커서 기본 미생성, D 가 필요 라운드를 지정하면 낸다
