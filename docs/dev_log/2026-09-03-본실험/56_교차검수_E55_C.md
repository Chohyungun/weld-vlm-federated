### 원시 격차의 정의

- **실험설계 8-5 와 맞는다.** 8-5 는 "IEEE Std 3652.1-2020 §9.3.1은 … 성능 격차를 `중앙집중 − 연합`으로 정의" 하고, 분리형 원시 격차를 `(중앙 − 로컬평균) × (1 − 회복률/100)` 로 환산한다고 적는다.

- **환산식과의 관계.** 환산식은 시드마다 정확히 성립한다(최대 오차 3e-17).

- **표준 원문은 대조되지 않았다 — 판정 불가.**

## 4. T2-b "분해 조항 발동(24.8 % < 80 %)" (과제 4) — **09-16 정정과 충돌한다(I-2)**

**80 % 문턱의 출처.**
- 결과표 템플릿 120–121 행("회복률 해석 구간 (구현설계 §9): 90 % 이상 강한 결과 / 80~90 % 방어 가능 / 80 % 미만 = non-IID 심화로 해석하되 클라이언트별 분해를 제시")이 구현설계 §9 "베이스라인과 해석 기준선" 표를 인용한다.
- 그 표의 참조점은 "non-IID FedAvg 문헌에서 통상 85~95 % 회복 보고" 한 줄이다. **구체 문헌이 없다.**
- `git log -S` 로 보면 이 줄은 저장소 최초 공개 커밋(`5a39195`, 08-21)부터 있었다.
- 참조점의 "회복" 이 어떤 산식인지도 적혀 있지 않다. 이 연구의 격차 정규화 회복률과 같은 척도인지 확인되지 않는다. 같은 모델 쌍에서 연합 ÷ 중앙은 54.8 %, 회복률은 24.8 % 다.

**정정 내용.**
- 실험설계 8-5 의 09-16 검토 정정(`5f54a10`)은 이 3구간을 적용 규칙("임계 독립 헤드라인에만 적용")에서 "기준 근거가 확인되지 않아 성능 판정의 근거로 제시하지 않는다" 로 바꿨다.
- **구현설계 §9 표와 결과표 템플릿 120–121 행에는 이 정정이 전파되지 않았다**(기존 불일치).

**충돌.**
- 새 문장 192–194 는 "T2 의 해석 규칙이 '80 % 미만이면 non-IID 심화로 해석하되 클라이언트별 분해를 제시' 로 정해져 있고, 채택된 대표 수치 +24.8 % 가 80 % 미만이라 이 조항이 발동했다" 이다.
- 이 문장은 **정정으로 판정 근거에서 빠진 문턱을 채택된 대표 수치에 적용한다.**
- 조항 안의 "non-IID 심화로 해석" 은 회복률의 크기에서 원인을 읽는 해석이다. 정정이 판정 근거에서 뺀 것을 그대로 되살린다.
- 본문에는 90/80 구간이 쓰이지 않았다(검색 0).

**처방.**
- T2-b 가 필수인 근거를 80 % 문턱이 아니라 **결정 항목의 병기 조건 (4)** 에 둔다. 조건 (4)는 "참여자 편익이 아니다 — 연합은 로컬 C1 보다 낮다(3/3), C3 는 자기 재질에서 부호가 갈린다" 이다. 여기에 22번 §5-3(분해 산출은 D 소관)을 더한다. 이렇게 해도 표는 필수로 남는다.
- 템플릿 120–121 행은 8-5 정정에 맞춰 "초기안의 해석 구간 — 근거 미확인, 판정에 쓰지 않음(09-16 정정)" 으로 고친다. E 소관이다.
