## 6. 이 결과가 말하는 것과 말하지 않는 것 — 사실만

- **말하는 것.** v3 의 칸 × 시드 15개 `map_50` 과 그로부터 낸 R_s·R̄ 가 **pycocotools 를 쓰지 않는 두 번째 구현**으로 같은 값이 나온다.
  I 모드는 동결 스냅샷·사상표·하한 레코드를 기존 채점 코드 없이 읽었고, 그 입력으로도 같은 값이다. 입력 규약 가운데 코드에서 온 것은
  위 둘(D9·R-paths)이고, D9 는 이번 데이터에서 발동하지 않았다.
- **말하지 않는 것.**
  - 두 구현은 **같은 정의**(53번 §3 = pycocotools 동작)를 따른다. 정의 자체가 옳은지, 다른 정의(VOC 면적·사다리꼴 적분 등)로 얼마나
    움직이는지는 이 검산의 범위 밖이다. ultralytics 참고치는 돌리지 않았다.
  - 입력 레코드(검출 결과)와 체크포인트는 v3 와 **같은 파일**이다. 추론을 다시 한 것이 아니다.
  - 대표 채택 여부는 판정하지 않는다(총괄 몫, 57번).
