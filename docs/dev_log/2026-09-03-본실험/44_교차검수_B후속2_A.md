## 1. I-1 — `verify_backup.py`

### 1-1. 코드

```python
BACKED_UP_STATUSES = frozenset({"expected", "restored"})

def sealed_dirs(registry=None, root=None) -> tuple[Path, ...]:
    reg = EXPECTED_SEALED if registry is None else registry
    base = REPO if root is None else Path(root)
    return tuple(base / rel for rel, e in reg.items() if e.get("status") in BACKED_UP_STATUSES)

SEALED_DIRS = sealed_dirs()
DEFAULT_DIRS = SEALED_DIRS + UNSEALED_DIRS
```

- `lost` 만 빠진다 — 명부 어휘(`SEALED_STATUSES = expected·lost·restored`, A 62f660b)와 정확히 상보다. 어휘가
  늘면 `BACKED_UP_STATUSES` 도 같이 늘려야 한다는 의존은 남는다 — 주석에 A 62f660b 를 가리켜 적어 뒀다.
- `main()` 의 "소실 기록 N곳은 목록에서 뺐다" 안내(226행)는 `status == "lost"` 를 그대로 세므로 새 상태와 어긋나지 않는다.
- `SEALED_DIRS`·`DEFAULT_DIRS` 는 여전히 import 시점 값이다(이전과 같음). 시험은 `sealed_dirs()` 를 명부 인자로 부른다.

### 1-2. `manifest_v1` — 순서 문제

`verify_backup` 은 `corpus.generate.frozen_out.EXPECTED_SEALED` 를 읽고, 그 명부(main `ac25cdd`·`b9ac222` 동일)에는
`data/interim/manifest_v1` 이 없다. A 명부(`data/frozen_guard.EXPECTED_SEALED`, 62f660b)에는 있다. 따라서 **이 커밋 시점의
백업 목록에 `manifest_v1` 은 들지 않는다.** 이것은 b9ac222 의 결함이 아니라 순서다 — 62f660b 가 main 에 없는 상태에서
B 는 `data.frozen_guard` 를 import 할 수 없다. 62f660b 머지 → B 의 import 전환 커밋(1줄) → `sealed_dirs()` 가
`expected` 인 `manifest_v1` 을 자동으로 집는다. 그때 백업 계획이 3.29 MB → 약 50.6 MB 로 커진다(41번 m-3, 총괄·사용자 판단).

## 2. m-6 — `_f1()`

```python
def _f1(prec, rec):
    if prec is None or rec is None: return None
    return 2 * prec * rec / (prec + rec) if prec + rec else 0.0
```

| 입력 | 결과 | 맞는가 |
|---|---|---|
| 예측 양성 0 (prec None) | None | 정의 안 됨 — 맞다 |
| 정답 양성 0 (rec None) | None | 맞다 |
| prec 0.0 · rec 0.0 | 0.0 | 전부 틀림 — 맞다(옛 코드는 None) |
| prec 0.0 · rec 0.5 | 0.0 | F1 = 0 — 맞다(옛 코드는 None) |

`_counts`·`_weighted_counts` 둘 다 이 헬퍼를 쓴다. 반올림은 반환 직전에만 하므로 f1 은 미반올림 정밀도·재현율로
계산된다(이전과 같음).

## 3. m-5 — 픽스처가 정밀도·재현율 둘 다 가른다

픽스처(`_weighted_fixture`)를 손으로 셌다. 층화 판정기는 deepseek, 후보는 phi.

| 층 (w) | phi 예측 | 정답 OK | TP | FP | FN | TN |
|---|---|---|---|---|---|---|
| pass (N 40 / k 20 → w 2) | i<8 또는 i≥18 | i<16 | 8 | 2 | 8 | 2 |
| fail (N 10 / k 10 → w 1) | i<5 또는 i≥8 | i<5 | 5 | 2 | 0 | 3 |

무가중: TP 13 · FP 4 · FN 8 → P 13/17 = 0.7647, R 13/21 = 0.6190. 가중: TP 8·2+5 = 21, FP 2·2+2 = 6, FN 8·2 = 16,
모집단 40+10 = 50 → P 21/27 = 0.7778, R 21/37 = 0.5676. **정밀도·재현율이 둘 다 갈린다** — 시험
`test_층화_판정기가_아닌_후보는_정밀도도_가중에_갈린다` 의 단언(13/4/8 · 21/6/16/50 · 두 비율 모두 `!=`)과 같다.
F 39번이 짚은 "층화 판정기 자신은 정밀도가 구조적으로 가중 == 무가중" 을 비껴가는 후보를 골랐다.
