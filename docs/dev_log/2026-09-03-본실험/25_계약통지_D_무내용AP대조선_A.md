## 3. §13-3 답 — 0.9149 와 0.9128 의 차이는 규칙 형태 차이다

### 3-1. 두 규칙 형태

| | 등록 F1 0.9149 (A, `scripts/recompute_baselines.py` `fit_rule`) | D 의 H (`evaluation/content_free.py` `_majority_of`) |
|---|---|---|
| 단위 | **클래스별** 독립 | **구간별** |
| 규칙 | 구간을 그 클래스 양성률 순으로 세우고, train+val F1 이 최대인 **접두사**의 구간에서 그 클래스를 주장 (Dinkelbach 접두사 정리 — 이 형태 안의 정확한 최적해) | 구간의 **최빈 정답 코드 집합**을 그대로 주장 |
| 과소표본(n<30)·미관측 구간 | 전역 규칙(축 없음)으로 폴백 | 예측 없음 |
| 결과 | 클래스별로 다른 임계 — 희귀 클래스는 양성률이 절반 아래인 구간도 주장할 수 있다 | 가장 흔한 조합 하나만 |

§11-2 표의 "H = 등록 상수 0.9149 와 같은 예측기" 와 §12-1 의 "차 0.0021 은 족 선택 절차의 잔차" 는 사실과 다르다.
족이 고정되면 족 선택 절차는 값에 영향이 없다 — 남는 것은 적합 규칙뿐이다.

### 3-2. 실측 (`scripts/verify_content_free_rule_form.py`, CPU)

같은 족(idq512)·같은 절단점·같은 적합 모집단(train+val 49,847)·같은 채점 모집단(eval 12,461) 위에서 두 형태를 적합했다.

| 항목 | 값 |
|---|---|
| (A) 클래스별 F1 최적 접두사, eval Macro-F1 | **0.914913** (등록 0.9149) |
| (D) 구간 최빈 코드 집합, eval Macro-F1 | **0.912842** (D 재구성 0.912842) |
| 차 | 0.002071 |
| 두 형태의 예측이 갈리는 구간 | **1 / 512** |
| A 절단점 구간 == D `stratum_of` 구간 (eval 12,461 전부) | 일치, 불일치 0 |
| eval 평균 유병률 | 0.142806 (= `all_positive` AP) |

절단점은 완전히 같고(둘 다 A 의 `data.id_strata` 절단점), 512 구간 중 **한 구간**에서만 두 형태의 주장이 갈리며 그것이 차이 전부다.
폴백도 원인이 아니다 — 폴백에 떨어진 구간은 0 이다.

### 3-3. 수치가 같은 말을 한다

하드 예측기는 `AP = P·R ≥ F1²`(클래스별) 이고 macro 평균에서 `mean(P·R) ≥ mean(F1²) ≥ (Macro-F1)²`(Jensen) 이다.
H 가 등록 F1 의 예측기였다면 `H ≥ 0.9149² = 0.8370` 이어야 하는데 실측 0.8355 다. D 자신의 예측기와는 정합한다 — `0.9128² = 0.8332 ≤ 0.8355`.
이 두 경계를 시험으로 박았다(`test_하드_AP_는_재구성_F1_의_제곱_이상이다`, `test_하드_AP_는_등록_F1_의_예측기가_아니다`).

### 3-4. 함의 — 결론은 안 바뀌고 문구는 바뀐다

- **주 대조선 F(0.9582)는 영향이 없다.** F 는 구간의 클래스 빈도를 점수로 쓰므로 코드 집합 선택과 무관하다. §6 판정(다섯 칸 전부 대조선 아래)은 그대로다.
- **H 는 "등록 F1 예측기의 AP" 가 아니라 "구간 최빈 집합 예측기의 AP" 다.** 등록 F1 의 예측기로 H 를 내면 경계상 ≥ 0.8370 이라 오히려 더 높다 — 어느 쪽이든 최고 칸 0.8229 위다.
- 게이트 판정을 바꿀 크기가 아니라는 §13-3 의 판단은 맞다. 그러나 **"같은 예측기" 라는 진술은 논문 표에 그대로 나가면 틀린 말이 된다.**

### 3-5. D 에 넘기는 것 (D 파일이라 A 가 고치지 않았다)

1. 17번 §11-2 표 H 행의 "등록 상수 0.9149 와 같은 예측기 · 두 축이 한 규칙을 말하게 된다" 와 §12-1 의 "족 선택 절차의 잔차" 를 §3-1 대로 정정.
2. 산출물 `self_check.note` 의 전제("재현하지 못하면 내 재구성이 A 의 규칙과 다른 것") 는 옳았고 실제로 다른 규칙이다 — 다만 0.002 라 결론이 안 바뀐다는 판단도 옳다. 두 문장을 같이 두면 된다.
3. 시드 2·3 대조선 산출 시 H 의 정의를 "구간 최빈 집합" 으로 명시(등록 F1 예측기로 오독되지 않게). F 는 그대로.
4. 원한다면 H 를 등록 F1 의 규칙(`fit_rule` 마스크)으로도 한 벌 더 낼 수 있다 — A 의 `fit_rule` 은 `scripts/recompute_baselines.py` 에서 import 된다. 그 경우 configs 에 `max_macro_ap_hard_f1rule` 로 따로 등록하고 `test_하드_AP_는_등록_F1_의_예측기가_아니다` 는 그 키에 맞춰 A 가 고친다. 지금 블록의 H 는 건드리지 않는다.
