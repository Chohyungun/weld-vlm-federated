### 1-2. (b) 증빙 필드가 실제로 돈 값을 남기는가

- **출처는 실측이다.** `self.val_loader_workers = int(nw)` 의 `nw` 는 `build_dataloader` 가 돌려준 로더 객체의
  `num_workers` 다. `self.args.workers` 같은 설정값이 아니다. `__init__` 에서 None 으로 초기화하므로
  로더가 만들어지기 전에는 "미계측" 이고, 만들어진 뒤에는 0 이다.
- **경로 3홉.** `trainer.val_loader_workers` → `round_runner.py` `RoundResult(val_loader_workers=getattr(trainer, "val_loader_workers", None))`
  → `client_det.py` `"val-loader-workers": float(v if v is not None else -1)` → `round_wiring.py` 원자 행
  `"val_loader_workers": float(m.get("val-loader-workers", -1))`. ②③ 은 `train_cell.py:57` `asdict(result)` 로
  meta.json 에 자동 포함(시드 2·3 부터 0, 시드 1 ②③ 은 키 부재 = None).
- **끊겨도 조용하다.** 세 홉이 전부 `getattr(…, None)`·`m.get(…, -1)` 기본값이라 속성 이름이 한 곳에서라도 어긋나면
  실패 없이 −1 로 격하된다. 세 홉을 한 번에 지나는 시험이 없다(§1-4). 지금 그 배선이 맞는 것은 내가 diff 를 눈으로
  확인한 사실이지 시험이 보증하는 사실이 아니다.
- **오라클은 이것을 판정하지 않는다.** `logs/recover/post_reboot_C.ps1:218-250`(미추적) 의 `Oracle-Round` 는
  sha256·`param_l2`·`global_l2` 만 `$ok` 에 넣고, `val_loader_workers` 행은 L248-249 에서 **로그만** 한다.
  오라클은 정의상 B on/off 를 구분하지 못하므로(등가가 곧 목표), **B 가 실제로 켜졌다는 유일한 기계 증거가 이 행**이다.
  −1 이 나와도 오라클 MATCH 로 통과한다 — run 자체는 유효하지만 "B on"·"−13.7 GB" 기록이 거짓이 된다. → 권고 1.
- 사소: `RoundResult` 주석의 "그 외 = B 가 꺼진 채 돈 실측값" 은 현 구현에서 도달 불가다(단언이 0 이 아니면
  죽이고, 오버라이드를 걷어내면 None). 실질 상태는 {None/−1, 0} 둘이다.

## 2. 과제 2 — 회계·속도 축 계약 통지에 대한 D 의 답

### 2-1. 원자 로그 `val_loader_workers` 지표 행 (라운드당 27→30, 시드 1 원장은 8 지표)

**영향 없음.** D 의 원자 로그 소비자는 `evaluation/rq3.py` 하나이고, `metric_name` 으로 행을 고른다. 궤적
점 수·통신량 누적·마지막 라운드 값 셋 다 새 행에 흔들리지 않는다는 것을 `tests/test_rq3.py` 에 시험 2건으로
박았다(§3). 버전 표(시드 1 = 8 지표, 이후 = 9)는 그대로 받는다 — 파서는 집합의 크기를 세지 않으므로 표는
**사람이 읽는 조건 기록**이지 코드 계약이 아니다.

요청 하나: `-1` 은 "미계측"(15번 §2-3 관례), `0` 은 "B on" 이다. **시드 1 ④ 재실행 원장에 −1 이 나오면 안 된다** —
나오면 증빙 배선이 끊긴 것이다(§1-2). 권고 1 이 그것이다.

### 2-2. accounting.csv 열 불변

### 2-3. 시드 1 ②③ meta.json `val_loader_workers=None`, ④ 재실행 0, 시드 2·3 전부 0

**채점기 영향 없음.** 채점(`scripts/probe/score_cells.py`)은 가중치·예측만 읽고 meta.json 을 읽지 않는다.

읽어야 한다(0 으로 읽으면 시드 1 ②③ 이 B on 으로 둔갑한다).

### 2-4. 속도 축 플래그 4종과 요약 평균 규칙 (15번 G9)

### 2-5. R 착지 시 audit.json 신규 필드 (`resume_events`·`segments`·`restored_cells`·`value_source="restored:accounting.csv"`)

**현재 파서 영향 없음** — D 는 audit.json 을 읽는 코드가 없다. audit.json 을 읽는 것은 `scripts/main_det.py:373-397`(C, `ok`·`failures`·`total_optimizer_steps`)뿐이다.

- `restored_cells` 는 `reconstructed_cells` 와 같은 꼴 `[[round, client], …]`.
