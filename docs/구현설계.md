# 학습·집계·평가 구현 안내

본실험은 비전언어모델이 결함 코드·바운딩박스·인용 조항과 설명문을 생성하는 경로를 사용한다. 분리형 검출기와 검색 기반 판정부의 과거 설계는 현재 통합형 실험과 구분한다.

## 데이터에서 결과까지

데이터 변환은 원본 라벨을 공통 결함 코드와 원본 영상 좌표로 변환한다. 학습·검증·평가 목록은 동결된 분할을 사용한다. 학습 입력은 영상·응답 쌍이고 평가 정답은 학습에 넣지 않는다. 두께와 실치수처럼 원자료에 없는 값은 임의로 채우지 않는다.

`vlm/pilot_vlm.py`는 모델 적재와 미세조정을 담당한다. `vlm/budget.py`는 참여자별 학습량을 결정한다. 같은 초기 어댑터·모델 revision·prompt·전처리를 사용하고 학습기는 감독 토큰(손실을 계산하는 응답 부분의 토큰) 수와 실제 갱신 기록을 남긴다. last 체크포인트가 평가 대상이다.

`fl/client_vlm.py`와 `fl/uni_fed.py`는 참여자별 학습 정보와 집계 기록을 관리한다. 현재 실험의 가중 단위는 감독 토큰이다. 논리적으로 자료를 분리한 시뮬레이션이며 실제 네트워크 환경의 통신 효율을 측정한 결과로 쓰지 않는다.

`vlm/export_model.py` 등 생성 경로는 고정한 모델과 생성 조건으로 출력을 기록한다. 출력은 구조화된 결과와 설명문을 함께 포함한다. 생성 종료 사유와 파싱 결과를 구분해 기록하고 이어 생성한 묶음은 동일한 실험 조건인지 확인한다.

`evaluation/strict_main.py`는 등록된 입력과 결과 묶음의 일치 여부를 검사하고 공통 채점기를 호출한다. `evaluation/strict_narrative.py`는 설명문 및 조항 일치성의 보조 분석을 담당한다. 출력 검증의 통과는 데이터의 독립성이나 전문가 판정의 타당성을 보증하지 않는다.

## 재현 시 확인할 자료

| 자료 | 확인 목적 |
|---|---|
| 등록 당시 설정 사본 | 모델·prompt·학습·생성·평가 조건 확인 |
| 동결 분할 목록과 해시 | 학습·평가 영상 범위 확인 |
| 초기·최종 어댑터와 학습 메타데이터 | 같은 초기 조건과 실제 학습량 확인 |
| 생성 출력과 시도 기록 | 누락·중복·이어 생성의 조건 확인 |
| 정식 채점 산출 | 지표·분모·구간·미산출 항목 확인 |

작업용 설정은 후속 실행 준비 과정에서 바뀔 수 있다. 과거 결과를 재현할 때는 해당 실행에 저장한 설정 사본을 사용한다. 재현에 필요한 자료와 주요 값은 [README 재현 범위](../README.md#재현-범위)에 정리하였다. 자료 접근 권한과 자산이 없는 공개 사본은 바로 실행 가능한 전체 패키지가 아니다.

## 변경 관리

좌표 변환, 라벨 매핑, 실패 처리, 집계 가중, prompt, 생성 한도를 바꾸면 비교 조건도 달라진다. 기존 결과를 새 설정의 결과로 바꾸어 설명하지 않는다.
