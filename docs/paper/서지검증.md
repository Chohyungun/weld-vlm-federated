# 참고문헌의 서지 대조 기록

기록 최종 갱신 2026-09-01 · 공개 문서 편집 2026-10-05  
당시 대조 방법: DOI 해석, arXiv·출판사 페이지, 웹 검색 교차 확인

이 문서는 [문헌 안내](../논문_리스트.md)에 적힌 문헌의 서지 필드를 어디까지 확인했는지
기록한다. 확인 날짜와 남은 항목을 보존했으며 **이번 문서 편집에서는 외부 출처나 원문을
다시 검증하지 않았다.** 확인 표시는 해당 기록의 범위에 한정된다.

| 판정 | 뜻 |
|---|---|
| 확인 | 기록에 명시한 제목·저자·게재지·연도 등을 외부 원천과 대조함 |
| 부분 확인 | 문헌의 존재는 확인했으나 일부 서지 필드 또는 내용의 대조가 남음 |
| 미확인 | 당시 웹 경로로 자료에 도달하지 못함. 서지 오류가 확인됐다는 뜻은 아님 |
| 미수행 | 해당 대조를 하지 않음 |

이 기록에서 보고된 오류 발견은 0건이다. 미확인 항목까지 정확하다는 결론은 아니며,
서지가 확인된 문헌도 아래 별도 행에 권·호·페이지나 인용 위치의 미대조 상태가 남을 수 있다.
유료 원문이나 팀이 보유한 자료는 이 공개 저장소에 포함되지 않는다.

## 7. 최종 인용 전에 남은 확인

당시 대조 가능한 필드에서는 오류를 찾지 못했다. 그러나 정성환·배진수 외·Lee et al.의 2026년
문헌 세 편은 웹 경로로 확인하지 못했다. 색인 지연은 가능한 설명일 뿐 확인된 원인은 아니다.
정성환의 인용문과 Lee et al.의 도메인 격차 수치는 서론·관련 연구의 핵심 근거로 검토 중이므로
원문 PDF 대조 전에 최종 인용으로 확정하지 않는다. 기록된 대조 일정은 **10월 첫 주**다.

IEEE 표준의 네 절은 문헌 존재가 아니라 인용 위치와 정의가 미대조인 경우다. 접근 제한은
유료 라이선스이며, 원문 보유자의 대조가 필요하다. 같은 투고 전 확인 목록에서 관리하되
색인 지연으로 분류하지 않는다. DOI·쪽수처럼 직접 읽지 않은 값도 조판 전에 수동 확인한다.

이 문서의 확인·부분 확인·미확인·미수행 구분을 최종 참고문헌에 반영한다. 확인 상태는 문서의
서식이나 표현을 고쳤다는 이유로 올리지 않는다.
