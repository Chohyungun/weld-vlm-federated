# 결과표 템플릿

작성 2026-08-17 · 실험설계 8-6의 확정판. **모든 수치 칸은 `—` 자리표시자이며,
값은 MLflow에서 스크립트로 추출해 채운다(구현설계 10-1 — 손으로 옮겨 적지 않는다).**

표기 규약

- 분리형 세 칸: 시드 3회 **평균 ± 표준편차** (`0.000 ± 0.000` 형식, 소수 셋째 자리)
- 통합형 두 칸: 1시드 값 + 클라이언트별 분산 병기(각주 c) — 실험설계 6-4. 시드 3회로
  확장되면 분리형과 동일 표기로 전환
- 채점 대상은 전 칸 **last 체크포인트** (best 아님)
- 통신량 0은 실측이 아니라 정의상 0이므로 `0`으로 표기 (자리표시자 아님)
- **회계 셀 인용 규칙 (2026-09-07 계약 통지, 본실험 20번).** 회계 원장(`accounting.csv`)에서
  논문으로 오는 수치(총 갱신 횟수·통신량·라운드 벽시계)는 `value_source == measured` 셀만
  읽는다. 재개 run 의 복원 셀(`restored:*`)과 재구성 셀(`reconstructed`)은 표시만 하고 수치로
  인용하지 않는다. 값 집합은 audit.json `value_source_values` 로 열거되며, 그 밖의 값이 나오면
  추출을 멈춘다. 재개 run 의 접두 라운드(1..k)는 accounting.csv 의 복원 셀이 아니라 **제자리에
  남는 원자 로그의 `measured` 행**에서 읽는다 — 절단은 k 이후 행만 격리하고 1..k 행은 원장에
  그대로 남으며, 마감이 kept_rows sha256 으로 불변을 보증한다(총괄 판정 09-07). 각주에
  "원자 로그 measured 행과 교차 대조됨" 을 적는다.
- **파일 단위 인용 금지 표식이 셀 단위 규칙보다 먼저다.** 고장이 고쳐지기 전 코드로 만든 산출물은
  디렉터리에 `DO_NOT_CITE.md` 표식과 금지 범위(파일 단위)를 달고 나온다. 표식이 막은 파일의 값은
  `measured` 여도 인용하지 않는다. 같은 디렉터리라도 막히지 않은 파일(검출 예측·가중치)은 쓸 수 있다.
- **재개 run.** 분리·연합이 중단 뒤 닫힌 라운드 경계에서 재개된 run 은 무중단 run 과의 등가
  검증(T-eq)을 통과한 경우에만 채점 표에 들어온다. 통과하지 못한 run 은 채점 불가라 표에 없다.
  통과한 run 은 채점 표에서 무중단 run 과 구분하지 않고, 이음매 라운드는 T6-a·T7 에만 표시한다.
- **속도 축 표본·플래그.** 검증 로더 워커 구성(`val_loader_workers`)이 다른 표본은 합산·평균하지
  않는다. 라운드 플래그(이음매·외부 GPU 점유·격리 세그먼트)는 제외가 아니라 표시이며, 요약
  평균은 플래그 라운드 제외 평균과 전체 평균을 둘 다 낸다.

## T2 · 헤드라인 숫자

| 항목 | 정의 | 값 |
|---|---|---|
| 분리형 회복률 | (분리·연합 − 분리·로컬 평균) / (분리·중앙 − 분리·로컬 평균) × 100% ^i^ | — % |
| 통합형 유지율 | 통합·연합 / 통합·중앙 × 100% | — % |
| RQ3 참여 편익 | C3(명목 AL — 별도 취득처)의 분리·연합 − 분리·로컬 (결함 recall 기준) | — %p |
| 분리형 원시 격차 ^j^ | 분리·중앙 − 분리·연합 | — |
| 통합형 원시 격차 ^j^ | 통합·중앙 − 통합·연합 | — |

- 기준 지표는 **Macro-F1로 사전 고정**한다. 결과를 본 뒤 유리한 지표를 고르는 것을 막기
  위해서다. 다른 지표 기준 값은 부록에 병기하고 본문 헤드라인은 Macro-F1 하나로 둔다.
- 회복률 해석 구간 (구현설계 §9): **90% 이상 강한 결과 /
  80~90% 방어 가능 / 80% 미만 = non-IID 심화로 해석하되 클라이언트별 분해를 제시하고
  비반출 조건을 감안해 서술.** 실험설계 8-5의 "70%대 정당화"는 이 3구간 안에서 읽는다.
- ^i^ 분리·로컬 평균은 **3사 단순 평균**(표본 수 가중 아님 — 가중하면 C3 열세가 희석되어
  RQ3 대비가 약해진다).
- 통합형은 로컬 칸이 없어 회복률을 정의할 수 없으므로 유지율로 보고한다(본문 한 문장).
- ^j^ 원시 격차는 IEEE Std 3652.1-2020 §9.3.1의 성능 격차에 대응하며, 위 세 항목과 부호
  방향이 반대다. **값이 작을수록 연합 모델이 중앙집중 모델에 가깝고, 음수는 연합 모델이
  앞섰음을 뜻한다.** 회복률은 이 값을 달성 가능 구간 (중앙 − 로컬 평균)으로 정규화한
  형태이며, `원시 격차 = (중앙 − 로컬 평균) × (1 − 회복률/100)` 으로 서로 환산된다.
  회복률과 유지율은 분모가 달라 두 구조 사이에 비교되지 않는 반면, 원시 격차는 두 구조에
  모두 정의되어 하나의 축에서 나란히 볼 수 있다.
- 참여자 이름은 `C1·C2·C3` 을 쓴다. 데이터에 회사 구분 필드가 없어 회사 이름을 붙이면
  실물에 없는 구분을 지어내는 것이 된다.
- RQ3 뒷받침용 참여자별 분해:

- `T_train_norm` = `T_train` / 학습 표본 수. 참여자의 데이터 규모가 달라 원시 시간끼리는
  비교되지 않는다. 다섯 조건이 같은 학습량 등가 조건에서 돌므로 정규화 값은 그대로 비교된다.
- `T_test_norm` 은 T1의 `처리 속도(ms/장)` 와 같은 값이다. 표준 용어와의 대응을 밝히기 위해
  여기에 다시 싣는다.
- **분리·로컬을 3사 평균으로 접지 않는다.** 표본 수가 다른 세 참여자를 한 줄로 접으면
  정규화의 목적이 사라진다. T1의 평균±sd 규약은 이 표에 적용하지 않는다.
- peak VRAM 은 표준의 `M_intr`(데이터용) + `M_aux`(코드용)에 해당하는 **합계**다. 분리
  측정에는 계측 방식 변경이 필요해 본 연구에서는 수행하지 않으며, 그 사실을 본문에 적는다.
- 통신량은 T1에 둔다. 표준 §9.4의 네 항목에 통신 지표가 없어 대응을 붙이지 않았다.
- ^k^ 분리·연합의 `T_train` 은 progress.jsonl 세그먼트별 벽시계의 합(기동 오버헤드 포함)이며,
  라운드별 값과 플래그는 T6-a 에 있다. 채점 run 의 표본만 싣고, 재개 run 의 접두 라운드는 원자
  로그 measured 행에서 읽는다(표기 규약). 검증 로더 워커 구성이 다른
  속도 표본(시드 1 의 중단 run 2건)은 T6-a 에 별도 블록으로 두고 이 행과 합산하지 않는다.
  시드 1 의 분리·로컬·분리·중앙은 검증 로더 워커를 켠 구성(T7)이나, 트레이너 생성이 3회·1회라
  벽시계 차이는 무시할 수 있다 — 표시만 한다.
- ^l^ 분리·연합의 벽시계는 「트레이너 생성 오버헤드 / 학습」으로 분해해 각주한다. 분해값은 C 의
  트레이서 실측에서 오며 추출 스크립트 밖 항목이라 출처 문서 경로를 병기한다.
- 시드 3세트 평균±sd 는 채점 run(검증 로더 워커 0) 사이에서만 낸다.

   - 1-a. 회계·감사 산출물의 읽기 계약(본실험 20번). 먼저 인용 금지 표식을 기계로 확인한다
     (`scripts/citation_ban.py --check <경로>` — 막힌 파일이 하나라도 있으면 그 파일은 읽지 않는다).
     그 뒤 accounting.csv 는 `value_source == measured`
     행만 수치로 읽고 복원·재구성 행은 T6-a 의 표시 열로만 보낸다. 재개 run 의 접두 라운드는 제자리에
     남는 원자 로그의 measured 행에서 읽는다(마감의 kept_rows sha256 이 불변 보증). audit.json 은 `segments`·
     `closed_prefix_k`·`resume_offset`·`restored_cells` 를 읽고 `value_source_values` 로 값 집합을
     검증한다(밖의 값이면 중단). 두 숫자가 `None` 인 audit.json 은 재개 사전검증에서 멈춘 실행이라
     "재개 판정 불가" 로 읽고 추출 대상에서 뺀다(D 19번 Minor 8). progress.jsonl 의 `segment`·`kind`·`start_round`·`end_round`·`rc`
     에서 분리·연합 총 벽시계(세그먼트 wall 합)를 낸다. `ok` 가 참이 아닌 run 은 추출 대상이 아니다.

     요약 행(플래그 제외 평균·전체 평균)은 둘 다 스크립트가 낸다.
