# 결과표 템플릿

작성 2026-08-17 · 실험설계 8-6의 확정판. **모든 수치 칸은 `—` 자리표시자이며,
값은 MLflow에서 스크립트로 추출해 채운다(구현설계 10-1 — 손으로 옮겨 적지 않는다).**

표기 규약

- 분리형 세 칸: 시드 3회 **평균 ± 표준편차** (`0.000 ± 0.000` 형식, 소수 셋째 자리)
- 통합형 두 칸: 1시드 값 + 클라이언트별 분산 병기(각주 c) — 실험설계 6-4. 시드 3회로
  확장되면 분리형과 동일 표기로 전환
- 채점 대상은 전 칸 **last 체크포인트** (best 아님)
- **헤드라인은 신뢰도 임계에 독립인 지표로 낸다** (2026-09-08 총괄 판정 22번). 임계에 의존하는
  축은 한 점으로 접지 않고 스윕 곡선 전 구간(T2-a)으로 싣는다. 단일 임계는 등록하지 않고
  **스윕 격자를 등록**한다.
- **격자는 사전등록이 아니다.** 격자가 설정 파일에 들어간 것은 시드 1 채점이 끝난 뒤다
  (`configs/base.yaml` 머리말·의사결정로그 2026-09-08 기록). 시드 2·3 에 대해서는 사전 고정이고,
  시드 1 에 대해서는 사후다. **등록 시점을 숨기지 않는다** — 표기는 "등록 격자"이며
  "사전등록 격자"로 쓰지 않는다. 선후 표는 본문 §4.4.
- 통신량 0은 실측이 아니라 정의상 0이므로 `0`으로 표기 (자리표시자 아님)
- **회계 셀 인용 규칙 (2026-09-07 계약 통지, 본실험 20번).** 회계 원장(`accounting.csv`)에서
  논문으로 오는 수치(총 갱신 횟수·통신량·라운드 벽시계)는 `value_source == measured` 셀만
  읽는다. 재개 run 의 복원 셀(`restored:*`)과 재구성 셀(`reconstructed`)은 표시만 하고 수치로
  인용하지 않는다. 값 집합은 audit.json `value_source_values` 로 열거되며, 그 밖의 값이 나오면
  추출을 멈춘다. 재개 run 의 접두 라운드(1..k)는 accounting.csv 의 복원 셀이 아니라 **제자리에
  남는 원자 로그의 `measured` 행**에서 읽는다 — 절단은 k 이후 행만 격리하고 1..k 행은 원장에
  그대로 남으며, 마감이 kept_rows sha256 으로 불변을 보증한다(총괄 판정 09-07). 각주에
  "원자 로그 measured 행과 교차 대조됨" 을 적는다.
- **파일 단위 인용 금지 표식이 셀 단위 규칙보다 먼저다.** 고장이 고쳐지기 전 코드로 만든 산출물은
  디렉터리에 `DO_NOT_CITE.md` 표식과 금지 범위(파일 단위)를 달고 나온다. 표식이 막은 파일의 값은
  `measured` 여도 인용하지 않는다. 같은 디렉터리라도 막히지 않은 파일(검출 예측·가중치)은 쓸 수 있다.
- **재개 run.** 분리·연합이 중단 뒤 닫힌 라운드 경계에서 재개된 run 은 무중단 run 과의 등가
  검증(T-eq)을 통과한 경우에만 채점 표에 들어온다. 통과하지 못한 run 은 채점 불가라 표에 없다.
  통과한 run 은 채점 표에서 무중단 run 과 구분하지 않고, 이음매 라운드는 T6-a·T7 에만 표시한다.
- **속도 축 표본·플래그.** 검증 로더 워커 구성(`val_loader_workers`)이 다른 표본은 합산·평균하지
  않는다. 라운드 플래그(이음매·외부 GPU 점유·격리 세그먼트)는 제외가 아니라 표시이며, 요약
  평균은 플래그 라운드 제외 평균과 전체 평균을 둘 다 낸다.

## T2 · 헤드라인 — 임계 독립 지표

|---|---|---|---|

- ^n^ **기준 지표를 임계 독립 지표로 둔다.** 평균 정밀도는 정밀도-재현율 곡선 전 구간에서
  산출되므로 신뢰도 임계를 고를 필요가 없다. 분류 축(Macro-F1·결함 놓침)은 임계를 고르는
  순간 값이 정해지고, 그 값이 임계에 따라 부호까지 바뀐다는 것이 실측됐다 — 그래서 헤드라인이
  아니라 곡선(T2-a)으로 싣는다.
- ^o^ 통합형은 검출 신뢰도 점수가 없어 출력이 구조적으로 한 점이다. **고를 임계가 없으므로**
  통합형의 Macro-F1 은 임계 의존이 아니고, 유지율의 기준 지표로 그대로 쓴다. 두 헤드라인은
  기준 지표가 달라 한 축에서 비교되지 않는다 — 회복률과 유지율의 분모가 다른 것과 같은 이유다.
  통합형의 평균 정밀도는 곡선이 한 점으로 축약되므로 참고치이며(T1 각주와 §4.2) 헤드라인에
  쓰지 않는다.
- **분류 축의 단일 임계 값은 헤드라인이 아니다.** 표·부록에 남기되 한 줄 결론으로 인용하지
  않는다.
- ^p^ **RQ2 는 점 대 곡선으로 읽는다** (2026-09-08 총괄 판정 22번 §3-1). 통합형의 한 점이
  분리형 곡선의 어디에 놓이는지를 보고, 보고 형식은 **"분리형 연합이 통합형과 같은 값을 내는
  임계 구간"** 이다. 구간을 보고하므로 분리형에서 임계 한 점을 고르지 않으며, 단일 임계 금지와
  충돌하지 않는다. 축마다 구간이 다르므로 두 분류 축(Macro-F1·결함 놓침) 각각에 대해 낸다 —
  T2-a 요약 행.
  **전제 확인(통합형 착수 전, C·D 소관).** 통합형 출력에서 박스별 신뢰도를 낼 수 있는지 먼저
  확인한다. 낼 수 있으면 통합형도 같은 격자로 곡선을 내고 **곡선 대 곡선**으로 비교한다(이쪽이
  낫다). 못 내면 위 점 대 곡선으로 가되, 임계 독립 지표가 통합형에 정의되지 않으므로 **RQ2
  헤드라인은 임계 독립 지표가 아니라 점 대 곡선 서술임을 논문에 명시한다** — RQ1 과 헤드라인의
  종류가 다르다.
- **격자는 등록물이고 단일 임계는 등록하지 않는다.** 격자(`configs/base.yaml` 의
  `conf_sweep_grid`, 14점)는 모든 시드·조건이 같은 것을 쓴다. 단일 임계 키는 설정 파일에
  **일부러 없고** 그 부재가 시험으로 고정돼 있다.
  **등록 시점은 시드 1 채점 이후다 — 사전등록이 아니다.** 그런데도 결과에 맞춰 고른 것이
  아닌 근거는 둘이다. 첫째, 격자는 값 선택이 아니라 **관측 범위**다 — 어느 점을 결론에
  쓰느냐가 아니라 어느 구간을 전부 보이느냐를 정한 것이고, 표는 전 구간을 싣는다. 둘째,
  14개 값 자체는 본실험 착수 전 채점 코드에 박혀 있었고 시드 1 이 그대로 썼다 — 결과를 본 뒤
  더해지거나 빠진 점이 없으며 바뀐 것은 값이 놓인 자리(코드 상수 → 설정 파일)뿐이다.
  격자에서 한 점을 골라 결론에 쓰는 것은 그대로 금지된다.
- **운용점 예시.** 신뢰도 0.25 는 파일럿의 폴백 상수에서 왔고, 등록 격자에서 고른 점이
  아니다. 현장 운용점의 예시로만 표기하며 **확증적 기준이 아니다.** 이 값을 고른 이유를
  결과로 정당화하지 않으며 게이트 재료로도 쓰지 않는다.
- ^q^ **분류 축 대표 지표는 아직 조건부다** (2026-09-08 총괄 판정 22번 §5). 이미지 수준
  macro-AP 로 지정하되, **그 축의 무내용 대조가 산출되고 값이 확인된 뒤에 확정한다.** 이유는
  이 연구가 늘 대조해 온 무내용 규칙(화소를 보지 않고 촬영 순서 분위만 쓰는 규칙)의 기준선이
  Macro-F1 축에만 있었기 때문이다. 대조선을 함께 옮기지 않으면 화소를 보지 않는 규칙이 다섯
  조건을 전부 이길 수 있다. **확정 전까지 이 축의 회복률 값을 대표 숫자 후보로 적지 않는다.**
  무내용 규칙에는 신뢰도가 없어 평균 정밀도를 내려면 점수 구성을 정해야 하는데, 값을 본 뒤
  고르면 임계에서 피하려던 잘못을 되풀이하는 것이므로 **구성을 산출 전에 문서로 고정한다.**
  위치 축(mAP@0.5)은 확정 상태다.
- 회복률 해석 구간 (구현설계 §9): **90% 이상 강한 결과 / 80~90% 방어 가능 / 80% 미만 =
  non-IID 심화로 해석하되 클라이언트별 분해를 제시하고 비반출 조건을 감안해 서술.**
  이 구간은 **임계 독립 헤드라인에만** 적용한다. 곡선 위의 점에는 적용하지 않는다 — 임계를
  옮기면 같은 모델이 세 구간을 다 지나가므로 구간 판정이 의미를 잃는다. 실험설계 8-5의
  "70%대 정당화"도 헤드라인 값에 대해서만 읽는다.
- **분모 안정성이 판정되기 전에는 어떤 회복률도 헤드라인이 아니다.** 회복률의 분모는
  (중앙집중 − 로컬 평균)이고, 그 폭이 시드 사이에서 안정한지는 시드 3세트의 표준편차가
  나온 뒤에 판정한다. 시드 1세트만으로는 판정 자체가 불가능하다.
- ^i^ 분리·로컬 평균은 **3사 단순 평균**(표본 수 가중 아님 — 가중하면 C3 열세가 희석되어
  RQ3 대비가 약해진다).
- 통합형은 로컬 칸이 없어 회복률을 정의할 수 없으므로 유지율로 보고한다(본문 한 문장).
- ^j^ 원시 격차는 IEEE Std 3652.1-2020 §9.3.1의 성능 격차에 대응하며, 위 세 항목과 부호
  방향이 반대다. **값이 작을수록 연합 모델이 중앙집중 모델에 가깝고, 음수는 연합 모델이
  앞섰음을 뜻한다.** 회복률은 이 값을 달성 가능 구간 (중앙 − 로컬 평균)으로 정규화한
  형태이며, `원시 격차 = (중앙 − 로컬 평균) × (1 − 회복률/100)` 으로 서로 환산된다.
  회복률과 유지율은 분모가 달라 두 구조 사이에 비교되지 않는 반면, 원시 격차는 두 구조에
  모두 정의되어 하나의 축에서 나란히 볼 수 있다.
- 참여자 이름은 `C1·C2·C3` 을 쓴다. 데이터에 회사 구분 필드가 없어 회사 이름을 붙이면
  실물에 없는 구분을 지어내는 것이 된다.

  코드). 값이 다른 표본은 합산·평균하지 않는다. `-1` 이 나오면 증빙 배선이 끊긴 것이므로 채우지 않고
  보고한다.
- 요약 평균은 두 열을 항상 함께 싣는다. 한 열만 싣는 것은 제외 규칙을 만드는 것이 된다.
- 이 표는 부록이다. 본문 T6 의 ^k^ 각주가 여기를 가리킨다.

     남는 원자 로그의 measured 행에서 읽는다(마감의 kept_rows sha256 이 불변 보증). audit.json 은 `segments`·
