# 논문 그림의 구성과 해석 범위

작성 2026-08-17 · 공개 문서 편집 2026-10-05  
연구 범위와 설정은 [논문 본문 초안](본문_초안.md)의 2026-10-01 기준을 따른다.

이 문서는 그림이 설명해야 할 내용과 결과를 표시하는 방법을 정리한다. 본실험은 통합형 모델의
로컬 단독·중앙집중·연합학습을 비교하는 계획이며 결과는 아직 없다. 분리형 검출기의 세 학습
조건은 완료된 사전실험이다. 두 실험을 구조 비교처럼 나란히 제시하지 않는다.

2026-08-17에는 설계 통합 1장, 갈래별 상세 3장, 결과 2장을 구상했다. 현행 포스터의 기본 구성은
F1·F3·F4이며, F2는 사전실험 설명에 필요한 경우에만 사용한다. 결과 그림은 해당 산출물이
확인된 범위에서 선택한다. 이 문서는 그림 명세이며 기존 SVG가 아래 조건을 모두 반영했다는
뜻은 아니다.

## 0. 공통 표현 규칙

| 항목 | 규칙 |
|---|---|
| 배경 | 흰색. 회색조 음영은 허용하며 배경색 채움은 쓰지 않는다 |
| 용어 | 처음 읽는 독자가 이해할 한국어를 사용하고, 전문 약어는 캡션에서 설명한다 |
| 모델·지표명 | 그림 안은 짧은 설명, 캡션은 정식 모델명과 지표명 |
| 범례 | 학습 부분은 실선 테두리와 옅은 채움, 고정 부분은 회색, 데이터는 문서 모양, 가중치 이동은 굵은 화살표, 데이터 이동 없음은 차단(⊘) 표시 |
| 상태 | 본실험 계획·사전실험 결과·선택적 확장을 그림과 캡션에서 구분한다 |
| 자리표시자 | 아직 측정하지 않은 수치는 `{}`. 예시 수치나 임의의 결과 곡선을 넣지 않는다 |
| 파일 | `docs/paper/figures/` 아래 SVG 원본과 PNG 내보내기. 파일명은 `F1_설계통합` 형식 |

### 그림 안 표기와 캡션 용어

| 그림 안 표기 | 캡션에서 설명할 용어·범위 |
|---|---|
| 가중치만 주고받는 학습(연합학습) | Federated Learning, FedAvg. 통합형은 어댑터만 교환 |
| 그림·글 통합 모델 | VLM, Qwen3.5 4B |
| 검출 모델 | YOLO11s, 사전실험에 사용 |
| 어댑터(작은 추가 가중치) | LoRA / QLoRA |
| 규정 조항 찾기 / 규정 색인 | RAG(검색 증강). 분리형 판정부의 이전 설계·선택적 확장에만 해당 |
| 판정문 | 현재는 결함 종류·위치·해당 조항의 서술. 실이미지의 치수 기준 합부는 출력하지 않음 |
| 방사선 촬영 사진(엑스레이) | RT(Radiographic Testing) |
| 위치 정확도 | 사전실험은 mAP@0.5, 통합형 본실험의 대표 지표는 미정. IoU 등은 정의를 캡션에 병기 |
| 참여자 C1·C2·C3 | 데이터로 구성한 역할. 실제 회사·취득처·실측 재질을 확인한 집단이 아님 |

모든 그림에서 C1·C2는 명목 재질 라벨 ST, C3는 명목 재질 라벨 AL로 쓴다. C3를 실제 알루미늄
자료나 다른 조선소로 단정하지 않는다. 회사·촬영 장소·실측 재질은 확인되지 않았다.
연합학습의 산업적 동기를 설명할 때와 공개 데이터로 구성한 실험을 설명할 때도 이 구분을 유지한다.

## 1. F1 — 연구 설계 전체

처음 보는 사람이 30초 안에 같은 모델을 세 학습 방식으로 학습해 같은 평가 자료와 채점기로 비교한다는
구성을 읽을 수 있게 한다. 포스터의 첫 그림이다.

### 배치

왼쪽에는 방사선 사진 62,308장을 놓고, 평가셋을 먼저 분리한 뒤 참여자를 나누는 순서를 그린다.

| 데이터 흐름 | 표기 |
|---|---|
| 평가셋 선분리 | 채점용 20%, 12,461장. 참여자 분할 전에 분리하며 학습에는 사용하지 않음 |
| 학습 풀 | 49,847장. C1·C2·C3으로 분할 |
| 학습 페어 | 유효한 페어 49,845장. 상자가 없는 2장 제외 |
| 본실험 채점 계획 | 동결 평가셋 12,461장 전량. 모든 모델·학습 시드·대조선에 같은 목록 적용 |

가운데에는 통합형 모델의 세 학습 방식을 배치한다. 로컬 단독은 참여자별 모델 셋을 작은 상자
셋으로 표현하고, 중앙집중과 연합은 모델 하나씩으로 표현한다.

| 열 | 그림 안 설명 |
|---|---|
| 로컬 단독 | 각 참여자가 자기 자료로 학습 |
| 중앙집중 | 전체 학습자료를 모아 학습하는 비교 기준 |
| 연합학습 | 자료는 각 참여자에 두고 어댑터만 교환 |

중앙집중은 데이터 반출이 제한된 현장의 도입안이 아니며 보장된 성능 상한도 아니라는 설명을
캡션에 둔다. 로컬 단독은 회복률과 참여자별 변화를 계산하는 데 필요하므로 제외 칸을 만들지 않는다.

오른쪽에는 공통 채점기를 놓고 다섯 모델의 출력을 연결한다. 사전실험을 함께 표시한다면
아래에 옅은 줄로 검출기 세 학습 조건을 두고, 통합형과 점수 크기를 직접 비교하는 선은 그리지 않는다.
규정 색인과 상세 지표는 이 그림에 넣지 않는다.

### 캡션 초안

> 그림 1. 통합형 본실험의 세 학습 방식. 로컬 단독은 참여자별 모델 셋, 중앙집중과 연합은 각각
> 모델 하나를 만든다. 평가셋은 참여자 분할 전에 분리하고 모든 모델을 같은 채점기로 평가한다.
> C1·C2·C3은 명목 라벨과 규모가 다른 자료로 구성한 역할이다. 본실험은 계획 단계이며,
> 평가셋과 학습 자료의 근사 중복 때문에 결과의 해석은 현행 분할에서의 탐색적 비교로 제한된다.
> 아래 옅은 줄을 표시하는 경우에는 검출기만으로 완료한 사전실험을 뜻한다.

## 2. F2 — 분리형 사전실험과 선택적 판정부 확장

2026-09-18에 구조 비교가 본실험에서 제외됐다. 분리형은 검출 단계까지 사전실험을 마쳤으며,
검출기와 판정부를 연결하는 과업은 수행 여부가 정해지지 않았다. 포스터에서는 F2를 생략하는
것이 기본이다. 포함한다면 완료한 검출 단계와 선택적 확장을 분리해서 그린다.

### 완료된 범위

방사선 사진 → 검출 모델 → 결함 종류·위치(픽셀 상자)로 표시한다. 검출 모델은 학습 대상으로
채우고, 사전실험의 분리형 연합 조건에서 검출 모델 전체 가중치를 교환했다는 설명을 캡션에 둔다.
상자의 픽셀 크기를 실제 치수로 표시하지 않는다.

### 이전 설계에 있던 판정부

아래 흐름은 판정부의 작동 구상을 설명할 때만 점선으로 덧붙인다.

1. 검출 결과와 결함 종류·크기·판 두께·품질 수준을 질의 키로 구성한다.
2. 규정 색인에서 조항 3건을 찾는다. 색인은 학습·교환·평균의 경계 밖에 두고 동일본 사용을 표시한다.
3. 고정된 판정 모델이 검출 결과와 찾은 조항을 받아 판정문을 생성한다.

이전 설계에는 합격/불합격 출력이 있었지만, 실이미지에는 판 두께와 픽셀→mm 환산 정보가 없다.
현재 데이터로 치수 기준 합부를 검증한 것처럼 그리지 않는다. 합성 수치의 규칙 적용과 실제
용접부의 합부 정확도도 구분한다.

### 캡션 초안

> 그림 2. 분리형 검출기의 사전실험 범위. 완료한 단계는 사진에서 결함 종류와 위치를 찾는 검출이다.
> 점선으로 표시한 규정 검색과 고정 판정 모델은 선택적 확장 구상이며 수행 결과가 아니다.
> 규정 색인은 학습·교환 대상이 아니다. 실제 치수 정보가 없는 현재 영상에는 치수 기준 합부를
> 산출하지 않는다.

## 3. F3 — 통합형 본실험의 입력과 출력

사진에서 구조화된 판정 서술을 생성하는 과정과 학습 대상이 어댑터뿐이라는 점을 설명한다.
이 그림은 통합형의 구성을 보여 주며 분리형과의 구조 비교를 뜻하지 않는다.

### 배치

- 방사선 사진을 큰 모델 상자에 연결한다.
- 상자 안에 고정된 기본 모델과 학습되는 작은 어댑터를 구분한다. 기본 모델은 Qwen3.5 4B,
  학습 방식은 4비트 QLoRA로 캡션에 적는다.
- 출력은 결함 종류·원본 픽셀 좌표 상자·해당 규정 조항 후보를 담은 구조화 출력(JSON) 하나다.
- 합격/불합격은 출력 항목에 넣지 않는다. 명목 AL 결함은 허용치 표의 범위 밖이어서 조항을
  특정하지 않고 사유를 적는다는 제한을 캡션에 설명한다.
- 별도 규정 검색은 붙이지 않는다. 생성문에서 인용한 조항이 맞는지는 인용 일치율과 무근거
  인용률로 평가할 계획이다.

### 캡션 초안

> 그림 3. 통합형 본실험의 구성. Qwen3.5 4B의 기본 가중치를 4비트로 고정하고 QLoRA 어댑터를
> 학습해 결함 종류·위치·해당 조항의 후보를 생성한다. 규정을 따로 검색하지 않으며 인용의
> 정확성은 별도로 평가한다. 실이미지의 치수 기준 합부는 출력하지 않는다. 허용치 표의 사람
> 이중 검수와 학습 페어의 사실성 검수는 아직 끝나지 않았다.

## 4. F4 — 연합학습의 한 라운드

참여자별 자료는 이동하지 않고 어댑터만 서버를 오가는 순환을 그린다. RQ3은 세 참여자 모두의
성능 변화를 묻기 때문에 C3만 참여 이득의 대상으로 강조하지 않는다.

### 참여자와 서버

| 참여자 상자 | 학습 풀 규모 | 캡션에서 설명할 차이 |
|---|---|---|
| C1 — 명목 ST | 26,451장 | C2와의 클래스 편중은 Dirichlet 분할로 구성 |
| C2 — 명목 ST | 16,253장 | C1과 같은 명목 라벨 |
| C3 — 명목 AL | 7,143장 | 명목 라벨·관측 클래스 분포·규모가 다름. 실제 취득처·재질은 미확인 |

각 상자 경계에 ⊘와 “사진은 참여자 밖으로 나가지 않음”을 표시한다. 산업의 비반출 조건을
모사한 것이며 실제로 서로 다른 회사가 참여한 실험이라는 인상을 주지 않는다.

본실험 서버의 문구는 “어댑터를 감독 토큰 수로 가중 평균”이다. 감독 토큰은 학습 손실을
계산하는 정답 출력 토큰이며 페어 수와 다른 단위다. 봉인 페어의 epoch당 값은
C1 2,211,295·C2 854,010·C3 336,841, 중앙집중 합계 3,402,146이다(본문 §5.3).
사전실험의 검출기 전체 가중치 집계는 참여자 표본 수를 사용했으며 본실험과 구분한다.

순환은 ① 서버의 어댑터 배포 → ② 참여자별 자기 자료 학습 → ③ 학습된 어댑터 반환 →
④ 가중 평균 → ①로 그린다. “`{R}`회 반복”으로 표시하고 R·E·N은 미정임을 캡션에 적는다.
왕복량의 빈칸을 실측 통신량처럼 보이지 않게 한다.

| 교환물 | 수치 표시 |
|---|---|
| 통합형 본실험 | 어댑터 `{} MB`. 실행 후 측정 범위와 함께 기록 |
| 분리형 사전실험 | 검출 모델 전체 `{} MB`. 상향 배열 바이트 기준 |

규정 색인은 통합형 본실험의 구성요소가 아니므로 이 순환도에 넣지 않는다. 분리형 판정부를
설명하는 경우에는 F2에서 교환·평균 대상 밖에 둔다.

### 캡션 초안

> 그림 4. 통합형 연합학습의 라운드. 각 참여자는 자기 자료로 학습한 어댑터만 서버로 보내고,
> 서버는 감독 토큰 총합을 가중치로 평균한다. C1·C2 사이의 편중은 연구자가 구성한 조건이며
> 명목 ST·AL 사이의 관측 분포 차이와 구분한다. 단일 GPU 시뮬레이션을 계획하고 있으며
> 실제 분산 환경의 통신·지연을 측정하는 실험은 아니다. 교환량은 배열 원소의 바이트 합이다.
> 사전실험의 하향 값은 따로 계측하지 않았고 상향 값을 복제했으므로, 두 방향 합을 보고할 때는
> 상향의 두 배임을 밝힌다. 직렬화·전송 부가량과 실제 회선 바이트는 포함하지 않는다.

| F2 | §6.1·§6.2·§7.3 | 완료된 검출기 사전실험과 선택적 판정부 |
| F3 | §5.2·§7.3 | 본실험 모델, 어댑터 학습, 조항 수준 출력 |
| F4 | §4.2·§5.3·§6.6 | 참여자 구성, 감독 토큰 가중 집계, 교환량의 범위 |

F1·F3·F4가 기본 구성이며 F2는 지면이 남거나 판정부 연결을 실제로 수행했을 때 추가한다.
F2와 F3를 나란히 놓아 두 구조의 성능 비교로 읽히게 하지 않는다.

## 6. 결과 그림 후보

결과 그림의 사용 여부는 본실험과 사전실험에서 따로 판단한다. 아래 제목은 후보이며 미완료
그림에 임의 수치나 예시 곡선을 넣지 않는다.

| 후보 | 내용 | 상태와 채택 조건 |
|---|---|---|
| R1 회복률·참여자별 변화 | 본실험 다섯 모델의 대표 지표와 화소 비사용 규칙, 회복률, 참여자별 절대 변화(%p) | 본실험 결과와 대표 채택 판정 이후. 대표 지표는 미정 |
| R2 라운드별 성능 | 연합 모델의 라운드별 성능과 중앙집중 참조선 | 본실험·사전실험을 구분. 라운드 수가 1이면 반복 집계의 효과나 수렴 경향을 해석하지 않음 |
| R3 클래스×참여자 분포 | 명목 라벨에 따른 분포 차이와 연구자가 구성한 편중 | 결과가 아닌 설계 절 삽입 후보. 지면 부족 시 우선 생략 |
| R4 RQ3 참여자별 변화 | C1·C2·C3의 로컬 단독과 연합 비교 | R1에서 충분히 설명되면 생략. C3만 실제 소기업처럼 강조하지 않음 |
| R5 신뢰도 임계 스윕 | 사전실험의 Macro-F1·결함 놓침 축과 회복률 변화 | 2026-09-08에 채택한 사전실험 결과 그림. 세부 규약은 §7 |
| R6 판별력 | Δ_AUC와 대응 차 신뢰구간, 메타데이터 대조선 | 보조 분석. 세 시드 집계만으로 대표 지표에 올릴 근거는 없음 |

R6의 구안은 화소를 보지 않는 규칙이 모두 정확히 0이라고 설명했으나, 현재 본문 §8.1에는
촬영 순서 규칙이 시드 1 연합·중앙집중보다 높은 값을 낸 반례가 기록돼 있다. 같은 점수를 내는
상수 규칙만 정의상 0이다. R6에 “지름길을 통과할 수 없는 축”이라는 문구를 쓰지 않는다.

## 7. R5 — 사전실험의 신뢰도 임계 스윕

R5는 분리형 검출기 사전실험의 그림이다. 구조 비교는 2026-09-18에 본실험 범위에서 제외됐다.
곡선은 [결과표 템플릿](결과표_템플릿.md)의 T2-a와 같은 스윕 산출물로 생성한다.
SVG 경로를 손으로 만들어 결과 모양을 그리지 않는다.

### 7-1. 확인할 관계

| 관계 | 표현 |
|---|---|
| 임계에 따른 회복률 변화 | 등록 격자 전 구간의 곡선 |
| 부호가 바뀌는 구간 | 0% 기준선과 교차 구간 표시 |
| 연합과 중앙집중의 순서 | 시드별 원 점수 비교를 요약한 띠 |
| 파일럿 운용점 | 세로 점선 하나와 “운용점 예시” 표기 |
| 실측점과 점 사이 연결 | 격자점마다 표식, 점 사이는 직선 |
| 화소 비사용 대조선과의 관계 | 같은 단위의 원 점수 패널에 모델과 대조선을 함께 표시 |

원 점수와 회복률은 단위가 다르므로 대조선의 원 점수를 회복률 축에 그대로 겹치지 않는다.
결함 놓침 비율과 Macro-F1도 좋음의 방향이 달라 별도 패널로 둔다. 기존 구안에 있던 예시
곡선은 실제 산출물이 아니므로 완성 그림에 사용하지 않는다.

### 7-2. 축과 배치

결함 놓침 축을 위, Macro-F1 축을 아래에 놓은 두 패널로 구성한다. 가로축은
`configs/base.yaml`의 `conf_sweep_grid` 14점 그대로 사용한다. 임계점을 임의로 더하거나
빼지 않는다. 점마다 실측 표식을 두고 직선 연결은 점 사이의 안내임을 구분한다.

0% 기준선은 굵게 표시한다. 선 위·아래의 의미는 해당 지표의 좋음 방향과 회복률 분모를 함께
확인해 설명한다. 미정의 회복률은 선으로 연결하지 않고 사유를 표시한다. 원 점수 패널에는
화소를 보지 않는 규칙을 같은 지표로 함께 표시한다.

연합과 중앙집중의 순서는 회복률 곡선만으로 설명하지 않는다. 별도 띠에 시드와 임계 구간별
대소를 표시한다. 시드 1의 사용 격자 전 구간에서는 중앙집중이 앞섰다는 관측이 있으나,
다른 시드·지표·평가 모집단까지 같은 관계라고 미리 그리지 않는다.

### 7-3. 시드와 등록 시점

세 시드의 곡선을 옅게 겹치고 평균 곡선을 덧붙이거나 평균±표준편차 띠를 사용한다.
부호가 바뀌는 임계가 시드마다 얼마나 이동하는지 읽을 수 있어야 한다.
조건별 색만으로 구분하지 않고 실선·파선·점선을 함께 써 흑백에서도 읽히게 한다.

14점 격자는 시드 1 채점 뒤 설정 파일에 등록됐다. 값 자체는 실험 착수 전 채점 코드에 있었고
시드 1도 그 값을 사용했다. 시드 2·3에는 사전에 고정돼 있지만 전체를 “사전등록 격자”라고
부르지 않는다. 등록 시점은 본문 §7.4의 표와 함께 제시한다.

파일럿의 신뢰도 0.25는 등록 격자에서 고른 점이 아니다. 운용점 예시로만 표시하며 확증적 기준이나
대표 수치 채택의 근거로 사용하지 않는다. 곡선이 만나도록 격자를 늘리는 것도 허용하지 않는다.

### 7-4. 캡션 초안

> 그림 5. 사전실험 검출기의 판단 기준선에 따른 회복률 변화. 위는 결함 놓침 비율,
> 아래는 Macro-F1이다. 회복률은 (연합 − 로컬 단독 평균) / (중앙집중 − 로컬 단독 평균) × 100으로
> 계산하며, 분모와 지표 방향을 함께 읽는다. 가로축은 등록 격자 14점이고 표식은 실측점이다.
> 격자는 시드 1 채점 뒤 등록돼 사전등록이 아니다. 세로 점선은 파일럿의 운용점 예시다.
> 조건 간 대소는 별도 띠에, 화소 비사용 규칙과의 차이는 같은 단위의 원 점수 패널에 표시한다.
> 본실험 통합형의 점수는 이 그림에 함께 놓지 않는다.
