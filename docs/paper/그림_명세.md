# 연구 설계와 결과 그림

통합형 본실험의 설계도와 사전실험의 결과 도표를 구분한다. 결과가 없는 항목에는 수치를 넣지 않는다.

## 0. 공통 규칙 (전 그림 적용)

| 항목 | 규칙 |
|---|---|
| 배경 | **흰색.** 회색조 음영은 허용, 배경색 채움 금지 |
| 용어 | 평이한 한국어. 전문 약어·내부 용어 금지 — 처음 보는 사람 기준 |
| 지표·모델명 | 본문 캡션에서만 정식 명칭 병기. 그림 안에는 평이어 |
| 범례 | 4그림 공통: 학습되는 부분=실선 테두리+옅은 채움 / 고정(동결)된 부분=회색 / 데이터=문서 모양 / 가중치 이동=굵은 화살표 / 데이터 이동 없음=차단(⊘) 표시 |

## 1. F1 · 연구 설계 통합도

**목적** 처음 보는 사람이 30초 안에 "같은 모델을 세 가지 방식으로 학습해 같은 데이터·같은 채점기로
비교하는 실험"임을 이해하게 한다. 포스터의 첫 그림.

**구성 요소 (좌→우 3단)**

1. **데이터 단** — 용접 방사선 사진 62,308장(문서 아이콘). 아래로 두 갈래:
   "채점용 20% — **가장 먼저 분리**, 어떤 학습에도 쓰지 않음" / "학습용 80% → 참여자 C1·C2·C3에 분배".
2. **학습 방식 세 열** — 통합형(사진을 넣으면 판정문까지 한 번에) 한 줄에 3열
   (로컬 단독 / 중앙집중 / 연합학습). 로컬 단독 칸은 세 참여자의 모델 셋임을 작은 상자 셋으로 보인다.
   분리형(검출 모델 + 판정 모델 분업)은 **사전실험**으로 아래에 옅게 한 줄 둔다. 각 열 머리에 한 줄 정의:
   - 로컬 단독 "각 참여자가 자기 데이터로만"
   - 중앙집중 "모든 데이터를 한곳에 모음 — **현실에서는 불가, 전체 학습자료를 쓰는 비교 기준**"
   - 연합학습 "데이터는 두고 학습된 가중치만 교환"
3. **채점 단** — 모든 조건의 출력이 **하나의 공통 채점기**로 수렴하는 화살표.
   채점기 상자 안에 "같은 채점용 사진, 같은 기준" 한 줄.

로컬 단독·중앙집중·연합학습을 모두 표시한다. 참여자별 단독 모델은 회복률과 참여자별 성능 변화의 비교 기준이다.

**금지** 규정 색인은 이 그림에 넣지 않는다. F2와 F4에서 다룬다. 지표명·모델명도 노출하지 않는다.

**캡션 골자** "통합형의 세 학습 방식(로컬 단독은 참여자별 모델 셋). 채점용 데이터는 참여자별 분배 전에
분리하며 모든 조건을 동일한 채점기로 평가한다. 아래 옅은 줄은 검출기만으로 먼저 돌린 사전실험이다."

## 2. F2 · 분리형 파이프라인 (사전실험 — 포스터 필수 아님)

분리형 사전실험에서 측정을 마친 범위는 검출 단계까지다. 규정 검색과 판정 모델의 연결은 측정 결과가 없는 구성으로 구분한다.

**목적** "숫자를 만드는 검출"과 "규정을 찾아 판정하는 언어 모델"의 분업, 그리고
**규정 색인이 학습·평균 대상이 아님**을 보인다.

**구성 요소 (좌→우)**

1. 방사선 사진 → **검출 모델**(실선=학습됨): 출력 "결함 종류 · 위치(상자) · 크기" — 숫자
2. 구조화 질의 키 상자: {결함 종류, 크기, 판 두께, 품질 수준} → **규정 조항 찾기**
3. **규정 색인** 상자는 **점선 경계 바깥**에 배치, 라벨: "규정 색인 — 공개 규정 문서.
   **학습하지 않고 모든 참여자가 동일본 사용**". 색인→조항 찾기로 화살표
4. **판정 모델**(회색=고정): 입력 "검출 결과 + 찾은 조항 3건" → 출력 **판정문**
   (관련 조항과 치수 정보 부족에 따른 판정 한계; 실이미지 합부 판정 제외)

**핵심 시각 장치** 학습되는 것은 검출 모델 하나뿐임을 채움색으로 대비. 연합학습에서
교환되는 것도 검출 모델뿐이라는 점을 F4와 연결하는 각주 화살표(선택).

**캡션 골자** "먼저 돌린 사전실험의 구성: 결함의 종류·위치·크기를 숫자로 만든 뒤, 고정된 판정
모델이 규정 조항을 찾아 근거를 인용한다. 규정 색인은 학습 대상이 아니며 모든 조건에서 동일하다.
이번 실험에서 완주한 것은 검출 단계까지다."

## 3. F3 · 갈래 상세 — 통합형 파이프라인

**목적** 사진에서 판정문까지 한 번에 가는 구조와, 학습되는 부분이 **어댑터(작은 추가
가중치)뿐**임을 보인다. 규정 검색이 **없다**는 비대칭을 명시한다(비교의 대비축).

**구성 요소 (좌→우)**

1. 방사선 사진 → **그림·글 통합 모델** 큰 상자. 내부 2겹:
   - 기본 모델(회색=고정, "모든 조건에서 같은 출발점")
   - 어댑터(실선=학습됨, 작게 그려 크기 대비 강조)
2. 출력: **판정문** — 결함 종류·원본 픽셀 상자·관련 조항을 담은 구조화 출력(JSON). 판 두께와 화소당 실치수가 없어 합부 판정은 제외한다.
3. 하단 주석: "규정을 따로 찾지 않고 모델이 배운 지식에서 직접 인용 — 인용이 실제 규정과
   맞는지는 채점 항목(무근거 인용률)"

**캡션 골자** "통합형: 사진을 넣으면 판정문까지 한 번에 생성한다. 학습은 어댑터만 하며
규정 검색 없이 직접 인용하며 통합형·분리형의 구조 비교는 본실험 범위 밖이다."

## 4. F4 · 갈래 상세 — 연합학습 라운드

**목적** "데이터는 참여자 밖으로 나가지 않고 가중치만 오간다"를 한눈에. RQ3의 재료인
세 참여자의 명목 재질 라벨과 규모 차이도 표시한다. 실제 회사·취득처·실측 재질은 확인되지 않았다.

**구성 요소**

1. **참여자 C1·C2·C3** (각각 상자, 데이터 아이콘과 함께):
   - C1 — 명목 재질 라벨 ST, 26,451장
   - C2 — 명목 재질 라벨 ST, 16,253장
   - C3 — 명목 재질 라벨 AL, 7,143장. 실제 취득처와 재질은 확인되지 않음
   각 상자 경계에 **⊘ "사진은 밖으로 나가지 않음"** 표시
2. **서버** (중앙 상단): "통합형은 감독 토큰 수로 어댑터 가중 평균 → 재배포". 분리형 검출기 사전실험의 가중은 표본 수다.
3. **라운드 순환 화살표** ①서버가 가중치 배포 → ②각 참여자가 자기 데이터로 학습 →
   ③학습된 가중치만 서버로 → ④평균 → ①로. "이 순환을 `{R}`회 반복" 표기
4. 교환물 주석: "1회 왕복에 오가는 양 — 분리형: 검출 모델 전체 `{} MB` /
   통합형: 어댑터만 `{} MB`" (실측 후 채움)
5. **규정 색인**은 순환 **점선 경계 바깥**에 별도 배치: "모든 참여자가 같은 색인 사용,
   교환·평균 대상 아님"
6. 하단 각주: "본 실험은 GPU 1장 위 시뮬레이션이며 통신량은 교환 객체 크기 실측 ×
   라운드 수로 산출" ← 논문 필수 명시 문장과 연동

**캡션 골자** "연합학습 라운드. 데이터는 각 참여자에 남고 가중치만 서버를 오간다. 세 참여자의
명목 재질 라벨과 규모 차이는 관측된 속성이고 C1·C2의 분포 편중은 Dirichlet 분할로 구성한 조건이다. 실제 취득처 차이는 확인되지 않았다."

## 5. 그림–논문 골격 대응

| 그림 | 배치 절 | 뒷받침 |
|---|---|---|
| F1 | 연구 설계 첫머리 | 세 학습 방식·선분리·공통 채점 |
| F2 | 사전실험의 분리형 정의 | 조항 정확도 축 |
| F3 | 본실험의 통합형 정의 | 무근거 인용률 |
| F4 | 연합학습 정의 | RQ1·RQ3, 통신량, 비반출 서사 |

**포스터 기본 구성은 F1·F3·F4 셋이다.** F3(통합형)이 본실험의 구조를 그리므로 그 자리를 F2 와
나눠 쓰지 않는다. F2 는 사전실험을 설명할 지면이 남을 때만 넣고 그때도 두 구조를 나란히 놓아
비교처럼 보이게 하지 않는다 — 구조 비교는 본실험 범위 밖이다.

만들지 않는다**.

## 7. R5 · 임계 스윕 곡선 (결과 절 주 그림 — 상세 설계)

이 곡선은 분리형 검출기 사전실험의 그림이다. 통합형 본실험과 같은 성능 축으로 비교하지 않는다. **곡선의 모양 자체가 데이터이므로 SVG 를 손으로 그리지
않는다.** 스윕 산출물에서 스크립트가 생성한다(결과표 템플릿 채움 절차 1-c — T2-a 와 같은
산출물). 아래는 그 스크립트가 지켜야 할 설계다.

### 7-1. 무엇이 한눈에 보여야 하나 (그림의 목적)

| # | 보여야 할 것 | 시각 장치 |
|---|---|---|
| 1 | 회복률이 임계에 따라 **크게 움직인다** | 곡선 자체 |
| 2 | 중간에서 **부호가 바뀐다** | 0% 수평 기준선 + 교차점 표시 |
| 3 | 연합↔중앙집중 순서는 **전 구간 견고**하다 | 상단 띠(전 구간 같은 색) |
| 4 | 운용점 예시는 **한 점일 뿐**이다 | 세로 점선 1개 + "운용점 예시" 꼬리표 |
| 5 | x축이 **등록 격자 그대로**다(임의 눈금이 아니다) | x축 눈금 = 격자 점 그대로, 눈금마다 표식 |

### 7-2. 배치 (2단 세로 또는 좌우 2패널)

```
  회복률(%)                                        위: 결함 놓침 축
  +100 ┤●─●─●
       │      ●─●
     0 ┤────────────●───────────────── 0% 기준선(굵게)
       │               ●─●
  −100 ┤                    ●─●
       └┬──┬──┬──┬──┬──┬──┬──┬──┬──   x = 등록 격자 점(14점)
        ┆        운용점 예시(세로 점선)

  회복률(%)                                        아래: Macro-F1 축
   +100 ┤   ●─●─●
        │ ●        ●─●
      0 ┤────────────────●───────────── 0% 기준선
        │                    ●─●
        └┬──┬──┬──┬──┬──┬──┬──┬──┬──

  [상단 띠]  연합 < 중앙집중 : 전 구간 동일 ────────────────────  (한 색으로 채움)
```

### 7-3. 규칙

- **x축은 등록 격자 점만.** 눈금을 임의로 늘리거나 줄이지 않는다. 점 사이는 직선으로
  잇되 **격자 점에 표식(●)을 찍어** 어디가 실측이고 어디가 보간인지 보이게 한다.
- **0% 기준선을 굵게.** 이 선을 넘는 것이 "연합이 로컬 단독보다 나은가"의 경계다. 교차하는
  임계 구간에 짧은 꼬리표를 단다("여기서 순서가 바뀜").
- **분류 축 패널에는 무내용 기준선을 함께 그린다**. 화소를 보지 않는 규칙의
  값을 수평선으로 얹고 "이 선 아래는 화소를 보지 않는 규칙보다 못하다"를 꼬리표로 단다.
  이 축에서 조건 곡선이 그 선 아래에 있다는 사실이 논문의 주장 범위를 정하므로 그림에서
  가려지면 안 된다. 위치 축 패널의 기준선은 사실상 0 이므로 값과 함께 한 줄로 표시한다.
- **연합↔중앙집중 견고성은 곡선이 아니라 띠로.** 회복률 곡선에는 그 정보가 없다. 그림 아래
  가로 띠 하나로 "전 구간에서 중앙집중이 앞섬"을 한 색으로 칠하고 뒤집히는 구간이 있으면
  그 구간만 색을 바꾼다. 뒤집힘이 없다는 것이 이 연구의 견고한 결론이므로 눈에 보여야 한다.
- **운용점 예시는 세로 점선 한 개 + 꼬리표.** 강조하지 않는다. 캡션에 "등록 격자에서 고른
  점이 아니며 확증적 기준이 아니다"를 적는다.
- **두 축을 한 패널에 겹치지 않는다.** 결함 놓침과 Macro-F1 은 좋음의 방향이 반대라 겹치면
  오독된다. 위아래 두 패널로 나누고 x축을 공유한다. 놓침 축을 위에 둔다.
- **시드 3세트에서는 시드별 곡선 3개를 겹쳐 그린다.** 평균 곡선 + 개별 곡선(옅게) 또는
  평균 ± 표준편차 띠. 부호가 바뀌는 임계가 시드마다 어디로 움직이는지가 보여야 한다.
- 용어는 평이어. "신뢰도 임계" → 그림 안에서는 **"검출 판단 기준선"**, 캡션에 정식
  용어 병기. "회복률" 은 그대로 쓰되 캡션에 산식을 적는다.
- 색은 흑백 인쇄에서도 구분되게 **선 모양(실선·파선·점선)으로 먼저 구분**하고 색은 보조로.
  포스터는 컬러지만 심사 출력본이 흑백일 수 있다.

### 7-4. 캡션 골격

> 그림 5. 검출 판단 기준선에 따른 회복률 변화. 위는 결함 놓침 비율 축, 아래는 Macro-F1 축.
> 회복률 = (연합 − 로컬 단독 평균) / (중앙집중 − 로컬 단독 평균) × 100. 가로축은 등록된
> 기준선 격자이며 표식은 실측 점이다. 격자의 등록 시점은 방법 절에 밝혔다(사전등록이 아니다).
> 0% 선 위는 연합이 로컬 단독 평균보다 나은 구간이다. 세로 점선은 파일럿에서 쓰인 운용점
> 예시로, 등록 격자에서 고른 점이 아니며 확증적 기준이 아니다.
> 아래 띠는 연합과 중앙집중의 순서를 격자 전 구간에서 표시한다. 통합형 본실험 결과는 이 그림에 포함하지 않는다.
