## 1. F1 · 연구 설계 통합도

**목적** 처음 보는 사람이 30초 안에 "구조 2종 × 학습 방식 3종에서 한 칸을 뺀 다섯 조건을
같은 데이터·같은 채점기로 비교하는 실험"임을 이해하게 한다. 포스터의 첫 그림.

**구성 요소 (좌→우 3단)**

1. **데이터 단** — 용접 방사선 사진 62,308장(문서 아이콘). 아래로 두 갈래:
   "채점용 20% — **가장 먼저 분리**, 어떤 학습에도 쓰지 않음" / "학습용 80% → 회사 3곳에 분배".
2. **다섯 칸 매트릭스** — 2행(위: 통합형 = 사진을 넣으면 판정문까지 한 번에 /
   아래: 분리형 = 검출 모델 + 판정 모델 분업) × 3열(로컬 단독 / 중앙집중 / 연합학습).
   좌상단 1칸은 빗금 + "제외" 표기. 각 열 머리에 한 줄 정의:
   - 로컬 단독 "각 회사가 자기 데이터로만"
   - 중앙집중 "모든 데이터를 한곳에 모음 — **현실에서는 불가, 성능 상한 기준**"
   - 연합학습 "데이터는 두고 학습된 가중치만 교환"
3. **채점 단** — 다섯 칸의 출력이 **하나의 공통 채점기**로 수렴하는 화살표.
   채점기 상자 안에 "같은 채점용 사진, 같은 기준" 한 줄.

**레이블 문구(안)** 상단 제목 없음(캡션으로 대체). 매트릭스 제외 칸: "제외 — 회사마다
대형 모델을 단독 구축하는 시나리오는 현실적이지 않음".

**금지** 규정 색인은 이 그림에 넣지 않는다. F2와 F4에서 다룬다. 지표명·모델명도 노출하지 않는다.

**캡션 골자** "다섯 가지 학습 조건. 채점용 데이터는 회사별 분배 전에 분리하며, 다섯 조건
전부 동일한 채점기로 평가한다. 통합형·로컬 제외 사유는 본문 X절."

## 2. F2 · 갈래 상세 — 분리형 파이프라인

**목적** "숫자를 만드는 검출"과 "규정을 찾아 판정하는 언어 모델"의 분업, 그리고
**규정 색인이 학습·평균 대상이 아님**을 보인다.

**구성 요소 (좌→우)**

1. 방사선 사진 → **검출 모델**(실선=학습됨): 출력 "결함 종류 · 위치(상자) · 크기" — 숫자
2. 구조화 질의 키 상자: {결함 종류, 크기, 판 두께, 품질 수준} → **규정 조항 찾기**
3. **규정 색인** 상자는 **점선 경계 바깥**에 배치, 라벨: "규정 색인 — 공개 규정 문서.
   **학습하지 않고 모든 회사가 동일본 사용**". 색인→조항 찾기로 화살표
4. **판정 모델**(회색=고정): 입력 "검출 결과 + 찾은 조항 3건" → 출력 **판정문**
   (합격/불합격 + 근거 조항)

**핵심 시각 장치** 학습되는 것은 검출 모델 하나뿐임을 채움색으로 대비. 연합학습에서
교환되는 것도 검출 모델뿐이라는 점을 F4와 연결하는 각주 화살표(선택).

**캡션 골자** "분리형: 결함의 종류·위치·크기를 숫자로 만든 뒤, 고정된 판정 모델이 규정
조항을 찾아 근거를 인용한다. 규정 색인은 학습 대상이 아니며 모든 조건에서 동일하다."

## 3. F3 · 갈래 상세 — 통합형 파이프라인

**목적** 사진에서 판정문까지 한 번에 가는 구조와, 학습되는 부분이 **어댑터(작은 추가
가중치)뿐**임을 보인다. 규정 검색이 **없다**는 비대칭을 명시한다(비교의 대비축).

**구성 요소 (좌→우)**

1. 방사선 사진 → **그림·글 통합 모델** 큰 상자. 내부 2겹:
   - 기본 모델(회색=고정, "모든 조건에서 같은 출발점")
   - 어댑터(실선=학습됨, 작게 그려 크기 대비 강조)
2. 출력: **판정문** — 결함 종류·위치·크기 + 합부 + 인용 조항이 든 한 개의 구조화 출력(JSON)
3. 하단 주석: "규정을 따로 찾지 않고 모델이 배운 지식에서 직접 인용 — 인용이 실제 규정과
   맞는지는 채점 항목(무근거 인용률)"

**캡션 골자** "통합형: 사진을 넣으면 판정문까지 한 번에 생성한다. 학습은 어댑터만 하며,
규정 검색 없이 직접 인용하는 구조 자체가 분리형과의 비교 대상이다."

## 4. F4 · 갈래 상세 — 연합학습 라운드

**목적** "데이터는 회사 밖으로 나가지 않고 가중치만 오간다"를 한눈에. RQ3의 재료인
세 회사의 실제 이질성(취득처·규모)도 이 그림이 보인다.

**구성 요소**

1. **회사 3곳** (각각 상자, 데이터 아이콘과 함께):
   - 회사 A — 강재, 26,451장 (대형)
   - 회사 B — 강재, 16,253장 (중형)
   - 회사 C — **취득처가 다름**(명목 재질 라벨 AL), 7,143장 (소형) ← RQ3 대상 표시
   각 상자 경계에 **⊘ "사진은 밖으로 나가지 않음"** 표시
2. **서버** (중앙 상단): "받은 가중치를 데이터 양에 비례해 평균 → 재배포"
3. **라운드 순환 화살표** ①서버가 가중치 배포 → ②각 회사가 자기 데이터로 학습 →
   ③학습된 가중치만 서버로 → ④평균 → ①로. "이 순환을 `{R}`회 반복" 표기
4. 교환물 주석: "1회 왕복에 오가는 양 — 분리형: 검출 모델 전체 `{} MB` /
   통합형: 어댑터만 `{} MB`" (실측 후 채움)
5. **규정 색인**은 순환 **점선 경계 바깥**에 별도 배치: "모든 회사가 같은 색인 사용,
   교환·평균 대상 아님"
6. 하단 각주: "본 실험은 GPU 1장 위 시뮬레이션이며, 통신량은 교환 객체 크기 실측 ×
   라운드 수로 산출" ← 논문 필수 명시 문장과 연동

**캡션 골자** "연합학습 라운드. 데이터는 각 회사에 남고 가중치만 서버를 오간다. 세 회사의
재질·규모 차이는 인위 설정이 아니라 데이터에 실재하는 이질성이다."

## 5. 그림–논문 골격 대응

| 그림 | 배치 절 | 뒷받침 |
|---|---|---|
| F1 | 연구 설계 첫머리 | 다섯 칸·선분리·공통 채점 |
| F2 | 분리형 정의 | RQ2, 조항 정확도 축 |
| F3 | 통합형 정의 | RQ2, 무근거 인용률 |
| F4 | 연합학습 정의 | RQ1·RQ3, 통신량, 비반출 서사 |

포스터 지면이 부족하면 F2와 F3을 한 장으로 합쳐 상하로 대비 배치한다. 두 구조를 나란히
놓는 편이 오히려 읽기 쉬울 수 있어 초안을 만든 뒤 정한다.

## 6. 결과 그림 후보 (수치 확보 후 제작 — 지금은 틀만)

| 후보 | 내용 | 채택 기준 |
|---|---|---|
| R1 회복률·유지율 막대 | 다섯 칸 Macro-F1 막대 + 회복률/유지율 주석. 분리형은 ±표준편차 오차 막대 | **기본 채택** — 헤드라인 숫자의 시각화 |
| R2 라운드-성능 곡선 | 연합 두 칸의 라운드별 글로벌 성능, 중앙집중 수평선 대비 | 기본 채택 — "몇 라운드에 어디까지 가나" |
| R3 클래스×참여자 분포 히트맵 | 데이터 담당 생성물. 자연 이질성의 증거 | 결과가 아니라 **설계 절** 삽입 후보. 지면 부족 시 1순위 제외 |
| R4 RQ3 분해 | 회사 C의 로컬 vs 연합 결함 recall 비교 | R1에 흡수 가능하면 생략 |

결과 그림도 공통 규칙(흰 배경·평이어·`{}` 자리표시자) 적용. **없는 수치로 예시 그림을
만들지 않는다** — 초안 검토용이라도 실수치 유입 경로가 된다.
