# 현재 포스터의 그림 설명

2026년 11월 10일 내용 수정 포스터의 그림 구성과 읽는 방법을 정리한다. 기존 그림의 수치와 사례를 설명하는 문서이며 원본 영상이나 새 그림을 제공하지 않는다.

## 그림 1. 실험 구성

(a) AI Hub 이용 신청 자료의 방사선 영상을 정제·분할하고 모사 참여자 C1·C2·C3의 학습 자료를 선택한다. (b) Qwen3.5-4B의 기본 가중치를 고정하고 LoRA를 학습한다. (c) 단독 3개·중앙집중 1개·연합 1개 모델을 구성한다. (d) 다섯 모델을 같은 평가 영상 1,059장에서 비교한다.

학습 자료는 11,224쌍, 학습 시드 1개, 선택 자료 1회 순회, 연합 집계 1회다. 집계 모델의 재배포·추가 학습·집계를 반복한 효과는 검증하지 못했다. 학습·검증 풀의 공통 전처리 통계를 사용했다. 실제 회사 세 곳의 분산 운영이나 개인정보 보호를 입증하는 그림으로 해석하지 않는다.

## 그림 2. RQ1 검출 성능

전체 Macro-F1과 네 결함별 F1을 함께 제시한다. 연합 0.0213, 단독 평균 0.0204, 중앙집중 0.0993을 비교하며 점선은 메타데이터 기반 baseline 0.1619다. 적합 자료는 baseline 49,847장, Qwen 학습 11,224쌍으로 다르다.

0에서 시작하는 축으로 차이를 표시한다. 중앙집중이 연합보다 높은 결함은 균열·기공·융합 불량이며 슬래그 혼입은 양쪽 모두 0이다. 실패 벌점 변경에 따른 평균 차이 반전도 함께 설명한다. 구간은 평가 묶음 재표집의 95% 구간으로 재학습 변동을 뜻하지 않는다.

## 그림 3. RQ2 참여자별 점수 변화

단독모델과 연합모델의 점수를 연결하고 연합−단독 차이와 95% 구간을 표시한다. C1 −0.0281, C2 +0.0155, C3 +0.0152이며 실패 벌점을 더해도 방향은 같다. 이 비교는 모든 모델이 같은 공통 평가셋을 사용한 결과다.

RQ2의 비용·기여·크레딧·보상까지 포함한 참여 편익은 평가하지 못했다. 점수 차이는 참여자가 받은 성능 편익이며 연합모델에 제공한 기여를 측정한 값은 아니다. 점수 차이의 순위를 기여도나 보상 순위로 바꾸어 읽지 않는다.

## 그림 4. 검출과 기준 설명의 사례

A는 중앙집중모델의 균열 검출 성공과 재질별 기준 오류, B는 단독모델들이 놓친 기공의 연합 검출, C는 단독 C1의 기공 검출, D는 결함 라벨이 없는 영상에서 연합모델의 오탐이다. 검출 상자와 해당 응답 설명을 같은 사례로 연결한다.

검출 성공은 종류 일치·IoU ≥0.5 기준이다. 실제 응답의 요약과 연구자의 검토를 구분한다. 결과 확인 후 선정한 사례이므로 대표 성공률이나 전문가가 검증한 판정 정확도로 해석하지 않는다. 사례의 세부 내용은 [포스터 해설](포스터_해설.md)에 있다.

원본·파생 방사선 영상은 이 공개 문서에 포함하지 않는다. 문서 동기화는 포스터 재제작이나 실물 인쇄·독자 시험의 완료를 뜻하지 않는다.

## 자료 분포와 C3 고찰

포스터의 연구 개요는 자료와 비교 구성을 설명하고 C3가 가장 작은 학습자료와 가장 높은 슬래그 라벨 영상 비율을 가졌음을 명시한다. 결함/정상 및 결함별 영상·상자 분포의 상세 표는 [자료 분포와 후속 검증](자료분포와_후속검증.md)으로 연결한다.

고찰의 C3 슬래그 F1 0.007은 설계 가중 F1 0.0068을 세 자리로 반올림한 값이며 전체 Macro-F1이나 AL 영상만의 결과가 아니다. 중앙집중·연합의 슬래그 F1은 모두 0이다. 이 결과를 C3의 기여도 0이라는 뜻으로 읽지 않는다. 자료 분포의 차이와 실제 기여를 구별하고 C3 포함·제외 및 조합 비교를 후속 과제로 남긴다.
