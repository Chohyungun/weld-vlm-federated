## 3. 방법 한계 (각주에는 넣지 않되 내부 기록)

- 2026-08-17 확인은 **검색 엔진 색인 경유**라 KCI·ScienceON 포털 네이티브 검색과 리콜이
  다를 수 있다. 정본은 포털 직접 검색(2026-08-03)이며, 8-17분은 보조 확인이다.
- 국제 문헌 쪽 확인(Semantic Scholar 전수 + 웹 검색)은 "국내 0건" 주장과 **층위가 다르다.**
  국내 주장에는 KCI·ScienceON만 인용하고, 국제 쪽은 WeldLLM 공백 서술에만 쓴다.
- 검색 엔진·색인 특성상 학위논문·학술대회 발표문은 누락될 수 있다.

## 4. 투고 직전 최종 재검색 (필수 절차)

- 시점: **10월 둘째 주** (초록 제출 10/20 직전)
- 방법: KCI·ScienceON **포털 직접 검색**, §2와 동일 검색어 4종
- 결과가 0건이 아니면 해당 문헌을 관련 연구에 편입하고 각주를
  "선행 1건 존재, 본 연구와의 차이는 ~"로 전환한다. 신규성 주장 문장을 수정한다.
- 이 절차는 논문 골격의 투고 전 체크리스트(14_spec_E §8)에 들어 있다.
