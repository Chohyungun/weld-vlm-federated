# 연합학습·용접 문헌의 검색 기록

검색 기록 최종 갱신 2026-08-17 · 공개 문서 편집 2026-10-05

이 기록은 “국내 문헌 검색에서 연합학습과 용접의 결합 사례를 확인하지 못했다”는 서술의
검색 범위를 밝힌다. 해당 연구가 어디에도 없다는 부재 증명은 아니다. 이번 공개 문서
편집에서는 재검색을 수행하지 않았으며 아래 날짜의 결과를 그대로 보존했다.

KCI·ScienceON 포털을 직접 검색한 기록은 2026-08-03이다. 2026-08-17에는 검색 엔진 색인을
통해 보조 확인했다. 두 방법의 검색 범위는 같지 않으므로 직접 검색과 보조 확인을 구분한다.
문헌별 활용 범위는 [문헌 안내](../논문_리스트.md), 논문의 주장 범위는
[본문 초안](본문_초안.md)의 §1·§2에 있다.

## 1. 논문에 사용할 각주 초안

각주에는 검색어·데이터베이스·일자·건수를 함께 적는다.

> 국내 문헌 기준. KCI와 ScienceON에서 “연합학습”을 “용접” 및 “조선”과 결합해 포털 직접
> 검색한 결과 해당 사례가 확인되지 않았다(2026-08-03 검색 0건). 검색 엔진 색인을 통한
> 2026-08-17 보조 확인에서도 결합 사례는 0건이었다. 투고 직전 포털 직접 검색의 최종
> 재확인 일자는 {일자}이며 검색어와 건수 전체 로그는 연구 저장소에 공개한다.

`{일자}`와 최종 검색 결과는 투고 직전 재검색 뒤 확정한다. 그 전에는 재검색을 마쳤다고
서술하지 않는다. 본문에는 “국내 문헌 검색에서 확인되지 않았다”를 사용하고 “세계 최초”로
확장하지 않는다. 검색 도구가 문헌을 빠짐없이 찾아내지 못할 수 있다는 제한은 RAFT 조사에도
동일하게 적용된다.

사용하지 않는다.

## 3. 검색 방법의 한계

2026-08-17 확인은 검색 엔진 색인을 경유했다. KCI·ScienceON 포털 직접 검색과 회수하는
문헌이 다를 수 있으므로 국내 주장의 기준 기록은 2026-08-03 포털 직접 검색이다.
검색 엔진과 색인의 특성상 학위논문·학술대회 발표문도 누락될 수 있다.

Semantic Scholar의 인용 조사와 국제 웹 검색은 “국내 0건”과 대상이 다르다.
국내 주장에는 KCI·ScienceON 결과를 인용하고, 국제 보조 결과는 WeldLLM이 다루지 않은
범위를 설명하는 자료로 한정한다.

## 4. 투고 전 재검색 계획

기록된 일정은 **10월 둘째 주, 초록 제출 10/20 직전**이다. KCI·ScienceON 포털에서 §2의
국내 검색어 네 조합을 직접 검색하고 날짜와 결과를 남긴다.

결합 사례가 발견되면 해당 문헌을 관련 연구에 포함하고 신규성 서술을 고친다. 예를 들어
한 편이 확인되면 “선행 1건 존재, 본 연구와의 차이는 ~”와 같이 실제 검색 결과에 맞춰
기술한다. 이 재검색은 투고 전 필수 확인 항목이며 현재 완료됐다는 기록은 없다.
