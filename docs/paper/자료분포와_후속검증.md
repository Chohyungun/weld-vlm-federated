# 학습자료 분포와 후속 검증

2026년 11월 10일 포스터와 Appendix에 보강한 자료 분포, C3의 성능 편익·기여 구별, 반복 학습·집계의 후속 과제를 정리한다. 아래 분포는 저장된 학습 라벨의 기술 통계이며 결과 확인 후 추가했다. 새 학습·추론·정식 재채점을 수행한 결과가 아니다.

## 전체 유효 학습 풀과 실제 선택 학습자료

학습 영상 분할 44,846장 중 유효 결함 좌표가 없는 1건을 제외한 전체 유효 학습 풀은 44,845쌍이다. 참여자별 약 1/4을 고정 시드로 선택하고 기울기 누적 단위에 맞춰 총 11,224쌍을 사용했다. 저장 자료의 선택 규칙으로 목록을 복원하여 완료 모델 세 개의 학습 목록 지문·행 수·감독 응답 토큰 합과 일치함을 확인했다.

유효 영상·응답 1쌍은 영상 1장에 해당한다. 결함 영상은 유효 결함 상자가 하나 이상인 영상, 정상 영상은 해당 결함 라벨이 없는 영상이다. 정상 라벨이 실제 무결함을 보증하지는 않는다. 결함별 영상 수는 복수 결함 때문에 중복되므로 네 종류를 더해 결함 영상 수로 쓰지 않는다. 상자는 한 영상의 여러 결함을 각각 센 값이다.

## 실제 선택 학습자료의 비율

| 참여자 | 학습 쌍 비중 | 결함 영상 비율 | 슬래그 영상 비율 |
|---|---:|---:|---:|
| C1 | 53.03% | 71.89% | 0.32% |
| C2 | 32.64% | 31.47% | 4.34% |
| C3 | 14.33% | 45.90% | 11.69% |

학습 쌍 비중의 분모는 전체 선택 11,224쌍이다. 결함·슬래그 영상 비율의 분모는 각 참여자의 선택 학습 쌍 수다. 상자 비율이나 평가 표본의 설계 가중 비율과 구별한다.

C1·C2의 명목 재질은 ST(강재), C3는 AL(알루미늄)이다. C3는 작은 자료로 다른 재질과 결함 구성을 제공하지만 용접 구조 자체의 독특함이나 현장 대표성은 이 집계만으로 확인할 수 없다. C3에 슬래그 자료가 있어도 C3만의 정보라고 단정할 수 없다. 선택 자료의 슬래그 상자는 C1 49개, C2 316개, C3 365개다. 자료량·재질·결함 빈도와 집계 방식의 영향을 분리한 비교가 필요하다.

## C3가 받은 성능 편익과 제공한 기여

공통 평가셋에서 단독 C3를 연합모델로 바꾸면 Macro-F1이 0.0061에서 0.0213으로 높아졌다(차이 +0.0152). 이는 C3 입장에서 모델 교체의 성능 편익이다. C3를 참여시켜 다른 참여자나 연합모델의 성능이 얼마나 좋아졌는지는 이 비교로 알 수 없다.

| 공통 평가의 슬래그 | 설계 가중 F1 | 검출(TP) | 오탐(FP) | 누락(FN) |
|---|---:|---:|---:|---:|
| 단독 C3 | 0.0068 | 1 | 31 | 261 |
| 중앙집중 | 0.0000 | 0 | 0 | 262 |
| 연합 | 0.0000 | 0 | 0 | 262 |

포스터의 0.007은 단독 C3의 슬래그 F1을 세 자리로 반올림한 값이다. 전체 Macro-F1 0.0061과 구별한다. 상자 수는 전체 재질을 포함한 공통 평가 1,059장 중 슬래그 정답 262개에 대한 비가중 집계이며 AL 영상만의 결과가 아니다. 설계 가중 F1은 이 비가중 건수로 직접 계산한 F1과 다를 수 있다.

C3 단독모델도 슬래그 검출은 1개이고 오탐은 31개였다. 중앙집중·연합모델 모두 슬래그를 검출하지 못해 C3의 자료 특성이 슬래그 성능 기여로 이어졌다는 근거는 얻지 못했다. 다만 이 결과만으로 C3의 모든 기여가 0이라고 판단할 수는 없다.

C3의 추가 기여를 확인하려면 같은 초기 모델·평가 자료·학습 예산 원칙을 고정하고 C1+C2와 C1+C2+C3를 비교해야 한다. 전체 및 재질·결함별 성능, C1·C2의 변화, 누락·오탐을 함께 봐야 한다. 포함·제외에 따라 바뀌는 자료량과 집계 가중치도 통제하거나 별도로 보고해야 한다.

포함·제외 비교는 특정 조합에서의 기여를 평가한다. Shapley 기여도에는 다른 참여자 조합도 필요하다. 감독 토큰 집계 가중치를 기여도·크레딧·보상으로 대체하지 않고 비용과 보상 규칙도 함께 평가해야 한다. 학습 순서가 다른 단독 어댑터로 같은 실행의 연합 참여자 어댑터를 임의 대체하지 않는다.

## 집계 1회에서 확인하지 못한 효과

이번에는 같은 초기 어댑터에서 참여자들이 각각 학습한 뒤 한 번 집계했다(R=1). 집계한 연합모델을 다시 배포하고 추가 학습·집계를 반복하지 않았다. 따라서 반복 교환에 따른 개선이나 수렴을 검증한 결과로 해석할 수 없다.

후속 비교에서는 연합모델 배포 → 참여자 추가 학습 → 집계를 여러 라운드 수행하며 라운드별 성능과 참여자 간 차이를 기록한다. 라운드가 늘면 총 학습량·통신량도 달라지므로 예산을 맞춘 단독·중앙집중 대조와 복수 시드가 필요하다. 아래 내용은 후속 설계이며 수행 결과가 아니다.

| 비교 축 | 확인할 질문과 조건 |
|---|---|
| 같은 11,224쌍에서 집계 횟수 변경 | 자료를 고정했을 때 반복 교환이 성능에 미치는 영향은 무엇인가? 총 학습량을 맞춘 대조가 필요하다. |
| 같은 집계 조건에서 학습 자료 확대 | 전체 유효 학습 풀 44,845쌍으로 늘렸을 때의 변화는 무엇인가? 자료량과 학습량을 함께 보고한다. |
| C3 포함·제외 및 참여자 조합 | C3가 제공한 정보의 추가 이득은 무엇인가? 재질·결함별 성능과 자료량 효과를 분리한다. |
| 독립 평가와 실제 운영 조건 | 결함별 누락·오탐, 시간·계산·통신·운용 비용을 함께 볼 때 참여 편익이 있는가? |

현재 모델을 평가 영상 12,461장 전체에서 평가하는 작업은 학습 자료 확대나 반복 집계와 별개다. 위 후속 비교와 전량 평가는 이번 제출에서 수행하지 못했다. 기관별 실제 검사 성능과 비용·기여·크레딧·보상을 함께 고려한 참여 편익도 평가하지 못했다.
