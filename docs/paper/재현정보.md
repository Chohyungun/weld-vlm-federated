# 실험 설정과 수치의 출처

본문의 주요 결과 표는 정식 평가 산출에서 작성했다. 표에 표시한 소수점은 반올림값이다. 실행 당시 설정과 결과 파일의 식별 기록은 연구자가 보관하며 재현할 때는 그 기록으로 사용 파일의 동일성을 확인해야 한다.

## 평가

M1은 네 결함의 바운딩박스 F1 매크로 평균이다. IoU 0.5 이상 최대 개수 매칭을 적용하고 주 분석에서는 실패 레코드를 빈 예측으로 읽는다. 민감도 분석은 실패 레코드마다 네 종류에 각각 FP를 추가한다. 소표본 분산 보정 없는 층 안 묶음 복원추출 2000회, 난수 시드 20260825를 사용한 산출이다. 모델 간 비교에 같은 재표집을 적용하였다. 재표집 세부 선택은 결과 파일의 미등록 선택으로 기록돼 있다.

## 재현 자료의 제공 범위

재현에는 실행 당시 설정 사본, 초기·최종 어댑터, 동결된 학습·평가 목록, 생성 출력과 채점 산출이 필요하다. 공개 문서에는 원자료와 운영 기록을 포함하지 않는다. 자료 접근 조건과 파일 동일성은 연구자가 보관한 실행 기록으로 대조해야 한다. 현재 작업용 설정이 과거 실행의 설정과 같은지는 별도로 확인한다.

## 결과 범위

정식 채점 전에 부분 미리 보기와 전체 예행연습 결과를 확인했다. 전량 평가 추가 조건에 해당했으나 이번 제출에서는 시행하지 않았다. 1차와 2차 실행은 학습량 외 조건도 달라 서로 통제된 학습량 비교가 아니다. 학습 시드가 하나여서 반복 학습의 변동을 보고하지 않는다.

## 현재 공개 코드와 당시 실행의 구분

문서와 코드 주석을 정리한 현재 공개본은 실행 당시의 전체 코드·자산 묶음이 아니다. 기존 등록 JSON·영수증·벡터와 설정 사본의 바이트는 보존한다. 과거 결과의 재현에는 그 기록이 가리키는 실행 당시 코드와 비공개 자산이 필요하다. 현재 파일의 해시를 과거 등록 해시로 바꾸거나 검증을 우회하지 않는다.

RQ2의 공통 평가셋 점수 차이는 성능 편익의 제한적 비교다. 기관별 실제 검사 성능과 계산·통신·운용 비용, 기여·크레딧·보상을 함께 고려한 참여 편익은 평가하지 못했다.

## 학습자료 분포표의 작성 근거

2026년 11월 10일 보강한 [자료 분포표](자료분포와_후속검증.md)는 저장된 학습 라벨의 기술 통계다. 학습 영상 분할 44,846장 중 유효 결함 좌표가 없는 1건을 제외한 전체 유효 풀은 44,845쌍이다. 참여자별 고정 시드 20260828과 약 1/4 선택, 기울기 누적 단위 8에 맞춘 올림 규칙으로 실제 선택 목록을 복원했다. 완료 모델 세 개의 학습 목록 지문·행 수·감독 응답 토큰 합과 각각 대조했다. 선택 자료 11,224쌍은 새로 학습한 자료가 아니라 보고한 실행에서 이미 사용한 자료다.

분포표는 결과 확인 후 보강했으며 학습·추론·정식 재채점을 추가로 수행하지 않았다. 원천 파일 바이트의 SHA256과 학습 메타데이터의 의미 기반 자료 지문은 서로 다른 값이므로 구별해 확인한다. 공개본에는 영상별 목록이나 생성 응답을 추가하지 않는다.
