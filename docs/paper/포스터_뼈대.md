# 포스터 뼈대 — 한 장의 칸 구성

대한산업공학회 2026 추계학술대회 포스터. 칸의 배치와 칸마다 들어갈 문장 · 그림 · 표의 자리를 정한다.
문장과 수는 논문 초안(`본문_초안.md`)과 등록 설정 파일에서 옮긴다. 포스터가 이 둘과 다르면 이 둘을 따르고,
논문 초안과 설정 파일이 서로 다르면 설정 파일이 정본이다.

## 칸의 성격 — 세 가지를 섞지 않는다

| 표시 | 칸의 성격 | 칸 |
|---|---|---|
| **[설계]** | 실험 전에 정한 것 — 문제 · 자료 구성 · 학습 방식 · 채점 규칙 | ① ② ③ |
| **[관찰]** | 이미 잰 사실만. 본실험 성능이 아니다 | ④ |
| **[미측정]** | 본실험 결과가 들어갈 자리. 표의 틀만 있고 값은 없다 | ⑤ |
| **[한계]** | 결과를 읽는 범위 | ⑥ |

- 칸 머리에 표시를 붙인다. [설계] · [관찰] · [미측정] 세 칸은 테두리와 바탕을 서로 다르게 해 멀리서도 갈리게 한다
  (예: [설계] 실선 · 흰 바탕, [관찰] 굵은 실선 · 옅은 회색 바탕, [미측정] 점선 · 빗금 바탕).
- [미측정] 칸의 표에는 숫자를 넣지 않고 "미측정" 만 적는다. 예시 수치도 넣지 않는다.
- [관찰] 칸의 수 옆에는 그 수가 무엇을 뜻하지 않는지를 함께 적는다.

## 제목

데이터를 공유하지 않는 조선 용접 결함 검출 · 조항 인용 모델의 연합학습: 단독 · 중앙집중 학습과의 비교

논문 초안 0절의 권고안이다. 회복률을 제목에 넣는 안은 학습 시드를 늘려 대표 채택 조건을 통과했을 때만 쓰며, 그때도
결과의 방향이나 "실증" 을 제목에 담지 않는다.

## ① 문제 [설계]

- 조선 용접부의 방사선 영상과 판정 기록은 회사마다 따로 쌓이고, 품질 · 공정 · 거래 관계가 드러날 수 있어
  밖으로 내보내기 어렵다.
- 연합학습은 자료를 각 참여자에 둔 채 학습된 가중치만 주고받는다. 국내 문헌 검색(KCI · ScienceON)에서는 용접 결함
  검출에 연합학습을 적용해 성능을 잰 사례가 확인되지 않았고(검색 범위에 한정되며 부재를 입증하지 않는다), 가장 가까운
  국외 선행 연구는 자료를 모을 수 없는 조건을 다루지 않았다.
- 대상은 방사선 영상 한 장에서 결함의 종류 · 위치와 해당 규정 조항을 함께 내는 시각-언어 모델 하나(통합형)다.
  합부 판정은 내지 않는다(⑥).
- **RQ1.** 통합형 시각-언어 모델의 연합학습 성능은 참여자 단독 학습 · 중앙집중 학습과 비교해 어떻게 달라지는가.
- **RQ2.** 참여자(C1 · C2 · C3)마다 자체 모델과 공동 모델 사이에 어떤 성능 차이가 있는가 — 이득과 손해, 그리고
  이득이 가장 작은 참여자.

## ② 설계 [설계] — 그림 F1 자리

그림 F1(연구 설계 통합도, `그림_명세.md` 1절): 자료 → 평가셋 선분리 → 세 참여자 → 세 학습 방식 → 하나의 채점기.

| 단계 | 내용 |
|---|---|
| 자료 | AI허브 용접 방사선 영상 62,308장(동결 스냅샷) |
| 평가셋 선분리 | 12,461장을 참여자 분할보다 먼저 뗀다(재질 × 클래스 층화, 중복 묶음 단위). 묶음은 파일 해시 일치 · 라벨 식별자 연속 구간 · 지각 해시 완전 일치로 만든 대용이라 같은 용접부를 모두 잡지는 못하며, 묶음 밖의 유사 사진 쌍은 학습 · 평가에 걸쳐 남는다(⑥) |
| 참여자 | 학습 풀 49,847장 → C1 26,451 · C2 16,253(명목 재질 ST, 둘 사이에만 Dirichlet 클래스 편중) · C3 7,143(명목 재질 AL). 공개 자료를 나눈 참여자 역할이며 실제 회사가 아니다. 학습은 학습 분할(44,846장)의 페어로 한다 |
| 학습 방식 | 로컬 단독(참여자마다 하나, 모두 셋) · 중앙집중(하나) · 연합(하나) — 학습 시드 하나에서 모델 다섯 |
| 연합의 형태 | cross-silo 모사 — 세 참여자 역할이 모두 집계에 참여한다. R = 1 이라 집계는 한 번이다. 한 장비 위의 시뮬레이션이다 |

## ③ 방법 [설계]

| 항목 | 설정 |
|---|---|
| 모델 | Qwen3.5 4B 시각-언어 모델. QLoRA — 기본 모델을 4비트 NF4(이중 양자화)로 고정하고 계산은 bfloat16, LoRA 어댑터만 학습 |
| 교환 | 학습 라운드에서는 LoRA 어댑터 행렬만 주고받는다. 전처리 기준인 256 구간 밝기 히스토그램은 학습 전에 참여자 집계값을 한 번 합친 통계량에 해당한다(시뮬레이션에서는 한곳에서 계산). 원본 영상은 보내지 않는다 |
| 집계 | 토큰 가중 FedAvg — 가중은 참여자 학습 자료의 감독 토큰 총합(C1 2,211,295 · C2 854,010 · C3 336,841) |
| 학습 예산 | N = E = R = 1 — 로컬 · 중앙집중은 1 epoch, 연합은 로컬 1 epoch 뒤 한 번 집계. 조기 종료 없이 마지막 체크포인트를 채점 |
| 학습 설정 | 마이크로 배치 1 · 기울기 누적 32 · 학습률 1e-4. 학습 타깃은 구조화 JSON(결함 종류 · 원본 픽셀 상자 · 판정 칸 · 인용 조항, 판정 칸은 늘 '판정불가') 전용 |
| 학습 시드 | 시드 1 하나 |
| 평가 표본 | 동결 평가셋 12,461장의 묶음 단위 층화 표본 — 명목 3,000장 · 실현 3,080장 · 300묶음, 층별 설계 가중 |
| 주 지표 | M1 — 클래스가 일치하는 상자를 IoU 0.5 로 짝지은 F1 의 네 결함 매크로 평균 |
| 생성 | 탐욕 생성 1회 · 생성 한도 512 토큰 · 재시도 없음 |
| 실패 처리 | 주 채점: 읽히지 않는 출력은 빈 예측. 민감도: 실패 레코드마다 평가 클래스별 오탐 1 |
| 대조선 | 화소를 보지 않는 규칙 — 영상 식별자 구간(512 구간)마다 클래스가 든 영상의 비율이 문턱 이상이면 그 구간 · 클래스의 학습 자료 정답 상자에서 좌표별 중앙값 상자를 낸다. 같은 지표 · 같은 표본으로 채점 |
| 교환량(실행 전 계산) | 어댑터 한 벌 129,859,584 B, 연합 누적(R = 1, 하향은 상향과 같은 크기로 어림) 779,157,504 B — 학습 풀(검증 분할 포함) 영상을 한 번 모으는 양(2,599,911,025 B)의 0.30배. 실측이 아니다. 두 양이 같아지는 라운드 수는 3.34 이므로 이 비교로 연합이 전송량을 줄인다고 일반화하지 않는다 |

그림 F3(통합형 파이프라인) · F4(연합학습 라운드) 자리 — `그림_명세.md` 3 · 4절.

회복률과 구간 · 미정의 재표집 비율 · 대표 채택 조건, 대조선 초과는 그 조건 5), T2 본실험 행(원시 격차 · 중앙집중 대비
비율 · 대조선과의 차 · 참여자별 차이 · 상대 향상률)이다. 템플릿에 자리가 없는 칸 — 표 1 의 조건별 평가 묶음 구간(대조선
행 포함) · 대조선과의 대응 차 구간 · 로컬 평균 행, 표 2 의 참여자별 대응 구간 — 은 템플릿에 먼저 더한 뒤 채운다. 이득이
가장 작은 참여자 행은 참여자별 차이(연합 − 로컬)가 가장 작은 참여자를 스크립트가 골라 채운다.

## ⑥ 한계 [한계]

- 평가셋과 학습 자료 사이에 같은 사진으로 의심되는 교차 쌍이 있어 비교는 탐색적이다. 학습에서 보지 못한 영상에
  대한 일반화를 말하지 않는다.
- 학습 시드가 하나라 시드에 따른 변동을 재지 않으며, 회복률을 대표 수치로 채택하지 않는다.
- 연합은 한 번 집계한다(R = 1). 반복 집계의 효과와 라운드에 따른 수렴은 재지 않는다.
- 한 장비 위의 시뮬레이션이다. 실제 기관 사이의 통신과 지연은 재지 않는다.
- 보안 집계와 차등 프라이버시를 적용하지 않았다. 주고받는 어댑터와 합친 히스토그램에서도 학습 자료의 정보가 추론될
  수 있으므로, 원본 영상을 내보내지 않을 뿐 프라이버시 보장을 주장하지 않는다.
- C3 의 재질은 명목 라벨이다. 재질 물리, 취득 조건, 주석 관행의 영향을 각각 분리할 수 없다.
- 판 두께와 화소당 실치수가 자료에 없어 치수 기준의 합부는 내지 않는다. 조항 점수는 사람이 검수하지 않은
  허용치 표와의 내부 일치다.
- 사전실험(분리형 검출기, 시드 1)의 분류 축에서는 화소를 보지 않는 식별자 순서 규칙이 검출기 다섯 모델을 모두
  앞섰다. 그래서 본실험도 분류 축 수치는 이 규칙과 나란히 싣되 성능 주장으로 쓰지 않는다.
