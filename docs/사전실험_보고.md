# 검출기 사전실험: 수행 내용, 결과와 한계

이 보고서는 공개 용접 방사선 영상으로 개별·중앙집중·연합학습을 비교한 **검출기 사전실험**을 설명한다.
2026년 8월의 데이터 준비와 작은 실행, 9월의 세 시드 학습, 이후 재채점·검토 결과를 다룬다.
통합형 비전-언어 모델의 정식 비교 결과나 현장의 합격·불합격 판정 성능을 보고하는 문서는 아니다.

처음 읽는다면 1절의 요약과 5절의 결과부터 보면 된다. 다음 실험의 현행 조건은 [실험 설계](실험설계.md), 코드의 연결은 [구현 설계](구현설계.md)에 있다.
9월 18일 이전에는 통합형 두 조건과 분리형 세 조건을 묶어 ‘다섯 칸’이라고 불렀다. 지금의 본실험은 통합형의 로컬·중앙집중·연합 비교에 집중하며 이 보고서의 사전실험과 구분한다.

## 1. 무엇을 했고 무엇을 알게 됐나

용접 방사선 이미지 62,308장을 정리해 공통 평가셋 12,461장을 먼저 분리했다.
나머지 학습·검증 자료를 세 참여자 역할로 나누고 YOLO11s 검출기를 세 방식으로 학습했다.
서로 다른 시드에서 세 번 반복해 총 15개 모델을 얻었다.

공통 평가셋의 세 시드 평균 mAP@50은 중앙집중 0.4946, 연합 0.2709, 로컬 평균 0.1973이었다.
그러나 로컬 C1은 연합보다 높았고 C3에 대응하는 출처에서도 로컬이 높았다. 공동 모델이 로컬 평균보다 높다는 결과를 모든 참여자의 이익으로 확대할 수는 없다.

계산을 다시 확인하는 과정과 별개로, 비교의 한계도 드러났다. 학습·평가 사이에 매우 유사한 영상이 섞여 있고 그 범위는 아직 확정하지 못했다.
사진 번호만 쓰는 규칙이 이미지 수준 분류에서 모델보다 높았으며 연합학습의 데이터 순서가 반복되는 경로도 확인했다.
따라서 이 보고서의 수치는 **기존 분할에서 얻은 탐색적 비교**로 해석한다. 새로운 영상이나 현장에 대한 성능 보증으로 사용하지 않는다.

## 2. 비교한 세 학습 방식

C1·C2·C3는 공개 데이터로 구성한 참여자 역할이다. 실제 세 회사가 참여한 현장 실험은 아니다.

| 방식 | 학습에 쓰는 자료 | 시드당 모델 수 |
|---|---|---:|
| 개별 학습(로컬) | 각 참여자 역할의 자체 학습 자료 | 3 |
| 중앙집중 학습 | 세 참여자의 학습 자료를 합친 풀 | 1 |
| 연합학습 | 각자의 자료로 학습한 모델 값을 반복 집계 | 1 |

시드는 난수의 시작값이다. 시드마다 모델 다섯 개를 얻고 세 번 반복했으므로 검출기는 15개다.
중앙집중은 전체 학습 자료를 활용하는 비교 기준이며 이론적인 성능 상한을 보장하지 않는다.
연합 집계에서 이미지를 교환하지 않았다는 사실만으로 정보 유출 방지까지 검증했다고 할 수는 없다.

분리형 시스템은 검출기와 규정 검색·판정부를 따로 두는 구성이다. 이번 반복 실험에서 완료한 범위는 그중 검출기다.
통합형은 이미지와 글을 함께 처리하는 모델로 결함과 근거를 출력하는 구성이다. 8월의 통합형 파일럿은 이후 좌표·학습률·어댑터 집계 등을 수정하기 전 결과이므로 성능 근거로 쓰지 않는다.

## 3. 데이터와 비교 조건

### 3-1. 데이터 분할

| 구분 | 장수 | 설명 |
|---|---:|---|
| 공통 평가셋 | 12,461 | 결함 7,086 · 정상 5,375 |
| 학습·검증 풀 | 49,847 | 학습 44,846 · 검증 5,001 |
| C1 | 26,451 | 명목 ST 자료의 일부 |
| C2 | 16,253 | 명목 ST 자료의 나머지 |
| C3 | 7,143 | 명목 AL 자료 |

C1·C2는 결함 분포가 다르도록 디리클레 분포를 이용해 나눴다. 위 참여자별 장수는 학습·검증 풀의 합이다.
ST·AL은 제공된 라벨에 따른 출처 구분이다. 명목 AL 파노라마의 판독 가능한 표본에서는 강 계열 규격이 확인됐고 결함 크롭의 실제 재질은 확인하지 못했다.
따라서 C3를 알루미늄 회사로 부르거나 집단 차이를 실제 재질의 물리적 효과로 단정하지 않는다.

평가 자료는 참여자 분할보다 먼저 분리했다. 파일 내용 해시, 같은 검사 방식·명목 재질 안의 연속 숫자 ID, 지각 해시 일치를 결합해 묶음을 만들었다.
ID는 실제 용접부나 촬영 세션을 확인한 식별자가 아니라 대용 기준이다. ID 묶음 안팎의 지각 해시 거리 분포가 잘 구별되지 않아 지각 해시는 거리 0인 경우에만 썼다.
분할 목록은 8월 31일 고정했지만, 이 절차가 누출을 모두 막았다는 뜻은 아니다.

원본 영상은 읽기 전용으로 관리한다. 어떤 영상을 사용했는지, 어느 분할에 속하는지는 매니페스트라는 파일 목록과 해시로 기록한다.
프로젝트 규약은 AI허브 영상의 학습·추론을 국내 장비로 제한한다. 이미지와 원본 규정 문서를 이 공개 저장소에 배포하지 않는다.

### 3-2. 맞춘 조건과 맞추지 못한 조건

검출기는 YOLO11s, 입력 크기는 640, 배치는 32로 고정했다.
로컬·중앙집중은 100 epoch, 연합은 50라운드 × 라운드당 2 epoch로 기준 표본의 순회 예산을 맞췄다.
한 epoch는 기준 학습 표본을 한 차례 순회하는 단위다. mosaic 증강의 추가 표본 노출, 실제 최적화 갱신 수와 계산 시간까지 같다는 뜻은 아니다.

조기 종료나 검증 점수가 가장 높은 모델 선택을 쓰지 않고 마지막 모델을 같은 공통 평가셋에서 채점했다.
기존 세 시드와 학습 순서 정책을 바꾼 후속 실험은 별도로 기록하고 합산하지 않는다.

### 3-3. 이미지를 보지 않는 대조선

전처리 전에는 결함 사진이 모두 1280×720 크롭이고 정상 사진은 대부분 긴 파노라마였다.
RT/ST 부분집합에서 이미지 크기만으로 결함 여부를 96.1% 맞힐 수 있었다.
정상 영상을 타일로 잘라 크기를 맞춘 뒤에도 크롭·타일의 출처 차이는 남는다.

사진 번호와 결함 종류도 얽혀 있어, 번호를 512구간으로 나누고 학습·검증 풀의 클래스 빈도를 쓰는 규칙을 대조선으로 삼았다.
번호가 실제 촬영 시간 순서라고 확인한 것은 아니다. 모델이 이 규칙보다 낮다는 결과만으로 모델의 내부 동작을 특정할 수는 없지만, 높은 점수가 영상의 결함 특징을 배웠다는 충분한 근거도 아니다.

당시 GPU 한 장에서 한 시드의 세 학습 방식을 실행하는 데 약 32시간이 걸렸다.

## 5. 무엇이 나왔나

### 5-1. 위치 검출과 회복률

mAP@50은 결함 종류와 상자 위치의 일치를 평가하는 지표다. 이미지 몇 퍼센트를 맞혔는지를 뜻하는 정확도와 다르다.
로컬 평균은 같은 평가셋에서 채점한 C1·C2·C3 점수의 비가중 산술평균이며, 모델 가중치를 합친 모델의 성능이 아니다.

| 비교 | 공통 평가셋의 세 시드 평균 mAP@50 |
|---|---:|
| 중앙집중 | 0.4946 |
| 연합 | 0.2709 |
| 로컬 평균 | 0.1973 |
| 로컬 C1 | 0.3595 |
| 중앙집중 − 연합 | 0.2237 |

회복률은 `(연합 − 로컬 평균) / (중앙집중 − 로컬 평균) × 100`이다.
시드별 29.0%, 22.6%, 22.7%를 평균하면 24.8%다. 정확도가 24.8% 상승했다는 의미가 아니다.
평가 묶음 부트스트랩 95% 신뢰구간은 [20.9%, 29.3%]다.
세 학습 시드를 고정하고 평가 묶음 1,245개를 2,000회 재표집한 구간이므로 새 학습 시드나 새 현장의 변동은 포함하지 않는다.
신뢰구간의 추가 판정 규칙은 세 시드 채점 뒤 정했으며 사전등록이 아니다.

공통 평가셋에서 C1 로컬 대비 연합의 시드별 상대 변화율 `100 × (연합 − C1 로컬) / C1 로컬`은 평균 −24.6%다.
24.6%p 하락이나 C1 자체 현장에서의 손익을 뜻하지 않는다. 이 변화율과 원시 격차의 신뢰구간은 별도로 산출하지 않았으므로 회복률 구간을 대신 붙이지 않는다.

| 같은 두 모델의 평가 대상 | C3 로컬 | 연합 |
|---|---:|---:|
| 공통 평가셋 12,461장 | 0.0984 | 0.2709 |
| 명목 AL 부분집합 1,786장 | 0.4802 | 0.2267 |

전체 혼합 자료와 출처별 자료에서 순서가 달랐다. 모든 참여자에게 연합학습이 유리했다고 결론 내릴 수 없다.

### 5-2. 학습·평가 영상의 독립성 한계

학습 자료와 평가 자료에는 같은 사진 또는 같은 용접부로 의심되는 교차 쌍이 있다.
2026-09-21에 무작위로 고른 40쌍의 배포 원본을 확인했다. 바이트가 완전히 같은 쌍은 없었지만 JPEG 압축 양자화표는 모두 같았고 평균 밝기 차이가 1 이하인 쌍은 39쌍이었다.
정합을 맞추지 않고 측정한 평균 절대차의 중앙값은 2.14였다. 확인한 쌍은 양쪽 모두 배포 원본에 있었다.

같은 사진의 재저장인지 같은 용접부의 재촬영인지는 구별하지 못했다. 후자여도 같은 시험체와 결함을 공유하므로 독립 관측이라고 보기 어렵다.
확인한 표본을 전체 중복률이나 성능 영향의 크기로 확대하지 않는다. 9월 21일 검토한 판정 규칙 네 개는 반례 검토에서 기각됐고 검증된 목록은 아직 준비 중이다.
미검증 제외 목록으로 센 노출 차이도 확정값이나 하한으로 쓰지 않는다.

따라서 24.8%는 기존 분할과 평가셋의 결과다. 학습에서 보지 못한 영상의 성능 대표값이 아니다.
나중에 제외 후 다시 채점하더라도 차이에는 평가 자료의 구성 변화가 섞이므로 중복의 인과효과로 단정하지 않는다.

### 5-3. 시드 1에서 확인한 지름길과 임계값 문제

시드 1의 위치 검출 mAP@50은 중앙집중 0.4926, 연합 0.2820, 로컬 평균 0.1958이고 회복률은 29.0%였다.
사진 번호 구간별 중앙값 상자를 쓰는 위치 대조선은 0.0044였다. 시험한 위치 대조선보다 모델 점수가 높지만 출처 편향 해소나 현장 일반화의 증거는 아니다.

이미지 수준 macro-AP에서는 가장 높은 검출기인 중앙집중이 0.8229, 사진을 보지 않는 규칙이 0.9582였다.
검출기 다섯 모델이 모두 이 규칙보다 낮아 분류 축의 대표 성과 수치 채택을 철회했다.
별도 판별력 지표도 사진 번호 규칙 0.6177이 가장 좋은 모델 0.5827보다 높았다. 지름길이 통과할 수 없는 지표라는 해석을 철회했다.

신뢰도 0.25를 적용하면 다섯 모델은 예측 상자의 87.6~94.2%를 버렸다. 남은 비율은 연합 5.84%, 로컬 C3 12.41%였다.
이는 실제 결함 누락률이 아니다. 임계값에 따라 모델 순서가 달라져 열네 개 값의 곡선과 mAP@50을 함께 보고한다.
mAP도 출력 하한과 추론 설정에는 의존한다. 열네 값은 9월 2일 코드에 고정했으나 공식 설정 등록은 시드 1 채점 뒤인 9월 8일이므로 사전등록으로 부르지 않는다. 시드 2·3 채점 전에는 등록했다.

### 5-4. 학습 순서와 편향의 영향

연합에서는 라운드마다 로더를 다시 만들며 같은 난수 시드를 사용해 학습 순서가 반복되는 경로가 있었다.
해당 구성을 모사한 CPU 검사에서 100 epoch 동안 서로 다른 순서는 연합 2개, 중앙집중 100개였다.
실제 YOLO의 모든 증강 경로를 계측한 결과는 아니며 성능에 미친 방향과 크기는 모른다.
같은 편향이 모든 모델에 들어갔다고 영향까지 같은 것은 아니다. 시드 1의 크롭 정상 영상 오탐률은 모델별 18.5~49.4%였다.

### 5-5. 계산 검산이 확인한 범위

검출기 15개의 mAP@50·mAP@50:95는 v1·v2·v3에서 같았다. 입력 출처나 검수 상태까지 모든 파일이 같다는 뜻은 아니다.
다른 구현에서도 같은 평가 기록과 정의로 15개 mAP@50 및 회복률이 일치했다.
계산 일치가 데이터 분할, 학습·추론, 지표 선택이나 현장 일반화를 검증하지는 않는다.

원 결과는 로컬 `outputs/main_d/seed{1,2,3}/score_cells_v3.json`, 집계는 `outputs/main_d/seed3set/`의 `aggregate_v3.json`과 `recovery_ci_v3.json`에 보존한다.
이 파일들은 공개 저장소에 없으며 공개된 [당시 결과표의 근거](회의/2026-09-13_결과근거.json)와 원 산출물을 구분한다.

## 6. 다음 실험에 반영할 사항

현재 본실험은 통합형 VLM의 세 학습 방식을 비교한다. 검출기·규정 판정부와의 구조 비교는 본실험에서 제외했으며 분리형 확장은 시간 여유가 있을 때 검토한다.
9월 18일 이전의 검출기 우선 확대안과 통합형 두 조건 계획을 현행 절차로 사용하지 않는다.

| 사전실험의 문제 | 후속 비교에서 확인할 것 |
|---|---|
| 평가 대상에 따라 모델 순서가 달라짐 | 같은 표본의 모델·대조선과 출처별 결과를 함께 보고하고 참여자별 목표 모집단을 명시 |
| 학습 순서 반복과 재개·로그 문제 | 공통 학습 정책, 마지막 모델, 저장·재개와 전체 실행 기록 확인 |
| 데이터와 지름길의 영향 | 중복·출처별 한계를 기록하고 기존 평가셋의 탐색적 성격 유지 |
| 채점기 버전·입력 연결 문제 | 코드·설정·입력·출력 해시로 결과의 출처를 연결 |
| 이미지에 실측 조건이 없음 | 이미지의 근거 제시와 조건부 텍스트 규칙 적용을 분리 |

현재 이미지에는 두께와 화소당 실제 길이가 부족하다. 결함 상자를 찾았다는 사실만으로 mm 단위 합부 판정을 검증할 수 없다.
합성문에 설정한 두께·길이는 이미지에서 측정한 값이 아니다. 원문 수치와 독립적인 사람 정답을 확인한 뒤 과업별 정확도를 평가해야 한다.
검증기 선택용으로 계획한 사람 라벨 100건은 최종 정확도를 입증하는 표본 수가 아니다. 선택용과 최종 평가용 자료, 가까운 변형을 분리하고 평가자에게 자동 판정·표집층을 가려야 한다.

이전 계획의 12.6~21.0 GPU-일은 한 시드의 12,461장에 분리형 판정부 5패스·통합형 2패스를 적용한 **추론 추정치**다.
학습 시간은 빠져 있으며 0.8B 실측에 미측정 4B 배율 ×3~5를 적용했다. 당시 `clause_only` 안의 통합형 2패스 추정은 6.7~11.2 GPU-일이었다.
이 값을 현재 실험 예산이나 실측 완료 기간으로 사용하지 않는다. 현행 예산·축소안·미정 사항은 [실험 설계](실험설계.md)를 따른다.

## 7. 이 결과로 말할 수 있는 것

공개 데이터에서 세 학습 방식을 실행하고 같은 평가 기록의 계산을 대조했다. 평가 대상에 따라 로컬과 연합의 순서가 달라졌고 비교를 해석할 때 통제할 문제도 찾았다.
연합이 중앙집중을 넘어야만 연구가 성립하는 것은 아니다. 다만 지금 수치만으로 기업의 참여 편익, 현장 합부 판정, 학습 순서의 인과효과를 결론 내릴 수는 없다.

본실험의 실행·검증을 마치기 전에는 코드 구현이나 좋은 사전실험 점수를 완료의 근거로 삼지 않는다.
과거 모델과 결과를 보존하고 조건을 바꾼 실행은 새 실험으로 기록한다.
