# 용접 결함 판정 연구 · 실험 설계

통합형 VLM의 로컬 단독·중앙집중·연합학습을 비교한다. 통합형과 분리형의 구조 비교는 본실험 범위에 포함하지 않는다.
통합·로컬은 각 참여자의 자체 학습을 기준으로 성능 변화를 측정하기 위해 포함한다.
분리형 검출기의 세 학습 조건·세 시드 결과는 완료된 사전실험으로 보존한다.
YOLO와 언어모델 판정부를 연결하는 과업은 시간 여유가 있을 때 검토한다.
평가셋 선분리, 묶음 단위 분할, 동결 스냅샷과 마지막 체크포인트 채점 원칙은 유지한다.
실험 설계는 다음 요소를 구분한다. 아래 정의와 예상치는 통합형 본실험의 측정 결과가 아니다.

| 항목 | 내용 |
|---|---|
| 통합형 대표 지표 | 대표값, 채점 규칙, 대조선, 분모와 신뢰구간 적용 |
| 통합형 학습 예산 | N·R·E와 공용 설정의 적용 범위 |
| 참여자별 평가 규약 | 공통 평가와 출처별 분석, 변화와 상대 향상률의 요약 규칙 |
| 시드와 축소 조건 | 시드 수, 소요 시간 산정, 축소 순서의 적용 조건 |
| 배경지식 학습 | 공통 출발점과 구현 범위 |

공개 데이터를 세 참여자 역할로 나눠 중앙집중 1개·로컬 3개·연합 1개를 시드별로 학습했다. 세 시드에서 검출기 15개를 얻었으며 실제 세 회사가 참여한 실험은 아니다. 같은 코드로 채점한 v3의 결과와 한계는 평가 절에 제시한다. 별도 구현과의 일치는 같은 평가 기록·정의에서의 mAP@50 계산에 한정되며, 평가셋 구성이나 현장 일반화 검증은 아니다. 규정 정답과 통합형 정식 비교는 완료되지 않았다.

시드 1 채점 역시 분리형 검출기 다섯 모델이 대상이며 통합형 결과는 포함하지 않는다. 아래의 실행 설계·예산 예상치는 완료 실적과 구분한다.

# 1. 연구 프레임

## 1-1. 문제

회사별 용접 검사 데이터를 한곳에 모으기 어려운 상황을 가정한다. 데이터를 모으지 않고 학습 결과만 주고받을 때 검출 성능이 어떻게 달라지는지 확인하는 것이 출발점이다.

그 위에 어떤 모델 구조를 얹을지에서 두 갈래가 나뉜다.

| 구조 | 동작 |
|---|---|
| **통합형** | 용접 이미지를 그림·글 통합 모델에 그대로 넣어 결함 판단과 판정문 작성을 한 번에 수행 |
| **분리형** | 전용 검출 모델이 결함의 종류·위치·크기를 숫자로 산출하고, 언어모델이 규정을 검색해 합부와 근거 조항을 정리 |

## 1-2. 학습 방식 세 가지

| 방식 | 정의 |
|---|---|
| **로컬 단독** | 각 회사가 자기 데이터로만 학습. 아무것도 주고받지 않음 |
| **중앙집중** | 전체 학습 데이터를 모아 학습하는 비교 기준. 보장된 성능 상한은 아님 |
| **연합학습** | 각 회사가 로컬 학습 후 가중치만 서버로 전송, 서버가 평균해 재배포 |

## 1-3. 실험 구성

본실험은 통합형 VLM의 세 학습 방식을 비교한다.
통합·로컬은 C1·C2·C3별로 학습한다.

| 구분 | 구성 | 범위 |
|---|---|---|
| 본실험 | 통합·로컬 | 각 참여자의 학습자료로 만든 자체 모델 |
| 본실험 | 통합·중앙 | 전체 학습 풀로 만든 비교 모델 |
| 본실험 | 통합·연합 | 참여자별 어댑터를 집계한 공동 모델 |
| 사전실험 | 분리형 검출기 × 로컬·중앙·연합 | 세 시드 학습과 검출 채점 완료 |
| 여유 시 과업 | YOLO와 언어모델 판정부 연결 | 수행 여부 별도 결정 |

참여자별 성능 변화는 통합형의 자체 학습 기준선과 비교하며 분리형 결과로 대신하지 않는다.

통합형의 학습 예산은 N = E = R = 1이며 학습 시드는 1이다.
소요 시간은 실제 사용 장비에서 다시 산정한다.
분리형 판정부까지 검증이 완료된 것은 아니다.

## 1-4. 연구 질문

| 질문 | 내용 | 비교 대상 |
|---|---|---|
| **RQ1** | 통합형 연합학습의 성능은 로컬 단독 및 중앙집중 학습과 비교해 어떻게 달라지는가 | 통합·로컬 평균 ↔ 통합·중앙 ↔ 통합·연합 |
| **RQ2** | C1·C2·C3 각 참여자 역할의 자체 모델과 공동 모델 사이에 어떤 성능 차이가 있는가 — 이득·손해와 이득이 가장 작은 참여자 | 각 통합·로컬 모델 ↔ 통합·연합 |

RQ1이 주 연구 질문이다.
중앙집중 학습은 전체 학습자료를 사용하는 비교 기준이다.
보장된 성능 상한은 아니다.
회복률의 대표 채택은 지표 선택과 분모·신뢰구간 검증을 거쳐 판단한다.
현장에서 허용할 수 있는 성능 차이는 별도 검증이 필요하다.

RQ2는 세 참여자 역할 모두의 성능 변화를 다룬다.
기본 비교는 공통 평가셋에서 수행한다.
명목 ST·AL별 결과는 출처 집단별 보조 분석으로 둔다.
모든 참여자의 성능이 향상된다고 가정하지 않는다.

## 1-5. 비교 항목 다섯 가지

결함을 놓치는 비율, 위치 정확도, 판정 근거의 신뢰도, 처리 속도, 회사 간 주고받는 양. 지표 정의는 8장.

# 2. 데이터 자산 개요

실험에 들어가는 데이터는 여섯 덩어리다.

| ID | 자산 | 용도 | 범위 |
|---|---|---|---|
| D1 | 이미지 + 결함 라벨(폴리곤) | 검출 학습, 통합형 학습 원천 | 회사별 분할 |
| D2 | 텍스트 원문 시드 (규격·학회지·선급 규정) | corpus 생성 재료, 규정 색인 | 공통 |
| D3 | 합성 텍스트 corpus 3종 | 배경지식 학습 | 공통 |
| D4 | 이미지-판정문 페어 | 통합형 학습 타깃 | 회사별 분할 |
| D5 | 규정 색인 (조항 단위) | 분리형 판정부 검색 | 공통 고정, 집계 대상 아님 |
| D6 | 평가 자산 (평가셋·정답 조항 목록·낯선 데이터) | 채점 | 격리 |

전체 흐름은 다음과 같다.

```
[A] 이미지 수집(D1) ─┬─ [B] 정제 · 평가셋 선분리 · 회사별 분할
[A'] 텍스트 시드(D2) ─┴─ [C] 합성 생성: corpus(D3) + 이미지-판정문 페어(D4)
        ↓
[D] 검증 · 스냅샷 고정 (D3 · D4 · D5)
        ↓
[E] 배경지식 학습 (유지 여부 미정)
        ↓
[F] 통합형 본실험 (로컬·중앙·연합)
        ↓
[G] 규정 검색 판정(분리형) / 직접 생성(통합형)
        ↓
[H] 평가 + 낯선 데이터 검증(D6)
```

이미지·평가 분할은 공통으로 사용한다. 배경지식 학습은 언어 모델의 준비 단계이며 검출
모델과 같은 초기값을 뜻하지 않는다. 구조별 입력과 검색 제공 여부의 차이는 비교 해석에
포함한다(1-1절, 5-3절).

## 3-2. 주 데이터 구성

AI허브 RT 데이터의 클래스별 수량은 다음과 같다. **실측값이다.**

| 구분 | 정상 | 균열 | 기공 | 융합불량 | 슬래그혼입 | 계 |
|---|---|---|---|---|---|---|
| RT 강재(ST) | 23,696 | 2,054 | 24,345 | 2,928 | 1,030 | **54,053** |
| RT 알루미늄(AL) | 4,698 | 294 | 2,621 | 300 | 1,032 | **8,945** |

강재는 기공이 45.0%이고 슬래그가 1.9%인 반면, 알루미늄은 기공 29.3%에 슬래그 11.5%다. 슬래그혼입은 절대 수량이 AL 1,032 대 ST 1,030으로 거의 같은데 비율이 여섯 배 가까이 갈린다. 라벨 집단에 따라 클래스 분포가 실제로 다르므로, 인위적으로 편중을 부여하지 않아도 이질성이 확보된다.

위 표와 백분율은 라벨 전수 집계다. **논문의 이질성 수치는 전처리·폐기를 반영한 동결 스냅샷의 값**을 사용한다. 이미지-유형 발생 기준으로 명목 ST·AL 집단의 클래스 분포 총변이거리는 **0.1910**, 슬래그혼입 비율 배수는 **5.91**(발생 이미지 ST 1,059 대 AL 1,049), 규모 불균형은 **1 : 5.98**(ST 53,379 대 AL 8,929)이다. 라벨 전수 집계와 동결 스냅샷은 분모가 다르므로 섞어 쓰지 않는다.

VT 66,615장은 클래스 체계가 다르다 (용입부족·언더컷이 있고 균열·슬래그가 없다). 주 실험에 섞으면 라벨 공간 자체가 어긋나는 별도 난이도가 생기므로, 주 실험은 RT로 한정하고 VT는 확장과 낯선 데이터 쪽으로 돌린다.

### 3-2-1. 규격 지름길 — 정상과 결함이 해상도로 갈린다

**시드 1에서 출처별 성능 차이가 나타났다.** 분리형 세 학습 조건의
검출기 다섯 모델 모두 정상 크롭에서 오탐이 더 많았고, 두 출처의 동등성을 설정한 허용 폭
안에서 확인하지 못했다. 기존 혼합 평가셋 결과를 보존하고 출처별 결과를 병기한다(결과표
T8·T8-a). 같은 방향의 편향이 있다는 사실만으로 상대 비교의 타당성이 보장되지는 않는다.
현재 결과는 동결한 혼합 모집단에 한정하며, 출처 비율 재가중이나 새로운 취득 조건의
평가는 별도 검증이 필요하다.

실측에서 나온 문제다. **결함 이미지는 전량 1280×720 크롭이고 정상 이미지는 대부분 파노라마**다. 모델이 결함을 배우지 않고 해상도만 보고 맞힐 수 있다는 뜻이다.

초기 분류 축은 4결함 Macro-F1 기준으로 비교했다. 모든 이미지에 결함을 주장하는 전량양성 대조선이 **0.2081**, 1280×720에만 주장하는 규격전용 규칙의 시험 범위 내 최댓값이 **0.3025**였다. **두 대조선의 점수 차이는 +0.0944**다. 검출 모델에서 규격 지름길의 인과 효과를 분리해 측정한 값은 아니다.

이 문제를 처음 보고할 때 인용한 **96.1%는 RT/ST 이진 규칙의 정확도**다. 위의 4결함 Macro-F1과 대상·지표가 달라 같은 성능 값으로 비교하지 않는다. Macro-F1을 대표 지표로 두었던 초기안은 8-5절에서 변경했다. 현재 분류 축에는 대표 성과 숫자를 두지 않는다.

대응은 **정상 파노라마의 타일링과 고정 기준값을 사용한 진단 실험을 결합해 검증**하는 것이다. 기준값은 파일럿 채점 뒤에 정했으므로 사전등록이 아니다. `fixed_before_main_runs`는 본실험 착수 전 확정이라는 뜻이다. 분할을 먼저 하고 타일링을 뒤에 한다.

## 3-3. 정제

**(a) 라벨 사상표.** 학습 라벨은 원본 체계를 그대로 쓰고, 조항 검색과 낯선 데이터 평가에서만 ISO 6520-1 코드를 쓴다. 원본 라벨을 바꾸면 선행 연구와 비교가 깨진다.

| 원본 (AI허브 RT) | ISO 6520-1 |
|---|---|
| 균열 Crack | 100번대 |
| 기공 Porosity | 2011 / 2012 |
| 융합불량 Lack of fusion | 401 |
| 슬래그혼입 Slag inclusion | 301 |
| 정상 | 해당 없음 |

RIAWELC의 용입불량(402)은 AI허브 RT에 없다. 낯선 데이터 평가는 공통 3클래스(균열·기공·정상)로 축소해 산출하고 사유를 명시한다.

**(b) 폴리곤에서 bbox 생성.** 검출 학습용 bbox는 폴리곤 좌표의 min/max로 만든다. 결함 크기(장축 길이, 등가 직경)는 폴리곤에서 직접 산출해 판정문 생성 재료로 쓴다. 변환 스크립트는 시드 고정 후 공개한다.

**(c) 중복 위험을 줄이기 위한 묶음.** 파일 내용 해시, 같은 검사 방식·명목 재질 안의 숫자 ID 연속 구간, 지각 해시 완전 일치를 결합해 묶고 같은 묶음은 같은 쪽에만 배정했다. 실제 용접부·연속 촬영 세션을 확인한 식별자는 아니므로 누출을 모두 막았다고 보지는 않는다.

**(d) 전처리 통일.** 입력 해상도 640, 정규화, 증강 설정을 다섯 칸에 동일하게 고정한다. AI허브 원본이 1280×720 이상이므로 레터박스 리사이즈 정책을 명시한다.
비교 조건 사이의 전처리 고정 범위는 6-1절을 따른다.

## 3-4. 평가셋 선분리와 회사별 분할

```
RT 62,308장 (동결 스냅샷)
  ├─ 글로벌 평가셋 20%   12,461   ← 재질·클래스 층화, 묶음 단위, 클라이언트 분할보다 먼저
  └─ 학습 풀 80%        49,847
       ├─ C1  RT 명목 ST  26,451  ┐ 설계 사전분포 2:1, 이 둘 사이에만 Dirichlet α=0.5
       ├─ C2  RT 명목 ST  16,253  ┘ (실현 지분 0.62 — 편중 배정의 실현값, 수용 밴드 안)
       └─ C3  RT 명목 AL   7,143    자연 분할. Dirichlet 미적용
```

**위 C1·C2·C3 규모는 평가셋 20%를 먼저 뗀 뒤의 학습 풀 기준이다**(불변조건 1-3의 순서를
지킨 값). 분할 단위는 위 대용 기준으로 만든 이미지 묶음이며, 동결 스냅샷의 묶음은 6,232개
(AL 954 / ST 5,278)다.

클라이언트를 회사 이름으로 부르지 않는다. 데이터에 회사 구분이 존재하지 않으므로(3-4-1)
실물에 없는 구분을 이름으로 붙이면 허위 서술이 된다. C1·C2·C3은 재질 라벨과 분할 규칙으로만
정의한다.

C3의 소수 클래스는 얇다. 동결 실측으로 균열 265장, 융합불량 257장이다.
클라이언트별 클래스 소실은 없으나 이 얇기를 결과 해석에 반영한다.

### 3-4-1. 자연 분할 축은 명목 재질 라벨 하나뿐이다

라벨 129,613개 전수에 회사·사업장·설비·촬영일·작업자 관련 키를 정규식으로 검색한 결과
**히트 0건**이다. 스키마가 22키뿐이고 그게 전부다. 사용 가능한 자연 축은 **재질(ST/AL)과
촬영방식(RT/VT)** 두 가지이고, 주 실험이 RT 한정이므로 실제로 쓸 수 있는 축은 **재질 라벨 하나,
값 두 개**다. 명목 AL의 파노라마 표본에서는 강 계열 스펙이 나타났지만, 마커가 없는 결함 크롭의 실제 재질까지 알 수 있는 것은 아니다(11-1).

실제 회사 정보로 C1과 C2를 나눌 근거는 없다. 명목 ST 자료 안에서 클래스 분포가 다른
참여자 역할을 구성하도록 C1·C2 사이에 Dirichlet α=0.5를 적용했다. C3에는 적용하지 않았다.

논문에는 **"명목 재질 라벨 기반 분할 + 명목 ST 내부 통제 이질성"**으로 쓴다.
실제 회사별 분할이나 실제 재질 차이를 확인한 실험으로 설명하지 않는다(11-1).

분할 이후에 평가셋을 떼면 비교 조건들이 서로 다른 기준으로 채점된다. 반드시 먼저 뗀다.

C3는 명목 AL 집단으로, 클래스 분포 차이(label skew)와 작은 규모(quantity skew)는 관측됐다. 실제 회사·프로젝트 구분은 확인되지 않았으므로 편익은 이 집단의 평가 결과로 한정한다.

명목 라벨에 따른 분할과 C1·C2의 통제 이질성을 함께 사용한 설계다. α 값과 분할 시드를 논문에 명시한다.

## 3-5. 사전 확인 실험 (반나절, 학습 없음)

사전학습 VLM의 제로샷 분류를 RIAWELC과 AI허브 RT 표본에서 측정한다. 용도는 두 가지다.

- 서론 동기: X선 영상에서 범용 VLM의 출발점이 어느 수준인지 실측으로 제시
- 결과 해석: 통합형 두 칸의 성능을 제로샷 대비 향상 폭으로 읽는 기준점

## 3-6. 백업 경로

**AI허브 확보가 끝나 이 경로는 발동 조건이 소멸했다.** 아래는 낯선 데이터 평가에서 RIAWELC을 쓸 때의 취급으로 남긴다.

유효 표본은 파일 수가 아니라 **고유 이미지 21,964장**이다(`testing` 2,443장은 `training`의 복제본). 논문에 규모를 적을 때 24,407을 쓰면 유효 표본을 부풀리게 된다. 해상도도 224×224가 아니라 **227×227**이다.

**저자 제공 분할을 그대로 쓸 수 없다.** 실측에서 저자 분할의 누수가 100%로 확인됐다. RIAWELC을 쓰는 어떤 경로에서든 **우리 분할 절차(중복 묶음 → 층화 → 분할)를 다시 태워야 한다.** 이 경우 검출이 아니라 분류 과제가 되어 위치 정확도 항목을 낼 수 없으므로, 비교 항목을 다섯에서 넷으로 줄이는 것을 논문에 명시한다.

# 4. 텍스트 데이터와 합성 생성 (D2 · D3 · D4)

## 4-1. 원문 시드 수집

| 출처 | 접근 | 용도 | 우선순위 |
|---|---|---|---|
| 대한용접접합학회지 | KCI 무료 | 서술문·QA 재료 | 최우선 |
| 한국선급(KR) 규정 | 홈페이지 공개 | 규정 색인, 판정 추론 재료 | 높음 |
| IACS Rec. 47 | 전문 무료 공개 | 규정 색인 필수 | 높음 |
| KS 용접 규격 | e나라표준 열람 | 조항 번호·요건 참조 | 중간 |
| ISO 6520-1 코드 체계 | 코드 번호는 사실 정보 | 라벨 온톨로지 | 필수 |
| ISO 5817 · 10675 허용치 | 원문 유료 | 수치 요건을 재서술로만 반영 | 방침 확정 필요 |
| 유료 핸드북, 중국어 자료 | | 제외 | |

한국어를 우선하는 이유는 국내 학회 발표라 명분이 서고, 라이선스가 깨끗하며, 최종 판정문 출력이 한국어여야 하기 때문이다.

저작권 방침은 다음과 같다. 유료 표준 원문은 corpus와 색인에 넣지 않는다. 조항 번호, 결함 코드, 허용치 수치는 사실 정보로 보고 재서술해 쓴다. 색인은 무료 공개 문서로만 구성한다.

허용치 표 추출은 본문 텍스트 추출과 별도로 수행한다.

## 4-2. 합성 corpus (D3)

배경지식 학습용으로 세 종류를 만든다.

| 종류 | 형태 | 목표량 | 대응 학습 단계 |
|---|---|---|---|
| (a) 지식 서술문 | 연속 서술문, 질문 형식 없음 | 추가 사전학습 채택 시에만 | 추가 사전학습 (선택) |
| (b) 질의응답 | Q / A | 20,000건 (하한 10,000) | 지시 학습 |
| (c) 판정 추론 과정 | 관찰 → 분류 → 조회 → 대조 → 판정 | 10,000건 | 추론 학습 |

(c)의 합성 수치 예시 형식(실이미지에서 측정한 값이나 검수 완료된 정답이 아님):

```
관찰 : 방사선 사진 중앙부에 직경 약 2 mm의 원형 음영
분류 : 형상과 밀도로 보아 기공 (ISO 6520-1 2011)
조회 : 모재 두께 12 mm, 품질 수준 C → 단일 기공 허용 직경 3 mm
대조 : 2 mm ≤ 3 mm
판정 : 합격. 근거 ISO 5817 품질수준 C
```

결함 유형 × 두께 구간 × 품질 수준 조합 중 실제로 존재하는 조합만 생성한다. 추가 사전학습은 본실험에 포함하지 않는다.

## 4-3. 이미지-판정문 페어 (D4)

통합형은 이미지를 넣어 판정문을 바로 받는 구조이므로, 학습에 쓸 페어 데이터가 별도로 필요하다.

```
생성 절차
  AI허브 라벨 (결함 종류 + 폴리곤)
    → 규칙 기반 골격 생성: 종류 · bbox · 적용 가능한 조항과 기준 서술
    → LLM으로 문장 표현만 변주 (골격 수치는 불변)
    → 출력 스키마 고정: 종류·bbox·기준 서술·인용 조항 (실치수와 치수 기준 합부는 생성하지 않음)
```

위 절차는 페어 데이터의 설계다.
파일럿과 본실험의 학습 답안은 `target_text`를 사용하지 않고 골격의 `defects`, `verdict`, `cited_clauses`로 구성한 구조화 JSON이다.
기준 서술과 영상 설명문은 다섯 모델의 학습 답안에 넣지 않는다. 대표 지표 M1은 결함 종류와 상자를 평가하며,
설명문을 생성한 사실이나 조항 필드가 존재한다는 사실을 규정 판정 성능의 검증으로 해석하지 않는다.

세 가지를 지킨다.

- 회사별 분할은 D1을 그대로 상속한다. C1 이미지의 페어는 C1에만 들어간다
- 평가는 텍스트 유사도로 하지 않는다. 필드 파싱(종류·좌표)과 조항 정확도로만 채점한다. 유사도로 재면 템플릿을 얼마나 잘 흉내내는지를 재게 된다
- 통합형 학습 타깃과 채점용 bbox는 원본 픽셀 좌표계 `ABS_ORIG`를 따른다.

> 기존에 인용한 BBox-IoU 0.055→0.938은 정렬 모듈 입력 수치 속성의 인코딩 비교로 읽힌다(후속 논문 Sun 외 2026, [DOI 10.1109/TII.2026.3678237](https://doi.org/10.1109/TII.2026.3678237), 6486쪽 V-G.2와 표 V 기준).
> 생성 출력의 좌표 규약을 정하는 근거로 사용하지 않는다.
> `ABS_ORIG` 규약의 근거인 합성 도형 4장 제로샷 검사는 0~1000 정규화 배제까지만 뒷받침한다. 시험한 크기에서는 리사이즈 전후 크기가 같아 원본·리사이즈 좌표 프레임을 구별하지 못했으며 미세조정 후 거동은 미측정이다.
> 검수에서 본실험 이미지 62,308장 전부가 1280×720이며 프로세서가 이를 1280×704로 줄이는 것을 확인했다. 본실험 착수 전에 좌표 프레임을 재확인하고, 결과에 따라 학습 정답·생성 출력·채점에 적용할 공통 규약을 확정한다.

## 4-4. 판정 기준의 스케일 문제

ISO 5817과 10675의 합부는 모재 두께 대비 결함 실측 크기(mm)로 갈린다. **전수 실측 결과 모재 두께·결함 실치수·픽셀→mm 환산 필드가 모두 없다.** 라벨 129,613개에 두께·스케일 관련 키를 정규식으로 검색해 히트 0건이고, 스키마 22키에 해당 항목이 존재하지 않는다.

**따라서 치수 기준 판정("2 mm ≤ 허용치 3 mm → 합격")은 원리적으로 성립하지 않는다.** 폴리곤 면적은 계산되지만 단위가 px²이고 mm²로 바꿀 환산 계수가 데이터에 없다. 정상 파노라마에 두께 표기가 찍힌 사례가 관측되나, 결함 이미지로 옮길 연결 키가 없고 곡면 배관의 필름 투영이라 선형 환산 자체가 별도 검증 사안이다.

실물에서 확보되는 축은 **결함 종류·위치·재질 라벨 세 가지**다. bbox의 픽셀 좌표는 실제
어노테이션에서 얻지만 결함 실치수(mm)는 얻을 수 없다. 현재 D4 페어에는 실치수를 만들어
넣지 않으며, 조항의 허용치 수치는 기준 설명으로만 제시한다.

현재 실이미지 페어는 조항 검색과 기준 서술까지로 한정한다
(`corpus/generate/make_pairs_pilot.py`). 가정값 기반 합부는 별도 합성 과업이며 실제 영상의
합부 정확도로 읽지 않는다. 다음 두 가지를 지킨다.

- 치수 기준 합부를 실측 근거로 주장하지 않는다.
- 가정값을 쓰는 경우 가정 두께·가정 스케일임을 지표명과 결과표 각주에 명시한다.

## 4-5. 검증과 버전 고정

생성한 것을 그대로 쓰면 오류가 학습에 들어간다. 세 단계로 거른다.

| 단계 | 방법 | 내용 |
|---|---|---|
| 1 | 규칙 검사 (프로그램) | ISO 코드 유효성, 조항 실존 여부, 부등식 계산, 두께·품질수준 조합 실존 |
| 2 | 조항 대조 (모델) | 인용 조항 원문을 가져와 내용 일치 확인. 생성한 모델이 자기 결과를 검증하지 않음 |
| 3 | 표본 전문가 검토 | 무작위 2~3%, 통과율을 논문에 보고. 도메인 전문가의 검수가 필요하며 아직 완료하지 않음 |

최종 corpus, 페어, 색인에 스냅샷 해시를 부여하고 논문에 명시한다. 재생성하면 검색 결과가 바뀌어 재현이 불가능해진다.

위 표는 검증 계획이다. 파일럿의 허용치 표는 미검수이며
(`corpus/rules/limits_v0_pilot.README.md`), 교차 계열 검증기의 정본은 사람 라벨 100건과의
비교 전까지 미정이다. `corpus/generate/cycle_pilot_v2/cycle_corpus_report.json`의 QA
188건은 형식·중복 검사 통과분으로 사실성 검증 통과분이 아니다. 표의 세 단계나 배경지식
학습이 모두 완료됐다고 보고하지 않는다.

# 5. 배경지식 학습

배경지식 학습의 유지 여부는 미정이다. 아래 절차는 이를 유지할 때의 설계이며 구현·학습 완료를 뜻하지 않는다.
> 폐지해도 기본 모델의 판본과 해시 고정, 다섯 모델의 초기 어댑터 증빙 대조, 중앙·로컬 학습 경로의 초기 가중치 주입 확인은 필요하다. 유지하면 코퍼스 생성·검증, 텍스트 학습 경로 구현, 학습·병합과 재양자화 검증, 출발 체크포인트의 해시 동결과 실제 로더 전달이 추가된다. 이 준비 시간은 본실험 학습 예산과 별도로 산정한다.

## 5-1. 적용 대상

| | 통합형 | 분리형 |
|---|---|---|
| 배경지식 학습 | 그림·글 통합 모델 전체 (QLoRA) | 언어모델 쪽만 |
| 검출 모델 | 없음 | 이미지로만 학습, 텍스트 미적용 |

분리형에서 검출 모델은 텍스트를 보지 않으므로 배경지식 학습 대상이 아니다. 두 구조가 갈라지는 첫 지점이다.

## 5-2. 절차

```
기본 모델
  ↓ (선택) 추가 사전학습: 지식 서술문, QLoRA r=128
  ↓ 지시 학습: 질의응답, QLoRA r=16
  ↓ 추론 학습: 판정 추론 과정, QLoRA r=16
  ↓ 어댑터 병합 → 도메인 체크포인트 동결
다섯 칸의 공통 출발점
```

어댑터는 반드시 기본 모델에 병합한 뒤 배포한다. 병합하지 않고 얹으면 이후 연합 집계 대상이 무엇인지 모호해진다.

추가 사전학습은 수행하지 않는다. 확보 가능한 원문 규모가 요구 수준에 크게 못 미쳐 효과를 기대하기 어렵다. 지시 학습과 추론 학습만으로 어디까지 가는지를 보고한다.

## 5-3. 모델 선정

| 역할 | 모델 | 근거 |
|---|---|---|
| 통합형 | Qwen3.5 4B | 네이티브 멀티모달이라 bbox grounding 출력을 지원하고, 판정부와 체크포인트를 공유할 수 있다 |
| 분리형 판정부 | Qwen3.5 4B (통합형과 동일 체크포인트) | 언어 모델의 초기값을 공유한다 |
| 분리형 검출부 | YOLO11s (9.4M) | 현장 장비 탑재 논거, AI허브 참조 모델(YOLOv5x-seg)과 계열 참조점 |

Qwen 체크포인트를 공유해도 시각 백본은 YOLO11s와 Qwen으로 다르고, 검색도 분리형에만 제공한다. 구성 전체의 차이에서 통합·분리 구조 자체의 효과를 분리할 수 없다.

검출은 bbox 검출로 확정한다. 세그멘테이션은 비용 대비 이득이 없고, 판정 입력에는 종류·위치·크기면 충분하다.

장비를 확보하지 못할 때의 대안은 24GB 기준 설계다.

본실험 페어 자산은 아직 없다.

통합·로컬 학습·채점, 시드별 다섯 모델 실행과 내보내기 경로는 구현이 남아 있다.
현재 채점 계약에는 `uni_local`이 없고, 참여자 식별 필드도 현재는 `sep_local`에만 허용된다.
통합형 실행 경로에는 0.8B 모델과 파일럿 페어 기본값이 남아 있다. 4B 모델과 동결한 본실험 페어 경로가 실제 학습 호출까지 전달되도록 구현해야 한다.
본실험 착수 전에 학습 답안 계약과 조항 정답을 확인한 파일럿 페어로 로컬 세 모델·중앙·연합의 학습·저장·내보내기·추론·채점 전 구간 리허설을 한 번 완료한다.

통합·연합의 LoRA 평균에는 알려진 문제가 있다. 낮은 랭크 어댑터는 두 행렬의 곱이므로 각각을 평균한 것의 곱과 곱을 평균한 것이 다르다.

```
avg(B) · avg(A)  ≠  avg(B · A)
```

실무에서는 각각 평균하는 방식이 널리 쓰이지만 심사에서 지적될 수 있다. 기본은 행렬별 평균으로 가고, 논문에 명시하며, 여유가 있으면 갱신량 자체를 평균하는 방식을 대안으로 비교한다.

## 6-3. 학습량 등가

표본 노출 횟수 기준으로 R × E = N을 맞춘다. 조기 종료 없이 고정 예산으로 돌린다.

| 대상 | 상태 | 로컬·중앙 N | 연합 R × E |
|---|---|---|---|
| 분리형 검출기 | 사전실험 확정 예산 | 100 epoch | R=50, E=2 |
| 통합형 | N = E = R = 1 | 로컬·중앙집중 1 epoch | 연합 1 라운드 × 로컬 1 epoch |

R=50·E=2·N=100은 검출 세 조건의 사전실험 예산이며 통합형 본실험의 N = E = R = 1과 구분한다.
현재 구현은 부분 epoch 실행을 지원하지 않는다.
부분 epoch를 채택하려면 학습 루프·표본 커서·재개·회계까지 검증해야 한다.
스텝 단위 학습률 스케줄만으로 실행 가능성을 판단하지 않는다.

각 예산에서 얻은 결과는 해당 예산의 비교로 보고한다.
다른 라운드 예산에서도 같은 결과가 나온다고 일반화하지 않는다.

이 등가는 학습 예산의 조건이며 데이터 순서·증강·optimizer 갱신 경로의 동치를 뜻하지 않는다. 분리형 연합 실행의 loader 난수 상태는 라운드마다 반복됐다. 중앙·로컬과의 차이가 성능에 미친 방향과 크기는 미확정이다. epoch별 재시드를 적용한 통제 비교는 별도 프로토콜로 구분하고 기존 seed 결과와 합산하지 않는다.

통합형은 N = E = R = 1로 실행하며 설정값과 실제 갱신 횟수를 함께 보고한다. 총 갱신 횟수는 원장의 실측 셀(`value_source == measured`)만 합하며 재개 실행의 복원·재구성 셀은 인용하지 않는다. 재개 실행의 접두 라운드는 원자 로그의 measured 행에서 읽는다.

## 6-4. 시드와 평가 표본

분리형 검출기 사전실험은 세 시드 결과를 보존한다. 통합형 본실험의 학습 시드는 1이다.
학습 시드 변동은 미검증으로 남기며 참여자 간 산포나 평가 묶음 신뢰구간으로 이를 대신하지 않는다.

평가는 동결 평가셋 12,461장에서 묶음 단위로 뽑은 층화 표본으로 한다. 명목 크기는 3,000장이고
실현 목록은 3,080장·300묶음이다. 재질 × 묶음의 이미지당 평균 결함 수 구간(0·1·2–3·4+)의
8층에서 묶음 수를 비례 배분한다. 표본 시드 문자열은 `eval_sample_v1|aihub71761_rt_v1|1f80e98b`다.
추출 입력은 이미지 식별자·분할·묶음·재질·결함 수 요약이며 평가 영상과 주석 상자를 학습에 넣지 않는다.

모든 비교 모델·시드·대조선에 같은 실현 목록과 설계 가중 `G_h/n_h`를 적용한다.
가중 없는 표본 값도 함께 보고한다. 표본 값은 평가셋 전체에 대한 추정이며 전량 평가의 실측과 구분한다.
목록의 지문과 등록 규칙의 지문을 채점·신뢰구간 산출물에 결속한다. 학습 부표본은 별도 실험으로 다룬다.

비용이 허락하면 4,000장 표본을 쓰고 전량 12,461장은 여유 시 덧붙인다. 시드 1 표본의 회복률 분모가
등록된 최소 격차보다 작을 때도 전량 평가를 덧붙인다. 표본 실행과 전량 실행의 예측은 섞지 않는다.
명목 AL의 네 결함 매크로와 출처 간 등가 판정은 표본에서는 판정 불가로 표시하고 점추정과 구간만 싣는다.
표본 목록·층별 가중·실현 크기와 지문은 평가 절에 제시한다.

공통 출발점 준비와 학습·추론·채점·기동·저장·집계 비용은 구분해 계측한다.
이 설계의 학습 설정과 표본 크기를 본실험 전체의 실측 시간이나 비용으로 읽지 않는다.

## 6-5. 통신량 산출

현재 계측값은 교환 배열의 페이로드 바이트다.
배열별 `nbytes`를 합산한다.
프로토콜 부가량을 포함한 실제 네트워크 송수신량은 아니다.

총 배열 페이로드 바이트는 모든 라운드·참여자의 업링크와 다운링크 값을 합산해 보고한다.
현재 다운링크 값은 별도 계측값이 아니라 업링크 값의 복사다.

| 구분 | 라운드당 교환물 | 크기 보고 |
|---|---|---|
| 통합·연합 본실험 | Qwen3.5 4B의 LoRA 어댑터(r=16) | 실제 교환 배열의 바이트 |
| 분리·연합 사전실험 | YOLO11s의 교환 대상 가중치·버퍼 | 실제 교환 배열의 바이트 |

현재 교환 규약에서 부동소수 배열은 fp32다.
정수 버퍼는 원래 dtype을 유지한다.

절감률을 보고하려면 비교 기준과 측정 범위를 먼저 정한다.
기준과 비교 대상의 모델·데이터·라운드·참여 조건을 명시한다.
가정한 전송량과 비교한 계산값은 실측 절감률과 구분한다.
어느 구성이 더 적게 전송하는지는 측정 결과로 판단한다.

# 7. 규정 검색 구성 (분리형 판정부)

| 항목 | 설정 |
|---|---|
| 색인 문서 | IACS Rec. 47, 한국선급 규정, ISO 6520-1 코드 체계, 검증된 합성 판정 사례 |
| 청킹 단위 | 조항 단위. 고정 길이로 자르면 조항 경계가 깨짐 |
| 메타데이터 | 문서명, 조항 번호, 결함 코드, 두께 범위, 품질 수준 |
| 임베딩 | 고정. 학습 방식별 재학습 없음 |
| 검색 | top-k = 3 고정 |
| 질의 | 구조화 키 {결함 코드, 크기, 두께, 품질 수준}. 자연어 질의 생성 금지 |

자연어 질의를 생성해 검색하면 재현성이 떨어지고, 검색 실패 원인이 질의 생성 탓인지 색인 탓인지 분리되지 않는다.

색인은 공개 문서와 검증된 합성 사례로만 구성하며 모든 클라이언트가 동일하게 갖는다. 학습 대상이 아니므로 집계 루프 바깥에 두고, 아키텍처 그림에서도 연합 경계 밖에 그린다.

정답 조항 목록은 결함 유형 × ISO 코드 × 조항 번호로 구성한다. 규모는 크지 않으나 전문가 확인이 필수다. 이 목록이 흔들리면 8-3의 지표 전체가 흔들리므로, 표준 원문의 조항 번호를 그대로 인용하는 방식으로 방어한다.

이 검색 구성은 분리형 확장 설계이며 통합형 본실험에 포함하지 않는다.

| 위치 정확도 | BBox-IoU, mAP@0.5, mAP@0.5:0.95 | 원본 픽셀 bbox로 채점. 통합형 생성 좌표는 `ABS_ORIG`로 파싱. 현재 통합형 mAP는 산출하지 않음(8-5절) |
| 판정 근거 신뢰도 | 8-3 지표군 | 8-3 |
| 처리 속도·자원 | 이미지당 latency, 파라미터 수, VRAM | 동일 장비 실측 |
| 모델 교환량 | 배열 페이로드 바이트 | 6-5절의 계측 범위 적용 |

분리형 사전실험의 대표 지표는 위치 축 mAP@0.5다.
통합형 본실험의 대표 지표는 M1이다.
적용 범위는 8-5절을 따른다.
분류 축을 임계값별 곡선과 메타데이터 대조선으로 함께 보고하는 방침은 분리형 사전실험에 그대로 적용한다.

결함 recall을 따로 뗀다. 현장에서 미검출은 오검출보다 위험하다.

**분류 축 두 지표는 신뢰도 임계의 함수다.** 한 점으로 줄이지 않고 등록 격자 전체의 곡선을 보고한다. 대표 수치는 임계 독립 지표를 사용한다.

신뢰도 임계에 따른 분류 곡선은 점수가 있는 분리형 출력에 적용한다.
통합형 생성 출력의 보고 방식은 8-5절을 따른다.

스키마 위반과 파싱 실패율을 별도로 보고한다.
실패 출력의 과업 지표 처리는 8-5절에 명시한다.

## 8-2. 근거 접지 (선행 연구 지표 계승)

| 지표 | 의미 |
|---|---|
| Class-Jaccard | 판정문이 언급한 결함 종류가 실제 라벨과 맞는가 |
| BBox-IoU | 판정문이 지목한 위치가 실제 위치와 맞는가 |

AI허브의 클래스·위치 라벨로 두 지표를 산출할 수 있다.
RIAWELC에서는 위치 라벨이 없어 BBox-IoU를 산출하지 않는다.
Class-Jaccard는 클래스 사상과 평가 과업의 정합성을 확인한 뒤 적용 여부를 정한다.

### 선행연구와의 관계

선행연구(WeldLLM, 2025년 학회 논문과 2026년 후속 논문)의 결함 종류·위치와 진단 설명을 연결하는 과업을 참고한다.
후속연구의 Qwen 계열 VLM 어댑터 학습도 설계의 참고 대상이다.
Class-Jaccard와 BBox-IoU는 근거 접지를 보는 지표로 활용한다.

본 연구의 통합형에는 별도 검출기의 특징을 결합하지 않는다.
방사선 영상에서 로컬·중앙·연합 학습을 비교한다.
참여자 분할과 데이터 비반출 조건도 연구 설정에 포함한다.

선행연구와는 영상 종류·데이터셋·모델 구성·채점 정의가 다르다.
따라서 보고값을 직접 비교하지 않는다.
지표 이름이 같아도 매칭 방식과 분모를 확인해야 한다.
상용 API가 생성한 응답은 학습 텍스트로 사용하지 않는다.

## 8-3. 조항 정확도 (신설)

| 지표 | 정의 |
|---|---|
| 조항 검색 정확도 | 정답 조항 대비 top-1 / top-3 적중률 (분리형 검색 단계) |
| 인용 일치율 | 최종 판정문이 인용한 조항 ↔ 정답 조항 (두 구조 공통) |
| 판정 정합성 | 입력 수치와 허용치로 재계산한 합부 ↔ 생성 합부. 실측·합성 수치를 구분하며 현재 실이미지의 치수 기준 합부는 산출 대상이 아님 |
| 무근거 인용률 | 실존하지 않거나 무관한 조항을 인용한 비율 |

8-2절의 두 지표는 생성 출력과 정답 클래스·위치의 일치를 잰다.
인용한 규정의 정확성은 별도 지표로 평가한다.
조항 평가의 타당성은 정답 자료의 검증 상태에 따라 제한된다.

합성 수치의 판정 정합성은 규칙 적용의 일치율이며 실제 용접부의 합부 정확도가 아니다.
학습 타깃과 정답이 같은 허용치 표에서 파생되므로 원문·전문가 대조 전에는 내부 일치 이상의
타당성을 주장하지 않는다. 무근거 인용률은 생성문이 존재하지 않거나 무관한 조항을 인용한
비율로 보고한다. 허용치 표와 코퍼스의 검증 상태는 4-5절을 따른다.

## 8-4. 낯선 데이터 검증

낯선 데이터 검증은 보조 평가로 둔다.
수행할 경우 통합형의 로컬·중앙·연합 모델을 같은 대상 자료로 평가한다.
추가 학습은 하지 않는다.
자료 정합성 확인과 추론·채점 비용은 별도로 산정한다.

- RIAWELC으로 추론, 공통 3클래스(균열·기공·정상)로 축소 산출하고 사유 명시
- 익숙한 데이터와의 성능 차이는 시험한 두 데이터셋 사이의 차이로 보고한다. 새 현장의 하락 폭을 직접 예측한 값은 아니다
- 주 결과와 함께 일반화 범위를 설명하는 보조 평가로 보고한다. 수행하지 못하면 미검증으로 남기며, 결과가 좋거나 나쁘다는 이유로 보고 여부를 바꾸지 않는다

## 8-5. 헤드라인 수치

### 통합형 본실험의 지표

통합형의 대표 지표는 M1(클래스 일치 박스 매칭 F1@IoU0.5, 네 결함 매크로)이다. 정의와 실패 처리, 평가 표본은 아래에 제시한다.

| 구분 | 후보 | 현재 상태 |
|---|---|---|
| M1 | 클래스 일치 박스 매칭 F1@IoU0.5(4결함 매크로) | 대표 지표. 구현 `evaluation/metrics/box_f1.py` |
| M2 | 토큰 로그확률 등으로 박스 점수를 정의한 mAP | 보조 후보. 점수 정의와 구현 검증 필요 |
| 분류 축 | 이미지 수준 Macro-F1·클래스별 P/R/F1·결함 재현율 | 현재 구현 있음. 박스 매칭 F1과 구분 |
| 접지 보조 지표 | Class-Jaccard·BBox-IoU | 매칭 방식과 분모를 함께 보고 |

M1을 채택하면 매칭·집계·정상 이미지·실패·빈 클래스 규칙을 함께 고정한다.
매칭의 기본안은 이미지별·클래스별로 원본 이미지의 절대 좌표에서 겹침 비율을 64비트 부동소수점으로 계산하고, 허용오차 없이 0.5 이상인 쌍만 후보로 삼는 것이다. 짝 수를 먼저 최대화하고, 같은 짝 수에서는 겹침 비율의 합이 큰 배정을 선택하며, 남은 동률은 정답·예측 항목 번호에 따른 고정 순서로 해소한다. 중복 예측은 별개 박스로 세고, 클래스별 정탐·오탐·미탐을 평가 모집단 전체에서 합산해 구한 네 결함 클래스의 F1을 산술평균한다.
정상 이미지는 평가 모집단에 남기며 예측 박스는 모두 오탐으로 센다. 정상 이미지의 빈 예측은 정탐·오탐·미탐 수를 늘리지 않는다. 부분집합의 정답에 없는 클래스는 모든 모델에 공통으로 매크로 평균에서 제외하고, 해당 클래스의 예측 수를 보고하며 전체 클래스의 계수를 합친 F1과 오탐 집계에는 남긴다. 평균에 포함한 클래스 목록과 수를 표시하고, 분모가 0인 지표와 정답이 전혀 없는 모집단의 매크로 F1은 미정의로 기록한다. 실패와 항목 폐기는 아래의 실패 처리 기본안에 따라 함께 정한다.
M1을 대표 지표로 채택하려면 원 구현과 별도로 작성한 매칭·집계 구현으로 검산한다. 같은 작성자가 두 구현을 작성해도 독립 구현 요건은 충족하지만 독립 연구자의 검토와 같은 뜻은 아니다. 공유 입력 방식은 같은 정규화 입력을 두 구현에 넣고, 독립 입력 방식은 원시 예측과 정답을 각각 읽는 단계부터 비교한다. 두 방식 모두 클래스별 TP·FP·FN, F1과 M1을 대조하고 입력·코드 식별 정보와 불일치 처리를 남긴다. 자체 시험이나 기존 채점 함수의 재호출은 독립 검산이 아니다.

현재 생성 출력에는 박스별 점수가 없다.
현재 채점 경로는 통합형 mAP를 `NOT_APPLICABLE`로 반환한다.
과거 파일럿의 상수 점수 mAP는 본실험 성능으로 인용하지 않는다.

M1의 주 대조선은 ID 구간과 클래스 빈도에 따라 박스 출력 여부를 정하는 규칙으로 등록한다. 해당 구간에서 클래스를 포함한 이미지의 비율이 문턱 이상일 때만 그 구간·클래스 정답 박스의 좌표별 중앙값 박스를 하나 출력하며, 화소는 사용하지 않는다.
K는 기존 `idq512`를 사용하고 학습자료로 적합한 뒤 검증자료로 문턱을 선택하며 평가자료로 채점한다.
구간 경계와 최종 재적합 절차도 함께 등록한다. 대조선 계산은 선택한 문턱을 고정한 뒤 학습자료와 검증자료를 합쳐 재적합했다. 평가 정답으로 문턱이나 적합 규칙을 고르지 않는다.
기존 상수 박스와 ID 구간 박스는 과거 위치 대조선과 같은 구성으로 병기한다.

동결 평가셋에서 M1은 상수 박스 0.0186, ID 구간 박스 0.0343, ID 구간과 클래스 빈도에 따른 박스 출력 규칙 0.1599였다. 마지막 값의 문턱은 검증자료에서 선택한 0.5다.
파일럿의 기존 예측을 M1으로 채점한 결과, 일곱 모델 모두 파일럿 비교용 박스 출력 규칙보다 낮았다. 파일럿 비교에는 별도로 선택한 구간 수 128·문턱 0.1을 사용했으므로 동결 평가셋의 0.1599와 구분한다.
파일럿은 본실험 성능의 예측이 아니다.

모델과 대조선의 매크로·micro·클래스별 값을 함께 보고한다.
모델−대조선 차의 신뢰구간은 같은 묶음 추첨을 모든 비교 모델·시드·대조선에 적용해 대응 방식으로 산출한다.
회복률 대표 채택의 기본안은 다음 다섯 조건을 모두 충족해야 한다. 첫째, 평균 분모가 양수이며 모델별 시드 표준편차의 합동값·최댓값·분모 자체 표준편차 각각의 3배 이상이다. 둘째, 평균 회복률 95% 신뢰구간의 반폭이 비율 단위 0.25(25%포인트) 이하다. 셋째, 등록한 모든 시드에서 분모의 95% 신뢰구간 하한이 양수다. 넷째, 평균 회복률이 미정의인 재표집 비율이 10% 이하다. 분모가 비양수인 재표집은 버리지 않고 분자 부호의 무한으로 구간 계산에 포함하므로 이것만으로 미정의로 세지 않는다. 미정의는 고정 평가 클래스의 정답 지지량이 사라진 경우와 판정 불가 재표집이다. 판정 불가는 분모가 비양수이고 분자가 0인 경우, 또는 시드 사이에 양과 음의 무한이 함께 나온 경우다.
다섯째, 등록한 모든 시드에서 중앙과 연합의 M1 점추정이 각각 등록 대조선의 M1보다 커야 한다. 로컬 평균은 이 조건에서 제외하고 대조선과의 관계를 병기한다. 이는 로컬 평균을 회복률 산식에서 제외한다는 뜻이 아니다. 대조선과 같은 값은 초과 조건을 충족한 것으로 보지 않는다.
다섯째 조건을 충족하지 못해도 정의되는 회복률 값과 모델−대조선 차의 대응 신뢰구간은 보고하며, 미정의이면 사유를 남긴다.
두 시드에서는 두 시드 모두의 분모 신뢰구간을 확인하고 실제 시드 수에 맞춰 표준편차와 자유도를 계산한다. 한 시드에서는 분모 안정성을 판정할 수 없으므로 회복률 대표 채택을 미판정으로 남긴다.
더 강한 무화소 규칙이 확인되면 기존 등록을 보존한 새 등록 블록에서 주 대조선을 갱신하고, 적용 시점과 사후 변경 여부를 기록한다.

통합형 본실험에서도 N-crop·N-tile 분리 M1과 정상 이미지 오탐률을 보고한다.
발화율을 기준으로 한 출처 고정 판별력과 P9도 함께 보고한다.
이 의무는 구조가 아니라 평가셋에 붙은 것이다.
지표가 정의되지 않거나 판정 조건을 충족하지 못한 부분집합은 미정의·미판정 사유를 표시한다.
부표본을 사용해도 출처별 보고 항목을 삭제하지 않는다.

기존 등록 블록은 변경하지 않고 통합형 본실험용 새 블록을 추가한다.
새 등록 블록에는 지표의 매칭·집계·미정의 규칙, 레코드 실패의 결합 범위와 항목 폐기 및 주 M1·민감도 M1, 대조선의 구성과 적합·선택 절차, 신뢰구간의 재표집 횟수·난수 시드·구간 방식과 대표 채택 조건, 학습 시드 목록·순서와 시드 수별 적용안, 평가 모집단의 식별 정보 또는 부표본 실현 목록의 해시, 부표본 적용 조건과 제외할 보조 분석, 학습 예산 N·R·E와 비교 조건별 적용 범위를 등록한다.
등록의 선후는 내용 해시와 실행 영수증으로 확인하며 커밋 식별자와 시각만으로 입증하지 않는다.
생성 설정과 채점 규칙의 내용 해시를 분리한다. 등록 병합 다음 커밋으로 남기는 영수증에는 두 해시, 시간대 차이를 포함한 등록 일시, 등록 병합 커밋과 장비를 기록한다.
추론은 시작 전에 영수증을 검증하고 생성 내용 해시를 시작 기록에 남긴다. 영수증의 등록 일시와 추론 시작 기록을 대조하며, 영수증이 없거나 필수 등록값이 미완성이거나 내용 해시가 어긋나면 추론과 본채점을 시작하지 않는다.
채점·신뢰구간 산출물에 생성·채점 내용 해시와 입력 식별 정보를 결속한다. 등록 내용이나 연결된 입력 식별 정보가 일치하지 않으면 해당 신뢰구간을 집계에 사용하지 않는다.
첫 예측 이후의 변경은 사후 변경이며 사전등록이 아니다. 생성 내용 해시가 바뀌면 기존 예측을 새 등록에 사용하지 않는다. 채점 규칙만 바뀌면 같은 생성 등록의 예측을 재채점할 수 있지만 적용 규칙과 변경 이유를 산출물에서 구분해야 한다.

### M1 · 실패 처리 · 보조 지표 · 평가 표본

확정 수치(클래스 코드 · 문턱 · 표본 시드 문자열 · 목록 해시 · 생성 한도)는 [`configs/eval_registration.yaml`](../configs/eval_registration.yaml)에 둔다. 이 절은 정의와 규칙만 적는다.

**정의.** M1 은 클래스 일치 박스 매칭 F1@IoU 1/2 의 네 결함(균열 · 기공 · 슬래그혼입 · 융합불량) 매크로 평균이다. 매칭 · 집계 · 정상 이미지 · 빈 클래스 규칙은 위 기본안 그대로다. 구현은 이미지 × 클래스 계수표를 만들고(`evaluation/metrics/box_f1.py`), 대표 산출은 그 계수표에 가중을 곱해 주 채점과 민감도를 함께 낸다(`evaluation/sample_weights.py` 의 `representative`).

**실패 처리.** 주 채점은 기본안이다 — 레코드 실패는 빈 예측(결합 규칙 `decoupled_v2`, 아래 「파싱 실패의 현재 처리」 절). 민감도 M1 은 **실패 레코드마다** 평가 클래스별 오탐 1 을 더한다. 정상 이미지의 실패에도 적용하고 결함 이미지의 미탐은 주 채점대로 둔다(변형 이름 `fp_per_class_every_failed_record`). 두 값을 함께 싣고 세 학습 방식의 순위와 회복률 부호가 바뀌는지 보고한다. 실패율은 정상 · 결함 별과 N-crop · N-tile 별로 나눈다.

**보조 지표 — 대표가 아니다.** Class-Jaccard · 이미지 수준 결함 유무 F1 · M1-micro · 클래스별 F1 · 처리 속도(초/장) · 모델 교환량(바이트). 이미지 축 둘은 화소를 보지 않는 촬영 순서 규칙의 값을 늘 옆에 둔다 — 사전실험 검출기 예측에서 그 규칙이 두 지표 모두에서 모델보다 높았다(단일 구현의 계산이며 독립 재계산으로 확인되지 않았다). 같은 예측에서 지표에 따라 회복률의 부호가 바뀌었으므로, 보조 지표의 부호가 대표와 다르면 그 사실을 본문에 쓴다.

**평가 표본.**
- 동결 평가셋 12,461 장의 층화 표본 **3,000 장**을 주 모집단으로 쓴다. 추첨 단위는 묶음이고 층은 재질 × 묶음의 이미지당 평균 결함 수 구간(0 · 1 · 2–3 · 4+)이며 층마다 묶음 수를 비례로 고정한다(최소 2). 단가가 허락하면 4,000 장을 쓴다.
- 2,000 ⊂ 3,000 ⊂ 4,000 세 목록을 학습 전에 봉인했다. 두 독립 구현이 세 크기 모두에서 같은 목록 바이트 · id 집합 · 곁 파일을 냈다. 목록 내용은 저장소 밖에 둔다.
- 추출의 입력은 매니페스트의 다섯 열(`image_id` · `split` · `group_id` · `material` · `n_defects`)뿐이다. 층 변수 `n_defects` 는 이미지 수준 요약 열로, 평가셋 분할의 `strata_key` 와 같은 원천에서 온 라벨 파생 열이다. 상자 · 좌표 · 주석 파일(`annotations.csv`)은 읽지 않는다 — 이 요약 열은 표본 추출에만 쓰며 학습 단계에 넣지 않는다.

### 회복률과 참여자별 병기 지표

회복률에 넣는 로컬 평균은 공통 평가셋에서 채점한 C1·C2·C3 점수의 비가중 산술평균이다.
회복률은 다음 식을 사용한다.

`회복률 = 100 × (연합 − 로컬평균) / (중앙 − 로컬평균)`

회복률의 대표 채택은 분모 안정성 검증을 거쳐 판단한다.
선택한 지표에 분모·신뢰구간 규칙을 적용할 수 있는지 검증한다.
기존 COCO mAP용 CI 구현을 M1에 그대로 사용할 수 있다고 가정하지 않는다.
CI가 없거나 필요한 규칙을 판정할 수 없으면 대표 채택을 완료한 것으로 표시하지 않는다.
이때도 원 점수와 원시 격차는 구분해 보고한다.

평가 신뢰구간은 묶음 단위로 산출한다.
같은 묶음 추첨을 모든 비교 모델에 적용한다.
평가 묶음의 불확실성과 학습 시드 변동은 별도로 보고한다.

| 병기 항목 | 산식 또는 보고 방식 |
|---|---|
| 중앙집중과의 원시 격차 | 중앙 − 연합 |
| 참여자별 절대 변화 | 연합 − 로컬_k |
| 참여자별 상대 향상률 | 100 × (연합 − 로컬_k) / 로컬_k |
| 중앙집중 대비 비율 | 100 × 연합 / 중앙 |

비율의 분모가 0이면 미정의로 기록한다.
원시 격차는 작을수록 좋다.
참여자별 변화는 음수도 그대로 보고한다.
상대 향상률의 단위는 `%`다.
0~1 점수의 차이를 100배해 표시할 때는 `%p`를 쓴다.

참여자별 상대 향상률의 평균과 평균 성능의 상대 향상률은 다른 값이다.
회복률의 로컬 기준선은 비가중 산술평균으로 정의한다.
참여자별 성능 변화와 상대 향상률을 전체 평균 하나로 요약하지 않는다. 세 참여자의 값과 가장 작은 이득을 각각 보고한다.
시드별 비율의 평균과 시드 평균 점수의 비율도 구분한다.

### 평가 모집단

참여자별 기본 비교는 공통 평가셋에서 수행한다.
각 로컬 모델과 연합 모델의 차이를 각각 보고한다.
명목 ST·AL 부분집합은 출처 집단별 보조 분석으로 둔다.

C1·C2가 같은 ST 부분집합을 쓰면 평가자료가 겹친다.
이를 독립 표본처럼 합산하지 않는다.
ST·AL 부분집합을 참여자 고유 시험셋으로 부르지 않는다.
부분집합별 이미지 수와 묶음 수를 함께 보고한다.
클래스별 평가 지지량도 확인한다.

명목 ST·AL만으로 실제 재질이나 회사를 확인할 수 없다.
출처와 클래스 구성의 교락도 남아 있다.
이 분석만으로 새 현장의 참여 편익을 주장하지 않는다.

### 파싱 실패의 현재 처리

현재 레코드 파싱 실패는 빈 예측 집합으로 채점된다.
결함 이미지에서는 해당 결함의 미검출로 반영된다.
정상 이미지에서는 분류 지표의 정답 음성으로 처리될 수 있다.
Class-Jaccard는 예측과 정답이 모두 공집합이면 1을 부여한다.
따라서 파싱 실패가 모든 지표에서 일률적인 0점이 되는 것은 아니다.

파싱 실패율과 실패 사유를 별도로 보고한다.
본문과 결과표에 과업 지표의 실패 처리 규칙을 명시한다.
M1의 주 채점에서 레코드 실패는 빈 예측으로 처리해 결함 이미지의 정답 박스를 모두 미탐으로 세며, 정상 이미지의 실패에는 정탐·오탐을 부여하지 않는다.
형식 오류·퇴화 박스·비유한 좌표·미지 코드·평가 대상 밖 코드는 해당 항목만 폐기하고 건수를 별도로 보고한다. 이미지 경계를 벗어난 유효 박스는 좌표를 보정하지 않고 채점한다. 항목 폐기와 레코드 실패는 구분하며, 실패 레코드를 평가 모집단에서 제외하지 않는다.
JSON이 읽히고 `defects`가 유효하면 박스를 채점하고 판정·인용 필드 오류는 조항 축에서만 실패로 센다.
출력이 절단됐거나 해독할 수 없으면 레코드 실패로 처리한다.

주 채점의 빈 예측 처리와 함께, 실패 레코드마다 평가 클래스별 오탐 1건을 부여하는 민감도 M1을 등록한다.
민감도 M1은 정상 이미지의 실패에도 적용하고, 결함 이미지의 미탐 수는 주 채점대로 유지한다. 주 M1과 민감도 M1에서 세 학습 조건의 순위와 회복률 부호가 달라지는지 보고한다.
실패율은 정상·결함 여부별과 N-crop·N-tile 출처별로 나누어 보고한다.
결합 범위는 등록 규칙에 고정하며 새 규칙을 과거 산출물에 소급해 적용하지 않는다.

### 곡선과 임계 독립 지표의 보고 범위

분리형 사전실험의 보고 규칙이다. 통합형 지표는 별도로 선택하되 화소를 사용하지 않는 대조선과 같은 평가 모집단에서 비교해야 한다.
> 통합형에서도 분리 M1·오탐률, 발화율 기준 출처 고정 판별력과 P9를 보고한다.

**산식은 그대로다.** 바뀌는 것은 어느 지표를 기준으로 넣고 어떻게 보고하는가다.

1. **분리형의 대표 지표는 위치 축 mAP@0.5로 둔다.** 회복률은 분모 안정성 조건을 충족한 범위에서 보고한다. 시드 1의 검출기 다섯 모델(분리형 세 학습 조건)은 시험한
   상수·ID 구간 중앙 박스 기준선을 앞섰고, 분류 축에서는 모두 ID 구간 빈도 대조선보다
   낮았다. 통합형 두 조건의 결과는 여기에 포함하지 않는다. 분류 축에는 대표 숫자를 두지
   않고 이미지 수준 macro-AP와 대조선을 병기한다. 위치 축 역시 현재 혼합 평가셋과 시험한
   기준선에 한정해 해석한다. 이 대조만으로 다른 지름길을 배제하거나 새로운 취득 조건에서의
   일반화를 입증하지는 못한다.
   **판별력 Δ_AUC도 지름길의 영향을 받는다.** N-crop에서 출처만 쓰는 상수 점수 예측기는 0이지만 촬영 ID 등 다른 메타데이터를 쓰면 그렇지 않다. train+val에 적합한 idq512 클래스 빈도의 최댓값을 점수로 쓴 Δ_AUC는
   **0.617654**였다. 본채점과 같은 N-crop 결함 7,086장·정상 654장으로 평가했으며 이미지는
   열지 않았다. 시드 1 연합 모델 0.572250과 중앙집중 모델 0.532414보다 높다. 기존
   `fit_idq`·`scored(FREQ)`·`gini` 함수로 재현한 반례다. 연합과 중앙집중의 차이는 관측값으로
   남기되 영상 내용 학습의 증거로 해석하지 않는다. 시드 반복만으로 이 한계를 해결할 수
   없으므로 메타데이터 대조와 별도 일반화 검증 없이 대표 지표로 승격하지 않는다.
2. **분류 축(Macro-F1·결함 놓침)은 곡선으로 보고한다.** 시드 1 첫 채점에서 이 축의 회복률이 임계의 함수이며 중간에서 부호까지 바뀌는 것이 실측됐다. 한 점을 고르면 사후 선택이다.
3. **단일 임계는 등록하지 않고 스윕 격자를 등록한다.** `configs/base.yaml` 의 `conf_sweep_grid`(14점)가 정본이고 전 시드·전 칸이 같은 격자를 쓴다. 단일 임계 키는 일부러 두지 않았고 부재를 시험으로 고정했다.
   **격자는 시드 1에 대한 사전등록이 아니며 시드 2·3에만 사전 고정이다.** 14점 전체를 보고한다. 같은 14개 값은 시드 1 채점 코드에도 있었으며 결과를 본 뒤 추가·삭제한 점은 없다. 코드 상수를 설정 파일로 옮긴 것과 사전등록은 구분한다.
4. **파일럿 폴백 임계(0.25)는 운용점 예시**로만 표기한다. 확증적 기준이 아니며, 고른 이유를 결과로 정당화하지 않는다.
5. **임계 의존성을 관측 결과로 보고한다.** 같은 임계에서 남는 예측의 수가 조건마다 다르다.
   집계가 신뢰도 보정에 영향을 주었을 가능성은 있지만, 현재 실험은 집계·학습 상태·데이터
   분포의 효과를 분리하지 않았다. 원인을 연합 평균 하나로 단정하지 않는다.
6. **분모 안정성 판정 전에는 회복률을 대표 수치로 쓰지 않는다.** 세 시드 산포뿐 아니라 분모·신뢰구간 규칙, 채점 입력·코드와 산출물을 검증해야 한다.

90/80~90/80 미만이라는 해석 구간은 근거가 확립되지 않아 성능 판정에 쓰지 않는다. 기준 지표나 분모가 다른 회복률과 유지율도 같은 척도로 비교하지 않는다.

원시 격차·C1 감소율의 신뢰구간은 따로 산출하지 않았으며 회복률 구간을 대신 쓰지 않는다.

별도로 구현한 채점기에서도 15개 검출기의 mAP@50과 회복률이 일치했다. 이는 같은 평가 기록·정의의 계산 검산이며 평가셋 구성, 학습·추론, 지표 선택이나 현장 일반화의 타당성까지 입증하지 않는다.

### 표준 지표와의 대응

> 아래 환산식은 같은 기준 지표를 사용하는 경우의 관계다.
> 지표 정의가 다르면 원시 격차도 두 구조 사이에서 직접 비교하지 않는다.
> 통합형의 대표 지표는 M1이다.
> 구조별 회복률·유지율 환산은 정의를 비교한 것이며 두 구조를 본실험에서 직접 비교한다는 뜻은 아니다.

아래 환산식은 시드별로 적용한다. 평균 원시 격차는 시드별 격차를 평균하며, 평균 회복률을
평균 분모와 곱해 계산하지 않는다.

IEEE Std 3652.1-2020 §9.3.1은 연합 모델의 성능 격차를 `중앙집중 − 연합`으로 정의한다. 위 세 산식은 이 격차를 각각 다른 분모로 본 것이고 정확히 환산된다. 분리형은 `원시 격차 = (중앙 − 로컬평균) × (1 − 회복률/100)`, 통합형은 `원시 격차 = 중앙 × (1 − 유지율/100)`이다. **산식을 바꾸지 않는다.** 표기를 하나 추가할 뿐이다.

원시 격차를 결과표에 함께 싣는다. 이유는 둘이다. 첫째, 표준 용어와 직접 대응해 지표 정의의 근거가 된다. 둘째, 회복률과 유지율은 분모가 달라 두 구조 사이에 비교되지 않는데 원시 격차는 두 구조 모두에 정의되므로 하나의 축에서 나란히 볼 수 있다.

부호 방향이 반대라는 점을 표 각주에 반드시 밝힌다. 원시 격차는 작을수록 좋고 음수면 연합이 중앙집중을 앞선 것이다.

표준의 격차 정의가 이 연구의 대표 지표 선택까지 정당화하는 것은 아니다. 위치 축의 mAP@0.5와 분류 축의 곡선·대조선은 각각의 과업과 관측된 지름길 문제를 근거로 구분해 보고한다.

`중앙 ≤ 로컬평균`이거나 분모가 불안정하면 격차를 메운 비율이라는 해석은 성립하지 않거나 불안정하다. 원시 격차는 별도로 보고할 수 있다. 계산 규칙의 통과와 대표 수치 채택은 구분한다.

## 11-1. R9 — 명목 재질과 ID 구간에 따른 분포 차이

라벨 구간별 분포와 이미지에서 판독한 실제 재질은 서로 다른 정보다.

**ID 구간별 차이.** 명목 AL 8,945장은 전부 작은 `info.id` 구간에 몰려 있다. ID 구간 순서로 폴리곤 꼭짓점 평균은 14.7 → 12.3 → 10.8 → 7.1로 감소한다. 숫자 ID가 실제 촬영·주석 시간 순서라는 근거는 없다. 이 차이만으로 촬영 시기·배치나 주석 관행 변화, 같은 결함의 주석 정밀도 저하를 확정하지 않는다. 클래스 구성과 형상의 영향도 분리되지 않았다.

**재질 라벨은 명목이다.** AL 버킷에서 시편 정보 시트를 읽을 수 있는 파노라마 표본의 재질은 강 계열이었다(탄소강 SA283C·크롬몰리브덴강 A335P11·스테인리스강 TP347H). 마커 표본 19장과 별도 판독 3장에서 알루미늄 스펙은 0건이었다. 이 결과는 시트가 보이는 파노라마에 한정하며 마커가 없는 결함 크롭의 실제 재질은 알 수 없다. 재질 필드의 의미 자체가 확정된 것도 아니다.

**C3는 명목 라벨 AL로 정의한 참여자 역할로 서술한다.** 실제 재질·회사·프로젝트가 확인된 집단은 아니다. RQ2의 기본 비교는 공통 평가셋에서 수행한다. 명목 AL 보조 분석에서는 이 집단에 대응하는 평가 자료에서 로컬과 연합의 성능을 비교한다. 관측된 차이에서 재질, 취득 조건과 주석 관행의 영향을 각각 분리하지는 못한다.

파급은 두 곳이다.

- **RQ2 해석.** 편익의 유무와 관계없이 원인을 재질로 단정할 수 없다. 파노라마 표본의 판독 결과만으로 실제 재질을 알 수 없는 결함 크롭의 재질 영향을 배제할 수도 없다.
- **평가 공정성.** 글로벌 평가셋에 두 출처 집단이 섞여 있는데 두 집단의 정답 폴리곤 정밀도가 다르면, 같은 모델이 명목 AL에서 낮은 IoU를 받는 것이 모델 탓인지 정답 탓인지 구분되지 않는다.

동결본과 분할은 보존한다. C1·C2·C3은 메타데이터와 분할 규칙으로 정의한 역할이며 실제 회사가 아니다. 공통 평가와 명목 ST·AL별 결과는 구분해 제시하고 미수행 추가 분석을 완료 결과로 쓰지 않는다.
