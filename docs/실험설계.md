# 용접 결함 진단의 연합학습 실험 설계

이 연구는 용접 검사 이미지를 한곳에 모으기 어려운 상황에서 공동 모델을 학습할 수 있는지 살펴본다. 공개 방사선 영상으로 세 참여자 역할을 만들고, 각자 학습한 모델·전체 자료로 학습한 모델·학습 결과를 교환한 모델의 성능을 비교한다. 실제 기업 세 곳이 참여한 현장 실험은 아니다.

2026-10-05 기준 본실험은 이미지와 글을 함께 다루는 Qwen3.5 4B VLM의 비교다. 본실험 성능 결과는 아직 없다. 학습·생성·채점 코드는 준비 중이며 실물 리허설을 통과하지 않았다. 완료된 YOLO11s 검출기 실험은 별도의 사전실험으로 보존한다. 구현 범위는 [구현설계](구현설계.md), 규칙을 바꾼 근거와 시점은 [의사결정로그](의사결정로그.md), 이미 얻은 결과는 [사전실험 보고](사전실험_보고.md)에 설명한다.

## 1. 무엇을 비교하는가

| 학습 방식 | 만드는 모델 | 자료와 교환 범위 |
|---|---|---|
| 로컬 단독 | C1·C2·C3의 자체 모델 세 개 | 각 참여자의 자료만 사용 |
| 중앙집중 | 비교 모델 한 개 | 전체 학습 풀을 모아 사용 |
| 연합학습 | 공동 모델 한 개 | 참여자별로 학습한 LoRA 어댑터를 서버가 집계해 재배포 |

한 학습 시드에서 비교하는 모델은 다섯 개다. 중앙집중 모델은 전체 학습자료를 사용하는 비교 기준이며 성능 상한을 보장하지 않는다. 시드는 학습의 난수 조건을 뜻한다. 여러 시드로 반복할 때 생기는 변동과 평가자료를 다시 뽑을 때 생기는 불확실성은 구분한다.

주 질문 RQ1은 통합형 연합학습의 성능이 로컬 단독 및 중앙집중 학습과 어떻게 다른지다. RQ3은 C1·C2·C3 각각의 자체 모델과 공동 모델 사이의 성능 변화를 묻는다. 손해가 난 참여자도 같은 기준으로 보고한다. 통합형과 분리형의 구조 비교였던 RQ2는 2026-09-18에 본실험에서 제외했으며 번호만 유지한다.

분리형은 검출기가 결함을 찾고 언어모델이 규정을 검색해 설명하는 설계다. 현재 완료된 사전실험은 이 중 검출기 부분의 세 학습 방식·세 시드 비교다. YOLO와 언어모델 판정부를 연결하는 작업은 여유 시 과업이다. 이를 통합형의 참여자별 비교 대신 사용하거나, 통합형 미완료를 이유로 본실험을 자동 대체하지 않는다.

## 2. 현재 확정한 범위와 남은 결정

| 항목 | 현재 상태 |
|---|---|
| 모델·정밀도 | Qwen3.5 4B QLoRA, 4bit, `enable_thinking=False`, greedy 1회 |
| 연구 범위 | 통합형 로컬 세 모델·중앙·연합의 탐색적 비교 |
| 주 분석 모집단 | 동결 분할의 eval 12,461장. 분할과 지문 유지 |
| 실제 평가 부표본 | 2,910장 채택. 묶음 단위·명목 재질×클래스 층화·희소층 전수 포함·층별 역확률 가중·평가 전용 시드 |
| 학습 페어 | `pairs_main_v1` 49,845건 봉인 완료. 결함 27,499·정상 22,346, 폐기 2건 |
| 미정 | 대표 지표, 통합형 N·R·E 예산, 생성 한도, 독립 학습 시드 수 |
| 실행 확인 | 실물 리허설 미통과. 모델·페어 설정 연결, 진단과 실행 조건의 미완료 항목이 남음 |

2,910장 평가는 2026-10-01 결정이다. 비용 산정은 시드당 채점 47.4시간이며 전량 12,461장의 산정값은 202.8시간이다. 완료 실행 시간은 아니다. 표본 수를 정한 사실과 목록·가중·신뢰구간까지 실행 전에 등록한 상태를 구분한다. 앞선 통계 검토에서는 2,910장이 희소층 전수 부분이고 나머지 층의 포함확률이 0이어서 전체 eval의 M1을 역확률 가중으로 추정할 수 없다고 지적했다. 최신 선택이 이 문제를 해소했다는 근거는 아직 확인되지 않았다. 2,910장의 점수를 전체 eval 추정값으로 보고하기 전에 평가 대상과 포함확률을 정리해야 한다.

배경지식 학습의 유지·폐지는 초기 계획에서 다시 검토 대상으로 넘어갔다. 유지하면 코퍼스 생성·검증, 텍스트 학습, 병합·재양자화 확인과 공통 출발점의 해시 고정이 필요하다. 폐지해도 기본 모델 판본과 다섯 모델의 공통 초기 어댑터를 확인해야 한다. 추가 사전학습(CPT)은 미수행 정책이다.

## 3. 데이터와 참여자 역할

### 자료의 종류

| ID | 자료 | 용도 |
|---|---|---|
| D1 | 이미지와 폴리곤 라벨 | 결함 검출, 이미지-답안 페어의 원천 |
| D2 | 규격·학회지·선급 규정 | 문서 코퍼스와 허용치 표의 원천 |
| D3 | 합성 QA·판정 추론 텍스트 | 배경지식 학습을 유지할 경우의 학습자료 |
| D4 | 이미지-판정문 페어 | 통합형의 학습 답안 |
| D5 | 조항 단위 규정 색인 | 분리형의 검색. 연합 집계 대상에서 제외 |
| D6 | 평가셋·정답 조항·외부 데이터 | 학습과 분리한 채점 자료 |

AI허브 71761의 2026-08-24 전수 조사에서는 라벨 JSON 129,613개를 확인했고 파싱 실패는 0건이었다. RT는 62,998장, VT는 66,615장이다. 주 실험은 RT로 한정한다. VT에는 용입부족·언더컷이 있고 RT의 균열·슬래그와 클래스 체계가 달라 같은 학습 문제로 섞지 않는다.

| 원본 라벨 집단 | 정상 | 균열 | 기공 | 융합불량 | 슬래그혼입 | 계 |
|---|---|---|---|---|---|---|
| RT 명목 ST | 23,696 | 2,054 | 24,345 | 2,928 | 1,030 | 54,053 |
| RT 명목 AL | 4,698 | 294 | 2,621 | 300 | 1,032 | 8,945 |

이 표는 원본 라벨 전수 조사다. 전처리와 폐기를 반영한 동결본은 62,308장이므로 분모를 섞어 쓰지 않는다. 동결본에서 명목 ST·AL의 클래스 분포 총변이거리는 0.1910, 슬래그혼입 발생 비율 배수는 5.91(ST 1,059·AL 1,049장), 규모 불균형은 1 : 5.98(ST 53,379·AL 8,929장)이었다. 데이터 확인 방법은 [AI허브 전수 확인](데이터셋_AI허브_전수확인.md)과 [연합설계 적합성](데이터셋_연합설계_적합성.md)을 따른다.

### 분할

```text
동결 RT 62,308장 / 6,232묶음
├─ 공통 eval 12,461장
└─ 학습 풀 49,847장 = train 44,846 + val 5,001
   ├─ C1 명목 ST 26,451장
   ├─ C2 명목 ST 16,253장
   └─ C3 명목 AL  7,143장
```

평가셋을 먼저 떼고 나머지를 참여자에게 배정했다. 같은 이미지 묶음은 같은 분할에만 둔다. C1·C2는 명목 ST 안에서 설계 사전분포 2:1과 Dirichlet α=0.5를 사용했다. 실현 C1 지분은 0.62로 수용 밴드 안이다. C3에는 Dirichlet 분할을 적용하지 않았다. 전체 묶음은 AL 954·ST 5,278개이며 실제 용접부나 촬영 세션을 확인한 식별자가 아니다.

회사·사업장·설비·촬영일·작업자 관련 키는 라벨 129,613개에서 발견되지 않았다. 스키마는 22키다. C1·C2·C3를 실제 회사로 부르지 않는 이유다. C3의 균열 265장·융합불량 257장, C2의 균열 30장·융합불량 15장, C1의 슬래그혼입 82장처럼 적은 클래스가 있어 클래스별 지지량을 보고한다.

ST와 AL도 확인된 재질이 아니라 데이터셋의 명목 라벨이다. AL 집단의 판독 가능한 파노라마 표본에서는 강 계열인 SA283C·A335P11·TP347H를 확인했다(마커 스캔 19장과 별도 판독 3장, 알루미늄 스펙 0건). 결함 크롭은 마커가 없어 실제 재질을 확인하지 못했고 운영기관의 필드 정의 회신도 필요하다. 숫자 ID 구간에 따른 폴리곤 꼭짓점 평균 14.7→12.3→10.8→7.1의 차이를 시간에 따른 주석 관행 변화로 단정하지 않는다. ID가 실제 시간 순서인지 확인되지 않았으며 클래스·형상 차이도 분리하지 못했다.

### 중복과 탐색적 비교의 한계

동결 분할은 파일 내용 해시, 같은 검사 방식·명목 재질 안의 숫자 ID 연속 구간, 지각 해시 완전 일치로 묶었다. pHash는 256-bit에서 임계 0을 채택했다. 초기 구현안의 해밍 거리 8은 현행 규칙이 아니다.

이 절차가 평가 독립성을 보장하지는 못했다. 원본 40쌍의 직접 확인과 후속 점검에서 분할을 건너는 유사 영상·중복을 확인했으며, 2026-10-01 결정은 최소 33쌍의 화소 쌍둥이와 묶음을 건너는 연결을 한계로 명시했다. 중복 범위를 추정하던 네 규칙은 반례 검토에서 기각됐다. 그 규칙으로 얻은 비율을 확정값이나 확정 하한으로 쓰지 않는다.

10월 1일까지 검증된 연결 목록으로 재분할하지 못해 현행 분할의 탐색적 비교를 채택했다. 근사 중복 성분을 뺀 민감도 분석을 보조로 계획하지만, 검증되지 않은 제외 목록만으로 독립 일반화가 입증되지는 않는다. 중앙·연합과 각 로컬의 학습자료가 달라 중복 노출도 대칭이 아니다. 편향의 방향이나 회복률 변화의 부호는 아직 정해지지 않았다.

### 이미지 크기와 출처를 이용하는 지름길

결함 이미지는 전량 1280×720 크롭이고 정상 이미지는 대부분 파노라마였다. 이 조건에서 모델은 결함 대신 이미지 크기나 취득 특징을 이용할 수 있다. 초기 4결함 Macro-F1 대조는 전량양성 0.2081, 규격전용 규칙의 시험 범위 내 최댓값 0.3025, 차이 +0.0944였다. RT/ST 이진 규칙의 정확도 96.1%는 별도의 과업이며 같은 지표로 비교하지 않는다.

정상 파노라마를 한 장당 한 타일로 바꾸고 전처리를 고정했다. 분할을 먼저 정해 학습 풀에서만 전처리 기준을 구했으며, 타일은 `sha256(image_id + seed) mod N_cand`로 선택한다. 밝기나 중앙 위치를 기준으로 좋은 타일을 고르지 않는다. 이후 마스킹과 히스토그램 정합을 거쳐도 출처 판별 AUC는 0.9972→0.9906→0.9802로 남았다. 지름길을 제거했다고 주장하지 않는다.

결과는 원본 크롭 출처인 N-crop과 파노라마에서 만든 N-tile을 나누어 보고한다. 두 출처의 오탐 차이가 허용 폭 안인지 보는 P9 등가 판정, 출처를 고정했을 때의 결함 발화율 차이도 병기한다. 발화는 모델이 하나 이상의 결함을 출력했다는 뜻이다. 이 지표들도 촬영 ID 등 다른 메타데이터 지름길에 대한 면역을 보장하지 않는다.

## 4. 판정문과 규정 자료

원본 라벨은 학습에 유지하며 규정 검색과 외부 데이터 비교에서만 ISO 6520-1로 대응한다. 균열은 100번대, 기공은 2011/2012, 융합불량은 401, 슬래그혼입은 301이고 정상에는 코드가 없다. 폴리곤의 x·y 최솟값과 최댓값으로 bbox를 만든다.

현재 데이터에는 모재 두께·결함 실치수·픽셀→mm 환산 필드가 없다. 따라서 픽셀 상자에서 mm 단위 결함 크기를 얻어 치수 기준 합부를 확정할 수 없다. 정상 파노라마에 두께 표기가 보여도 결함 이미지로 연결할 키가 없고 필름 투영의 환산은 별도 검증이 필요하다.

실이미지 페어에는 결함 종류·위치·적용 가능한 조항·기준 설명을 담는다. 실치수를 만들어 넣지 않는다. 가정 두께와 크기를 사용하는 텍스트 판정은 별도의 합성 과업이며, 지표명과 각주에 가정값을 표시한다. 허용치 표에서 학습 답안과 평가 정답을 함께 파생했다면 원문·전문가 대조 전의 점수는 내부 규칙 일치로 한정한다.

본실험 페어 49,845건은 봉인됐으나 사람 정답 검증은 미완료다. 허용치 표 12행이 모두 ST여서 AL 결함 3,372건은 `clause_only`, `verdict=null`을 유지한다. RT 11행의 원문 계보에 관한 이용 범위 판단도 남아 있다. 파일 검증 통과를 내용·전문가 검증 완료로 서술하지 않는다.

합성 텍스트의 초기 목표는 QA 20,000건(하한 10,000), 판정 추론 10,000건이었다. 규칙이 수치·조항·부등식을 정하고 로컬 오픈 가중치 모델은 표현만 변주하도록 설계했다. 검증은 규칙 검사, 다른 계열 모델의 조항 대조, 전문가 표본 2~3% 검토 순서다. 2026-09-09 확인한 파일럿 QA 188건은 형식·중복 검사 통과분으로 사실성 검증 통과분이 아니다.

색인은 무료 공개 규정과 이용 범위를 확인한 자료를 조항 단위로 구성한다. 유료 표준 전문을 코퍼스나 색인에 넣지 않는다. 허용치·결함 코드·조항을 재서술하더라도 출처와 이용 범위를 확인한다. 규정 검색은 결함 코드·두께·품질 수준 등 구조화 키로 후보를 좁히고 복수 후보일 때만 dense 유사도로 top-3을 정한다. 2026-09-01의 100질의 시험은 모두 후보가 한 개이고 네 청크의 본문도 비어 있어 임베딩 모델을 선택할 근거가 되지 못했다.

## 5. 학습과 생성의 비교 조건

같은 구조의 학습 방식 사이에서는 기본 모델 판본, 어댑터 설정(rank·alpha·대상 레이어·dropout), 최적화, 전처리, 프롬프트와 채팅 템플릿 모드, 생성 규칙을 고정한다. 검출기와 VLM의 서로 다른 백본·전처리까지 같다고 설명하지 않는다. 통합형 기본 구성에는 규정 검색을 붙이지 않는다.

조기 종료 없이 정한 예산을 채우고 `last`를 채점한다. 연합의 라운드 수 R, 라운드당 로컬 epoch E, 로컬·중앙의 총 epoch N 사이에 `R × E = N`을 맞춘다. 이 등가는 원본 이미지 방문 횟수에 관한 조건이다. 자료 순서·증강·optimizer 경로까지 동일하다는 뜻은 아니다.

사전실험은 N=100, R=50, E=2, 시드 `[20260828, 20260829, 20260830]`을 사용했다. 연합 로더가 매 라운드 같은 첫 두 epoch의 순열을 반복한 정책도 당시 실행 조건의 일부다. 중앙·로컬과의 차이가 성능에 미친 방향·크기는 미확정이다. 새 셔플 정책을 적용한 결과와 합산하지 않는다. 통합형의 최종 예산은 별도 결정이며, 초기안 N=3·R=6·E=0.5를 그대로 실행 가능한 확정값으로 쓰지 않는다. 현재 부분 epoch 실행은 지원하지 않는다.

통합형의 LoRA A·B 행렬은 각각 가중 평균한다. `avg(B)·avg(A) ≠ avg(B·A)`이므로 행렬별 평균과 갱신량 평균의 차이를 밝혀야 한다. 2026-09-02에는 손실 정규화와 맞추기 위해 통합형의 집계 가중 단위를 감독 토큰 총합으로 정했다. 페어 수 가중과 구분한다. 기존 선택에서 토큰 밀도는 1.9배, C3 가중 변화는 1.52배였다.

학습 정답·생성 출력·채점의 좌표를 일치시킨다. 저장 규약은 2026-09-02 채택한 원본 픽셀 `ABS_ORIG`다. 자체 합성 도형 4장의 제로샷 확인은 0~1000 정규화 배제까지 뒷받침하며 원본·리사이즈 좌표 프레임이나 미세조정 후 거동을 확정하지 못했다. 동결 이미지 62,308장은 1280×720이고 프로세서는 1280×704로 줄이므로 실물 좌표 진단이 필요하다. 선행연구의 BBox-IoU 0.055→0.938은 정렬 모듈 입력 수치의 인코딩 비교이며 생성 좌표 규약의 근거로 사용하지 않는다(Sun 외, 2026, [DOI](https://doi.org/10.1109/TII.2026.3678237), 6486쪽 V-G.2·표 V).

리허설에서는 최종 eval을 열지 않고 학습→저장→중단→재개→생성→채점 연결을 확인한다. 판본 식별과 구판 거부, 좌표, 입력 스키마·실패율, 출력 보존, 장당 지연·생성 길이가 모두 확인돼야 한다. 합성 대역 시험이나 코드 존재만으로 이 조건을 충족했다고 쓰지 않는다.

현재 통합형 생성 출력에는 검증된 박스별 점수가 없어 mAP를 `NOT_APPLICABLE`로 반환한다. 파일럿에서 상수 점수로 계산한 mAP는 본실험 성능으로 인용하지 않는다. M1 구현은 존재하지만 대표 지표 채택은 아직 결정되지 않았다.

### M1의 매칭·집계 계약

이미지별·클래스별 정답 박스와 예측 박스 가운데 IoU가 0.5 이상인 쌍을 후보로 삼는다. 짝 수를 먼저 최대화하고, 같은 짝 수에서는 IoU 합을 최대화하며 남은 동률은 항목 번호의 고정 순서로 해소한다. 중복 예측은 별도 박스로 센다. 클래스별 TP·FP·FN을 모집단 전체에서 합산해 F1을 구하고 네 결함 클래스를 산술평균한다.

현재 경계 구현은 JSON을 읽은 binary64 좌표를 기준으로 `2×교집합 ≥ 합집합`을 판정한다. `|2×교집합−합집합| ≤ 1e-9 × max(1, 합집합)`인 경계쌍은 해당 이진 값의 정확한 유리수로 재판정하고 건수를 기록한다. 십진 문자열의 기하와는 다를 수 있으며, 이 규약을 바꾸려면 새 채점 지문을 등록한다.

정상 이미지의 예측 박스는 모두 FP다. 정상의 빈 예측은 TP·FP·FN을 늘리지 않는다. 부분집합의 정답에 없는 클래스는 모든 모델에 공통으로 매크로 평균에서 제외하고 클래스 목록·수와 예측 수를 보고한다. 해당 예측은 micro F1과 오탐 집계에는 남긴다. 분모가 0인 지표와 정답이 전혀 없는 모집단의 매크로 F1은 미정의다.

대표 채택 전에는 원 구현과 별도로 작성한 구현으로 공유 정규화 입력과 원시 예측·정답 직접 파싱 두 경로를 대조한다. 클래스별 TP·FP·FN, F1과 M1, 코드·입력 식별자, 불일치 처리를 남긴다. 같은 작성자가 두 구현을 작성해도 되지만 그 사실을 보고한다. 필요한 사람 검토는 담당·완료 여부를 별도로 표시한다.

### 실패와 항목 폐기

현재 레코드 파싱 실패는 빈 예측으로 채점된다. 결함 이미지에서는 미검출이 되지만 정상 이미지에서는 오탐 벌점을 받지 않는다. Class-Jaccard는 정답과 예측이 모두 비면 1을 부여하므로 모든 지표에서 일률적인 0점은 아니다. 이 처리가 적용될 수 있는 정상 이미지는 5,375장, 전체의 43.1%다.

통합형 실패 처리의 기본안은 유효한 `defects`를 채점하고 판정·인용 필드의 오류는 조항 축에서만 실패로 세는 것이다. 절단·해독 불가 출력은 레코드 실패로 둔다. 형식 오류·퇴화 박스·비유한 좌표·미지 코드·대상 밖 코드는 항목만 폐기하고 건수를 보고한다. 이미지 경계 밖의 유효 박스는 좌표를 보정하지 않는다. 실패 레코드를 모집단에서 제외하거나 다시 생성하지 않는다.

주 M1과 함께 실패 레코드마다 평가 클래스별 FP 한 건을 부여하는 민감도 M1을 등록하는 안이다. 결함 이미지의 FN은 유지하며 정상 실패에도 적용한다. 두 방식의 순위·회복률 부호 변화를 보고하고 실패율을 정상·결함 및 N-crop·N-tile별로 나눈다. 결합 범위와 민감도 규칙은 대표 지표 등록 전에 확정해야 한다.

### 화소를 보지 않는 대조선

M1의 주 대조선 기본안은 `idq512` ID 구간에서 클래스 포함 비율이 문턱 이상이면 해당 구간·클래스의 좌표별 중앙값 박스를 하나 출력하는 규칙이다. train에서 적합하고 val에서 문턱을 고른 뒤 고정 문턱으로 train+val에 재적합한다. eval 정답으로 문턱을 선택하지 않는다. 상수 박스와 ID 구간 박스도 병기한다.

동결 eval의 기존 계산은 상수 박스 0.0186, ID 구간 박스 0.0343, ID 구간·클래스 빈도 규칙 0.1599(문턱 0.5)였다. 파일럿 일곱 모델은 별도 구간 수 128·문턱 0.1 대조선보다 낮았으며, 이 비교와 0.1599를 섞지 않는다. 파일럿은 본실험 성능의 예측값이 아니다.

### 회복률과 참여자별 변화

```text
로컬평균 = 공통 평가셋의 C1·C2·C3 점수 비가중 산술평균
회복률 = 100 × (연합 − 로컬평균) / (중앙 − 로컬평균)
원시 격차 = 중앙 − 연합
참여자별 절대 변화 = 연합 − 로컬_k
참여자별 상대 향상률 = 100 × (연합 − 로컬_k) / 로컬_k
중앙집중 대비 비율 = 100 × 연합 / 중앙
```

0~1 점수 차이를 100배해 쓰면 단위는 `%p`, 상대 향상률은 `%`다. 분모가 0인 비율은 미정의로 기록한다. 원시 격차가 음수이면 연합이 중앙보다 높다는 뜻이다. IEEE Std 3652.1-2020 §9.3.1의 격차 정의와 대응하지만 이 표준이 대표 지표 선택까지 정당화하지는 않는다.

회복률 대표 채택에는 양수·안정적인 분모, 평균 회복률 95% CI 반폭 0.25 이하, 모든 시드의 분모 CI 하한 양수, 미정의 재표집 비율 10% 이하를 확인하는 기본안을 둔다. 분모 안정성은 평균 분모를 모델별 시드 표준편차의 합동값·최댓값·분모 표준편차 각각의 3배와 비교한다. 중앙·연합의 대조선 초과에 관한 조건 ⑤는 [의사결정로그의 정본](의사결정로그.md#대조선-초과-조건-⑤)을 따른다. 팀 결정 전 기본안이며 조건 미충족과 값 미정의는 구분해 보고한다. 한 시드로는 시드 변동에 기초한 분모 안정성을 판정하지 못한다.

평가 신뢰구간은 같은 묶음 추첨을 모든 비교 모델·시드·대조선에 적용해 대응 방식으로 구한다. 통합형의 2026-10-01 구간 규약은 분모 실패 추첨을 버리지 않고 분자 부호의 무한으로 포함하며 보간하지 않는 순위 백분위를 쓴다. 판정 불가·지지량 소실은 별도로 센다. 점추정의 분모 실패에는 무한을 적지 않는다. 정확한 상태와 계산식은 [구현설계](구현설계.md)에 적었다. 사전실험 CI에는 이 규약을 소급하지 않는다.

RQ3의 기본 모집단은 공통 eval이다. ST·AL 부분집합은 출처 집단별 보조 분석이며 C1·C2 고유 시험셋으로 부르지 않는다. C1·C2의 ST 평가자료가 겹치면 독립 표본처럼 합산하지 않는다. 시드별 비율의 평균과 시드 평균 점수의 비율, 참여자별 상대 향상률 평균과 평균 성능의 상대 향상률은 서로 다르므로 산식을 명시한다.

### 부표본과 등록

희소층 전수 포함의 기존 검토안은 균열·융합불량·슬래그혼입을 하나라도 포함한 묶음과 명목 AL 결함 양성 묶음을 모두 포함한다. ST 슬래그혼입 양성은 27묶음이고 이 조건의 실현값은 261묶음·2,910장이었다. 최종 표본은 채택된 층별 역확률 가중 뼈대에 맞춰 지지량·재표집 규칙·실현 목록을 등록해야 한다. 과거 목표 2,000장에 대해 얻은 2,108장·197묶음 목록을 자동 승계하지 않는다.

모든 모델·시드·대조선은 같은 실현 목록을 사용한다. 목록 해시, 확정층, 남은 층별 배정, 추첨 시드, 출처별·클래스별 지지량, 산출하지 않을 보조 분석과 이유를 남긴다. 학습 부표본은 별도 실험이다.

생성 설정과 채점 규칙은 별도 내용 해시로 등록한다. 등록 병합 다음 커밋에 영수증을 남기고 시간대가 포함된 등록 일시·커밋·장비를 기록한다. 추론은 영수증과 등록값을 검증하고 시작 기록에 생성 해시를 남긴다. 영수증 부재·필수값 미완성·해시 불일치이면 추론과 본채점을 시작하지 않는다. 첫 예측 후 변경은 사후 개정이며, 생성 해시가 바뀌면 옛 예측을 새 등록에 재사용하지 않는다. 같은 생성 등록의 채점 규칙만 바꾼 재채점은 사유·시점과 함께 구분한다.

## 7. 사전실험의 결과를 읽는 범위

검출기 15개의 v3 재채점에서 mAP@50은 중앙집중 0.4946, 연합 0.2709, 로컬 평균 0.1973, 원시 격차 0.2237이었다. 사전실험에서 채택한 회복률은 세 시드 평균 24.8%, 평가 묶음 부트스트랩 95% CI [20.9%, 29.3%], 시드별 29.0%·22.6%·22.7%다. 본실험의 대표 수치가 아니다.

이 CI는 학습 시드 세 개를 고정하고 평가 1,245묶음을 2,000회 재표집한 구간이다. 학습 시드 변동은 담지 않는다. 추가 CI 판정 규칙은 세 시드 채점 뒤 등록해 사전등록이 아니다. 2026-09-17 두 번째 구현에서도 같은 평가 기록·정의의 mAP@50 계산을 확인했지만 평가 독립성·학습·추론·현장 일반화 검증을 대신하지 않는다.

공통 평가셋에서 C1 로컬 대비 연합의 시드별 상대 변화율 평균은 −24.6%였다. 명목 AL에서도 C3 로컬이 연합보다 높았다. 원시 격차와 C1 감소율의 CI는 별도로 산출하지 않았으므로 회복률 CI를 대신 붙이지 않는다.

분류 축은 대표 숫자를 두지 않고 신뢰도 임계 14점 곡선과 메타데이터 대조선을 함께 보고한다. 격자와 AP 대조선은 시드 1 결과 이후 설정에 등록했고 시드 2·3에 대해서만 사전 고정됐다. 같은 방향의 출처 편향만으로 모델 간 상대 비교의 타당성이 보장되지 않으며, 순위와 회복률은 평가 출처 구성에 따라 달라질 수 있다.

## 8. 자원·외부 검증·축소 순서

모델 교환량은 배열별 `nbytes` 합이다. 부동소수 교환 배열은 fp32, 정수 버퍼는 원래 dtype을 유지한다. 현재 하향 값은 별도 계측 없이 상향 값을 복제하므로 양방향 합은 상향의 두 배다. 네트워크 프로토콜 부가량이나 실제 회선 바이트를 측정한 값은 아니다. 비교 기준 없이 실측 절감률을 주장하지 않는다.

기존 검토의 통합형 학습 단가는 2.36~3.50초/샘플의 계획 범위였다. 시드당 세 조건 합계는 N=3·R×E=3×1에서 265~393시간, N=2·R×E=2×1에서 176~262시간으로 산정했다. 로컬 세 모델 시간의 합을 포함하며 통계적 CI나 본실험 완주 측정값은 아니다. 공통 출발점 준비·추론·기동·저장·집계·재실행 비용은 별도다.

비용이 부족하면 여유 과업 제외, 착수 전 공통 학습 예산 조정, 등록된 공통 평가 부표본 적용, 시드 수 축소 순서로 검토한다. 필수 검증과 대조선은 여유 과업에 넣지 않는다. 미완료 조건을 결과에서 삭제하거나 분리형 결과로 교체하지 않는다.

외부 데이터 평가는 보조 과업이다. RIAWELC은 파일 24,407개지만 고유 이미지 21,964장, 해상도 227×227이며 `testing` 2,443장이 `training`의 복제다. 저자 분할을 그대로 쓰지 않는다. 위치 라벨이 없어 공통 균열·기공·정상 3클래스로만 평가한다. LoHi-WELD 3,022장은 가시광 확장용이며 RT 주 실험에 섞지 않는다. MWDD는 2026-09-20 기록상 Zenodo 등록·접근 제한 상태로 자료 확보·사용 승인과 구분한다. Intel 자료는 승인 대기, KAMP·Notre Dame 자료는 미확인 기록이다. 외부 평가를 못 하면 일반화 미검증으로 남기며 결과가 좋고 나쁨에 따라 보고 여부를 바꾸지 않는다.
