작성 2026-08-13 · 대한산업공학회 추계학술대회 포스터 (초록 10/20, 최종 11/10) · 실험 가용 9주

# 1. 연구 프레임

## 1-1. 문제

조선 용접 검사 데이터는 회사별로 흩어져 있고 외부 반출이 불가능하다. 데이터를 모으지 않고 학습 결과만 주고받는 방식이 실제로 쓸 만한지 확인하는 것이 출발점이다.

그 위에 어떤 모델 구조를 얹을지에서 두 갈래가 나뉜다.

| 구조 | 동작 |
|---|---|
| **통합형** | 용접 이미지를 그림·글 통합 모델에 그대로 넣어 결함 판단과 판정문 작성을 한 번에 수행 |
| **분리형** | 전용 검출 모델이 결함의 종류·위치·크기를 숫자로 산출하고, 언어모델이 규정을 검색해 합부와 근거 조항을 정리 |

두 구조를 같은 이미지, 같은 참여 회사 구성, 같은 학습량으로 돌려 비교한다.

## 1-2. 학습 방식 세 가지

| 방식 | 정의 |
|---|---|
| **로컬 단독** | 각 회사가 자기 데이터로만 학습. 아무것도 주고받지 않음 |
| **중앙집중** | 전체 데이터를 한곳에 모아 학습. 현실에서는 불가능하나 성능 상한 기준 |
| **연합학습** | 각 회사가 로컬 학습 후 가중치만 서버로 전송, 서버가 평균해 재배포 |

## 1-3. 실험 다섯 칸

구조 2종 × 학습 방식 3종에서 한 칸을 뺀 다섯 칸으로 구성한다.

| | 로컬 단독 | 중앙집중 | 연합학습 |
|---|---|---|---|
| **통합형** | 제외 | **통합·중앙** | **통합·연합** |
| **분리형** | **분리·로컬** | **분리·중앙** | **분리·연합** |

통합형·로컬을 빼는 이유는 세 가지다. 회사마다 단독으로 대형 VLM을 만드는 상황은 현실 배포 시나리오가 아니고, 참여 편익 질문은 분리형 쪽 비교로 답할 수 있으며, 다섯 칸 중 학습 비용이 가장 크다. 제외 사유는 논문에 한 문장으로 밝힌다.

비용 분포는 다음과 같다. 분리형 세 칸은 소형 검출 모델이라 GPU 1장에서 각 수 시간에서 하루. 통합·중앙은 QLoRA 기준 1~2일, 통합·연합은 라운드가 누적되어 2~4일. 총량이 9주 예산 안에 들어간다.

## 1-4. 연구 질문

| 질문 | 내용 | 비교 대상 |
|---|---|---|
| **RQ1** | 데이터를 내보내지 않는 조건에서 중앙집중 성능을 얼마나 회복하는가 | 통합·중앙 ↔ 통합·연합 / 분리·로컬 ↔ 분리·중앙 ↔ 분리·연합 |
| **RQ2** | 같은 연합 조건에서 통합형과 분리형 중 어느 쪽이 나은가 | 통합·연합 ↔ 분리·연합 |
| **RQ3** | 소규모·특수 재질 취급 회사가 연합 참여로 얻는 이득 | 분리·로컬 ↔ 분리·연합 (알루미늄 클라이언트 개별값) |

RQ1이 이 연구의 주 기여다. 데이터를 한곳에 모을 수 없는 조건에서 공동 모델을 학습할 수 있는지, 그때 성능 손실이 현장에서 감내 가능한 수준인지를 실측한다. 국내 문헌 검색에서 연합학습과 용접을 결합한 사례가 확인되지 않았다 (KCI·ScienceON, 2026-08-03 검색, 0건). 검색 로그를 각주로 남긴다.

RQ2는 부차 기여다. 같은 연합 조건에서 통합형과 분리형을 동일 프로토콜로 비교한 통제 실험이 드물다는 점에서 값어치가 있으나, 논문의 성립은 RQ1에 걸려 있다. 통합형 두 칸이 완주하지 못해도 분리형 세 칸으로 RQ1과 RQ3에 답할 수 있다.

## 1-5. 비교 항목 다섯 가지

결함을 놓치는 비율, 위치 정확도, 판정 근거의 신뢰도, 처리 속도, 회사 간 주고받는 양. 지표 정의는 8장.

# 2. 데이터 자산 개요

실험에 들어가는 데이터는 여섯 덩어리다.

| ID | 자산 | 용도 | 범위 |
|---|---|---|---|
| D1 | 이미지 + 결함 라벨(폴리곤) | 검출 학습, 통합형 학습 원천 | 회사별 분할 |
| D2 | 텍스트 원문 시드 (규격·학회지·선급 규정) | corpus 생성 재료, 규정 색인 | 공통 |
| D3 | 합성 텍스트 corpus 3종 | 배경지식 학습 | 공통 |
| D4 | 이미지-판정문 페어 | 통합형 학습 타깃 | 회사별 분할 |
| D5 | 규정 색인 (조항 단위) | 분리형 판정부 검색 | 공통 고정, 집계 대상 아님 |
| D6 | 평가 자산 (평가셋·정답 조항 목록·낯선 데이터) | 채점 | 격리 |

전체 흐름은 다음과 같다.

```
[A] 이미지 수집(D1) ─┬─ [B] 정제 · 평가셋 선분리 · 회사별 분할
[A'] 텍스트 시드(D2) ─┴─ [C] 합성 생성: corpus(D3) + 이미지-판정문 페어(D4)
        ↓
[D] 검증 · 스냅샷 고정 (D3 · D4 · D5)
        ↓
[E] 배경지식 학습 (다섯 칸 공통 준비)
        ↓
[F] 본 실험 다섯 칸 (비교 변수: 학습 방식 × 구조)
        ↓
[G] 규정 검색 판정(분리형) / 직접 생성(통합형)
        ↓
[H] 평가 + 낯선 데이터 검증(D6)
```

[A]부터 [E]까지는 다섯 칸에 똑같이 적용된다. 이 단계에서 조건이 어긋나면 [F]의 차이를 구조나 학습 방식 탓으로 해석할 수 없다.

## 3-2. 주 데이터 구성

AI허브 RT 데이터의 클래스별 수량은 다음과 같다. **실측값이다.**

| 구분 | 정상 | 균열 | 기공 | 융합불량 | 슬래그혼입 | 계 |
|---|---|---|---|---|---|---|
| RT 강재(ST) | 23,696 | 2,054 | 24,345 | 2,928 | 1,030 | **54,053** |
| RT 알루미늄(AL) | 4,698 | 294 | 2,621 | 300 | 1,032 | **8,945** |

강재는 기공이 45.0%이고 슬래그가 1.9%인 반면, 알루미늄은 기공 29.3%에 슬래그 11.5%다. 슬래그혼입은 절대 수량이 AL 1,032 대 ST 1,030으로 거의 같은데 비율이 **6.05배** 갈린다. 재질에 따라 클래스 분포가 실제로 다르므로, 인위적으로 편중을 부여하지 않아도 이질성이 확보된다. 재질 간 클래스 분포의 총변이거리는 **TVD 0.1831**이고 규모 불균형은 **1 : 6.0**이다.

VT 66,615장은 클래스 체계가 다르다 (용입부족·언더컷이 있고 균열·슬래그가 없다). 주 실험에 섞으면 라벨 공간 자체가 어긋나는 별도 난이도가 생기므로, 주 실험은 RT로 한정하고 VT는 확장과 낯선 데이터 쪽으로 돌린다.

### 3-2-1. 규격 지름길 — 정상과 결함이 해상도로 갈린다

실측에서 나온 문제다. **결함 이미지는 전량 1280×720 크롭이고 정상 이미지는 대부분 파노라마**다. 모델이 결함을 배우지 않고 해상도만 보고 맞힐 수 있다는 뜻이다.

크기를 헤드라인 축에서 정확히 재면 다음과 같다. 4결함 Macro-F1 기준으로 규격을 무시하고 모든 이미지에 결함을 주장하는 전량양성 하한이 **0.2081**, 1280×720에만 주장하는 규격전용 최적이 **0.3025**다. **규격 지름길의 순 기여는 +0.0944**다.

여기서 구분해야 할 것이 있다. 이 문제를 처음 보고한 자리에서 인용된 **96.1%는 RT/ST 이진 규칙의 정확도이지 우리가 채점하는 값이 아니다.** 우리 헤드라인은 4결함 Macro-F1이고 그 축에서의 크기는 위의 0.2081 → 0.3025다. 두 숫자를 섞어 쓰면 문제의 크기를 과대평가하게 된다.

대응은 **정상 파노라마의 타일링과 사전등록 상수·프로브 기반 증명을 결합**하는 것으로 정했다(`docs/dev_log/2026-08-22-데이터확정/40_규격지름길_대응판정.md`). 분할을 먼저 하고 타일링을 뒤에 한다.

## 3-3. 정제

**(a) 라벨 사상표.** 학습 라벨은 원본 체계를 그대로 쓰고, 조항 검색과 낯선 데이터 평가에서만 ISO 6520-1 코드를 쓴다. 원본 라벨을 바꾸면 선행 연구와 비교가 깨진다.

| 원본 (AI허브 RT) | ISO 6520-1 |
|---|---|
| 균열 Crack | 100번대 |
| 기공 Porosity | 2011 / 2012 |
| 융합불량 Lack of fusion | 401 |
| 슬래그혼입 Slag inclusion | 301 |
| 정상 | 해당 없음 |

RIAWELC의 용입불량(402)은 AI허브 RT에 없다. 낯선 데이터 평가는 공통 3클래스(균열·기공·정상)로 축소해 산출하고 사유를 명시한다.

**(b) 폴리곤에서 bbox 생성.** 검출 학습용 bbox는 폴리곤 좌표의 min/max로 만든다. 결함 크기(장축 길이, 등가 직경)는 폴리곤에서 직접 산출해 판정문 생성 재료로 쓴다. 변환 스크립트는 시드 고정 후 공개한다.

**(c) 중복 제거.** 같은 용접부를 연속 촬영한 프레임이 학습셋과 평가셋에 나뉘어 들어가면 성능이 부풀려진다. 지각 해시로 근접 이미지를 묶고 같은 묶음은 같은 쪽에만 배정한다.

**(d) 전처리 통일.** 입력 해상도 640, 정규화, 증강 설정을 다섯 칸에 동일하게 고정한다. AI허브 원본이 1280×720 이상이므로 레터박스 리사이즈 정책을 명시한다.

## 3-4. 평가셋 선분리와 회사별 분할

```
RT 62,998장
  ├─ 글로벌 평가셋 20%   12,600   ← 재질·클래스 층화, 묶음 단위, 클라이언트 분할보다 먼저
  └─ 학습 풀 80%        50,398
       ├─ C1  RT 강재 2/3    28,828  ┐ 이 둘 사이에만 Dirichlet α=0.5
       ├─ C2  RT 강재 1/3    14,414  ┘
       └─ C3  RT 알루미늄     7,156    자연 분할. Dirichlet 미적용
```

**위 C1·C2·C3 규모는 평가셋 20%를 먼저 뗀 뒤의 학습 풀 기준이다**(불변조건 1-3의 순서를
지킨 값). 분할 단위는 이미지가 아니라 연속 촬영 묶음이며, RT 전체 묶음은 6,328개
(AL 956 / ST 5,372)다.

클라이언트를 회사 이름으로 부르지 않는다. 데이터에 회사 구분이 존재하지 않으므로(3-4-1)
실물에 없는 구분을 이름으로 붙이면 허위 서술이 된다. C1·C2·C3은 재질과 분할 규칙으로만
정의한다.

C3의 소수 클래스는 얇다. 학습 풀 기준 추정으로 균열 약 235장, 융합불량 약 240장이다.
클라이언트별 클래스 소실은 없으나 이 얇기를 결과 해석에 반영한다.

### 3-4-1. 자연 분할 축은 재질 하나뿐이다

라벨 129,613개 전수에 회사·사업장·설비·촬영일·작업자 관련 키를 정규식으로 검색한 결과
**히트 0건**이다. 스키마가 22키뿐이고 그게 전부다. 사용 가능한 자연 축은 **재질(ST/AL)과
촬영방식(RT/VT)** 두 가지이고, 주 실험이 RT 한정이므로 실제로 쓸 수 있는 축은 **재질 하나,
값 두 개**다.

따라서 C1과 C2를 가를 실물 근거가 없다. 아무 처리 없이 2:1로 자르면 두 클라이언트가 분포가
같은 복제본이 되고 C1↔C2 비교가 IID 비교로 퇴화한다. **Dirichlet α=0.5를 C1·C2 사이에만
유지하는 이유가 이것이다. 제거할 수 없다.** C3에는 적용하지 않는다. 자연 이질성을 인위
이질성으로 덮어쓰게 되기 때문이다.

논문에는 **"재질 기반 자연 분할 + 강재 내부 통제 이질성"**으로 정확히 쓴다. "회사별 분할"로
쓰면 허위다.

분할 이후에 평가셋을 떼면 다섯 칸이 서로 다른 기준으로 채점된다. 반드시 먼저 뗀다.

C3는 재질이 다르고(feature skew), 클래스 분포가 다르며(label skew), 규모가 작다(quantity skew). 세 가지가 데이터에 실재하는 속성으로 동시에 성립하므로, RQ3의 "소규모·특수재 취급 회사가 연합에서 얻는 편익"을 인위적 설정 없이 측정할 수 있다.

C1과 C2는 같은 강재라 그대로 두면 사실상 균등 분할이 된다. 이 둘 사이에만 Dirichlet α=0.5로 클래스 편중을 준다. 자연 이질성과 통제 이질성을 섞은 설계이며, α 값과 분할 시드는 논문에 명시한다.

## 3-5. 사전 확인 실험 (반나절, 학습 없음)

사전학습 VLM의 제로샷 분류를 RIAWELC과 AI허브 RT 표본에서 측정한다. 용도는 두 가지다.

- 서론 동기: X선 영상에서 범용 VLM의 출발점이 어느 수준인지 실측으로 제시
- 결과 해석: 통합형 두 칸의 성능을 제로샷 대비 향상 폭으로 읽는 기준점

## 3-6. 백업 경로

**AI허브 확보가 끝나 이 경로는 발동 조건이 소멸했다.** 아래는 낯선 데이터 평가에서 RIAWELC을 쓸 때의 취급으로 남긴다.

유효 표본은 파일 수가 아니라 **고유 이미지 21,964장**이다(`testing` 2,443장은 `training`의 복제본). 논문에 규모를 적을 때 24,407을 쓰면 유효 표본을 부풀리게 된다. 해상도도 224×224가 아니라 **227×227**이다.

**저자 제공 분할을 그대로 쓸 수 없다.** 실측에서 저자 분할의 누수가 100%로 확인됐다. RIAWELC을 쓰는 어떤 경로에서든 **우리 분할 절차(중복 묶음 → 층화 → 분할)를 다시 태워야 한다.** 이 경우 검출이 아니라 분류 과제가 되어 위치 정확도 항목을 낼 수 없으므로, 비교 항목을 다섯에서 넷으로 줄이는 것을 논문에 명시한다.

# 4. 텍스트 데이터와 합성 생성 (D2 · D3 · D4)

## 4-1. 원문 시드 수집

| 출처 | 접근 | 용도 | 우선순위 |
|---|---|---|---|
| 대한용접접합학회지 | KCI 무료 | 서술문·QA 재료 | 최우선 |
| 한국선급(KR) 규정 | 홈페이지 공개 | 규정 색인, 판정 추론 재료 | 높음 |
| IACS Rec. 47 | 전문 무료 공개 | 규정 색인 필수 | 높음 |
| KS 용접 규격 | e나라표준 열람 | 조항 번호·요건 참조 | 중간 |
| ISO 6520-1 코드 체계 | 코드 번호는 사실 정보 | 라벨 온톨로지 | 필수 |
| ISO 5817 · 10675 허용치 | 원문 유료 | 수치 요건을 재서술로만 반영 | 방침 확정 필요 |
| 유료 핸드북, 중국어 자료 | | 제외 | |

한국어를 우선하는 이유는 국내 학회 발표라 명분이 서고, 라이선스가 깨끗하며, 최종 판정문 출력이 한국어여야 하기 때문이다.

저작권 방침은 다음과 같다. 유료 표준 원문은 corpus와 색인에 넣지 않는다. 조항 번호, 결함 코드, 허용치 수치는 사실 정보로 보고 재서술해 쓴다. 색인은 무료 공개 문서로만 구성한다.

허용치 표 추출은 본문 텍스트 추출과 다른 작업이다. 담당자를 지정한다 (8/14 회의 안건).

## 4-2. 합성 corpus (D3)

배경지식 학습용으로 세 종류를 만든다.

| 종류 | 형태 | 목표량 | 대응 학습 단계 |
|---|---|---|---|
| (a) 지식 서술문 | 연속 서술문, 질문 형식 없음 | 추가 사전학습 채택 시에만 | 추가 사전학습 (선택) |
| (b) 질의응답 | Q / A | 20,000건 (하한 10,000) | 지시 학습 |
| (c) 판정 추론 과정 | 관찰 → 분류 → 조회 → 대조 → 판정 | 10,000건 | 추론 학습 |

(c)의 예시 형식:

```
관찰 : 방사선 사진 중앙부에 직경 약 2 mm의 원형 음영
분류 : 형상과 밀도로 보아 기공 (ISO 6520-1 2011)
조회 : 모재 두께 12 mm, 품질 수준 C → 단일 기공 허용 직경 3 mm
대조 : 2 mm ≤ 3 mm
판정 : 합격. 근거 ISO 5817 품질수준 C
```

결함 유형 × 두께 구간 × 품질 수준 조합 중 실제로 존재하는 조합만 생성한다. (a)는 추가 사전학습 포함 여부(8/16 결정)에 종속되며, 기본안은 미포함이다.

## 4-3. 이미지-판정문 페어 (D4)

통합형은 이미지를 넣어 판정문을 바로 받는 구조이므로, 학습에 쓸 페어 데이터가 별도로 필요하다.

```
생성 절차
  AI허브 라벨 (결함 종류 + 폴리곤)
    → 규칙 기반 골격 생성: 종류 · bbox · 크기 · 적용 조항 · 조건부 합부
    → LLM으로 문장 표현만 변주 (골격 수치는 불변)
    → 출력 스키마 고정: JSON {defects:[{type, bbox, size}], 판정문, 인용 조항}
```

세 가지를 지킨다.

- 회사별 분할은 D1을 그대로 상속한다. C1 이미지의 페어는 C1에만 들어간다
- 평가는 텍스트 유사도로 하지 않는다. 필드 파싱(종류·좌표)과 조항 정확도로만 채점한다. 유사도로 재면 템플릿을 얼마나 잘 흉내내는지를 재게 된다
- bbox 좌표는 0~1000 정규화 표기로 통일한다. 선행 연구에서 원시 픽셀 좌표를 그대로 넣었을 때 BBox-IoU가 0.055로 떨어졌고, 정규화하면 0.938이었다

## 4-4. 판정 기준의 스케일 문제

ISO 5817과 10675의 합부는 모재 두께 대비 결함 실측 크기(mm)로 갈린다. **전수 실측 결과 모재 두께·결함 실치수·픽셀→mm 환산 필드가 모두 없다.** 라벨 129,613개에 두께·스케일 관련 키를 정규식으로 검색해 히트 0건이고, 스키마 22키에 해당 항목이 존재하지 않는다.

**따라서 치수 기준 판정("2 mm ≤ 허용치 3 mm → 합격")은 원리적으로 성립하지 않는다.** 폴리곤 면적은 계산되지만 단위가 px²이고 mm²로 바꿀 환산 계수가 데이터에 없다. 정상 파노라마에 두께 표기가 찍힌 사례가 관측되나, 결함 이미지로 옮길 연결 키가 없고 곡면 배관의 필름 투영이라 선형 환산 자체가 별도 검증 사안이다.

실물에서 확보되는 축은 **결함 종류·위치·재질 세 가지**이며, D4(이미지-판정문 페어)의 수치 부분은 전량 합성이 된다.

판정 과업을 어디까지 좁힐지는 아직 정해지지 않았다. 조항 검색과 기준 서술까지로 한정하는 안과 가정값 기반 조건부 합부를 유지하는 안이 열려 있다. 어느 쪽이든 다음 두 가지는 확정이다.

- 치수 기준 합부를 실측 근거로 주장하지 않는다.
- 가정값을 쓰는 경우 가정 두께·가정 스케일임을 지표명과 결과표 각주에 명시한다.

## 4-5. 검증과 버전 고정

생성한 것을 그대로 쓰면 오류가 학습에 들어간다. 세 단계로 거른다.

| 단계 | 방법 | 내용 |
|---|---|---|
| 1 | 규칙 검사 (프로그램) | ISO 코드 유효성, 조항 실존 여부, 부등식 계산, 두께·품질수준 조합 실존 |
| 2 | 조항 대조 (모델) | 인용 조항 원문을 가져와 내용 일치 확인. 생성한 모델이 자기 결과를 검증하지 않음 |
| 3 | 표본 전문가 검토 | 무작위 2~3%, 통과율을 논문에 보고. 외부 도메인 전문가(협의 예정) 경로 타진 |

최종 corpus, 페어, 색인에 스냅샷 해시를 부여하고 논문에 명시한다. 재생성하면 검색 결과가 바뀌어 재현이 불가능해진다.

# 5. 배경지식 학습 (다섯 칸 공통 준비)

## 5-1. 적용 대상

| | 통합형 | 분리형 |
|---|---|---|
| 배경지식 학습 | 그림·글 통합 모델 전체 (QLoRA) | 언어모델 쪽만 |
| 검출 모델 | 없음 | 이미지로만 학습, 텍스트 미적용 |

분리형에서 검출 모델은 텍스트를 보지 않으므로 배경지식 학습 대상이 아니다. 두 구조가 갈라지는 첫 지점이다.

## 5-2. 절차

```
기본 모델
  ↓ (선택) 추가 사전학습: 지식 서술문, QLoRA r=128
  ↓ 지시 학습: 질의응답, QLoRA r=16
  ↓ 추론 학습: 판정 추론 과정, QLoRA r=16
  ↓ 어댑터 병합 → 도메인 체크포인트 동결
다섯 칸의 공통 출발점
```

어댑터는 반드시 기본 모델에 병합한 뒤 배포한다. 병합하지 않고 얹으면 이후 연합 집계 대상이 무엇인지 모호해진다.

추가 사전학습은 수행하지 않는다. 확보 가능한 원문 규모가 요구 수준에 크게 못 미쳐 효과를 기대하기 어렵다. 지시 학습과 추론 학습만으로 어디까지 가는지를 보고한다.

## 5-3. 모델 선정

| 역할 | 모델 | 근거 |
|---|---|---|
| 통합형 | Qwen3.5 4B | 네이티브 멀티모달이라 bbox grounding 출력을 지원하고, 판정부와 체크포인트를 공유할 수 있다 |
| 분리형 판정부 | Qwen3.5 4B (통합형과 동일 체크포인트) | 백본 차이가 두 구조 비교에 섞이지 않는다 |
| 분리형 검출부 | YOLO11s (9.4M) | 현장 장비 탑재 논거, AI허브 참조 모델(YOLOv5x-seg)과 계열 참조점 |

통합형과 분리형 판정부가 같은 체크포인트에서 출발하므로 두 구조의 성능 차이를 백본 차이로 설명해야 하는 교란이 없다. 검출부만 별도 모델이며, 이는 과업이 다르기 때문이다.

검출은 bbox 검출로 확정한다. 세그멘테이션은 비용 대비 이득이 없고, 판정 입력에는 종류·위치·크기면 충분하다.

GPU는 기관 AI 노드 사용 가능 여부를 1주차에 확인한다. 불가하면 24GB 기준 설계를 유지한다.

# 6. 본 실험

## 6-1. 고정 조건

다섯 칸에 동일하게 적용한다.

| 항목 | 고정 내용 |
|---|---|
| 기본 모델 | 동일 체크포인트, 버전 명시 |
| 어댑터 | rank, alpha, 대상 레이어, dropout 동일 |
| 최적화 | 학습률 스케줄, 배치 크기, warmup 동일 |
| 전처리 | 해상도, 정규화, 증강 동일 |
| 프롬프트·출력 스키마 | 완전 동일 |
| 규정 검색 | 동일 색인 스냅샷, 동일 검색기, top-k=3 |
| 디코딩 | greedy(온도 0), 최대 토큰 동일 |
| 시드 | 동일 세트 |

## 6-2. 칸별 정의

| 칸 | 내용 |
|---|---|
| **통합·중앙** | 학습 풀 전체의 페어 데이터로 VLM QLoRA 학습 |
| **통합·연합** | C1~C3가 각자 페어로 로컬 학습, 서버가 어댑터를 FedAvg로 평균해 재배포 |
| **분리·로컬** | C1~C3가 각자 검출 모델만 학습. 판정부는 공통 동결본. 3사 개별값과 평균 모두 보고 |
| **분리·중앙** | 학습 풀 전체로 검출 모델 1회 학습. 판정부 동일 |
| **분리·연합** | 검출 모델 전체 가중치를 FedAvg로 집계. 모델이 작아 어댑터가 불필요. 판정부 동일 |

분리형 세 칸에서 판정부는 같은 동결본을 쓴다. 세 방식의 차이는 검출 가중치에서만 발생한다.

통합·연합의 LoRA 평균에는 알려진 문제가 있다. 낮은 랭크 어댑터는 두 행렬의 곱이므로 각각을 평균한 것의 곱과 곱을 평균한 것이 다르다.

```
avg(B) · avg(A)  ≠  avg(B · A)
```

실무에서는 각각 평균하는 방식이 널리 쓰이지만 심사에서 지적될 수 있다. 기본은 행렬별 평균으로 가고, 논문에 명시하며, 여유가 있으면 갱신량 자체를 평균하는 방식을 대안으로 비교한다.

## 6-3. 학습량 등가

원칙은 표본 노출 횟수 기준으로 R × E = N을 맞추는 것이다. 조기 종료 없이 고정 예산으로 돌린다.

| 대상 | 중앙집중 N | 연합 R × E 예시 |
|---|---|---|
| 검출 모델 | 100 epoch | R=50, E=2 또는 R=100, E=1 |
| 통합형 학습 | 3 epoch | R=6, E=0.5 (로컬 스텝 수로 환산) |

맞추지 않으면 "연합학습이 진 게 아니라 덜 학습한 것"이라는 반론을 막을 수 없다. 구체값은 3주차 파일럿 후 고정하고, R·E·N과 총 갱신 횟수를 논문에 모두 적는다.

## 6-4. 시드 정책

- 분리형 세 칸: 3시드, 평균 ± 표준편차
- 통합형 두 칸: 1시드에 클라이언트별 분산 보고, 비용 사유 명시
- 시드 축소는 최후 수단이다. 표준편차 없는 결과는 설득력이 떨어진다

## 6-5. 통신량 산출

```
총 통신량 = 라운드당 (업링크 + 다운링크) × 라운드 수 × 클라이언트 수
```

| 구조 | 라운드당 교환물 | 예상 규모 |
|---|---|---|
| 통합·연합 | LoRA 어댑터 (3B, r=16) | 수십 MB급 |
| 분리·연합 | 검출 모델 전체 가중치 (nano급, fp16) | 수 MB급 |

실측치로 표를 채운다. 분리형이 주고받는 양이 가장 적다는 주장의 정량 근거가 된다.

# 7. 규정 검색 구성 (분리형 판정부)

| 항목 | 설정 |
|---|---|
| 색인 문서 | IACS Rec. 47, 한국선급 규정, ISO 6520-1 코드 체계, 검증된 합성 판정 사례 |
| 청킹 단위 | 조항 단위. 고정 길이로 자르면 조항 경계가 깨짐 |
| 메타데이터 | 문서명, 조항 번호, 결함 코드, 두께 범위, 품질 수준 |
| 임베딩 | 고정. 학습 방식별 재학습 없음 |
| 검색 | top-k = 3 고정 |
| 질의 | 구조화 키 {결함 코드, 크기, 두께, 품질 수준}. 자연어 질의 생성 금지 |

자연어 질의를 생성해 검색하면 재현성이 떨어지고, 검색 실패 원인이 질의 생성 탓인지 색인 탓인지 분리되지 않는다.

색인은 공개 문서와 검증된 합성 사례로만 구성하며 모든 클라이언트가 동일하게 갖는다. 학습 대상이 아니므로 집계 루프 바깥에 두고, 아키텍처 그림에서도 연합 경계 밖에 그린다.

정답 조항 목록은 결함 유형 × ISO 코드 × 조항 번호로 구성한다. 규모는 크지 않으나 전문가 확인이 필수다. 이 목록이 흔들리면 8-3의 지표 전체가 흔들리므로, 표준 원문의 조항 번호를 그대로 인용하는 방식으로 방어한다.

통합형은 규정 검색을 붙이지 않는 것이 기본이다. 모델이 생성문 안에서 직접 인용한다. 이 비대칭이 판정 근거 신뢰도 비교의 대비축이므로 제거하지 않는다. 다만 공정성 지적에 대비해, 여유가 있으면 통합형에 검색 결과를 컨텍스트로 넣은 보조 조건 1회를 부록에 추가한다.

# 8. 평가

## 8-1. 비교 항목과 지표

| 비교 항목 | 지표 | 산출 방법 |
|---|---|---|
| 결함 놓침 비율 | 결함 recall, Macro-F1, 클래스별 P/R/F1, 혼동행렬 | 분리형은 검출 출력, 통합형은 생성 JSON 파싱 |
| 위치 정확도 | mAP@0.5, mAP@0.5:0.95, IoU | 분리형은 bbox, 통합형은 정규화 좌표 파싱 |
| 판정 근거 신뢰도 | 8-3 지표군 | 8-3 |
| 처리 속도·자원 | 이미지당 latency, 파라미터 수, VRAM | 동일 장비 실측 |
| 주고받는 양 | 총 통신량 MB | 6-5 실측 |

Macro-F1을 검출 주 지표로 둔다. 클래스 불균형이 크기 때문이다 (슬래그 1,140 대 기공 27,040). 전체 정확도만 보고하면 다수 클래스 뒤에 실패가 숨는다.

결함 recall을 따로 뗀다. 현장에서 미검출은 오검출보다 위험하다.

통합형이 스키마를 어긴 출력을 내면 오답으로 처리하고 파싱 실패율을 별도로 보고한다.

## 8-2. 근거 접지 (선행 연구 지표 계승)

| 지표 | 의미 |
|---|---|
| Class-Jaccard | 판정문이 언급한 결함 종류가 실제 라벨과 맞는가 |
| BBox-IoU | 판정문이 지목한 위치가 실제 위치와 맞는가 |

AI허브에 위치 라벨이 있으므로 두 지표 모두 산출 가능하다. RIAWELC 백업으로 갈 경우에만 산출 불가다.

## 8-3. 조항 정확도 (신설)

| 지표 | 정의 |
|---|---|
| 조항 검색 정확도 | 정답 조항 대비 top-1 / top-3 적중률 (분리형 검색 단계) |
| 인용 일치율 | 최종 판정문이 인용한 조항 ↔ 정답 조항 (두 구조 공통) |
| 판정 정합성 | 인용 조항의 허용치와 실측값으로 도출한 합부 ↔ 최종 판정 |
| 무근거 인용률 | 실존하지 않거나 무관한 조항을 인용한 비율 |

8-2의 두 지표는 검출 결과와의 일치를 잰다. 검출이 맞다는 전제에서만 의미가 있고, 인용한 규정이 실제 표준과 맞는지는 재지 않는다. 세 번째 축을 세우는 것이 이 연구의 평가 쪽 기여다.

판정 정합성은 조항을 맞게 찾고도 결론을 틀리게 내는 실패를 잡는다. 무근거 인용률은 통합형이 생성문 안에서 인용을 지어내는 정도를 정량화한다.

## 8-4. 낯선 데이터 검증

두 구조 모두에 똑같이 적용한다. 학습 없이 추론만 하므로 비용이 사실상 0이다.

- RIAWELC으로 추론, 공통 3클래스(균열·기공·정상)로 축소 산출하고 사유 명시
- 익숙한 데이터와의 성능 차이가 새 현장에서 예상되는 하락 폭이 된다
- 결과가 나쁠 가능성이 높다. 주 결과가 아니라 한계 절에 배치하고 "일반화 공백의 정량화"로 서술한다. 시간이 부족하면 가장 먼저 잘라도 논문은 성립한다

## 8-5. 헤드라인 수치

```
분리형 회복률 = (분리·연합 − 분리·로컬평균) / (분리·중앙 − 분리·로컬평균) × 100
통합형 유지율 = 통합·연합 / 통합·중앙 × 100
RQ3 편익      = C3의 분리·연합 성능 − C3의 분리·로컬 성능
```

통합형은 로컬 칸이 없어 회복률을 정의할 수 없으므로 유지율로 보고한다. 회복률이 90%를 넘으면 강한 결과이고, 70%대여도 데이터를 내보내지 않는 조건을 감안하면 정당화된다.

## 11-1. R9 — 재질과 어노테이션 시기의 교락 (한계 절 필수 항목)

실측에서 나온 사안이며, 이번 데이터 확정에서 가장 무거운 발견이다.

알루미늄 8,945장이 **전부 가장 이른 `info.id` 구간에 몰려 있다.** 즉 알루미늄은 별도 시기·별도 배치로 촬영·어노테이션됐다. 같은 데이터에서 어노테이션 관행이 시간에 따라 변한 흔적도 관측된다. id 구간을 시간 대용축으로 삼으면 폴리곤 꼭짓점 평균이 **14.7 → 12.3 → 10.8 → 7.1**로 단조 감소한다. 뒤로 갈수록 같은 결함을 성기게 따고 있다는 뜻이다.

**따라서 C3(알루미늄)의 이질성 중 얼마가 재질 물리이고 얼마가 어노테이션 관행 차이인지 분리할 수 없다.** RQ3이 측정하는 값이 "소규모·특수 재질 참여자의 편익"인지 "어노테이션 기준이 다른 참여자의 편익"인지 데이터만으로는 판별되지 않는다.

파급은 두 곳이다.

- **RQ3 해석.** 편익이 관측되든 아니든 그 원인을 재질로 단정할 수 없다.
- **평가 공정성.** 글로벌 평가셋에 AL과 ST가 섞여 있는데 두 집단의 정답 폴리곤 정밀도가 다르면, 같은 모델이 AL에서 낮은 IoU를 받는 것이 모델 탓인지 정답 탓인지 구분되지 않는다.

이 사실은 논문 한계 절에 선언한다. 대응 방식(예: 재질별 IoU 분리 보고)은 평가 프로토콜을 바꾸는 일이라 아직 결정하지 않았고, 결정 전까지 확정된 것처럼 서술하지 않는다.
