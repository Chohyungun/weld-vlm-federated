# 단독·중앙집중·연합 미세조정의 비교 설계

이 문서는 2차 등록 실행에서 실제 비교한 조건을 설명한다. 사전실험, 실행 전 대안, 전량 학습 준비값은 이번 실행의 조건으로 소급하지 않는다.

## 연구 질문과 비교 단위

RQ1은 연합모델의 검출 성능을 단독 평균 및 중앙집중모델과 비교한다. RQ2는 각 참여자가 연합모델로 바꿀 때의 성능 변화와 계산·통신·운용 비용, 연합모델에 대한 기여와 기여 인정(크레딧)·보상까지 고려한 참여 편익을 묻는다. 이번 실험에서는 공통 평가셋의 점수 차이만 비교해 질문에 일부 답했으며 나머지 항목을 함께 고려한 참여 편익은 평가하지 못했다. 세 참여자는 AI Hub 이용 신청 자료를 분할해 구성했으며 실제 기업별 효과를 측정하지 않는다.

| 조건 | 학습 자료 | 평가 모델 |
|---|---|---|
| 단독 | 각 참여자에게 배정한 자료 | C1·C2·C3 모델 각각 |
| 중앙집중 | 세 참여자의 학습 자료 합집합 | 중앙집중모델 |
| 연합 | 참여자별 자료를 분리해 학습 | 어댑터를 한 차례 집계한 모델 |

## 연구 질문의 변경 이력

참여자별 성능 비교를 묻던 RQ2는 연구 진행 중 비용·기여·크레딧·보상을 포함하도록 확장했다. 확장한 질문과 실제로 완료한 분석을 구분한다. 기존 성능 비교의 등록이 확장한 항목 전체의 사전등록을 뜻하지 않는다. 감독 토큰 수에 따른 집계 가중이나 파라미터 거리만으로 참여자의 기여·보상을 대신 평가하지 않는다.

## 학습 조건

기본 모델은 Qwen/Qwen3.5-4B다. 4비트 NF4와 LoRA를 사용하며 rank 16, alpha 32, dropout 0.0를 적용한다. AdamW, 초기 학습률 0.0001, 미니배치 1, 기울기 누적 8을 공통으로 사용했다. 학습 자료는 참여자별 약 1/4을 누적 단위에 맞춰 선택한 11,224개 쌍이다.

중앙집중과 단독은 한 번 순회하고 연합은 로컬 학습 한 번 뒤 한 차례 집계했다. last 체크포인트를 평가하고 조기 종료나 best 선택을 사용하지 않는다. 학습량 비교는 자료 순회 횟수 기준이다. 최적화 갱신 수나 계산 시간을 같게 맞춘 실험은 아니다.

연합 가중은 감독 토큰 수 비율이고 A·B 행렬을 각각 평균한다. 이미지 수 가중과 구분하며, 행렬 곱 갱신량의 정확한 평균이라고 설명하지 않는다. 부분 에폭을 이용한 반복 집계와 FLoRA·FFA-LoRA 비교는 이번 실행에 포함되지 않는다.

집계한 연합모델을 다시 배포해 참여자의 추가 학습과 집계를 반복하지 않았다(R=1). 반복 교환에 따른 개선이나 수렴은 이번 결과로 검증하지 못했다. 자료를 더 사용하는 효과와 집계를 반복하는 효과도 분리해 비교하지 못했다.

## 평가

동결 평가셋 12,461장 중 8개 층에서 101개 묶음, 1,059장을 뽑았다. 묶음에는 연속 식별자와 중복 신호를 사용했지만 실제 용접부 독립성은 검증되지 않았다. 각 층의 전체 묶음 수/표본 묶음 수를 설계 가중치로 쓴다.

M1은 IoU 0.5 이상 최대 대응 후 계산한 네 결함 종류의 매크로 F1이다. 메타데이터 기반 baseline을 같은 표본·가중·채점기로 평가한다. 모델 생성은 greedy 방식이며 출력 한도 1,280토큰이다. 파싱 실패는 주 분석에서 빈 예측으로, 민감도 분석에서는 각 종류의 추가 FP로 처리한다. 실패율과 종료 사유도 별도로 보고한다.

차이의 구간은 층 안 묶음 대응 부트스트랩 2,000회로 계산했다. 소표본 분산 보정이 없고 학습 시드 변동을 포함하지 않는다. 재표집 세부 방식은 산출의 미등록 선택으로 기록돼 있어 모든 절차가 사전등록되었다고 주장하지 않는다.

## 회복률과 미이행 평가

회복률은 100×(연합−단독 평균)/(중앙집중−단독 평균)으로 계산하는 보조 지표다. 단일 시드 결과와 대조선 초과 여부를 포함한 채택 규칙 때문에 대표 성과로 사용하지 않는다. RQ1은 원점수와 차이로도 답할 수 있다.

분모 0.078897가 0.115보다 작아 전량 평가 추가 조건에 해당했다. 이번 제출에서는 시행하지 않기로 결정했다. 등록 계획의 미이행과 표본 범위 제한을 결과에 함께 남긴다. 전량 평가는 현재 모델의 평가 범위를 확대하는 절차이고 학습 자료를 전량으로 늘리는 후속 학습과는 다르다.

## 결과 해석

학습 시드는 하나, 연합 집계는 한 번이다. 참여자별 독립 시험자료와 전문가가 검수한 합부 판정 정답이 없다. 1차와 2차 실행은 응답·prompt·생성 조건 등이 함께 바뀌어 학습량 효과를 분리하지 못한다. 연구 결과는 [본문](paper/본문_초안.md), 수치와 분모는 [결과표](paper/결과표_템플릿.md), 고정 설정은 [재현 정보](paper/재현정보.md)를 따른다.

## C3 기여와 반복 집계를 확인할 후속 비교

공통 평가셋의 연합−단독 차이는 참여자가 받은 성능 편익이다. C3가 제공한 기여는 같은 초기 모델·평가 자료·학습 예산 원칙 아래 C1+C2와 C1+C2+C3를 비교해 확인할 필요가 있다. 포함·제외로 바뀌는 자료량과 집계 가중치는 통제하거나 따로 보고하고 전체 및 재질·결함별 성능, C1·C2의 변화, 누락·오탐을 함께 봐야 한다. 특정 조합의 차이를 모든 참여자 조합에 기반한 Shapley 기여도로 부르지 않는다.

반복 집계에서는 연합모델 배포 → 참여자 추가 학습 → 집계를 여러 라운드 수행하며 라운드별 점수를 비교한다. 총 학습량·통신량도 달라지므로 예산을 맞춘 단독·중앙집중 대조와 복수 시드가 필요하다. 같은 11,224쌍에서 집계 횟수를 바꾸는 비교, 집계 조건을 고정하고 유효 학습 풀 44,845쌍으로 확대하는 비교, 현재 모델을 12,461장 전체에서 평가하는 작업은 구별한다. 이 후속 비교는 수행하지 못했다. 분포와 비교 축은 [자료 분포와 후속 검증](paper/자료분포와_후속검증.md)에 있다.
