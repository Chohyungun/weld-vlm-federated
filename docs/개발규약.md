# 연구 자료와 실험 결과의 관리 원칙

이 저장소는 단독·중앙집중·연합 미세조정의 비교 연구를 위한 것이다. 현재 결과와 실행 전 계획을 구분하고 문서의 설명을 바꿀 때도 원자료와 평가 결과는 보존한다.

## 데이터 취급

원본 영상과 라벨을 변경하지 않는다. 정제·제외·분할 내역은 별도 기록으로 남긴다. 평가 목록과 정답을 학습에 투입하지 않으며 분할 목록을 동결한 뒤에는 같은 실험의 이름으로 다시 생성하지 않는다. 동일·유사 영상의 분할 간 중복 위험을 검토하고 해결하지 못한 부분은 한계로 보고한다.

AI Hub 자료는 승인된 연구 목적과 이용 범위 안에서 취급한다. 공개 저장소에 원본 영상이나 제3자 제공용 데이터 사본을 넣지 않는다. 외부 상용 모델 API로 영상을 보내거나 그 출력으로 학습 자료를 만들지 않는다. 유료 표준 전문과 개인 자격증명·계정 정보·개인 경로도 공개하지 않는다. 연구용 클라우드 실행의 범위는 기존에 확인한 이용 조건과 연구 책임자의 승인에 따른다. 새로운 전송과 유료 실행에는 별도 승인이 필요하다.

## 비교 조건

같은 비교 안에서는 기본 모델 revision, 초기 어댑터, 전처리, prompt와 채팅 템플릿, 생성 방식, 채점기를 고정한다. 조기 종료와 best 체크포인트 선택을 사용하지 않고 지정 학습량의 last 결과를 평가한다. 실제 완료한 학습 시드 수를 보고하며 계획한 시드 수를 완료 수로 쓰지 않는다.

학습량은 등록한 단위로 비교한다. 자료 순회 횟수, 최적화 갱신 횟수, 감독 토큰 수, 계산 시간은 서로 다른 값이다. 집계 가중도 이미지 수인지 감독 토큰 수인지 밝힌다. 생성 실패를 숨기거나 실패한 결과만 유리한 prompt로 다시 생성하지 않는다.

## 결과와 주장

지표의 정의·분모·가중 방식·실패 처리·구간의 범위를 함께 기록한다. 정식 평가와 미리 보기, 사전실험과 본실험, 등록 분석과 사후 분석을 구분한다. 계산 검산은 산술 일치를 확인하는 절차이며 정답의 타당성이나 데이터 독립성을 대신하지 않는다.

규정 조항의 일치성은 허용치 표 기준의 보조 지표다. 판 두께·실치수·전문가 검수가 없는 결과를 실제 용접부의 합격·불합격 판단이나 규정 준수 성능으로 표현하지 않는다. 실행하지 않은 등록 조건은 이유와 함께 남기고 결과에 맞춰 등록 규칙을 삭제하거나 문턱을 바꾸지 않는다.

## 문서 변경

공개 독자에게 필요한 현재 설명과 내부 운영 기록을 분리한다. 수정 전 파일과 근거를 보존하고 사실 정정·구성 변경·문체 변경을 구별해 기록한다. 공개 게시 전에는 문서 간 수치와 링크, 데이터 이용 범위, 내부 경로·계정 정보 포함 여부를 확인한다.
