# 개발 규약 — 연합학습 기반 용접 결함 판정 연구

조선 용접 검사 데이터의 외부 반출 제약 하에서, 데이터를 모으지 않고 가중치만 교환하는
연합학습의 실효성을 검증하고, 통합형 VLM과 분리형(검출 + 판정) 중 현장 적용에 적합한
구조를 규명한다.

- 담당: 조현건(총괄·연합학습), 김예서(통합형·판정 생성), 박상은(데이터·검출·평가)
- 1차 목표: 대한산업공학회 2026 추계학술대회 포스터 — **초록 10/20, 논문 전문 11/10**
- 실험 가용: 9주, GPU 1장 기준 (GPU 확보는 미해결 병목)

## 실험 구조 (5칸)

|        | 로컬 단독 | 중앙집중 | 연합학습 |
|--------|----------|---------|---------|
| 통합형 | 제외      | 통합·중앙 | 통합·연합 |
| 분리형 | 분리·로컬 | 분리·중앙 | 분리·연합 |

- RQ1 데이터를 모을 수 없는 조건에서 공동 모델을 어떻게 학습하는가. 중앙집중 대비 성능을 얼마나 회복하는가 (**주 기여**)
- RQ2 같은 연합 조건에서 통합형과 분리형 중 어느 쪽이 나은가 (부차 기여)
- RQ3 소규모·특수재질 회사가 연합 참여로 얻는 이득

비교 항목: 결함 놓침 비율 / 위치 정확도 / 판정 근거 신뢰도 / 처리 속도 / 통신량

헤드라인 숫자: `회복률 = (연합 − 로컬) / (중앙집중 − 로컬) × 100%`

# 프로젝트 불변조건

아래 세 절은 이 저장소에서 일하는 **모든 트랙에 예외 없이 적용된다.**
어기면 실험 결과가 무효가 되거나 법적·계약적 문제가 된다. 지시문에 없어도 지켜야 한다.

## 1. 데이터 취급 규칙

1. **원본 불변.** `data/raw/` 이하는 읽기 전용이다. 어떤 스크립트도 원본을 수정·삭제·덮어쓰지
   않는다. 변환 결과는 항상 새 경로에 쓴다.
2. **매니페스트가 단일 진실.** 학습·평가 코드는 원본 폴더를 직접 읽지 않고 `manifest.csv`만
   읽는다. 매니페스트가 바뀌면 실험 결과가 바뀐 것이다. 분할 확정 후 읽기 전용으로 잠근다.
3. **평가셋은 회사별 분할보다 먼저 뗀다.** 20%, 재질×클래스 층화, 중복 묶음 단위.
   순서가 바뀌면 다섯 칸이 서로 다른 기준으로 채점된다.
4. **평가 자산은 격리.** 평가셋·정답 조항 목록·한국어 평가셋(599행)은 어떤 학습 단계에도
   투입하지 않는다. 누출은 곧 논문 철회 사유다.
5. **중복 묶음 단위 분할.** 같은 용접부 연속 촬영이 학습·평가로 갈리면 성능이 부풀려진다.
   pHash로 묶고 묶음 ID를 매니페스트에 기록, 분할은 묶음 단위로 한다.
6. **스냅샷 고정.** corpus·페어·색인은 sha256 부여 후 재생성 금지. 해시는 논문에 싣는다.
7. **허용치 CSV가 단일 소스.** 골격 생성기·RAG 청크 메타데이터·채점기 정답 기준 세 곳이
   모두 이 한 파일에서 파생된다. 여기가 어긋나면 판정 정합성 지표가 통째로 무의미해진다.
8. 라벨 문자열을 코드에 하드코딩하지 않는다. 사상표 YAML(원본 라벨 ↔ ISO 6520-1)을 import한다.

## 2. 보안 레드라인

**연구의 서사 자체가 "데이터를 밖으로 내보내지 않는다"이다.** 아래를 어기면 논문의 전제가
스스로 무너진다. 편의를 이유로 예외를 만들지 않는다.

1. **AI허브(71761) 데이터는 국외 반출 금지.** 내국인 신청 한정이며 이용약관에 성과 보고
   의무가 있다. 해외 호스팅 스토리지·해외 리전 클라우드·외부 API에 원본이나 파생 이미지를
   업로드하지 않는다. 발표 전 약관 재확인은 필수 절차다.
2. **원본 이미지를 외부 상용 API에 전송하지 않는다.** 통합형·판정부 학습과 추론은 전부
   로컬 가중치로 수행한다. 상용 VLM API 호출로 라벨·판정문을 만들지 않는다.
3. **외부 클라우드 실험 로깅 금지.** 추적은 MLflow 로컬(sqlite + 파일 artifact)만 쓴다.
   W&B 등 기본이 클라우드 로깅인 도구는 채택하지 않는다 — 비반출 서사와 충돌한다.
4. **상용 API 출력으로 모델을 학습시키지 않는다.** 벤더 약관 위반이다. 합성 생성은 오픈
   가중치 모델 로컬 추론으로 한다. (질의응답 한정 배치 API 검토는 의사결정로그의 미정 항목)
5. **유료 표준 전문을 corpus·색인에 넣지 않는다.** RAG 색인은 무료 공개 문서만
   (IACS Rec.47, 한국선급 규정 등). ISO 결함 코드 번호·명칭은 사실 정보이므로 라벨 체계로
   쓰는 데 문제없다.
6. 개인 자격증명·로컬 절대경로·GPU 계정 정보는 추적하지 않는 로컬 파일에 두고 커밋하지 않는다.

## 3. 모델·실험 정책

1. **조기 종료 금지.** 전 단계에서 early stopping·patience 기반 중단을 쓰지 않는다.
   학습량 등가(`R × E = N`)가 논문의 공정성 주장이다. Ultralytics는 기본 patience가
   조기 종료로 작동하므로 epoch 수 이상으로 설정해 끈다.
2. **best 체크포인트 금지. last를 채점한다.** best 선택은 val 기준 암묵적 조기 종료다.
3. **다섯 칸 공통 고정:** 기본 모델 체크포인트, 어댑터 설정(r/alpha/target/dropout),
   최적화, 전처리, 프롬프트(한 글자도 다르면 안 됨), 검색 설정·top-k, 디코딩, 시드 3세트.
4. **재시도·재프롬프트 금지.** greedy 1회. 스키마 위반 출력은 오답 처리하고 실패율을 별도 보고.
5. **생성 모델이 자기 결과를 검증하지 않는다.** 검증기는 반드시 다른 계열 모델.
6. **합성 검증 실패분은 재생성하지 않고 폐기한다.** 통과율을 기록해 논문에 싣는다.
7. **다섯 칸 출력을 공통 JSON 스키마로 변환한 뒤 단일 채점기로 채점한다.** 칸마다 채점
   코드를 따로 짜면 공정성 주장이 무너진다.
8. bbox는 원본 픽셀로 저장하고, 학습용 변환·채점용 역변환을 각각 함수로 둔다. 학습 타깃은
   채택 모델의 네이티브 좌표계를 따른다(0~1000 정규화 통일이 아니다).
9. CPT(추가 사전학습) **미수행** — 원문 규모가 CPT 요구치에 두 자릿수 미달. SFT + RAG 집중.
10. 불용어 제거·형태소 분석은 하지 않는다. 패딩은 collator가 처리한다.

`code/` 는 **다른 프로젝트의 실습 자료**다(참고용, git 미추적). 구현 시 참조는 가능하나
이 프로젝트의 산출물이 아니며 여기 규칙이 적용되지 않는다.

## 스택

- Python 3.11 (uv로 고정 — 시스템 PATH의 3.14는 쓰지 않는다) / PyTorch 2.x
- 설정은 YAML + OmegaConf / 시드 전역 고정, cudnn.deterministic
- 검출: YOLO11s (AGPL — 사업화 시 Apache 계열 전환 전제, 기록으로 남김)
- 통합형·판정부: Qwen3.5 4B QLoRA (동일 체크포인트 공유)
- 합성 생성: 오픈 가중치 로컬(vLLM 서빙) / 검증: Gemma·DeepSeek 등 **다른 계열**
- 연합: Flower 시뮬레이션 (Ray, GPU 1장, VLM은 동시성 1)
- 추적: MLflow 로컬 / 저장: jsonl·parquet + sha256 (RDB 불필요)

## 다관점 병렬 검증 대상 구간

아래는 한 번에 정답이 나오지 않아 시행착오가 예상되는 구간이다. 착수 전에 해당 여부를
먼저 확인하고, 해당하면 단일 접근으로 밀지 않는다. 서로 다른 관점의 설계안을 병렬로 세운 뒤
적대 검증으로 무너뜨려 보고 살아남은 것을 채택한다.

실제로 값을 했다. 세 관점이 공통으로 채택한 64-bit pHash가 적대 검증에서 기각됐고,
나중에 정답이 박힌 픽스처로 재보니 over-merge가 28,304쌍 대 112쌍이었다.
합의가 정답의 증거는 아니라는 것이 수치로 확인된 사례다.

| # | 구간 | 트랙 | 함정 |
|---|---|---|---|
| 1 | Ultralytics × Flower 결합 | C | 자체 저장·재개 로직과 Flower 파라미터 주입이 충돌. 커스텀 트레이너 래핑이 필요 |
| 2 | BatchNorm 연합 평균 | C | 글로벌 모델 1개를 글로벌 평가셋으로 채점하는 설계라 FedBN을 쓸 수 없다. 강재↔알루미늄 분포 차이로 흔들릴 수 있음 |
| 3 | LoRA 어댑터 집계 | C | `avg(B)·avg(A) ≠ avg(B·A)`. PEFT state dict 교환·병합 시점 |
| 4 | VLM bbox 좌표계 | C·D | Qwen2-VL은 0~1000 정규화, Qwen2.5-VL은 절대 픽셀. **불일치 시 IoU가 0.938 → 0.055로 붕괴**한다 |
| 5 | sm_120 / cu128 환경 구축 | A | Blackwell 신규 아키텍처. 휠 호환성 시행착오가 예상됨 |
| 6 | 판정 골격 생성기 | B | 틀리면 corpus 1만 건이 통째로 오염된다. 부등식 경계·조합 누락 |
| 7 | Docling 표 추출 | B | 스캔본·한글 특수 조판 실패. 허용치 표는 판정 데이터의 핵심 재료 |
| 8 | pHash 임계 + 묶음 단위 층화 분할 | A | 과병합·과분리. 누수와 직결 |
| 9 | 다중 데이터셋 클래스 통일 + 연합 분할 축 판정 | A·F | 5종의 클래스 정의 경계가 달라 **같은 이름이 다른 뜻**일 수 있다. 1:N 사상은 쪼갤 수 없다. 분할 축이 실물에 없으면 RQ1 전체가 인위적이 된다 |
| 10 | 판정 재료 실물 확보 — 픽셀→mm 변환 | F·B·D | bbox 는 픽셀, 허용치 표는 mm. 잇는 정보(화소당 실치수·IQI·스케일 마커)가 없으면 **치수 기준 판정이 원리적으로 불가능**하고 D4 페어가 전량 합성이 된다 |
| 11 | 결함/정상 이미지 규격 지름길 | A·D | 창원 데이터셋에서 결함은 전량 1280×720 크롭, 정상은 대부분 파노라마다. **이미지 크기만으로 96.1% 분류가 된다.** 다섯 칸 전부에 똑같이 실려 이상치로 드러나지 않는다 |
| 12 | 재질↔어노테이션 시기 교락 | F·D | 창원 AL 전량이 최이른 id 구간에 몰려 있고 꼭짓점 평균이 14.7→7.1 로 단조 감소한다. **C3 이질성에서 재질 물리와 어노테이션 관행 변화를 분리할 수 없다.** RQ3 의 답이 무엇을 잰 것인지 불명해진다 |

이 표는 고정이 아니다. 새 함정 구간을 발견하면 총괄에 보고하고 목록에 추가한다.
