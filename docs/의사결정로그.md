# 의사결정 로그

이 문서는 연구 범위, 데이터, 평가와 구현에서 무엇을 선택했고 어떤 근거로 바꾸었는지 설명한다. 날짜는 결정·관측의 시점이며, 계획이나 정책 채택을 실행 완료로 뜻하지 않는다. 현행 실험 절차는 [실험설계](실험설계.md), 코드 계약은 [구현설계](구현설계.md), 공통 작업 규칙은 [개발규약](개발규약.md)에 모았다.

현재 본실험은 Qwen3.5 4B의 로컬 세 모델·중앙·연합을 비교하는 탐색적 연구다. 검출기 세 시드 결과는 사전실험이며 통합형의 결과를 대신하지 않는다. 2026-10-05 기준 통합형 본실험 채점은 아직 없고 실물 리허설도 통과하지 않았다.

## 1. 현행 본실험의 결정

### 통합형 세 학습 방식으로 범위 변경 — 2026-09-18

통합형과 분리형의 구조 비교 RQ2를 본실험에서 제외했다. 통합형의 연합학습 효과를 묻는 RQ1과 각 참여자 역할의 성능 변화를 묻는 RQ3을 수행한다. 통합형 로컬 C1·C2·C3를 포함해 시드당 다섯 모델을 비교한다. 분리형 검출기 세 방식·세 시드는 사전실험으로 보존하고 YOLO와 언어모델 판정부 연결은 여유 과업으로 둔다.

이 결정은 초기의 ‘통합형 로컬 제외, 두 구조 다섯 조건’을 대체한다. 과거의 비용·단독 배포 사유와 분리형 RQ3으로 답할 수 있다는 논리는 현행 통합형 자체 학습 기준선을 생략하는 근거가 아니다. 미완료 조건은 미완료로 보고하며 본실험을 분리형으로 자동 대체하지 않는다.

### 모델·자료·참여자 해석 — 2026-09-25 이후

| 항목 | 채택·상태 | 근거와 한계 |
|---|---|---|

| AL 결함 답안 | 3,372건 `clause_only`, `verdict=null` | 허용치 표 12행이 모두 ST이고 AL 행이 없음 |

셔플은 승인한 `random.Random(f"{derive_seed(base, r, c)}:{ep}")` 규칙으로 학습 정책을 식별한다. 인접 정수 시드끼리 epoch 순열을 공유했던 문제를 새 정책으로 구분하며 과거 실행을 소급해 바꾸지 않는다. 조기 종료 없이 last를 채점하고 `R × E = N`의 이미지 방문 횟수 등가를 유지한다.

2026-10-05에는 모델 revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`, 봉인 페어 `pairs_main_v1`의 설정 연결을 승인했다. 해당 페어 계약서 지문은 `456ea6151d502b3d44113f983f412d71a92c3db12383a93a5c4ce33ee3c0ff9d`다. 설정 연결·제한 시간·중복 연결 목록·리허설과 프레임 진단 구현·진단 문턱 등 착수 조건이 남아 있다. RT 허용치 11행의 계보와 이용 범위 판단도 미완료다.

### 평가 모집단과 부표본 검토 — 2026-10-01, 10-05 변경

현행 동결 eval 12,461장을 주 분석 모집단으로 유지하되 주장 범위를 탐색적 비교로 낮춘다. 10-01에는 실제 평가 부표본 2,910장과 묶음 단위·명목 재질×클래스 층화·희소층 전수 포함을 선택했다. 그러나 10-05에 이 부표본 계획을 철회하고 동결 eval 12,461장 전량 채점으로 변경했다. 모든 모델·학습 시드·대조선에 같은 목록을 적용한다. 목록·지문·생성 설정·주 지표·구간 규칙은 실행 전에 등록해야 한다.

10-01 표본 설계에는 해결되지 않은 불일치가 있었다. 09-25 검토에서 2,910장은 확정층 전수 부분이고 나머지 층의 포함확률이 0이므로 전체 eval의 M1을 역확률 가중으로 복원할 수 없다고 정정했다. 당시 확률표본을 더한 유효 최소안은 4,086장·386묶음이었다. 10-05 전량 평가 결정으로 이 표본 추정 문제는 본실험의 현행 계획에서 제외됐다. 다만 분할 간 중복과 실제 용접부 식별자 부재는 그대로 남아 있다.

이 결정은 10월 1일까지 검증된 중복 연결 목록으로 재분할할 수 있는지 확인한 뒤 내렸다. 당시 근사 중복 판정 규칙의 재설계가 완료되지 않았다. 시한이 지났다는 이유로 현행 전량 평가를 독립 일반화의 확증 근거로 자동 채택하지 않고, 탐색적 비교와 확증 비교 보류 중 전자를 선택했다. 앞선 2026-09-25 기록의 ‘시한 내 실패하면 전량으로 자동 승계’ 문안은 현행 규칙이 아니다.

최소 33쌍의 화소 쌍둥이, 묶음을 건너는 중복 연결, 모델별 노출 비대칭을 본문 한계에 명시한다. 근사 중복 성분을 제외한 민감도 분석은 보조로 둔다. 제외 규칙·목록 판본이 검증되지 않았으면 그 범위를 확정 비율로 쓰지 않는다. 재분할은 진단·리허설에서 사용한 영상 노출 원장을 포함한 후속 과업이다.

기각된 규칙의 목록에서 중앙·연합 31.3%, C1 23.9%, C2 11.9%, C3 4.2%라는 노출 비율이 나왔으나 크기와 참여자 사이 순서는 규칙에 종속된다. 로컬 학습 풀이 중앙·연합의 부분집합이라는 구조만으로 노출의 방향은 설명할 수 있다. 점수·회복률 편향의 크기나 부호는 이 수치만으로 결정되지 않는다. ‘노출이 큰 쪽이 분자·분모 양쪽에서 유리하다’는 단정은 09-25에 철회했다.

이전 장비 기준 채점 비용은 부표본 시드당 47.4시간, 전량 202.8시간으로 산정했다. 완료 실행 시간이나 현재 장비의 계측값이 아니며 시드 수는 별도 결정으로 남는다.

## 2. 통합형 평가의 채택 조건

### 대조선 초과 조건 ⑤

2026-09-21 제안에 09-25 보완을 반영한 정본이다. **팀 결정 전 기본안**이며 M1의 대표 지표 채택이나 본실험 등록 완료를 뜻하지 않는다.

중앙집중과 연합 각각이 다음 두 조건을 모두 만족해야 회복률을 대표 수치로 올린다.

1. 등록한 모든 학습 시드에서 M1 점추정이 등록 대조선의 M1보다 크다.
2. 같은 추첨·같은 가중으로 산출한 `시드 평균 M1 − 대조선 M1` 대응 차의 95% 신뢰구간 하한이 0보다 크다.

로컬 평균은 이 초과 조건에서 제외하고 대조선과의 관계를 병기한다. 회복률 산식의 로컬 기준선에서 제외한다는 뜻은 아니다. 대조선과 동률은 초과가 아니다. 어느 조건이든 미충족이면 대표 수치로 채택하지 않되 정의되는 회복률과 미충족 사유, 대조선 위·아래·구분 불가 표시는 함께 보고한다. 분모·반폭·미정의 비율에 관한 다른 조건도 적용한다.

이 규칙을 여러 문서에서 독립적으로 고치지 않는다. 다른 문서는 이 절을 가리킨다. 더 강한 무화소 대조선이 확인되면 기존 등록을 보존한 새 블록에 정의·적용 시점·사후 변경 여부를 남긴다.

### M1 대조선·실패·출처 보고 — 2026-09-21 보완

주 대조선 기본안은 ID 구간과 클래스 빈도로 박스 출력 여부를 정하는 규칙이다. 기존 상수 박스와 ID 구간 박스도 병기하며 매크로·micro·클래스별 값과 모델−대조선 대응 CI를 보고한다. 적합·문턱 선택은 train·val에서 끝내고 eval은 채점에만 쓴다.

실패 결합의 기본안은 JSON과 `defects`가 유효하면 박스를 채점하고 판정·인용 오류는 조항 축에서만 실패로 세는 것이다. 절단·해독 불가 출력은 레코드 실패로 둔다. 민감도 M1을 함께 등록하며 정상·결함과 N-crop·N-tile별 실패율을 보고한다. 이 결합 범위는 대표 지표 등록 전에 확정한다.

N-crop·N-tile별 M1과 정상 오탐률, 발화율에 기초한 출처 고정 판별력, P9 등가 판정을 통합형에도 적용한다. 이는 모델 구조가 아니라 평가 모집단에 붙은 보고 의무다. 정의되지 않거나 지지량이 부족한 부분집합에는 미산출·미판정 사유를 적는다.

### 별도 구현 검산 — 2026-09-26, 09-28 보완

M1은 원 구현과 별도로 작성한 매칭·집계 구현으로 검산한다. 공유 정규화 입력을 사용하는 방식과 원시 예측·정답을 별도로 읽는 방식 모두에서 TP·FP·FN, 클래스별 F1과 M1을 대조한다. 입력·코드 식별자, 수행자, 비교 결과와 불일치 처리를 남긴다.

09-26에는 ‘원 구현자가 아닌 다른 연구자가 작성’에서 ‘원 구현과 별도로 작성한 구현’으로 작성자 요건을 바꿨다. 같은 작성자가 두 구현을 작성해도 되지만 그 사실을 결과 보고에 적는다. 필요한 사람 연구자의 별도 검토는 담당과 완료 여부를 표시한다. 이 변경은 main 반영 전 원저자가 아닌 쪽의 코드 검수나 두 입력 경로 대조를 면제하지 않는다.

### 백분위·무한 처리 — 2026-10-01

통합형 구간 규약은 다음과 같이 채택했다. 라이브러리 소스에서 도출한 거동과 합성 벡터 실행 45칸이 일치했고, 본실험 점수는 없는 상태에서 결정했다.

| 항목 | 채택한 규칙 |
|---|---|
| 분모가 0 이하인 추첨 | 버리지 않고 분자 부호의 ±무한으로 남김. 미정의 비율의 분자에서 분모 실패 제외 |
| 분자 0 | 분모 실패와 함께 나오면 판정 불가. 분자 0은 부동소수 정확 비교 |
| 시드 사이 무한 부호 충돌 | +∞와 −∞가 함께 나오면 판정 불가 |
| 무한 | 정렬의 끝값으로 구간에 포함 |
| 백분위 | 보간 없음. 하한 내림 자리·상한 올림 자리의 추첨값 사용. 방식 이름 대신 순위 식 등록 |
| 적용 범위 | 통합형 산출물의 모든 백분위 구간. 구간별 규약 ID 기록 |
| 끝점·반폭 | 유한·무한·없음의 상태로 표현. 같은 부호 무한끼리 반폭은 미정의 |
| 집계 길이 n | 집계에 들어간 유한·무한 추첨 수 |
| 점추정 분모 실패 | `absent`와 사유. 점추정에는 무한을 적지 않음 |
| 사전실험 | 동결된 기존 규약 유지. 새 규약 소급 계산은 등록 뒤 별도 ‘판정에 쓰지 않음’으로 표시 |

원 채택표의 동률 문구는 ‘분모와 분자가 함께 0’이었다. 이후 계약과 구현은 분모가 비양수이고 분자가 0인 경우로 범위를 명시하고 시드 사이 무한 부호 충돌도 판정 불가로 분류했다. 공개 실험설계에 문구 정정 요청 상태가 기록돼 있으며, 이 차이를 숨기지 않는다. 현재 구현식과 상태는 [구현설계](구현설계.md#통합형의-백분위-규약)에 적었다.

기본 보간을 쓰지 않는 이유는 무한 꼬리 내부에서 보간값이 미정의가 되는 거동을 확인했기 때문이다. 사전실험의 `evaluation/recovery_ci.py`는 수정하지 않고 통합형 전용 모듈·등록 규약을 사용한다.

선택 근거의 독립성에도 제한이 있다. 규약 작성 측은 사전실험의 버린 추첨 수를 09-16·09-21에 열람했다고 기록했고, AI를 사용한 총괄 검토도 09-16 구간 결속 작업에서 해당 산출물을 다뤘다. 사용자의 값 열람 여부는 확인되지 않았다. 규약은 이 사전실험 값에 맞춘 성능 판단이 아니라 규칙의 의미와 합성 벡터 거동을 근거로 선택했으며 열람 이력은 함께 보존한다.

### 좌표 지문 변경과 과거 산출물 — 2026-09-25
