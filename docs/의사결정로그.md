### 규격 지름길 대응 (2026-08-24 확정, 4관점 적대 검증)

판정 문서 `docs/dev_log/2026-08-22-데이터확정/40_규격지름길_대응판정.md`

- **채택: 정상 파노라마 k=1 타일링(A) + 사전등록 상수·프로브 증명(D) 결합.**
  표본 선택과 온더플라이 창 샘플링은 **어떤 조건에서도 채택하지 않는다** —
  전자는 오탐 측정을 없애고 후자는 계약 #4(`image_id` 당 예측 1건)를 깬다.
- **지름길 크기를 헤드라인 축에서 재정의했다.** 4결함 Macro-F1 기준
  전량양성 0.2081 → 규격전용 최적 0.3025, 순 기여 **+0.0944**.
  최초 보고된 96.1% 는 "1280×720이면 결함" 이진 규칙의 정확도이고
  **계약 #4가 채점하지 않는 과제의 값이다.** 게이트는 전부 0.2081→0.3025 축에 놓는다.
- **실행 순서: 분할을 먼저 하고 타일링을 뒤에 한다.** 전처리 상수가 평가셋 픽셀 통계에서
  유도되면 불변조건 1-4 가 실질에서 깨진다. 예비 분할 → 학습 풀에서만 캘리브레이션 →
  타일링 → 최종 분할 → 잠금.
- **타일 선택 함수는 `split` 을 입력으로 받지 않는다.** `sha256(image_id + seed) mod N_cand`
  결정론적 균일 선택이고 평가셋에도 예외 없이 같은 규칙·시드를 적용한다.
  **내용 기반 선택(중앙·밝기·대비) 금지** — 정상 쪽에만 걸리는 편향이라 새 교란이다.

### 데이터셋 장수 (2026-08-23 트랙 F 실측 확정)

**"파일 수"와 "고유 이미지 장수"는 다른 값이다. 섞어 쓰지 않는다.**

- **LoHi-WELD 원본 3,022장** (저해상 2,000 + 고해상 1,022). 문서 기재가 옳았다.
  파일 34,489개는 저자 5-fold 사본·라벨·캐시를 전부 합친 값이다.
  `kfold_*` 는 **전량 파생본이라 매니페스트에 넣지 않는다.**
- **RIAWELC 고유 이미지 21,964장** (파일 24,407). **`testing` 2,443장이 `training` 의
  바이트 동일 복제본이다.** 전수 sha256 대조 2,443/2,443 일치.
  → **저자 분할을 쓰지 않는다. 쓰면 테스트 누수 100% 다.** 우리 pHash 묶음 분할을 태운다.
  백업 시나리오에서 RIAWELC 를 주 데이터로 올릴 때 이 조항이 없으면 저자 분할을
  그대로 쓰게 된다.

### GPU — 로컬 파일럿 후 산정 (2026-08-24 총괄 확정)

**유료 전환 판단을 로컬 파일럿 실측 뒤로 미룬다.** 무상 확보 경로는 팀 전원이 찾아봤고
없다. 로컬 RTX 5060 Ti 16GB 로 다섯 칸 축소 파일럿을 완주하고, 거기서 나온 칸별
소요 실측을 외삽해 본실험이 로컬로 되는지, 유료가 필요하면 얼마나 필요한지 산정한다.
추정이 아니라 실측으로 정한다.

### 판정 축 — 현행 유지 (2026-08-24 총괄 확정)

**본실험의 판정 과업 정의를 지금 좁히지 않는다.** 치수 기준 판정이 창원 실측으로
성립 불가가 확인됐지만, 허용치 표(IACS Rec.47·한국선급) 확보 작업이 진행 중이라
축소 결정은 그 결과를 보고 한다.

**파일럿은 좁혀도 된다.** 1사이클 테스트 단계의 판정부는 원인·조치 축이나
조항 검색 + 기준 서술로 좁혀 돌린다. 파일럿의 목적은 판정 품질이 아니라
경로가 끊기는 지점을 찾는 것이다.

### 데이터 적재 위치

- **"드라이브"는 공유 드라이브를 뜻한다** (2026-08-22 총괄 확정). 데이터셋은 개인
  드라이브에 적재하지 않는다. 팀 3인이 같은 경로를 봐야 하고, 개인 계정에 두면
  담당자가 바뀔 때 접근이 끊긴다. 새 데이터셋도 대상지는 공유 드라이브다.
- RIAWELC·LoHi-WELD 가 개인 드라이브에 적재돼 팀원 2인이 접근하지 못했다.
  AI허브 3종이 있는 `공유 드라이브 > 대한산업공학회_추계학술대회` 아래로 옮기고
  개인 드라이브 원본은 지운다.
- **이동 순서를 고정한다.** 복사 → 무결성 대조(파일 수·용량·표본 sha256) →
  동기화 완료 확인 → 원본 삭제. 대조가 어긋나면 삭제하지 않는다.
  지우고 나서 옮길 수 없다는 것이 이 작업의 유일한 실패 모드다.

### 교정된 오해

- **bbox 좌표**: 0~1000 정규화 통일이 아니라 채택 모델의 네이티브 좌표계를 따른다. 선행 연구 0.055→0.938 사례의 처방은 정규화가 아니라 좌표계 일치
- **텍스트 전처리**: 불용어 제거·형태소 분석은 dense 임베딩·LLM 경로에 불필요하거나 해로움. 패딩은 collator 처리
- **YOLO는 ViT가 아님**: CNN 기반 검출기. RT-DETR도 CNN 백본 + 트랜스포머 하이브리드
- **"작은 모델 = 증류된 모델"이 아님**: 패밀리마다 다르고, 벤더의 사전학습 단계 증류와 과제 특화 증류는 층위가 다름
- **모델을 키운다고 결함 검출이 좋아지지 않음**: 검출은 비전 인코더가 하는 일이고, 27B와 9B의 차이는 대부분 언어 파라미터
