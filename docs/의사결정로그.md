### 규격 지름길 대응 (2026-08-24 확정, 4관점 적대 검증)

판정 문서 `docs/dev_log/2026-08-22-데이터확정/40_규격지름길_대응판정.md`

- **채택: 정상 파노라마 k=1 타일링(A) + 사전등록 상수·프로브 증명(D) 결합.**
  표본 선택과 온더플라이 창 샘플링은 **어떤 조건에서도 채택하지 않는다** —
  전자는 오탐 측정을 없애고 후자는 계약 #4(`image_id` 당 예측 1건)를 깬다.
- **지름길 크기를 헤드라인 축에서 재정의했다.** 4결함 Macro-F1 기준
  전량양성 0.2081 → 규격전용 최적 0.3025, 순 기여 **+0.0944**.
  최초 보고된 96.1% 는 "1280×720이면 결함" 이진 규칙의 정확도이고
  **계약 #4가 채점하지 않는 과제의 값이다.** 게이트는 전부 0.2081→0.3025 축에 놓는다.
- **실행 순서: 분할을 먼저 하고 타일링을 뒤에 한다.** 전처리 상수가 평가셋 픽셀 통계에서
  유도되면 불변조건 1-4 가 실질에서 깨진다. 예비 분할 → 학습 풀에서만 캘리브레이션 →
  타일링 → 최종 분할 → 잠금.
- **타일 선택 함수는 `split` 을 입력으로 받지 않는다.** `sha256(image_id + seed) mod N_cand`
  결정론적 균일 선택이고 평가셋에도 예외 없이 같은 규칙·시드를 적용한다.
  **내용 기반 선택(중앙·밝기·대비) 금지** — 정상 쪽에만 걸리는 편향이라 새 교란이다.

### R3 판정 — 출처 지름길 잔존 수용 (2026-08-31 총괄 확정)

**사다리가 끝났다.** R3 히스토그램 정합도 통과선에 닿지 못했다.
현행 매니페스트(정합본)로 분할을 동결한다. 상세는
`docs/dev_log/2026-08-22-데이터확정/57_R3_판정_잔존수용.md`.

| 조건 | 통과선 | 원본 | R2-a | R3 |
|---|---|---|---|---|
| P2 `raw` | ≤ 0.60 | 0.9972 | 0.9906 | **0.9802** |
| P3 `shuffle` | ≤ 0.65 | 0.9852 | 0.8476 | **0.8646** |
| P3 `lowres` | ≤ 0.65 | 0.9975 | 0.9961 | **0.9934** |

정합은 겨냥한 채널을 닫았다 — 1백분위 밝기 0.8801 → **0.5901**, 두 출처 평균이
125.3 대 128.6 으로 수렴. 남은 것은 **밝기의 공간 배치**(블록 통계 단독 0.8085)이며,
전역 단조 픽셀 사상으로는 구성상 건드릴 수 없다. 픽셀을 옮기면 결함 위치가 파괴되고
지역별 사상은 결함의 국소 대비를 왜곡하므로 **전처리로 더 좁힐 여지가 없다.**

**검토했으나 채택하지 않은 것 — 정상을 원본 크롭으로 한정.** 결함은 전량 N-crop
이므로(N-tile 0장) 정상을 크롭으로 한정하면 지름길이 구성적으로 사라진다. 다만 학습
풀이 49,847 → 30,076 (-39.7%) 이 되고 C2 가 62.6% 빠져 설계한 강재 2:1 이 3.24:1 로
깨진다. 평가 정상은 5,375 → 654. **증거 없이 데이터 40% 를 버리지 않는다** —
검출기가 실제로 출처를 이용하는지는 아직 재지 않았다.

**대신 P9(교차 출처 오탐, TOST δ=0.10)를 파일럿 필수 산출물로 승격한다.**
오탐이 출처별로 쏠리면 크롭 한정본을 본실험 구성으로 승격하고, 안 쏠리면 잔존은
논문의 한계 문단이다. 어느 쪽이든 다섯 칸에 동일하게 적용한다.

**논문 게재:** 3단 AUC 대조와 채널 분해표를 그대로 싣는다. 출처별 오탐 분해를
결과에 넣고, 정상을 크롭으로 한정한 지름길 무력 부표를 부록에 붙인다.
**어느 문장에서도 "지름길이 죽었다"고 쓰지 않는다.**

### R2-a 불합격 → 히스토그램 정합 1회 시도 (2026-08-27 총괄 확정)

- 마스킹 후에도 **raw 0.9906 / shuffle 0.8476 / lowres 0.9961 전부 불합격.**
  shuffle 만 0.14 내려갔다 — 테두리 국소 무늬는 지워졌으나 전역 통계는 그대로다.
- 잔존 채널 위치 특정: **마스크 내부만 잘라 재측정해도 p1 밝기 AUC 0.8837** —
  마스킹 전 전체 이미지 값 0.8801 과 사실상 같다. **어두운 영역이 테두리가 아니라
  타일 전면에 퍼져 있다.** 파노라마와 크롭의 노출·농도 차이가 촬영 단계에서 실렸다.
- 클램프는 기각됐다(결함 p25 = 배경 p75 = 104, 분포 겹침. 한 통계를 맞추면 판별이
  옆 통계로 이동). R2-b 는 밴드 205px 대 타일 720px 라 기하적으로 불가.
- **총괄 판단: 히스토그램 정합을 1회 시도하고 결과로 정한다.** 이미지별 단조 변환이라
  밝기 주변 통계는 구성상 동일해지고 이미지 내 순서(결함 대 주변 대비)는 보존된다.
  공간 배치가 남아 실패가 예상되나 **측정 없이 마지막 후보를 접지 않는다.**
  검출 성능 영향도 함께 재서 판단 재료로 남긴다.
- **분할 동결을 8/29 로 하루 미룬다** (40번 판정의 허용 슬립 범위).

### P2·P3 불합격 → R2-a 발동 (2026-08-26, 사전 확정 사다리 준수)

- **P2 raw AUC 0.9972 / P3 shuffle 0.9852 / lowres 0.9975 — 전부 불합격** (통과선 0.60/0.65).
  타일링은 규격 축을 없앴지만 **지름길이 밝기 축으로 옮겨 살아남았다.**
- 판별 채널 특정: **1백분위 밝기 단독 AUC 0.8801** (N-crop 108.6 / N-tile 48.1).
  99백분위는 0.5046 으로 차이 없음 — **어두운 쪽 끝만 다르다.** 파노라마 타일에
  필름 가장자리·배경의 어두운 영역이 들어오고 원본 크롭에는 없다.
- 교란 제거 절차가 판정을 살렸다: 첫 실행은 출처와 클래스가 겹쳐 해석 불가
  (N-tile 100% 정상) → **정상 이미지만으로 재실행**해 출처 자체가 판별됨을 확정.
- 40번 4-5 사전 확정 사다리에 따라 **R2-a 발동**: RT 전량 동일 상대 테두리
  마스킹(각 변 8%) 후 프로브 재실행. R1(폐색 규명)은 AUC>0.70 이라 건너뛴다.
- 서술 규율 유지: **어느 단계에서도 "지름길이 죽었다"고 쓰지 않는다.**
  출처 판별 AUC 측정값과 함께만 서술한다.

### 함정 #8 종결 — 창원 데이터에서 pHash 는 정확 일치만 잡는다 (2026-08-26)

스펙 6-4 절차를 tiles_v1 전량에 밟은 결과 **"pHash 부적합" 분기**로 떨어졌다.

- 같은 용접부 쌍의 해시 거리 중앙값 126/256 — 무작위(128)와 사실상 동일.
  상한 96 에서도 같은 용접부 쌍 회수율 0.41%(ST)/1.16%(AL)
- 원인은 타일링이 아니다 — 원본 그대로 통과한 결함 이미지도 같은 분포.
  물리적으로 타당하다: 연속 촬영은 같은 장면의 재촬영이 아니라 **긴 용접부의
  서로 다른 구간**이라 지각적으로 실제로 다른 이미지다
- 구현은 정상 (바이트 동일 = 거리 0, q60 재압축 = 거리 6)

**t\* = 0 (정확 일치)로 적용.** E3 엣지 90, 묶음 6,322 → 6,232.
**실질 누수 방어선은 E1·E2(연속 촬영 id 축)이며** pHash 는 바이트급 중복만 잡는다.
RIAWELC 의 "비겹침 타일은 pHash 로 못 잡는다"와 같은 결론이 주 데이터에서 재확인됐다.
논문 한계 절에 싣는다.

분할 재실행: eval 20.00%, Dirichlet 재추첨 17→12회, 위반 0.
**이전 분할과 배정 일치율 34.51%** (묶음 변화 4.75% 대비) — 분할 함수는 결정론이되
입력에 연속적이지 않다. 학습 전이라 실해는 없고, 동결이 한 번뿐인 이유가 이것이다.

### E3 선행 후 동결 (2026-08-26 총괄 확정)

- **분할 동결 전에 pHash 묶음(E3)을 넣고 최종 분할을 한 번 더 돌린다.** 묶음은 합쳐질
  뿐 쪼개지지 않으므로, E3 를 잠근 뒤에 더하면 서로 다른 split 의 묶음이 합쳐져 분할
  원자성이 깨진다. 순서를 지적한 것은 데이터 담당이다.
- 방법은 기존 검증 그대로다: **256-bit pHash + cap 96** (함정 #8 다관점 검증 + 실측 입증).
  절대 임계 t* 만 실데이터(tiles_v1)에서 §6-4 절차로 도출한다 — 새 결정이 아니라
  검증된 절차의 적용이다.
- Dirichlet 재추첨이 15→17회로 늘었다. E3 재분할에서 다시 세고, 계속 늘면 밴드 폭을
  재검토한다. C1 의 균열 33장·융합불량 31장 편중은 의도된 것이나 결과 해석에서
  분포를 먼저 제시한다 — 구현 오류로 읽히지 않게 한다.

### 채널 수 지름길 — 규격이 선제 차단 (2026-08-25 기록)

M2 전수 스캔의 부수 발견이다. **그레이스케일 비율이 결함 15.3% 대 정상 41.4%(26.1%p 차)** —
채널 수만 읽어도 상당히 갈린다. 확정 규격의 `mode: "L"`(전량 그레이스케일 변환)이 이 축을
없애므로 규격 변경은 없다. 규격이 무엇을 없애는지를 정량화한 수치로 기록한다.

### 계약 밖 클래스 처리 (2026-08-24 총괄 확정)

- **incomplete penetration(용입부족) 2장은 제외 유지.** 라벨 사상표에도 평가 공간에도
  없는 클래스가 실물에 있었다. 62,996장 중 2장으로는 학습도 평가도 성립하지 않으므로
  계약을 넓히지 않고 이미지째 제외하고 건수를 기록한다. 매니페스트 v0 기준이다.
- 밴드 초과(4.05%)는 폐기가 아니라 **밴드 중심 크롭**이다. 밴드가 타일보다 크면 포함
  관계가 뒤집혀 타일 전체가 검사된 용접부 안이라 정상 승계가 안전하다. 회계 셀
  `oversized_band_cropped` 로 별도 집계한다.
- Dirichlet 재추첨이 15회 걸렸다(밴드 하단 0.6088). v1 에서 pHash 엣지로 묶음이 더
  굵어져 다시 15회를 넘으면 밴드 폭을 재검토한다.

### 데이터셋 장수 (2026-08-23 트랙 F 실측 확정)

**"파일 수"와 "고유 이미지 장수"는 다른 값이다. 섞어 쓰지 않는다.**

- **LoHi-WELD 원본 3,022장** (저해상 2,000 + 고해상 1,022). 문서 기재가 옳았다.
  파일 34,489개는 저자 5-fold 사본·라벨·캐시를 전부 합친 값이다.
  `kfold_*` 는 **전량 파생본이라 매니페스트에 넣지 않는다.**
- **RIAWELC 고유 이미지 21,964장** (파일 24,407). **`testing` 2,443장이 `training` 의
  바이트 동일 복제본이다.** 전수 sha256 대조 2,443/2,443 일치.
  → **저자 분할을 쓰지 않는다. 쓰면 테스트 누수 100% 다.** 우리 pHash 묶음 분할을 태운다.
  백업 시나리오에서 RIAWELC 를 주 데이터로 올릴 때 이 조항이 없으면 저자 분할을
  그대로 쓰게 된다.

### 판정 축 — 현행 유지 (2026-08-24 총괄 확정)

**본실험의 판정 과업 정의를 지금 좁히지 않는다.** 치수 기준 판정이 창원 실측으로

### 교정된 오해

- **bbox 좌표**: 0~1000 정규화 통일이 아니라 채택 모델의 네이티브 좌표계를 따른다. 선행 연구 0.055→0.938 사례의 처방은 정규화가 아니라 좌표계 일치
- **텍스트 전처리**: 불용어 제거·형태소 분석은 dense 임베딩·LLM 경로에 불필요하거나 해로움. 패딩은 collator 처리
- **YOLO는 ViT가 아님**: CNN 기반 검출기. RT-DETR도 CNN 백본 + 트랜스포머 하이브리드
- **"작은 모델 = 증류된 모델"이 아님**: 패밀리마다 다르고, 벤더의 사전학습 단계 증류와 과제 특화 증류는 층위가 다름
- **모델을 키운다고 결함 검출이 좋아지지 않음**: 검출은 비전 인코더가 하는 일이고, 27B와 9B의 차이는 대부분 언어 파라미터

| **재질↔어노테이션 시기 교락** | **즉시 (RQ3 직결)** | 꼭짓점 평균이 id 구간을 따라 14.7→12.3→10.8→7.1 단조 감소한다. **AL 8,945장이 전부 최이른 구간에 몰려 있다.** C3 이질성 중 재질 물리와 어노테이션 시기 차이를 분리할 수 없다. 회사·촬영일 필드가 없어 통제도 어렵다. 평가셋에 AL·ST 가 섞여 있고 둘의 정답 기준이 다르면 단일 채점기 원칙이 문면으로만 남는다 |
| 판정 재료 부재 확정 대응 | 지름길 판정 후 | **픽셀→mm 변환 불가 확정.** 판정 라벨 없음, 결함인데 합격 0건, 조치 지침 없음, 자유 기술 필드 0건. D4 는 전량 합성이고 실물 축은 종류·위치·재질 3개뿐. 판정을 종류·유무 기준으로 좁힐지 결정 필요 |
