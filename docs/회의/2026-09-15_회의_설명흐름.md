# 사전실험에서 본실험으로 — 회의 설명 순서

2026년 9월 15일 · 처음 참여하는 팀원을 위한 설명 자료

설명은 약 12분, 이후에는 본실험 범위와 담당을 논의하는 진행안입니다. 수치는 9월 15일 검토한 회의 자료를 따랐습니다. 아래 본실험 순서는 제안이며 회의에서 확정한 결정은 아닙니다.

## 시작할 때

이번 연구에서는 회사마다 용접 검사 사진을 따로 보관하는 상황을 가정합니다. 사진을 모아 학습할 때와 각자 학습할 때, 사진을 옮기지 않고 모델 값을 합칠 때의 성능을 비교하려고 합니다.

지금까지는 공개 데이터로 이 상황을 구성해 결함 검출기를 학습했습니다. 규정 근거를 제시하는 기능과 통합형 모델 비교는 검증을 더 해야 합니다. 오늘은 이미 얻은 결과를 설명하고 다음 실험에서 확인할 범위를 정하겠습니다.

## 1. 연구 질문부터 설명합니다 — 1분

주 질문은 **데이터를 한곳에 모으기 어려울 때 연합학습이 얼마나 도움이 되는가**입니다. 여기서 도움이 된다는 말은 두 가지로 나눠야 합니다.

- 전체 자료에서 공동 모델의 검출 성능이 나아지는가.
- 각 참여자가 자기 자료에 가까운 검사 대상에서도 이득을 얻는가.

두 결과는 다를 수 있습니다. 사전실험에서도 실제로 다른 방향의 결과가 나왔습니다.

모델 구성 비교는 별도 질문입니다. 분리형은 검출기가 결함을 찾고 검색·판정부가 규정 근거를 붙이는 구조입니다. 통합형은 이미지와 글을 함께 처리하는 시각언어 모델(VLM)이 결함과 근거를 함께 출력하는 구조입니다. 이번에 반복 실험을 마친 범위는 분리형의 검출기입니다.

## 2. 어떤 자료를 어떻게 나눴는지 설명합니다 — 2분

용접부 X선 사진 62,308장을 정리했습니다. 그중 12,461장을 공통 평가셋으로 먼저 떼어 놓고 학습에는 사용하지 않았습니다. 나머지 49,847장은 학습 44,846장과 검증 5,001장입니다.

학습·검증 풀에는 C1·C2·C3라는 참여자 역할을 부여했습니다. C1과 C2는 명목 ST 자료를 결함 분포가 다르게 나눴고 C3에는 명목 AL 자료를 배정했습니다. 실제 세 회사가 참여한 실험은 아닙니다. ST·AL도 제공된 라벨의 구분이므로 C3를 실제 알루미늄 회사라고 설명하면 안 됩니다.

자료의 흐름은 다음과 같습니다.

원본 확인 → 중복 위험이 있는 자료 묶기 → 공통 평가셋 분리 → 나머지의 참여자·학습·검증 분할 → 파일 목록과 해시 고정

같은 사진이나 비슷한 출처의 자료가 학습과 평가 양쪽에 섞이지 않도록 파일 해시, 라벨 숫자 ID의 연속 구간, 지각 해시 일치를 이용했습니다. 실제 용접부 식별자가 없어 누출을 모두 막았다고 보장할 수는 없습니다. 분할 목록은 8월 31일 고정했습니다.

이 단계에서 팀원이 구분할 용어는 세 개입니다. 학습셋은 모델을 학습시키는 자료, 검증셋은 설정과 동작을 점검하는 자료, 평가셋은 정한 기준으로 결과를 비교하는 자료입니다. 기존 평가셋은 이미 결과를 여러 번 살펴봤으므로 후속 실험에서 처음 보는 독립 자료로 취급하지 않습니다.

## 3. 세 학습 방식이 어떻게 다른지 설명합니다 — 2분

| 방식 | 학습할 때 하는 일 | 시드당 얻는 검출기 |
|---|---|---:|
| 로컬 | C1·C2·C3가 자기 집단의 학습 자료만 사용합니다 | 3개 |
| 중앙집중 | 세 집단의 학습 자료를 합쳐 모델 하나를 학습합니다 | 1개 |
| 연합 | 같은 공동 모델에서 출발해 각 집단이 학습하고 모델 값을 합치는 과정을 반복합니다 | 1개 |

연합학습 한 라운드는 **공동 모델 전달 → 각 집단의 학습 → 모델 값 회수·집계 → 다음 공동 모델 전달** 순서입니다. 사진은 집계 단계에서 교환하지 않습니다. 다만 모델 값을 주고받는 것만으로 정보 유출 방지까지 입증한 것은 아닙니다.

검출기는 YOLO11s를 사용했습니다. 중앙집중과 로컬은 100 epoch, 연합은 50라운드에서 매번 2 epoch씩 학습했습니다. epoch는 기준 학습 표본을 한 차례 순회하는 단위입니다. 표본 순회 예산을 맞췄지만 증강으로 추가되는 이미지, 실제 갱신 횟수, 계산 시간까지 같지는 않습니다.

시드는 난수의 시작값입니다. 서로 다른 세 시드로 같은 비교를 반복했고 각 시드에서 로컬 3개·중앙집중 1개·연합 1개를 얻었습니다. 따라서 완료한 검출기는 15개입니다. 통합형을 포함한 연구의 다섯 조건을 모두 완료했다는 뜻은 아닙니다.

학습 중 가장 잘 나온 모델을 고르지 않고 마지막 모델을 같은 공통 평가셋에서 채점했습니다.

## 4. 결과는 두 표로 설명합니다 — 2분

위치 검출 지표인 mAP@50을 사용했습니다. 예측한 결함 종류와 상자 위치가 맞는지를 종합해 비교하는 값입니다. 값이 클수록 좋지만 사진을 몇 퍼센트 맞혔는지를 나타내는 정확도와는 다릅니다.

첫 표는 공통 평가셋 12,461장의 세 시드 평균입니다. 출력 신뢰도 하한은 0.01입니다.

| 비교 | mAP@50 |
|---|---:|
| 중앙집중 | 0.4946 |
| 연합 | 0.2709 |
| 로컬 세 모델 평균 | 0.1973 |
| 로컬 C1 | 0.3595 |

공통 평가셋에서 연합은 로컬 평균보다 높았지만 로컬 C1보다 낮았습니다. 중앙집중과 로컬 평균 사이 격차를 얼마나 줄였는지 계산하면 시드별 회복률의 평균은 24.8%입니다. 정확도가 24.8% 올랐다는 의미가 아닙니다. 회복률의 신뢰구간은 아직 산출하지 않았습니다.

두 번째 표에서는 같은 C3 로컬 모델과 연합 모델을 평가 대상만 바꿔 비교합니다.

| 평가 대상 | C3 로컬 | 연합 |
|---|---:|---:|
| 전체 공통 평가셋 | 0.0984 | 0.2709 |
| 명목 AL 부분집합 1,786장 | 0.4802 | 0.2267 |

전체에서는 연합이 높지만 C3에 대응하는 출처에서는 로컬이 높습니다. 전체 평균만 보고 모든 참여자가 이득을 얻는다고 말할 수 없는 이유입니다. 본실험에서도 전체 성능과 참여자별 목표 자료의 성능을 따로 보고해야 합니다.

## 5. 사전실험에서 드러난 문제를 설명합니다 — 2분

### 학습 곡선의 변화와 평가 성능의 변화는 다릅니다

연합학습의 데이터 순서가 라운드마다 반복되는 경로를 확인했습니다. CPU 모사에서는 100 epoch 동안 서로 다른 순서가 연합 2개, 중앙집중 100개였습니다. 실제 증강까지 전부 계측한 결과는 아니며 성능에 미친 영향도 아직 모릅니다.

91 epoch 부근의 손실 변화는 여러 이미지를 합치는 mosaic 증강을 끄는 시점과 겹칩니다. 시점이 같다는 관찰만으로 원인을 확정하지 않았습니다. 과거 로그의 validation 열에는 측정하지 않은 0과 열 밀림도 있어 해당 열을 성능 곡선으로 사용하면 안 됩니다.

학습 곡선이 달라진 원인은 실행 코드·설정·로그와 저장된 모델을 대조해 확인해야 합니다.

### 높은 점수에 이미지 내용 외의 단서가 섞일 수 있습니다

정상 사진과 결함 사진의 원래 규격이 달랐고 사진 번호와 결함 종류도 얽혀 있었습니다. 사진 번호만 사용한 대조선이 이미지 수준 분류 점수에서 검출기보다 높았습니다. 위치 검출 점수와는 다른 지표입니다.

검출기가 번호를 읽었다는 증거는 아닙니다. 다만 높은 분류 점수만으로 용접 결함의 영상 특징을 제대로 배웠다고 판단하기 어렵습니다. 출처별 평가와 같은 표본의 대조선 비교를 유지해야 합니다.

### 이미지에서 모르는 조건을 합성문이 대신 측정해 주지는 않습니다

현재 이미지에는 두께와 화소당 실제 길이가 없습니다. 결함 위치를 찾아도 mm 단위 치수에 따른 합부 판정까지 검증할 수는 없습니다. 실제 재질도 확인이 필요합니다.

합성 텍스트에는 두께와 길이를 조건으로 넣을 수 있습니다. 이 경우 확인하는 능력은 주어진 조건에 규칙을 적용하는 능력입니다. 실제 이미지에서 그 조건을 알아내는 능력과는 구분합니다. 합성 규칙표의 원문 수치 검수와 독립적인 사람 정답 검증도 아직 끝나지 않았습니다.

## 6. 본실험은 이 순서로 제안합니다 — 2분

검출기 비교의 조건을 먼저 확인하고 규정 과업과 통합형 비교를 추가하는 순서입니다. 원하는 점수가 나왔는지를 보고 다음 단계 진행 여부를 정하지 않습니다. 평가 프로토콜은 수정 조건 학습을 시작하기 전에 고정합니다.

| 순서 | 할 일 | 다음 단계 전에 확인할 것 |
|---|---|---|
| 1. 기존 모델 진단 | 88·90·92·94 epoch의 공동 모델을 같은 검증 입력과 추론 설정으로 채점합니다 | 손실 변화와 검출 성능 변화가 함께 나타나는지. 현재 네 시점 대조는 미실행 |
| 2. 학습 정책 검증 | 데이터 순서·증강·학습률·저장·재개를 점검하고 변경 내용을 기록합니다 | 각 변경의 효과를 따로 확인할지, 수정된 시스템 전체만 비교할지 결정 |
| 3. 수정 조건 비교 | 로컬·중앙집중·연합에 같은 정책을 적용합니다. 한 시드에서 실행을 점검한 뒤 같은 설정의 세 시드로 확대하는 안입니다 | 실행 검증과 자원 조건 충족. 기존 결과를 덮어쓰거나 합산하지 않음 |
| 4. 평가 | 전체·출처별 결과와 대조선을 비교하고 시드 변동과 평가 표본의 불확실성을 따로 계산합니다 | 프로토콜은 실행 전에 고정. 새 독립 자료가 없으면 기존 벤치마크 비교로 주장 제한 |
| 5. 규정·통합형 확대 | 아래 두 규정 과업을 정의하고 사람 정답과 비용을 확인한 뒤 통합형 비교에 착수합니다 | 원문 검수, 정답 분리, 출력·채점 계약, 속도·메모리 실측 |

현재 공동 모델은 2 epoch 간격으로 저장돼 91 epoch만 완료한 공동 모델은 없습니다. 네 시점 대조는 변화 확인용이며 그 비교만으로 원인이 확정되지는 않습니다.

규정 과업은 입력에 따라 나눕니다.

- **이미지 기반 근거 제시:** 예측한 결함과 알려진 조건으로 후보 조항·조건별 기준·부족한 정보를 제시합니다. 두께 등을 모르면 단일 합부 판정을 강제하지 않습니다.
- **조건부 텍스트 규칙 적용:** 재질·검사 방식·두께·결함 치수가 주어진 사례에서 기준과 결론을 맞히는지 봅니다. 단순 규칙 조회를 대조선으로 두고 원문과 사람이 확인한 정답으로 평가합니다.

현재 검색기는 두께가 없는 질의를 거부하므로 첫 과업은 이름만 바꿔 바로 실행할 수 없습니다. 미상 조건을 그대로 두는 검색·출력·채점 경로가 필요합니다.

통합형과 분리형은 같은 평가 입력과 정답으로 비교하되 모델·시각 인코더·검색 사용의 차이를 기록합니다. 완성된 시스템끼리의 비교이며 구조 하나만의 효과로 단정하지 않습니다. 자원이 부족하면 검출기 통제 비교를 우선하고 통합형 비교 질문은 미답으로 남깁니다.

## 7. 설명을 마친 뒤 결정할 사항 — 토의

| 오늘 정할 것 | 남길 기록 |
|---|---|
| 검출기 비교를 주 결과로 삼고 규정 과업·통합형을 조건부로 추가할지 | 포함·제외할 연구 질문 |
| 기존 모델 진단과 수정 조건 비교를 어떤 순서로 할지 | 설정, 진행 조건, 필요한 시간과 자원 |
| 새 독립 평가 자료를 확보할 수 있는지 | 확보 담당 또는 기존 자료만 사용할 때의 주장 범위 |
| 규정 원문 검수와 사람 평가를 누가 어떻게 할지 | 검수 범위, 평가 양식, 선택용·최종 평가용 자료 분리 |
| 다음 회의까지 누가 무엇을 가져올지 | 담당·기한·확인할 산출물 |

마무리 설명은 이렇게 하시면 됩니다.
