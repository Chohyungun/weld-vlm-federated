# 사전실험 검토와 본실험 설계

2026년 9월 13일 회의 자료 · 회의 전 제안안

9월 15일 검토에서 데이터 묶음의 생성 방식과 검증 상태를 정정했습니다. 실제 회의 결정은
전달받지 않았으므로 아래 안건과 담당 배분은 제안으로 남깁니다.

이 연구는 용접부 X선 사진으로 결함을 찾고 규정상 확인할 기준을 제시하는 모델을 다룹니다.
여러 회사가 검사 사진을 한곳에 모으기 어려운 상황을 가정하고 각자 학습하는 방식과 데이터를
모아 학습하는 방식, 데이터를 두고 모델 값만 교환하는 연합학습을 비교합니다. 지금까지 사용한
자료는 공개 데이터셋입니다. 실제 세 회사가 참여한 현장 실험은 아직 하지 않았습니다.

사전실험에서는 데이터를 나누고 학습·채점 경로를 실행해 분리형 검출기 15개를 얻었습니다.
공통 평가셋의 위치 검출 성능은 중앙집중, 연합, 로컬 평균 순이었습니다. 동시에 데이터의 출처와
학습 순서가 비교에 영향을 줄 수 있다는 문제가 드러났습니다. 오늘은 이 결과를 공유하고
후속 실험에서 무엇을 검증할지와 어디까지 수행할지를 정합니다.

이 문서의 실험 수치는 9월 11일까지 생성된 결과를 9월 13일과 15일에 다시 확인한 값입니다. 아래 설계와
담당 배분은 제안이며 회의에서 확정해야 합니다. 저장소가 9월 실행을 `main` 또는 본실험으로
부르는 경우가 있습니다. 여기서는 8월의 소규모 실행과 9월의 기존 정책 3시드 실행을 함께 검토하고
학습 조건과 평가 절차를 보완해 수행할 실험을 ‘후속 본실험’으로 구분합니다.

## 1. 오늘 회의에서 정할 것

권고안은 검출기 비교의 타당성을 먼저 확인하고 규정 근거 제시와 통합형 비교를 조건부로
추가하는 것입니다. 다음 여섯 항목을 결정하면 실행 순서와 필요한 자원을 정할 수 있습니다.

| 안건 | 결정할 내용 | 이 문서의 제안 |
|---|---|---|
| 연구 범위 | 이번 연구가 답할 질문과 제외할 주장 | 공개 데이터의 통제 비교를 주 과제로 두고 현장 합부 판정은 제외 |
| 학습 조건 | 순서·증강·재개 문제를 어떻게 확인할지 | 기존 모델 진단 후 한 시드의 수정 조건 비교, 검증 뒤 반복 확대 |
| 평가 자료 | 기존 평가셋을 재사용할지, 새 자료를 확보할지 | 기존 결과는 탐색 결과로 보존하고 새 자료 확보 가능성을 별도 판단 |
| 규정 과업 | 이미지와 텍스트에서 각각 무엇을 평가할지 | 이미지의 후보 조항 제시와 조건이 주어진 텍스트의 규칙 적용을 분리 |
| 통합형 범위 | 두 조건을 언제 추가하고 자원이 부족하면 어디서 멈출지 | 사람 정답과 실행 비용을 확인한 뒤 착수 여부 결정 |
| 담당·기한 | 다음 회의까지 누가 어떤 증거를 가져올지 | 7절의 작업별 완료 조건과 담당을 확정 |

## 2. 무엇을 비교하는 연구인가

### 학습 방식과 모델 구성은 서로 다른 비교입니다

로컬 모델은 자기 집단의 자료만 학습합니다. 중앙집중 모델은 모든 집단의 학습 자료를 모아
학습하고 연합 모델은 집단별 학습을 반복한 뒤 모델 값을 합칩니다. 중앙집중은 전체 자료를
사용하는 비교 기준이며 반드시 가장 높은 성능을 내는 이론적 상한은 아닙니다.

모델 구성은 두 가지입니다. 분리형은 검출기가 결함 위치와 종류를 찾고 별도의 검색·판정부가
규정 본문을 찾아 근거를 제시합니다. 검색한 규정 본문을 모델에 제공하는 방식을 RAG라고 부릅니다.
통합형은 시각언어 모델(VLM)이 이미지에서 결함과 근거를 함께 출력하도록 학습합니다.

| 모델 구성 | 로컬 학습 | 중앙집중 학습 | 연합학습 |
|---|---|---|---|
| 분리형 | 집단별 검출기 3개 | 공동 검출기 1개 | 공동 검출기 1개 |
| 통합형 | 현재 연구 범위에서 제외 | 후속 비교 대상 | 후속 비교 대상 |

분리형에는 학습 조건이 세 개지만 모델은 시드마다 다섯 개입니다. 같은 설정을 서로 다른 난수
시작값인 시드로 세 번 실행해 검출기 15개를 만들었습니다. 통합형 두 조건과 규정 판정까지
완료했다는 뜻은 아닙니다. 모델 값을 교환하는 방식만으로 정보 유출 방지까지 입증하지도 않았습니다.

## 3. 사전실험에서 수행한 일

### 데이터 정리와 분할

AI허브 용접 방사선 데이터 62,308장을 정리했습니다. 평가 자료를 먼저 떼어 놓고 나머지를
C1·C2·C3 세 학습 집단으로 나눴습니다. 중복 자료가 학습과 평가 양쪽에 들어갈 위험을 줄이려고
파일 내용 해시 일치, 라벨 숫자 ID의 연속 구간, 지각 해시 일치를 결합해 묶었습니다.
숫자 ID는 같은 검사 방식·명목 재질 안에서 1씩 이어지는 구간을 한 묶음으로 봤습니다.
실제 용접부나 연속 촬영 세션을 확인한 식별자는 아닙니다.

ID 기반 묶음 안팎의 지각 해시 거리 분포가 잘 구분되지 않아 지각 해시는 완전히 같은 경우
(거리 0, `t*=0`)에만 사용했습니다. 이 묶음 단위로 분할했습니다. 파일 목록과 분할을
매니페스트에 기록하고 8월 31일 해시로 고정했습니다. 실제 같은 용접부를 빠짐없이 식별하거나 학습·평가
사이의 누출을 모두 막았다는 뜻은 아닙니다.

| 구분 | 이미지 수 | 용도 |
|---|---:|---|
| 공통 평가셋 | 12,461 | 결함 7,086장, 정상 5,375장. 학습에 사용하지 않음 |
| 학습·검증 풀 | 49,847 | 학습 44,846장, 검증 5,001장 |
| C1 | 26,451 | 명목 ST 자료의 일부. C2와 결함 분포가 다르게 분할 |
| C2 | 16,253 | 명목 ST 자료의 나머지 |
| C3 | 7,143 | 명목 AL 자료 |

C1·C2·C3은 실제 회사명이 아니라 데이터로 구성한 참여자 역할입니다. ST·AL도 제공된 라벨에
따른 출처 구분입니다. AL 파노라마의 판독 가능한 표본에서 강 계열 스펙이 확인됐고 결함 크롭의
실제 재질은 확인하지 못했습니다. C3를 알루미늄 회사로 부르거나 결과를 재질의 물리적 차이로
해석하면 안 됩니다. 세 집단의 장수는 학습·검증 풀의 합계입니다.

### 작은 실행부터 3시드 학습까지

8월에는 분리형과 통합형의 작은 실행으로 데이터 입력부터 출력까지 연결되는지 확인했습니다.
초기 통합형 결과는 좌표 변환, 학습률, 연합 어댑터 집계 등을 수정하기 전이어서 성능 근거로
사용하지 않습니다.

9월에는 YOLO11s 검출기로 분리형 세 학습 방식을 실행했습니다. 입력 크기는 640, 배치는 32로
고정했습니다. 연합은 총 50라운드를 진행하며 라운드마다 각 집단이 2 epoch씩 학습하고 로컬과 중앙집중은 100 epoch를
학습했습니다. 한 epoch는 기준 학습 표본을 한 차례 순회하는 단위입니다. 여기서는
100 epoch의 순회 예산을 맞췄습니다. 여러 이미지를 합치는 mosaic 증강의 추가 표본, 최적화 갱신 수,
계산 시간까지 같다는 뜻은 아닙니다.

조기 종료나 검증 점수가 가장 높은 모델 선택은 하지 않고 마지막 모델을 채점했습니다.
세 시드 모두 검출기 다섯 개의 학습과 예측을 마쳤습니다. 중간에 실패한 실행은 처음부터 다시
수행했으며 최종 세 시드에 중단 지점부터 이어 학습한 기록은 없습니다.

규정 쪽에서는 공개 문서에서 조항을 정리하고 규정표에서 조건을 뽑아 합성 문장과 이미지-문장
페어를 만드는 경로를 마련했습니다. 현재는 파일럿 범위입니다. 원문 수치 검수와 사람 정답 검증은
끝나지 않았으므로 규정 판정 정확도의 실험 결과로 제시하지 않습니다.

코드 검토에서는 학습 로그 형식, 저장 훅, 검색 본문 전달과 코퍼스 채택 조건 등을 수정했습니다.
9월 11일 최종 CPU 회귀는 1,515개 통과, 22개 건너뜀, 1개 실패였습니다. 당시 실패한 시험은
파일럿 동결 자산 부재와 관련됐습니다. 9월 15일 재검증은 1,553개 통과, 21개 건너뜀, 실패 0개였습니다.
자원을 많이 쓰는 시험 5개는 제외했습니다. 건너뛴 시험과 실물 대조 경고 2건까지 검증을 마친 것은 아닙니다.

누락됐던 이미지-문장 페어의 파일럿 v1은 복구본 파일 3개의 해시가 계약과 일치했습니다.
v2와 3,000장 이미지 파일럿 스냅샷은 현재 경로에 없습니다. v1 복구와 전체 자산 복구를 구분해야 합니다.
GPU 재개 동치와 사람 평가도 별도로 남아 있습니다. CPU 시험 통과가 이 검증을 대신하지 않습니다.

## 4. 어떤 결과가 나왔는가

### 4.1 공통 평가셋에서는 연합이 로컬 평균보다 높았습니다

위치 검출은 mAP@50으로 비교했습니다. 예측 상자가 정답 상자와 충분히 겹치는지(IoU 0.5 이상)와
결함 종류가 맞는지를 보고 여러 신뢰도 기준의 정밀도·재현율을 종합하는 지표입니다. 값이 클수록
좋지만 0.49를 ‘사진의 49%를 맞혔다’고 읽지는 않습니다. 아래 값은 출력 신뢰도 하한 0.01과
공통 평가셋 12,461장을 기준으로 합니다. 출력 하한·중복 상자 제거 등 추론 설정에는 여전히 의존합니다.

| 모델 | 시드 1 | 시드 2 | 시드 3 | 평균 |
|---|---:|---:|---:|---:|
| 중앙집중 | 0.4926 | 0.4916 | 0.4997 | 0.4946 |
| 연합 | 0.2820 | 0.2639 | 0.2668 | 0.2709 |
| 로컬 C1 | 0.3584 | 0.3577 | 0.3623 | 0.3595 |
| 로컬 C2 | 0.1358 | 0.1321 | 0.1338 | 0.1339 |
| 로컬 C3 | 0.0932 | 0.1025 | 0.0995 | 0.0984 |
| 로컬 세 모델 평균 | 0.1958 | 0.1974 | 0.1985 | 0.1973 |
| 회복률 | 29.0% | 22.6% | 22.7% | 24.8% |

로컬 평균은 같은 공통 평가셋에서 채점한 세 로컬 모델 점수의 산술평균이며 각 회사의 자체
평가셋 점수 평균과 구분합니다. 연합은 로컬 평균보다 높지만 로컬 C1보다 낮습니다.

회복률은 `(연합 − 로컬 평균) ÷ (중앙집중 − 로컬 평균) × 100`으로 계산합니다. 24.8%는
중앙집중과 로컬 평균 사이 격차의 약 4분의 1을 메웠다는 뜻이며 정확도가 24.8% 올랐다는
뜻은 아닙니다. 표의 평균은 시드별 회복률을 평균한 값입니다. 원본 수치를 재계산해 일치를 확인했습니다.
회복률의 부트스트랩 신뢰구간은 아직 없습니다. 이 신뢰구간은 평가 표본을 재추출해 불확실성을 계산하여 구합니다.
학습 조건의 차이도 남아 있습니다. 대표 성과 지표로
채택할지는 이 검증 뒤에 결정합니다.

### 4.2 공통 성능 개선이 모든 참여자의 이익은 아니었습니다

같은 두 모델도 평가 대상을 바꾸면 순서가 바뀝니다. 아래는 세 시드의 mAP@50 평균입니다.

| 평가 대상 | C3 로컬 | 연합 | 해석 |
|---|---:|---:|---|
| 공통 평가셋 12,461장 | 0.0984 | 0.2709 | 전체 혼합 자료에서는 연합이 높음 |
| 명목 AL 부분집합 1,786장 | 0.4802 | 0.2267 | C3에 대응하는 출처에서는 로컬이 높음 |

따라서 본실험에서는 전체 성능과 참여자별 목표 모집단 성능을 따로 보고해야 합니다. 현재 명목
AL 결과도 실제 회사 현장 성능을 직접 측정한 값은 아닙니다. 데이터를 더 가진 참여자와 특정
출처에 집중된 참여자가 서로 다른 결과를 얻는지 확인할 필요가 있습니다.

### 4.3 결함 종류 점수에는 데이터의 지름길이 있었습니다

전처리 전 원자료에서 결함 사진은 1280×720 크롭인 반면 정상 사진은 대부분 파노라마였습니다.
이때 RT/ST 부분집합에서는 이미지 크기만으로 결함 여부를 96.1% 맞힐 수 있었습니다. 현재 동결본은
정상 파노라마를 타일로 잘라 크기를 맞췄지만 크롭·타일 출처의 차이는 남습니다. 사진 번호와 결함
종류도 얽혀 있습니다.

그래서 이미지를 읽지 않고 사진 번호만 쓰는 대조선을 만들었습니다. 학습·검증 풀 49,847장에서
사진 번호를 512구간으로 나누고 구간별 결함 클래스 빈도를 점수로 사용했습니다. 시드 1의
공통 평가셋에서 이미지 수준 macro-AP는 중앙집중 모델 0.8229, 이 대조선 0.9582였습니다.
macro-AP는 결함 종류별 평균 정밀도를 평균한 분류 지표이며 앞의 위치 mAP와 다른 값입니다.
검출기 다섯 모델이 모두 대조선보다 낮았습니다.

이 비교는 모델이 실제로 사진 번호를 사용했다는 증거가 아닙니다. 높은 분류 점수만으로 영상
내용을 학습했다고 판단할 수 없다는 반례입니다. 사진 번호가 실제 촬영 시간 순서와 같다는
확인도 없습니다. 위치 검출에서는 시험한 메타데이터 대조선보다 모델이 높았지만 그것만으로
출처 편향이 해소됐다고 볼 수는 없습니다.

### 4.4 학습 곡선과 최종 성능을 구분해야 합니다

연합학습에서는 매 라운드 새 데이터 로더를 만들면서 학습 순서의 난수가 반복되는 경로가
확인됐습니다. 해당 구성을 모사한 CPU 시험에서 100 epoch 동안 서로 다른 순서는 연합 2개,
중앙집중 100개였습니다. 실제 YOLO의 모든 증강 경로를 계측한 결과는 아니며 이 차이가
성능을 올렸는지 내렸는지와 영향의 크기는 아직 모릅니다.

또한 91 epoch 부근에서 연합의 학습 손실이 급격히 달라졌습니다. 여러 이미지를 합치는 mosaic
증강을 끄는 시점과 겹치지만 원인으로 확정하지 않았습니다. 연합 클라이언트의 학습 손실은
집계된 공동 모델의 평가 성능과도 다릅니다. 과거 CSV의 validation 열에는 실제 측정값이 아닌
0과 마지막 행의 열 밀림이 있어 그 열을 성능 곡선으로 사용하면 안 됩니다.

채점할 때 선택하는 신뢰도 기준도 영향을 줬습니다. 시드 1에서 기준을 0.25로 두면 연합 모델의
예측 상자 94.2%가 제외됐습니다. 다른 네 모델도 87.6~92.2%가 제외됐으므로 연합만 상자를
대량으로 버린 것은 아닙니다. 원래 상자 중 남는 비율은 연합 5.84%, 로컬 C3 12.41%였습니다.
이 비율은 실제 결함의 누락률과 다릅니다. 한 기준의 점수만 비교하지 않고 등록된 14개 기준의
곡선과 mAP를 함께 확인해야 합니다.

## 5. 사전실험을 후속 본실험에 어떻게 활용할 것인가

기존 결과는 버리지 않습니다. 데이터 분할, 학습·채점 경로, 소요 시간과 실패 기록을 바탕으로
다음 실험을 준비합니다. 단, 기존 결과와 수정 조건의 결과는 다른 실험으로 보관합니다.

### 5.1 검출기 비교부터 학습 조건을 확인합니다

먼저 새 학습 없이 로그와 저장된 모델을 검사하는 방안을 권합니다. 연합의 88·90·92·94 epoch
완료 모델을 검증셋 5,001장 또는 그 안에서 사전에 정한 고정 표본에 같은 추론 설정으로 적용하면
학습 손실만 변했는지, 고정 입력의 검출 성능도 변했는지
살필 수 있습니다. 현재 라운드당 2 epoch이므로 91 epoch만 완료한 공동 모델은 없습니다.
이 비교만으로 원인이 확정되지는 않으며 이 네 시점의 모델을 같은 입력으로 대조한 결과는 아직 없습니다.

이후 필요하면 loader 난수와 mosaic 전환을 분리해 진단합니다. epoch를 줄인 작은 실험은 동작
점검용으로 쓰고 원래 학습률·전환 위치를 검증한 실험으로 설명하지 않습니다. 두 변경을 함께
적용한 결과만 있으면 각각의 효과를 분리할 수 없으므로 변경별 원인을 주장할지 수정된 시스템
전체를 비교할지도 먼저 정합니다.

수정 조건의 주 비교는 로컬·중앙집중·연합 모두 같은 정책으로 수행합니다. 한 시드에서 실행과
회계가 맞는지 확인한 뒤, 같은 설정의 세 시드 반복으로 확대하는 안을 제안합니다. 확대 여부는
유리한 점수가 나왔는지가 아니라 미리 정한 실행 검증과 자원 조건으로 판단합니다.

| 실행 전에 고정할 항목 | 기록·검증 방법 |
|---|---|
| 데이터·초기 모델·시드 | 분할 해시, 초기 가중치 식별자, 시드 목록을 실행 기록에 저장 |
| 학습 예산 | 기존 100 epoch 순회 예산을 출발점으로 삼고 배치 수·갱신 호출 수·실제 성공 갱신 수·시간은 별도 기록 |
| 학습률·워밍업·증강 | 전체 학습 진행 위치를 기준으로 정책을 명시하고 라운드마다 뜻하지 않게 초기화되지 않는지 검사 |
| 모델 선택 | 조기 종료·best 선택 없이 마지막 모델 사용 |
| 저장과 재개 | 로그 보존, 최종 가중치 저장 성공 후 복구 파일 정리, 중단 없는 실행과의 비교 시험 |
| 실험 식별 | 기존 결과를 덮어쓰지 않는 새 경로와 정책 기록, 코드·의존성·입력 해시 보존 |

현재 코드의 갱신 카운터는 혼합정밀도 연산(AMP)이 실제 갱신을 생략해도 증가할 수 있습니다. 이를 성공한 갱신
횟수라고 부르지 않도록 계측을 정리해야 합니다. 재개 시험이 미완료라면 자동 재개를 검증된 기능으로
사용하지 않는 제한적 운영안도 자원 계획과 함께 결정합니다. 처음부터 재실행할 때는 실패 산출물을
보존하고 별도 실행·재개 경로에서 같은 초기 가중치로 시작해야 합니다. 기존 경로에서 같은 명령을
다시 실행하는 것만으로 처음부터 시작된다고 가정하지 않습니다.

### 5.2 기존 평가셋과 독립 검증 자료를 구분합니다

현재 평가셋은 학습에는 들어가지 않았지만 결과를 보고 지표와 보고 방식을 여러 차례 검토하는 데
사용했습니다. 새 코드나 새 시드로 다시 실행해도 처음 보는 독립 평가가 되지는 않습니다.
미관측 출처·시기의 자료를 확보할 수 있으면 프로토콜을 먼저 고정하고 마지막 평가에 사용합니다.
확보가 어렵다면 기존 벤치마크의 통제 비교와 민감도 분석으로 주장 범위를 제한합니다. 평가 결과를
반복해 모델·방법 선택에 사용하면 평가 자체에도 선택 편향이 생길 수 있습니다.
([Cawley·Talbot, 2010](https://www.jmlr.org/papers/v11/cawley10a.html))

주 보고는 공통 평가셋의 mAP@50, 모델 간 절대 차이, 출처별 결과로 구성하는 안을 제안합니다.
회복률은 분모 안정성과 신뢰구간을 확인한 뒤 함께 싣습니다. 결함 누락·정상 오탐·분류 점수는
보조 지표로 두고 운용 기준이 필요하면 검증셋에서 정한 뒤 평가셋에 고정 적용합니다.

출처 분석은 명목 ST/AL과 크롭/타일을 구분합니다. 출처 구성비가 달라진 상황도 실행 전에
시나리오로 정합니다. 출처별 AP를 이미지 장수로 가중평균해 전체 AP라고 하지 않고 정한
재표집 모집단에서 AP를 다시 계산해야 합니다. 대조선과 모델은 항상 같은 평가 표본을 사용합니다.

시드별 값·평균·표준편차와 평가 표본의 불확실성은 따로 보고합니다. 평가 신뢰구간은 동결 매니페스트의
묶음을 모델 간 짝지어 재표집하는 방식으로 설계하고 결함 클래스가 없는 재표집이나 회복률 분모가
불안정한 경우의 처리도 미리 정합니다. 이 신뢰구간이 적은 학습 시드나 현장 대표성을 보완하지는
않습니다. 시드 3개를 안정적인 분산 추정으로 과장하지 않고 다른 모델의 분산을 임의로 합치지도
않습니다. 이 묶음 사이의 실제 용접부 독립성이 보장된다는 뜻도 아닙니다. 데이터 표집·초기화·
증강 등의 변동을 구분해야 한다는 비교 연구의 권고를 반영한 제안입니다.
([Bouthillier 외, 2021](https://proceedings.mlsys.org/paper_files/paper/2021/file/0184b0cd3cfb185989f858a1d9f5c1eb-Paper.pdf))

### 5.3 규정 과업은 입력으로 알 수 있는 범위에서 정합니다

현재 이미지에는 두께와 화소당 실제 길이가 없습니다. 이미지의 상자 크기를 곧바로 mm 단위 결함
치수로 바꾸거나, 모르는 두께를 추정값으로 채워 합부를 확정하면 안 됩니다. 명목 ST/AL을 실제
규정 적용용 재질로 바로 사용하지 않고 재질 미상도 부족한 정보로 남깁니다. 합성 텍스트에는
두께·길이를 넣을 수 있지만 그것은 측정값이 아니라 설정한 조건입니다.

| 실험 | 입력과 출력 | 확인할 수 있는 것 | 별도 한계 |
|---|---|---|---|
| 이미지 검출 | 이미지 → 결함 종류·위치 | 주어진 이미지 분포에서의 검출 성능 | 실측 치수·현장 합부 판정은 확인 불가 |
| 이미지 기반 근거 제시 | 예측 결함과 알려진 조건 → 후보 조항·조건별 기준·부족한 정보 | 검색 누락, 관련 없는 조항, 근거 없는 단정 | 두께 등 필수 조건이 없으면 단일 판정을 강제하지 않음 |
| 조건부 텍스트 규칙 적용 | 명시된 재질·검사 방식·두께·결함 치수 → 적용 기준과 결론 | 원문 규칙의 적용·경계 조건·단위 처리 | 실제 이미지에서 조건을 알아내는 능력을 검증한 것은 아님 |

현재 검색기는 두께가 없는 질의를 거부하므로 과업 이름만 바꾸면 실행되지 않습니다. 미상 조건을
보존하면서 후보 조항을 돌려주는 검색·출력·채점 경로를 먼저 정의해야 합니다. 여러 후보가 타당하면
정답도 허용 후보 집합으로 만듭니다. 정답 결함코드를 주는 검색부 진단과, 예측 결함부터 시작해
누락까지 포함하는 전체 시스템 평가는 분리합니다. 모든 조항을 출력하는 답이 유리해지지 않도록
후보 조항의 정밀도·재현율과 근거 없는 단정 비율을 함께 보고합니다.

현재 파일럿 표에는 알루미늄과 다른 품질규격의 공백이 있고 누적·혼재·군집 조건 일부도 구현되지
않았습니다. 검수된 범위와 범위 밖 사례를 나누어 평가합니다.

규정표는 원문과 독립적으로 대조해야 합니다. 생성기와 채점기가 같은 표를 쓰면 내부 계산은
맞아도 표의 단위·부등호·각주가 함께 틀릴 수 있습니다. 조항과 조건 수가 적은 과업에서는 단순
규칙 조회를 대조선으로 두고 높은 점수를 곧바로 언어 모델의 추론 능력으로 해석하지 않습니다.

사람 평가자는 평가할 생성문과 원문을 보되 생성 모델명·후보 검증기의 통과/기각 결과·표집층은
보지 않고 먼저 독립 평정하는 안을 제안합니다. 불일치는 별도 조정하고 평가자별 원답도 남깁니다.
검증기는 합성문 품질을 검사하는 모델입니다. 현재 계획의 100건을 검증기 선택에 쓰면 그 문장과
가까운 변형을 최종 평가에 다시 쓰지 않습니다. 학습·개발·평가의
예시를 원천 구절·생성 골격·유사 문장 묶음으로 나누되, 고정 규정 문서를 RAG에서 공유하는 것과
평가 정답 누출은 구분합니다. 층화 표집의 비율은 내부에 보존하고 모집단 지표에는 적절한 가중치를
적용합니다. 100건이면 최종 정확도를 충분히 입증한다는 뜻은 아니며 최종 평가 수는 범위와
필요한 정밀도를 정한 뒤 산정합니다.

### 5.4 통합형은 조건을 갖춘 뒤 추가합니다

통합형 중앙집중·연합은 사람 정답, 규정 과업, 좌표 계약과 저장·집계 검증을 갖춘 뒤 실행하는
안입니다. 분리형과는 평가 입력·정답·출력 형식·채점 기준을 맞추되, 모델·시각 인코더·검색 사용이
다르다는 사실을 함께 기록합니다. 두 완성 시스템의 비교이며 구조 하나의 인과효과로 해석하지 않습니다.

비용도 다시 측정해야 합니다. 기존 12.6~21.0 GPU-일 추정은 한 시드의 12,461장에 분리형
판정부 5패스와 통합형 2패스를 적용하는 추론 시간이며 학습 시간은 제외돼 있습니다. 0.8B 실측에
아직 측정하지 않은 4B 배율을 적용한 값입니다. 분리형 생성 추론을 생략하는 기존 `clause_only`
계획의 통합형 2패스 추정은 6.7~11.2 GPU-일이지만 오늘 정하는 과업과 구현에도 그대로 적용된다는
보장은 없습니다. 짧은 속도·메모리 실측으로 학습·추론·재실행 여유 시간을 따로 산정해야 합니다.

자원이 부족하면 검출기 통제 비교를 우선 완료합니다. 통합형 중앙집중만 완료하면 그 범위만
비교하고 통합형을 하나도 완료하지 못하면 시스템 구성 비교 질문은 답하지 못한 것으로 남깁니다.
통합형 한 시드 결과를 세 시드 검출기 비교와 같은 강도의 반복 근거로 설명하지 않습니다.

## 6. 성공 여부를 무엇으로 판단할 것인가

사전실험은 실행 가능한 연구 경로와 확인해야 할 문제를 찾았다는 점에서 의미가 있습니다.
후속 연구도 계속할 근거가 있습니다. 다만 연합이 중앙집중을 이기거나 기존 회복률 24.8%를
넘는 것만을 성공으로 정하지 않습니다.

연구 결과로 보고할 최소 조건은 비교 정책과 평가 절차를 실행 전에 고정하고 같은 모집단에서
대조선과 모델을 비교하며 반복 변동·참여자별 손익·계산 및 통신 비용을 함께 설명하는 것입니다.
규정 과업을 포함한다면 원문 검수와 독립 사람 정답이 추가로 필요합니다. 원하는 성능이 나오지
않아도 검증된 비교 결과는 보고할 수 있지만 논문화가 보장되지는 않습니다. 선행 연구와의 차별성도
별도로 점검해야 합니다.

실용적 성능의 허용선은 오늘 논의할 항목입니다. 결함 누락률, 정상 오탐률, 조항 누락과 근거 없는
단정, 처리 시간 중 무엇을 얼마나 줄여야 의미 있는지 먼저 정해야 합니다. 근거가 없는 목표 숫자를
결과에 맞춰 정하지 않습니다. 현재 자료만으로 산업 현장 적용 가능성을 확정하지는 않습니다.

## 7. 회의 진행과 다음 작업

60분 회의를 가정한 진행안입니다. 참석자와 실제 시간에 맞춰 조정할 수 있습니다.

|---|---|---|

| 15분 | 결과와 해석의 한계 | 기존 결과의 사용 범위, 주·보조 지표 |
| 15분 | 검출기 진단과 후속 평가 설계 | 학습 정책, 독립 평가 자료 확보 여부, 진행 조건 |
| 15분 | 규정 과업·통합형·자원 | 사람 검수 범위, 과업 출력, GPU 예산과 축소 순서 |
| 5분 | 담당·기한 확정 | 아래 작업표와 다음 검토일 |

| 다음 작업 | 담당안 | 완료를 확인할 산출물 | 담당·기한 확정 |
|---|---|---|---|

| 규정표와 사람 평가 준비 | 규정·판정 담당 | 원문 대조표, 과업별 정답 양식, 선택용·최종 평가용 분리 | 회의에서 기록 |
| 통합형 비용과 범위 확정 | 통합형 담당·총괄 | 실제 모델 속도·메모리·총 소요 시간, 진행·축소 조건 | 회의에서 기록 |
| 연구 질문과 공개본 정리 | 총괄·팀 공동 검토 | 확정 결정문, 남은 이견, 공개본과 내부 증거의 연결 | 회의에서 기록 |

회의 뒤에는 제안을 확정 사항으로 덮어쓰지 않고 결정일·근거·변경 내용을 덧붙입니다. 확정 전에는
새 학습 실행이나 자원 확보가 승인된 것으로 취급하지 않습니다.
