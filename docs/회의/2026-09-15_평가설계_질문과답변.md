# 평가설계에 관한 회의 질문과 사후 검토 답변

2026년 9월 15일 회의에서 나온 질문을 기존 실험 기록과 대조한 보충 문서다. 회의 합의나 참석자의 발언 정정본이 아니며, 후속 실험의 제안은 별도 확정이 필요하다. 수치는 9월 11일까지 생성된 결과를 9월 15일 재확인한 값이다.

9월 16일 보충: 아래 수치는 기존 채점(v1) 기록이다. 시드별 채점기 코드 버전 차이를 확인해 동일
버전의 v2 재채점과 회복률 신뢰구간 검증을 진행하고 있다. 산술 재계산의 일치와 채점 조건의
타당성을 구분하며, v2 검수 전에는 v1을 최종 비교값으로 확정하지 않는다. 아래 답변은 평가 대상과
집계 정의를 설명하며 진행 중인 검증의 완료 보고가 아니다.

## 1. 로컬 평균은 어느 자료에서 평가한 값인가

각 로컬 모델은 C1·C2·C3 중 자기 집단의 학습 자료만 사용했다. 평가는 세 모델 모두 같은 공통 평가셋 12,461장에서 수행했다. 각 시드의 로컬 평균은 이 세 모델의 mAP@50을 산술평균한 값이다. 모델 가중치나 예측을 합친 모델의 성능도, 회사별 자체 평가셋 점수의 평균도 아니다.

따라서 이 비교는 각자 학습한 모델을 전체 혼합 자료에 적용할 때와 공동 모델을 적용할 때의 차이를 보여 준다. 특정 참여자가 자기 현장에서 얻을 이익까지 직접 나타내지는 않는다. 세 집단 모두 용접 방사선 영상이며, C1·C2는 명목 ST를 결함 분포가 다르게 나눈 집단, C3는 명목 AL 집단이다. 실제 세 회사나 서로 다른 세 검사 방식을 뜻하지 않는다. ST·AL을 실제 재질로 단정할 근거도 부족하다.

## 2. 연합이 로컬 평균보다 높으면 모두에게 유리한가

공통 평가셋의 세 시드 평균 mAP@50은 중앙집중 0.4946, 연합 0.2709, 로컬 평균 0.1973이다. 다만 로컬 C1은 0.3595로 연합보다 높다. C3도 평가 대상을 바꾸면 순서가 반대가 된다.

| 평가 대상 | C3 로컬 | 연합 |
|---|---:|---:|
| 공통 평가셋 12,461장 | 0.0984 | 0.2709 |
| 명목 AL 부분집합 1,786장 | 0.4802 | 0.2267 |

표는 모두 세 시드 평균이다. 전체 혼합 자료와 C3에 대응하는 출처에서 같은 결론이 나오지 않았다는 결과이며, 실제 알루미늄 현장 성능을 검증한 것은 아니다.

회복률은 `(연합−로컬 평균)/(중앙집중−로컬 평균)×100`이다. 시드별 29.0%, 22.6%, 22.7%의 평균인 24.8%는 두 기준 사이 격차를 메운 비율이다. 정확도가 24.8% 상승했다는 뜻이 아니며 회복률 신뢰구간은 아직 없다. 중앙집중도 이론적 상한으로 보장되는 값은 아니다.

## 3. 출처별 평가를 하려면 다시 학습해야 하는가

추가 학습은 필요하지 않다. 평가셋을 참여자의 학습 자료로 돌리는 대신, 평가 이미지의 출처 정보를 이용해 채점 대상을 구분한다. 저장된 예측과 정답에서 같은 이미지 목록을 선택해 다시 채점하거나, 고정된 모델로 해당 평가 표본을 추론한다. 어느 경우에도 모델 가중치는 갱신하지 않는다.

공통 평가와 출처별 평가는 함께 보고할 수 있다. 모델과 대조선은 같은 표본·정답·추론 설정으로 비교해야 한다. 출처별 AP를 이미지 수로 가중평균해 전체 AP라고 하지 않고 해당 모집단의 예측과 정답으로 다시 계산한다. 출처별 점수를 내는 절차와 새 자료에 맞춰 가중치를 학습하는 절차는 구분된다.

## 4. 지금까지 검증한 범위는 어디까지인가

완료한 반복 실험은 분리형 검출기 비교다. 시드마다 로컬 3개, 중앙집중 1개, 연합 1개를 학습·채점해 총 15개를 얻었다. 통합형 두 조건과 규정 판정 정확도까지 검증한 결과는 아니다. 코퍼스 생성·매칭 경로의 파일럿 실행과 원문 수치·사람 정답 검증도 다르며, 후자는 끝나지 않았다.

현재 이미지 자료에서는 두께와 화소당 실제 길이를 확인할 수 없어 실측 치수 기반 합부를 확정할 수 없다. 이미지에서 후보 조항과 부족한 정보를 제시하는 과업, 조건이 주어진 텍스트에 규칙을 적용하는 과업을 분리해야 한다. 학습 순서 반복과 출처 편향의 영향도 남아 있어 현재 성능 차이의 원인을 하나로 단정하지 않는다.

## 5. 자료가 들어올 때마다 실행하면서 본실험을 진행해도 되는가

자료 추가와 설정 변경을 반복하는 실행은 탐색·동작 점검으로 구분해 기록할 수 있다. 다만 서로 다른 자료·정책으로 얻은 점수를 같은 조건의 반복 결과처럼 합치면 안 된다.

최종 비교 전에는 데이터·분할 해시, 초기 모델, 시드, 학습 예산, 학습률·증강·순서 정책, 마지막 모델 선택, 추론·채점 설정과 주·보조 지표를 고정해야 한다. 100 epoch 순회 예산을 맞추는 것과 실제 갱신 횟수·증강 표본·계산 시간이 같은 것은 다르다. 수정 정책은 로컬·중앙집중·연합에 함께 적용하고 기존 결과와 별도 경로로 보존한다.

기존 평가셋은 결과를 반복 검토한 자료이므로 새 시드로 실행해도 독립 검증 자료가 되지 않는다. 새 자료 확보 여부, 평가 불확실성의 처리, 진행·중단 조건도 미리 정한다. 탐색 중 나온 좋은 점수를 기준으로 비교 조건이나 종료 시점을 바꾸지 않는 것이 후속 비교의 원칙이다.
