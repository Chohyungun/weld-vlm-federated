# 문서 안내

이 저장소는 용접 검사 영상을 한곳에 모으기 어려운 상황에서 세 학습 방식을 비교하는 연구의 코드와 문서를 담고 있다.
이미 실행한 검출기 사전실험과 준비 중인 통합형 모델 본실험을 나눠 읽으면 된다.

## 연구를 빠르게 이해하려면

1. [연구 개요](../README.md)에서 질문과 현재 진행 상태를 읽는다.
2. [사전실험 보고](사전실험_보고.md)에서 실제 수행한 일, 결과와 한계를 확인한다.
3. [실험 설계](실험설계.md)에서 다음 비교의 조건과 미확정 항목을 살핀다.
4. 실행을 검토한다면 [구현 설계](구현설계.md)와 [개발 규약](개발규약.md)을 함께 읽는다.

‘구현’은 코드가 있다는 뜻이고 ‘실행’은 그 코드로 해당 절차를 수행했다는 뜻이다. ‘검증’은 무엇을 어떤 자료로 확인했는지 범위를 붙여 쓴다.
작은 합성 입력의 검사, 기존 결과의 계산 검산, 실제 모델의 전체 실행, 사람 정답 검증은 서로 대신할 수 없다.

## 논문과 결과 작성

[논문 초안](paper/본문_초안.md)은 완성된 연구 결과가 아니다. 본실험 결과가 없는 곳은 미측정 상태로 남긴다.
[결과표 양식](paper/결과표_템플릿.md)은 값을 채울 조건을, [그림 작성 기준](paper/그림_명세.md)은 도표에 표현할 범위와 유의점을 설명한다.
참고문헌은 [논문 목록](논문_리스트.md), 검색 과정은 [검색 기록](paper/검색로그.md), 확인 수준은 [서지 검증 기록](paper/서지검증.md)을 참고한다.
