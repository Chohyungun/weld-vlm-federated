# 문서 안내

이 연구는 용접 검사 영상을 한곳에 모으기 어려운 상황을 가정하고, 비전-언어 모델의 로컬·중앙집중·연합학습을 비교한다. 공개 데이터를 세 참여자 역할로 나눈 실험이며 실제 기업 세 곳의 현장 운영을 검증한 것은 아니다.

- [연구 개요](../README.md): 무엇을 비교하는지, 사전실험에서 무엇이 나왔는지
- [실험 설계](실험설계.md): 비교 조건, 지표, 결과를 해석할 범위
- [구현 설계](구현설계.md): 데이터 처리와 학습·집계·평가 경로
- [연구 규칙](개발규약.md): 데이터 이용, 평가 격리, 공정한 비교 원칙

## 논문과 결과

[논문](paper/본문_초안.md)은 연구 방법과 결과의 해석을 다룬다. 미측정 결과는 수치로 채우지 않는다. [결과표 양식](paper/결과표_템플릿.md)과 [그림 명세](paper/그림_명세.md)는 같은 구분을 따른다.

## 공개 범위와 재현성

원본·파생 영상, 학습된 모델, 비공개 실행 자료는 이 저장소에 포함하지 않는다. AI허브 자료는 별도 이용 조건을 따르며 공개 데이터라는 이름만으로 재배포가 허용되는 것은 아니다.

일부 고정 검사 입력과 로컬 데이터 연동 자료도 포함하지 않는다. 따라서 공개 코드만으로 모든 검사를 재실행하거나 같은 결과를 얻을 수 있다고 보장하지 않는다. 공개 문서·주석의 정리로 파일 바이트가 달라진 경우 과거 실행 영수증의 구현 지문과 같다고 가정해서도 안 된다. 공개본 전체의 실행 시험 통과를 주장하지 않는다.
