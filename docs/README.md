# 문서 안내

이 저장소는 용접 검사 영상을 한곳에 모으기 어려운 상황을 가정하고, 비전-언어 모델의 개별·중앙집중·연합학습을 비교하는 연구의 코드와 문서를 담고 있다. 공개 자료를 세 참여자 역할로 나누며, 실제 세 회사가 참여한 현장 실험은 아니다.

검출기 사전실험의 측정 결과와 준비 중인 통합형 모델 본실험을 나눠 읽으면 된다. 코드 구현, 합성 입력 검사, 실제 모델 실행, 사람 검수는 확인하는 범위가 서로 다르다. 데이터 생성이나 자동 판정만으로 본실험 성능을 검증했다고 보지 않는다.

## 처음 읽는다면

1. [연구 개요](../README.md)에서 연구 질문과 진행 상태를 읽는다.
2. [사전실험 보고](사전실험_보고.md)에서 검출기 15개 비교의 결과와 한계를 확인한다.
3. [실험 설계](실험설계.md)에서 통합형 모델의 비교 조건과 미확정 항목을 살핀다.
4. 실행을 검토한다면 [구현 설계](구현설계.md)와 [개발 규약](개발규약.md)을 함께 읽는다.

[의사결정 기록](의사결정로그.md)은 설계가 바뀐 이유와 적용 시점을 남긴다. 날짜가 다른 예산·생성·판정 정책은 당시 결정으로 읽고, 현재 적용 범위는 후속 기록과 함께 확인한다.

## 논문과 결과 작성

[논문 초안](paper/본문_초안.md)은 완성된 연구 결과가 아니다. 본실험 결과가 없는 곳은 미측정 상태로 남긴다. [결과표 양식](paper/결과표_템플릿.md)은 값을 채울 조건을, [그림 작성 기준](paper/그림_명세.md)은 도표에 표현할 범위와 유의점을 설명한다.

참고문헌은 [논문 목록](논문_리스트.md), 검색 과정은 [검색 기록](paper/검색로그.md), 확인 수준은 [서지 검증 기록](paper/서지검증.md)을 참고한다. 초록과 논문·발표자료의 제출 일정은 [실험 설계](실험설계.md) 9장의 공고 확인 기록을 따른다.

## 공개 범위

공개본에는 원본 영상·모델과 비공개 작업 기록을 포함하지 않는다. `docs/dev_log/`와 `_workspace/`는 공개 대상에서 제외한다. 문서에 남은 검토 번호·경로·해시는 출처를 구분하기 위한 기록이며, 해당 자료가 모두 공개되었거나 이 저장소만으로 모든 실험을 재현할 수 있다는 뜻은 아니다.

일부 고정 검사 입력과 로컬 데이터 연동 검사는 공개 묶음에서 제외했다. 해당 탐침·연동 시험은 이 저장소만으로 재실행할 수 없다.

공개본은 개발 기록에서 비공개 파일을 빼고 주석·문서의 내부 운영 표기를 정리한 스냅샷이다. 주석만 달라도 전체 파일 해시는 바뀔 수 있으므로, 과거 실행 영수증에 기록된 구현 신원과 공개본의 바이트가 같다고 가정하지 않는다. 기존 실측값이나 고정 입력의 해시를 공개본에 맞춰 다시 쓰지는 않았다. 공개 투영본의 전체 시험 통과를 주장하지 않는다.

권리 확인 대기 중인 문헌 포인터 목록과 내부 산출 이력도 제외했다. 그 자료를 입력으로 쓰는 절차는 공개된 코드·집계 문서만으로 그대로 재실행할 수 없다.
