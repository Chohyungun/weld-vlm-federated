RQ2는 성능 변화뿐 아니라 비용·기여·크레딧·보상까지 포함한다. 이번 실험에서 비교한 공통 평가셋의 검출 성능 변화는 그 질문의 일부다. 받은 성능 편익과 제공한 기여를 구별하며 나머지 항목을 함께 고려한 참여 편익은 평가하지 못했다.

`paper/`에는 제출 포스터 PDF, 보충 Appendix PDF와 포스터 미리보기를 둔다. 이 자료에 수록된 사례 외에 원본 데이터셋·모델 어댑터·영상별 생성 응답 전체는 제공하지 않는다. 저장소 안의 사전실험·검사기 개발용 문서는 각 파일에 적힌 적용 범위를 따른다.
