# 문서 안내

이 연구는 용접 검사 영상을 한곳에 모으기 어려운 상황에서 비전-언어 모델의 학습 방식을 비교한다.
공개 데이터를 세 참여자 역할로 나누고 로컬 단독, 중앙집중, 연합학습으로 얻은 다섯 모델을 평가한다.

## 처음 읽는 순서

1. [연구 개요와 진행 상황](../README.md): 연구 질문, 완료한 작업, 아직 측정하지 않은 결과
2. [실험 설계](실험설계.md): 비교 조건, 대표 지표 M1, 표본 평가와 한계
3. [데이터 현황](데이터셋_현황.md): 자료의 범위와 이용 조건
4. [구현 설계](구현설계.md): 학습·집계·추론·채점의 연결

## 용어를 먼저 읽어도 된다

| 용어 | 이 연구에서의 뜻 |
|---|---|
| 참여자 | 공개 데이터를 나눈 세 역할. 실제 회사 세 곳을 뜻하지 않음 |
| 로컬 학습 | 한 참여자의 자료만 쓰는 학습 |
| 중앙집중 학습 | 세 참여자의 자료를 모아 하는 학습 |
| 연합학습 | 각 참여자가 학습한 가중치를 합치는 방식 |
| 생성 | 영상 설명문을 만드는 단계 |
| 모델 판정 | 생성과 다른 모델이 설명문을 검사하는 단계 |
| SFT | 정해진 입력과 답안 쌍으로 모델을 미세조정하는 학습 |
| 학습 데이터 사용 승인 | 품질·권리·사람 검수 조건을 확인하고 학습에 사용할 목록을 확정하는 단계 |

생성 완료, 모델 판정 완료, 학습 데이터 사용 승인, 모델 학습 완료는 서로 다른 상태다.
설명문 생성량을 본실험 성능이나 학습 완료량으로 해석하지 않는다.

## 자료 공유와 재현 범위

원본·파생 영상, 학습된 모델, 비공개 실행 자료는 공개 저장소에 포함하지 않는다.
AI허브 자료에는 별도 이용 조건이 적용된다. 문서나 코드가 공개됐다고 이미지와 생성물을
그대로 재배포할 수 있는 것은 아니다.

일부 검사 입력과 로컬 데이터 연동 자료도 공개하지 않는다. 공개본만으로 모든 검사를 재실행하거나
동일 결과를 얻을 수 있다고 보장하지 않으며, 공개본 전체의 실행 시험 통과를 주장하지 않는다.
