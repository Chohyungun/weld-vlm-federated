## 최우선 — 베이스라인

**Sun, Q., Yin, Z., Zhang, F., Shi, X., Qin, L. (2026).**
WeldLLM: A Multimodal Framework for Welding Defect Detection and Automated Diagnostic Reasoning.
*IEEE Transactions on Industrial Informatics*, 22(7), 6478-6487. DOI 10.1109/TII.2026.3678237

중국과학원대학(UCAS). 2026-04-29 게재. 코드 MIT 공개.

```
[1] WTDWR-YOLO (용접 전용 검출망)
     ├ Dilated Weighted Residual Segmentation → 다중 스케일 공간 특징
     └ Wavelet-Transformed Convolution → 주파수 영역 표현, 저대비 결함 대응
          ↓
[2] Lightweight Modality Alignment Module
     → 영역 시각 특징 + 구조화 검출 속성을 통합 토큰 시퀀스로 인코딩
          ↓
[3] Qwen-VL → 고수준 의미 추론
          ↓
[4] LoRA 파인튜닝 → 진단 추론 + 시각 보고서 생성
```

**중요**: 순수 VLM이 아니라 전용 탐지기 + ROI 정렬 + LoRA VLM의 하이브리드다.
우리 차별점은 이들이 단일 조직 통합 학습인 반면 우리는 연합학습이라는 점.

**같은 팀 계보**
- 2025.07 WeldLLM (ICCSN), DOI 10.1109/ICCSN66511.2025.11172613 — YOLOv11 + Qwen2.5-VL-3B
- 2025.12 MFINet (ICCC), DOI 10.1109/ICCC68654.2025.11437970 — IoU 0.8743, 0.58M 파라미터

## 방향 판단

**温浩钰, 王小鹏, 于兴华 (2026).**
视觉语言模型在焊接缺陷检测中的应用现状与展望. *焊接学报* 47(6), 75-85.
DOI 10.12073/j.hjxb.20260402002 (2026-08-17 검증 시 확보)

증거 3등급 프레임워크로 VLM 용접 적용을 진단한 리뷰.

| 대상 | 모달 | VLM 잠재력 | 증거 등급 |
|---|---|---|---|
| 표면 결함 | 가시광 | 중간 | A류 |
| **내부 결함** | **X선/초음파** | **제한적** | **B류/C류** |
| 성형 이상 | 3D/가시광 | 높음 | A류 |

실증 6편 중 5편이 가시광. X선 단독 사례 없음.
결론은 혼합 상보 구조 권고. 전통 비전이 정밀 위치지정, VLM이 상위 의미 해석.
6.4절: 환각 위험. VLM 출력은 보조 해석이며 최종 판정은 자격 검사원이 확인해야 함.

**Khvatskii, G., Lee, Y.S., Angst, C., Gibbs, M., Landers, R., Chawla, N.V. (2025).**
Do multimodal large language models understand welding?
*Information Fusion*, 120, 103121. arXiv:2503.16537

범용 MLLM의 용접 이해도 평가 방법. 평가 설계의 출발점. WeldLLM도 인용.

**Lee, S.-H. et al. (2026).**
An Unsupervised Learning Framework With Efficient Weld Seam Extraction for Weld Defect
Detection in Radiographic Images. *IEEE Access*, 14, 32395-32406.

부산대 + 삼성중공업. 조선소 RT 실데이터 432장(학습은 정상 183장).
정확도 94.5%, 재현율 95.7%.

서론 인용문:
> These images represent the complete set approved for research use through the shipyard's
> internal data governance and export approval procedures

도메인 격차 수치: GDXray에 도메인 특화 학습 없이 적용 시 Pixel AUROC 0.9557 → 0.73
향후 과제가 우리 연구: "validation across diverse RT sources from different shipyards"

> 민감한 데이터 공유 없이도 공동의 불량 탐지 모델을 고도화하는 생태계를 조성해야 한다

*대한산업공학회지* 52(3), 268-278.

참여자별 표준편차 지표, 참여자/미참여자 시나리오 분리.

*AI Network Lab 인사이트* 2022년 6호 (2022-07-07). nia.or.kr 공개 다운로드.

받치는 용도로는 쓰지 않는다.** 그 자리는 아래 「연합학습 × 파운데이션·생성형 모델」 절이 맡는다.

미확정** — 본문 확인 후 관련연구 등재. **쓸 자리: 관련연구(제조 연합 검출 선례) +

## 조선 용접 도메인 LLM (별도 세션 정리분)

**Ye, S. et al. (2025).** Intelligent Q&A System for Welding Processes Based on a Symmetric
KG-DB Hybrid-RAG Strategy. *Symmetry* 17(11), 1994. SCIE Q2, IF 2.2

강소과기대 + 강소성 조선해양공정 설계연구원. SWP-Chat.

*RCIM* 102, 103341. SCIE Q1, IF ~10

**주의**: 실제 아크 용접 미수행(마커로 토치 모사). 베이스라인 비교·ablation 전무.

**Jin, B., Yoon, J., Han, J., Arık, S.Ö. (2025).** Long-Context LLMs Meet RAG.
*ICLR 2025* (채택률 32.08%). arXiv:2410.05983

UIUC + Google Cloud AI Research. 9 데이터셋 × 5 모델 × 4 검색기.

**핵심 발견**: 검색 문서를 늘릴수록 RAG 성능이 역U자로 하락한다.
좋은 검색기일수록 더 빨리 무너진다. 원인은 하드 네거티브(관련 있으나 정답 없는 문서).
해법 3종 중 검색 재배치는 학습 불필요하며 40개 이상에서 2~5%p 개선.

**교차 발견**: SWISS 논문의 `k=5` 설정이 이 역U자 곡선의 실증 사례다.
SWISS 저자는 현상만 관측하고 원인을 설명하지 못했다.

**용접 도메인이 취약한 이유**

| 문서 A | 문서 B | 벡터 유사도 | 실제 파라미터 |
|---|---|---|---|
| 탄소강 T-이음 12mm WPS | 스테인리스강 T-이음 12mm WPS | 매우 높음 | 전혀 다름 |
| 1Y급 용접재료 인장강도 | 3Y급 용접재료 인장강도 | 매우 높음 | 전혀 다름 |

## 평가지표 설계 참고

```
[기존 지표]     AUROC, AUPRC, TPR/TNR, mAP@50
                → 판정 정확성. 한민기 외(2025)의 TPR≥TNR 제약 적용

[변형 필요]     사실 일치도 (서술을 구조화 추출 후 정답과 대조)
                → BLEU/ROUGE 부적합. 템플릿 생성물이므로 n-gram 겹침은 무의미

[신규 설계]     근거 정합성 (서술 위치 ↔ 실제 결함 위치 IoU)
                환각률 (정답에 없는 결함 생성 비율)
                → HotpotQA의 supporting facts 개념을 이미지로 이식

[연합학습 고유] 참여자별 표준편차, 참여 효과, 통신량
                → 배진수 외(2026) 방식
```

**분량 고려**: 포스터논문에는 기존 지표 + 연합학습 지표만 넣는다.
근거 정합성은 2027년 학회지 논문의 핵심 기여로 이월한다.

**규모 참고**: 이예원 외(2025)는 평가를 30개 QA로 하고 팀원 4명이 O/△/X를 매겼다.
정량 지표가 없으면 소규모 정성 평가로 가는 것도 이 학회에서 통한다.
