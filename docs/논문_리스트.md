# 연구에 참고한 문헌

이 목록은 용접 결함 검사와 연합학습을 연결하는 연구 배경, 설계의 근거, 후속 검토 후보를
정리한 읽기 안내다. 인용 가능한 최종 참고문헌 목록과는 다르다. 문헌마다 활용 범위와 확인
상태가 다르며 일부는 제목·서지 또는 원문 내용의 대조가 남아 있다.

처음 읽는 독자는 WeldLLM과 용접 VLM 리뷰에서 과업을 이해한 뒤, 연합학습 기초와
파운데이션 모델의 연합 미세조정 문헌을 읽으면 된다. RAFT와 조선 용접 LLM 문헌은 검색·서술
확장을 검토한 배경이다. 현재 본실험은 Qwen3.5 4B의 세 학습 방식 비교이며 구조 비교는 포함하지
않는다. 연구 범위는 [논문 본문 초안](paper/본문_초안.md)을 따른다.

아래 서지 확인은 당시 기록을 옮긴 것이다. 공개 문서 편집일은 2026-10-05이며 이번 편집에서
웹·DOI·원문을 다시 확인하지 않았다. 최신 확인 기록은 2026-09-01의
[서지 검증 기록](paper/서지검증.md)에 있다.

| 읽는 목적 | 해당 문헌 묶음 | 확인할 제한 |
|---|---|---|
| 데이터 사용 조건 | RIAWELC·LoHi-WELD·AI허브 71761 | 실제 사용하는 데이터의 인용·출처 표기만 적용 |
| 가장 가까운 선행 연구 | WeldLLM과 용접 VLM 리뷰 | 구조·데이터·채점 정의가 달라 수치 직접 비교 불가 |
| 학습·집계 설계 | FedAvg·FedProx·FedLoRA·OpenFedLLM·Flower | 이론의 가정과 구현 선택을 구분 |
| 국내 산업 배경 | 국내 제조·용접·연합학습 문헌 | 정성환·배진수 외·Lee et al. 2026은 원문 대조 미완료 |
| 검색·서술 확장 | RAFT·SWP-Chat·용접 LLM·Long-Context RAG | 조사 범위의 공백과 실제 부재를 구분 |

## 데이터를 사용할 때 필요한 인용

아래는 데이터 사용 조건에 포함된 인용 항목이다. 선택적 참고문헌과 구분해 기록한다.
2026-08-21에 배포처와 대조한 기록이 있으며, 공저자·약관 표기 형식 등 남은 확인 사항은 각 항목에 적었다.

### RIAWELC — 2편 모두 인용 (저장소가 명시적으로 요구)

- **Totino, B., Spagnolo, F., Perri, S. (2022).** RIAWELC: A Novel Dataset of Radiographic
  Images for Automatic Weld Defects Classification. *Proceedings of the Interdisciplinary
  Conference on Mechanics, Computers and Electrics (ICMECE 2022)*, October 6-7, 2022,
  Barcelona, Spain.
- **Perri, S., Spagnolo, F., Frustaci, F., Corsonello, P. (2023).** Welding Defects
  Classification Through a Convolutional Neural Network. *Manufacturing Letters*, 35, 29-32.
  - 저장소 README는 게재 전 시점이라 `in press`로 적혀 있으나, 실제 게재본은 위 권·쪽이다
- **사용 조건:** 외부 데이터 평가에 사용하면 두 편을 인용한다. 과거에는 AI허브 미승인 시
  RIAWELC을 주 데이터로 대체하는 안도 검토했으며, 그 경우에는 주 데이터 인용이 된다.
  현재 본실험의 주 데이터는 AI허브 71761이다.
- 참고 범위: 데이터 절 + 참고문헌

### LoHi-WELD — 사용 시 1편

- **Block, S.B. et al. (2024).** LoHi-WELD: A Novel Industrial Dataset for Weld Defect
  Detection and Classification, a Deep Learning Study, and Future Perspectives.
  *IEEE Access*, 12, 77442-77453.
  - 제1저자·제목·저널·권·쪽·연도 확인. **공저자 전체는 미대조**(배포처 접근 차단) —
    조판 전 보완 필요
- **사용 조건:** 가시광 확장을 수행할 때만. 현재 주 실험(방사선)에는 클래스 체계가 맞지
  않아 미사용 예정이며, **쓰지 않으면 인용하지 않는다**
- 참고 범위: (사용 시) 데이터 절 + 참고문헌

### AI허브 71761 — 출처 표기 의무

- 정식 명칭: **창원 지역 특화산업 고도화 및 디지털 전환 촉진을 위한 용접 AI 학습 데이터**
  (AI허브 데이터셋 번호 71761)
- 구축 주체: 과학기술정보통신부·한국지능정보사회진흥원 「지능정보산업 인프라 조성」 사업
- **표기 문구 초안** — 사사(謝辭) 또는 데이터 절에 넣는다.
  > 본 연구는 과학기술정보통신부와 한국지능정보사회진흥원의 「지능정보산업 인프라 조성」
  > 사업으로 구축된 '창원 지역 특화산업 고도화 및 디지털 전환 촉진을 위한 용접 AI 학습
  > 데이터'(AI허브, 데이터셋 번호 71761)를 활용하였다.
- **주의 두 가지.** ① 이용약관에 **성과 보고 의무**가 있다. ② 정확한 표기 형식은 약관 원문을
  따라야 하므로 **투고 전 재확인이 필수 절차**다(10월 둘째 주). 위 문구는 초안이다
- 참고 범위: 데이터 절 + 사사

## 가장 가까운 선행 연구 — WeldLLM

**Sun, Q., Yin, Z., Zhang, F., Shi, X., Qin, L. (2026).**
WeldLLM: A Multimodal Framework for Welding Defect Detection and Automated Diagnostic Reasoning.
*IEEE Transactions on Industrial Informatics*, 22(7), 6478-6487. DOI 10.1109/TII.2026.3678237

중국과학원대학(UCAS). 2026-04-29 게재. 코드 MIT 공개.

```
[1] WTDWR-YOLO (용접 전용 검출망)
     ├ Dilated Weighted Residual Segmentation → 다중 스케일 공간 특징
     └ Wavelet-Transformed Convolution → 주파수 영역 표현, 저대비 결함 대응
          ↓
[2] Lightweight Modality Alignment Module
     → 영역 시각 특징 + 구조화 검출 속성을 통합 토큰 시퀀스로 인코딩
          ↓
[3] Qwen-VL → 고수준 의미 추론
          ↓
[4] LoRA 파인튜닝 → 진단 추론 + 시각 보고서 생성
```

WeldLLM은 전용 탐지기·ROI 정렬·LoRA VLM을 결합한 구조다. 본 연구는 데이터를 모을 수 없는
조건에서의 연합학습을 다룬다. WeldLLM과는 구조·데이터·채점 정의가 달라 보고값을 직접
비교하지 않는다. TII 권·호·페이지와 같은 팀의 두 학회 논문 제목은 일부 미대조 상태다.

**같은 팀 계보**
- 2025.07 WeldLLM (ICCSN), DOI 10.1109/ICCSN66511.2025.11172613 — YOLOv11 + Qwen2.5-VL-3B
- 2025.12 MFINet (ICCC), DOI 10.1109/ICCC68654.2025.11437970 — IoU 0.8743, 0.58M 파라미터

## 용접 VLM의 적용 범위와 방사선 영상

**温浩钰, 王小鹏, 于兴华 (2026).**
视觉语言模型在焊接缺陷检测中的应用现状与展望. *焊接学报* 47(6), 75-85.
DOI 10.12073/j.hjxb.20260402002 (2026-08-17 검증 시 확보)

증거 3등급 프레임워크로 VLM 용접 적용을 진단한 리뷰.

| 대상 | 모달 | VLM 잠재력 | 증거 등급 |
|---|---|---|---|
| 표면 결함 | 가시광 | 중간 | A류 |
| **내부 결함** | **X선/초음파** | **제한적** | **B류/C류** |
| 성형 이상 | 3D/가시광 | 높음 | A류 |

실증 6편 중 5편이 가시광. X선 단독 사례 없음.
결론은 혼합 상보 구조 권고. 전통 비전이 정밀 위치지정, VLM이 상위 의미 해석.
6.4절: 환각 위험. VLM 출력은 보조 해석이며 최종 판정은 자격 검사원이 확인해야 함.

**Khvatskii, G., Lee, Y.S., Angst, C., Gibbs, M., Landers, R., Chawla, N.V. (2025).**
Do multimodal large language models understand welding?
*Information Fusion*, 120, 103121. arXiv:2503.16537

범용 MLLM의 용접 이해도 평가 방법. 평가 설계의 출발점. WeldLLM도 인용.

**Lee, S.-H. et al. (2026).**
An Unsupervised Learning Framework With Efficient Weld Seam Extraction for Weld Defect
Detection in Radiographic Images. *IEEE Access*, 14, 32395-32406.

부산대 + 삼성중공업. 조선소 RT 실데이터 432장(학습은 정상 183장).
정확도 94.5%, 재현율 95.7%.

원문 대조가 끝나지 않은 인용문 후보다. 인용 전 PDF 확인이 필요하다.

> These images represent the complete set approved for research use through the shipyard's
> internal data governance and export approval procedures

도메인 격차 수치: GDXray에 도메인 특화 학습 없이 적용 시 Pixel AUROC 0.9557 → 0.73
후속 검증 과제로 제시한 범위: "validation across diverse RT sources from different shipyards".
본 연구의 현행 동결 분할만으로 이 범위의 일반화를 확인할 수는 없다.

## 국내 제조업·용접 연구와 산업 배경

**정성환 (2026).** 우리나라 제조업 품질관리 머신러닝 적용 연구의 국제적 수준 분석.
*대한산업공학회지* 52(3), 231-244.

다음은 기존 문헌 검토 기록이다. 이 문헌은 웹 경로로 원문에 도달하지 못해 최종 인용을 보류한다.
2010~2025 논문 1,624편(국내 99편) 계량서지학 분석. 유한대 단독 저자.

핵심 인용문:
> 제조 데이터의 기밀성 문제를 극복하기 위해 연합 학습 기술을 도입하여 원청과 협력사 간에
> 민감한 데이터 공유 없이도 공동의 불량 탐지 모델을 고도화하는 생태계를 조성해야 한다

3단계 성숙도 프레임워크(감지/예측/제어). 국내 99편 중 품질검사 54편으로 Level 1 집중.
Offline 34편, Online 45편, Real-time 20편. 조선 산업은 별도 집계되지 않을 만큼 연구가 드묾.

**배진수 외 (2026).** 이상 고객 데이터에 강건한 냉장고 온도 예측용 데이터 수준 연합학습 기법.
*대한산업공학회지* 52(3), 268-278.

기존 검토 기록상 고려대 김성범 연구실 + 삼성전자의 국내 FL 선례다. 원문 대조는 남아 있다.
참여자별 표준편차 지표, 참여자/미참여자 시나리오 분리.
비교군 5종: 사전학습, FedAvg, FedProx, FLTrust, FL-DIAC.
FLTrust는 AUROC 0.705로 사전학습 모델보다 낮았다(이질성 크면 정상 참여자도 오탐).
cross-device 설정(냉장고 1,011대)이므로 우리(cross-silo)와 구분됨.

**한국지능정보사회진흥원(NIA) (2022).** 산업분야에서 연합학습 동향 및 시사점.
*AI Network Lab 인사이트* 2022년 6호 (2022-07-07). nia.or.kr 공개 다운로드.

국내 기관 자료 중 연합학습 산업 적용을 다룬 공개 발간물. 2026-08-18 제목·발행기관·
발행일·호수·공개 접근 확인. 같은 주제의 컨설팅 발간물도 검토했으나 안정적인 공개
배포처가 없어 인용하지 않는다.

국내 산업 맥락을 설명하는 보조 문헌이다. ChatGPT 출시(2022-11) 이전 자료여서 연합학습과
생성형·파운데이션 모델의 결합은 다루지 않는다. VLM을 연합으로 미세조정하는 문제 설정은
아래 「연합학습 × 파운데이션·생성형 모델」 절의 문헌을 참고한다.

**한민기, 김도희, 배혜림 (2025).** 임곗값 최적화 기반 용접 결함 분류: 클래스 불균형
문제 해소를 중심으로. *대한산업공학회지* 51(6), 515-526.

용접 결함 국내 선례. 불량률 2.79%. 기본 임곗값 0.5에서 TPR 0.0523.
TPR ≥ TNR 제약 적용. 정형 데이터 기반이므로 검사 이미지는 다루지 않음.

## 연합학습 기초

- **McMahan, H.B. et al. (2017).** Communication-efficient learning of deep networks from decentralized data. *AISTATS*, PMLR 54, 1273-1282.
- **Li, T. et al. (2020).** Federated optimization in heterogeneous networks (FedProx). *MLSys*, 2, 429-450.
  - 통계적 이질성(client drift) + 시스템적 이질성(straggler) 구분
  - proximal term, γ-inexact solution, B-local dissimilarity
  - 스트래글러 0/50/90% 실험. 90%에서 FedAvg 대비 평균 22% 개선
- **Li, X., Huang, K., Yang, W., Wang, S., Zhang, Z. (2020).** On the convergence of FedAvg on non-IID data. *ICLR*. arXiv:1907.02189
  - **Theorem 4:** 해당 정리의 가정 아래 어떤 고정 학습률로도 최적점에 도달하지 못하며 학습률 감쇠가 필요하다
  - E는 U자형 함수. 너무 작으면 통신 비용, 너무 크면 로컬 발산
  - 강볼록 가정 위의 결과이므로 DNN에 그대로 적용되지 않음을 명시할 것
- **Hsu, T.-M.H. et al. (2019).** Measuring the effects of non-identical data distribution for federated visual classification. arXiv:1909.06335
  - Dirichlet 분할의 출처 (구현설계 2-6이 인용). 2026-08-17 arXiv 제목·제1저자 대조 확인
- **Kairouz, P. et al. (2021).** Advances and open problems in federated learning. *FnT ML* 14(1-2).
  - cross-device / cross-silo 구분. 우리는 cross-silo
- **Beutel, D.J. et al. (2020).** Flower: A friendly federated learning research framework. arXiv:2007.14390
- **IEEE (2021).** IEEE Guide for Architectural Framework and Application of Federated Machine
  Learning (IEEE Std 3652.1-2020). IEEE Standards Association.
  - 이사회 승인 2020-09-24 / 발행 2021-03-19 / IEEE Computer Society, C/AISC 인공지능
    표준위원회 FML 작업반 / Xplore 문서 9382202. **DOI·쪽수는 미대조** (서지검증 참조)
  - **설계에서 참조할 범위:** §5.2 수평적 연합, §9.3.1 성능 격차, §9.4 시간·메모리,

    아니라는 지적이 가능하다. 용어와 지표 정의의 근거로만 쓴다
  - 유료 라이선스본이다. 원문 PDF·추출 텍스트를 저장소·corpus·색인에 넣지 않는다

  - 극심한 label shift에서 PromptFL 대비 평균 +19%p
- **Bo, W. et al. (2025).** FedMGP. *NeurIPS*.
  - 텍스트 > 비주얼 프롬프트 기여도. 프롬프트 길이는 길수록 좋지 않음

## RAFT 계열의 제조·용접 적용 조사

**RAFT** (Zhang, T. et al., 2024, arXiv:2403.10131, UC Berkeley Gorilla 팀)
검색 결과에 방해 문서가 섞여도 답하도록 훈련 + 근거 구절 인용.

**Semantic Scholar API 전수 조사 (2026-08-11)**

| 논문 | 인용 수 | 제조 관련 | 용접·조선 |
|---|---|---|---|
| RAFT | 377편 | 5편 | 없음 |
| RA-DIT | 251편 | 2편 | 없음 |
| Self-RAG | 1,500편 | 38편 | 없음 |

당시 검색 범위에서 총 2,128편을 확인했고 **용접·조선 도메인 적용 사례를 찾지 못했다.**

**제조 응용 5편의 계보**

```
RAFT ①distractor 훈련 ────── 제조 적용 없음  ← 공백
     ②근거 인용 ──────────── IEEE TIM 고장진단 (그래프 경로로 변형)
     ③도메인 후속훈련 ────── 공정공학 계산(직계) / EMNLP 검색기(반대편)
     ④open-book 설계 ─────── LLM OS (교재를 그래프로)
```

**한계 명시**: Semantic Scholar 색인 기준이므로 중국 학회지·국내 논문은 누락 가능하다.
RAFT를 인용하지 않고 같은 아이디어를 쓴 논문도 존재할 수 있다.
논문에 쓸 경우 검색일·도구·확인 편수를 각주에 기록할 것.

## 초기 평가지표 구상과 현행 설계의 구분

아래 도식은 문헌을 읽으며 정리한 초기 구상이다. 현재 본실험의 대표 지표는 미정이며,
클래스 일치 상자 매칭 F1@IoU0.5의 네 결함 매크로 평균이 후보이다. 사전실험의 mAP@0.5와
통합형의 대표 지표를 같은 척도로 비교하지 않는다. 현행 규약은 본문 §5.4~§7.4를 따른다.

```
[기존 지표]     AUROC, AUPRC, TPR/TNR, mAP@50
                → 판정 정확성. 한민기 외(2025)의 TPR≥TNR 제약 적용

[변형 필요]     사실 일치도 (서술을 구조화 추출 후 정답과 대조)
                → BLEU/ROUGE 부적합. 템플릿 생성물이므로 n-gram 겹침은 무의미

[신규 설계]     근거 정합성 (서술 위치 ↔ 실제 결함 위치 IoU)
                환각률 (정답에 없는 결함 생성 비율)
                → HotpotQA의 supporting facts 개념을 이미지로 이식

[연합학습 고유] 참여자별 표준편차, 참여 효과, 통신량
                → 배진수 외(2026) 방식
```

**분량 고려**: 포스터논문에는 기존 지표 + 연합학습 지표만 넣는다.
근거 정합성은 2027년 학회지 논문의 핵심 기여로 이월한다.

**평가 규모를 검토한 참고 사례:** 이예원 외(2025)는 30개 QA를 팀원 4명이 O/△/X로 평가했다.
소규모 정성 평가의 사례로 기록하되, 이 사례만으로 본 연구의 평가 적정성이나 학회 수용 여부를
판단하지 않는다.
