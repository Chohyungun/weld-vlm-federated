**결함 이미지는 사실상 전량 1280×720 크롭이고, 정상 이미지는 80%가 파노라마 전장 필름이다.**

# 5. 이 결과가 A·B·D에 미치는 영향

## 데이터 파이프라인

1. **매니페스트 총량을 129,613으로 잡아라.** 144,019는 미공개 홀드아웃을 포함한 값이다.
   RT 주 실험 기준은 **62,998장**(ST 54,053 + AL 8,945)이다.
2. **`group_id`를 파일명 id의 연속 run으로 채워라.** pHash를 돌릴 필요가 없다.
   99.0%가 묶음에 속하고 묶음의 9.1%가 클래스를 가로지르므로, 분할은 반드시 run 단위여야 한다.
3. **폴리곤→bbox 변환에 clamp를 넣어라.** 안 넣으면 음수 bbox가 1,280개 파일에서 들어온다.
   `class="normal"` 폴리곤 60,890개는 **버려야** 한다.
4. **이미지 규격을 하드코딩하지 마라.** 9,767종이다. 헤더에서 읽어야 한다.
5. 사상표 자연 키는 파일명의 **숫자 클래스 코드**(`00`~`06`)를 권한다. 2-5 참조.

## 코퍼스·합성

1. **두께 구간을 실물에서 가져올 수 없다.** 골격 생성기의 두께 축은 **가정값**으로 확정하고,
   허용치 CSV의 두께 구간을 우리가 정의해야 한다.
2. 결함 클래스는 **RT 5종**(균열·기공·융합불량·슬래그혼입·정상)으로 닫힌다.
   VT 2종(용입부족·언더컷)은 주 실험 밖이다.
3. **재질 축은 실물에 있다**(ST/AL). 재질별로 기준이 갈리는 조합은 실제 분포에 근거해 만들 수 있다.
4. 판정문의 치수·합부·조치는 **전량 합성**이다. 실물 근거는 `{클래스, 폴리곤 위치, 재질}` 세 축뿐이다.

## 평가·채점

1. **폴리곤이 있으므로 mAP·BBox-IoU·Class-Jaccard가 전부 산출 가능하다.**
   RIAWELC 백업 시나리오에서만 사라진다.
2. **판정 정합성 지표는 실측 두께로 못 낸다.** 정답 데이터에 내장된 가정값 기준으로만
   산출된다. 이 전제를 채점기 설계에 못박아야 한다.
3. **4-4의 규격 지름길을 통제하지 않으면 모든 검출 지표가 부풀려진다.**
   대응 전에는 어떤 칸의 수치도 신뢰할 수 없다. 통제 실험(이미지 크기만으로 학습한
   베이스라인)을 부록에 두는 것을 권한다.
4. 채점 대상에서 **`class="normal"` 폴리곤을 제외**해야 한다. 안 하면 정상 이미지가
   60,890개의 오탐을 만든다.
