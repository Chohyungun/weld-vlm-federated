# 1. Non-IID 관점에서 이 데이터를 쓸 수 있는가

## 1-2. (A-2) 이질성 유형 — 넷 중 **셋이 실재하고 하나는 대용 검사로만 관측된다**

### ① label skew — **실재. 슬래그혼입이 6.05배**

| 클래스 | AL 비율 | ST 비율 | 배수(AL/ST) |
|---|---|---|---|
| **슬래그혼입** | **11.5%** (1,032) | **1.9%** (1,030) | **6.05×** |
| 기공 | 29.3% (2,621) | 45.0% (24,345) | 0.65× |
| 융합불량 | 3.4% (300) | 5.4% (2,928) | 0.62× |
| 균열 | 3.3% (294) | 3.8% (2,054) | 0.86× |
| 정상 | 52.5% (4,698) | 43.8% (23,696) | 1.20× |

**총변이거리(TVD) = 0.1831** (0이면 동일, 1이면 완전 분리).

슬래그혼입은 **절대 수량이 AL 1,032 대 ST 1,030으로 거의 같은데 비율이 6배 갈린다.**
알루미늄 용접에서 슬래그가 상대적으로 흔하다는 물리가 데이터에 그대로 찍혔다. 인위 조작이 아니다.

### ② quantity skew — **실재. 1 : 6.0**

```
AL  8,945  :  ST  54,053   =  1 : 6.0
```

### ③ feature skew — **실재하나 상당 부분이 4-4 규격 지름길과 얽혀 있다**

| | 해상도 종수 | 화소수 평균 | 최소 | 최대 |
|---|---|---|---|---|
| AL 전체 | 332 | 1.88 MP | 0.92 | 5.09 |
| ST 전체 | **9,635** | 1.84 MP | 0.55 | **36.17** |

**그런데 정상 이미지를 빼고 결함만 비교하면 거의 사라진다.**

| 결함 클래스만 | n | 해상도 종수 | 화소수 평균 |
|---|---|---|---|
| AL | 4,247 | **16** | 0.930 MP |
| ST | 30,357 | **1** | 0.922 MP |

**→ 재질 간 feature skew의 대부분은 "정상=파노라마 / 결함=크롭"이라는 규격 지름길
(전수확인 4-4, 함정 구간 11번)에서 온다.** 지름길을 통제하면 결함 이미지의 규격 차이는
AL 16종 대 ST 1종 정도로 줄어든다. **약하지만 0은 아니다.**

### ④ concept drift — **🔴 관측된다. 다만 시간축이 없어 대용 검사다**

회사·촬영일 필드가 없어 직접 못 잰다. `info.id`가 전역 순번이므로 **id 구간을 시간 대용축**으로
삼아 어노테이션 관행이 변했는지 봤다.

| 구간 | id 범위 | n | 재질 | **꼭짓점 평균** | 면적 중앙값(px²) | 인스턴스/장 |
|---|---|---|---|---|---|---|
| 1 | 3,368 ~ 14,497,454 | 12,599 | **AL 8,945 + ST 3,654** | **14.7** | 2,568 | 2.34 |
| 2 | — | 12,599 | ST | (결함 없음) | — | — |
| 3 | 14,511,420 ~ 14,525,486 | 12,599 | ST | **12.3** | 1,185 | 3.53 |
| 4 | 14,525,487 ~ 14,539,411 | 12,599 | ST | **10.8** | 1,152 | 3.73 |
| 5 | 14,539,412 ~ 14,553,404 | 12,602 | ST | **7.1** | 2,544 | 2.73 |

**꼭짓점 평균이 14.7 → 12.3 → 10.8 → 7.1로 단조 감소한다.** 같은 결함을 뒤로 갈수록
**성기게(coarser) 따고 있다.** 어노테이션 기준이 작업 진행에 따라 변했다는 뜻이다.

재질별로도 같은 차이가 나온다.

| | 인스턴스/장 | 꼭짓점 평균 | 면적 중앙값(px²) | is_crowd=1 |
|---|---|---|---|---|
| AL | 2.34 | **14.7** | 2,568 | 0.9% |
| ST | 3.27 | **9.9** | 1,510 | 0.5% |

**🔴 그리고 재질과 시기가 교락(confound)돼 있다.** 알루미늄 8,945장이 **전부 가장 이른
id 구간에 몰려 있다.** 즉 AL은 별도 시기·별도 배치로 촬영·어노테이션됐다.

### 이것이 왜 중요한가 — 감독 판단 요청 사항

**C3(알루미늄)의 이질성 중 얼마가 재질 물리이고 얼마가 어노테이션 시기 차이인지 분리할 수 없다.**

- **긍정적 해석**: 실제 회사 간 연합에서도 회사마다 검사 기준이 다르므로, 이 교락은
  오히려 현실적이다. RQ1이 다루려는 어려움의 실물 사례다.
- **부정적 해석**: **글로벌 평가셋 채점의 공정성을 흔든다.** 평가셋에 AL과 ST가 섞여 있는데
  두 집단의 정답 폴리곤 정밀도가 다르면, 같은 모델이 AL에서 낮은 IoU를 받는 것이
  모델 탓인지 정답 탓인지 구분되지 않는다.

**논문 한계 절에 반드시 선언해야 한다.** 대응(예: 재질별 IoU 분리 보고)은 감독 결정 사안이라
여기서 정하지 않는다.

## 1-3. (A-3) Dirichlet이 필요한가 — **판정 2: 자연 축 + 보조 Dirichlet**

```
① 자연 축만으로 충분 → Dirichlet 제거          ✗
② 자연 축 + 보조 Dirichlet                     ✓ 채택
③ 자연 축 없음 → 전면 인위 분할                ✗
```

**근거.**

**자연 축은 실재하지만 값이 둘뿐이다.** 재질 축은 label skew(TVD 0.183, 슬래그 6.05배),
quantity skew(1:6.0), 약한 feature skew, 어노테이션 관행 차이를 모두 만든다. 인위 조작 없이
얻은 것이므로 **C3의 근거로 충분하다.**

**그러나 C1·C2를 가를 자연 축이 없다.** 강재 54,053장을 나눌 실물 근거가 데이터에 존재하지
않는다(1-1). 아무 처리 없이 2:1로 자르면 **C1과 C2는 분포가 사실상 동일한 복제본**이 되고,
그러면 "연합학습이 non-IID에서 어렵다"는 주장의 절반이 증발한다. C1↔C2 비교가 IID 비교가 된다.

**→ Dirichlet α=0.5는 C1·C2 사이에만 유지한다. 제거하면 안 된다.** C3에는 적용하지 않는다
(이중 적용이 되고, 자연 이질성을 인위 이질성으로 덮어쓴다).

이 구성은 현행 설계(`docs/개발규약.md`)와 동일하다. **실물로 검증됐으니 바꿀 이유가 없다.**

**논문 서술 시 정직하게 쓸 것**: "재질은 자연 분할, 강재 내부 2분할은 Dirichlet(α=0.5)으로
부여한 통제 이질성"이라고 명시한다. 자연 축이 하나뿐이라는 사실을 감추면 심사에서 공격받는다.

## 1-4. (A-4) 클라이언트 수와 규모

**평가셋 20% 선분리 후** 기준이다 (불변조건 1-3).

```
RT 전체            62,998
├─ 글로벌 평가셋 20%   12,600   (재질×클래스 층화, 묶음 단위)
└─ 학습 풀 80%        50,398
   ├─ C1 강재 2/3     28,828
   ├─ C2 강재 1/3     14,414
   └─ C3 알루미늄      7,156
```

### 몇 개까지 쪼갤 수 있는가

제약은 두 가지다. **자연 축이 주는 상한**과 **묶음(run) 수가 주는 하한**이다.

| | RT 이미지 | 연속 묶음 수 | 평균 |
|---|---|---|---|
| AL | 8,945 | **956** | 9.4장 |
| ST | 54,053 | **5,372** | 10.1장 |

분할은 묶음 단위여야 하므로(불변조건 1-5) 실제 분할 단위는 이미지가 아니라 **6,328개 묶음**이다.
평가셋 20%를 떼면 학습 풀에 AL 약 765묶음, ST 약 4,298묶음이 남는다.

- **묶음 수로는 여유가 크다.** ST를 10개 클라이언트로 쪼개도 클라이언트당 430묶음(~4,300장)이다.
- **자연 축으로는 2개가 상한이다.** 3개째부터는 전부 인위 분할이다.

### 판정 — **3개를 유지한다**

| 안 | 구성 | 평가 |
|---|---|---|
| 2 클라이언트 | AL / ST | 가장 정직하나 **FedAvg 시연으로 빈약**하고 규모 대비(RQ3)를 못 만든다 |
| **3 클라이언트** | **C1/C2 강재 + C3 알루미늄** | **채택.** RQ1·RQ3를 동시에 지탱하는 최소 구성 |
| 5~6 클라이언트 | ST를 4~5분할 | 인위성이 커지고 클라이언트당 표본만 줄어든다. 얻는 것이 없다 |

**클라이언트당 최소 표본은 충분하다.** 가장 작은 C3가 7,156장(약 765묶음)이고, YOLO11s 검출
학습에 부족하지 않다. **다만 C3의 희소 클래스는 빠듯하다** — 평가셋 제외 후 C3의 균열은
약 235장, 융합불량은 약 240장이다. **클라이언트별 클래스 소실은 없으나 소수 클래스가 얇다.**

| C3(알루미늄) 학습 풀 추정 | 장수 |
|---|---|
| 정상 | ~3,758 |
| 기공 | ~2,097 |
| 슬래그혼입 | ~826 |
| 융합불량 | ~240 |
| 균열 | ~235 |

**저널 확장 시 α 민감도 분석(0.1/0.5/1.0)은 C1·C2 사이에만 적용 가능하다.** C3는 자연 분할이라
α를 못 바꾼다 — 이 비대칭을 미리 기록해 둔다.

# 2. 클래스 통일이 가능한가

**주의: 창원 단독 분석이다.** 104·42는 미착수라 제외했고, RIAWELC·LoHi-WELD는 앞선
`docs/데이터셋_실물확보.md` 실측을 근거로 함께 판정했다.

## 2-1. (B-1) 사상 가능성

창원 RT·VT + RIAWELC + LoHi-WELD의 **(데이터셋, 클래스) 쌍 18건** 기준이다.

| 유형 | 건수 | 내역 |
|---|---|---|
| **1:1** | **8** | 균열·융합불량·슬래그혼입(창원RT), 융합불량·용입부족·언더컷(창원VT), CR·LP(RIAWELC) |
| **N:1** | **0** | — |
| **🔴 1:N (사상 불가)** | **4** | **기공**(창원RT), **기공**(창원VT), **PO**(RIAWELC), **pore**(LoHi) |
| **🔴 사상 불가** | **6** | 정상(창원RT), 정상(창원VT), ND(RIAWELC) / **deposit·discontinuity·stain**(LoHi) |

### 1:N 4건 — 전부 기공이고 원인이 같다

ISO 6520-1은 기공을 `2011`(단일 가스공) `2012`(균일분포) `2013`(군집) `2014`(선상)으로
쪼개는데 **네 데이터셋 모두 "기공" 하나로 뭉뚱그려 라벨링했다.** 원본에 없는 구분이라
쪼갤 수 없다. `실험설계.md` 3-3이 "기공 → 2011 / 2012"로 두 코드를 병기한 것이 이 지점이다.

**처방 — 사상 단위를 4자리에서 3자리 그룹코드로 낮추면 4건 전부 1:1이 된다.**

| 원본 | 3자리 그룹코드 | 4자리로 갈 때의 문제 |
|---|---|---|
| 균열 / crack / CR | **100** | 1001·1002·1003… 방향 구분 없음 |
| 기공 / porosity / PO / pore | **201** | 2011·2012·2013·2014 구분 없음 ← **1:N의 원인** |
| 슬래그혼입 / slag inclusion | **301** | — |
| 융합불량 / lack of fusion | **401** | 4011·4012·4013 위치 구분 없음 |
| 용입부족 / incomplete penetration / LP | **402** | — |
| 언더컷 / undercut | **501** | 5011·5012 연속·단속 구분 없음 |

**→ 3자리 그룹코드가 유일한 통일 경로다.** 4자리를 고집하면 통일 불가다.

### 사상 불가 6건 — 성격이 둘로 갈린다

| 건 | 성격 | 처리 |
|---|---|---|
| 정상(창원RT) · 정상(창원VT) · ND(RIAWELC) | ISO에 코드가 없을 뿐 **정의는 명확** | 별도 클래스로 두면 된다 |
| **deposit**(LoHi) | **정의 미확인** — 정의 문서를 못 찾았다 | **추정하지 않는다** |
| **discontinuity**(LoHi) | ISO 체계 **전체를 가리키는 상위어** | 특정 코드에 못 붙인다 |
| **stain**(LoHi) | 표면 오염. **ISO 6520-1의 용접 결함이 아니다** | 제외 대상 |

**→ LoHi-WELD는 창원과 클래스 체계를 공유하지 못한다.**

## 2-2. (B-2) 같은 이름 다른 뜻

**정의 문서를 확보한 것은 없다. 전부 "정의 미확인"으로 남긴다. 추정하지 않았다.**

| 확인 항목 | 상태 |
|---|---|
| 기공(porosity) 대 블로홀 구분 | **정의 미확인** — 창원 가이드라인 미확보 |
| 균열 방향(종·횡) 구분 유무 | **없다** (창원은 `crack` 단일. RIAWELC도 `CR` 단일) |
| 용입부족(402) 대 융합불량(401) 경계 | **정의 미확인.** 두 클래스가 모두 존재하므로 구분은 하고 있으나 기준 문서 없음 |
| 언더컷 깊이 기준 | **정의 미확인** (창원 VT에만 존재) |
| "정상"이 무결함인가 허용치 이내인가 | 🔴 **판정 필드가 없으므로 허용치 개념 자체가 데이터에 없다.** `class="normal"` 폴리곤이 붙어 있을 뿐이다 (v3 참조) |

**마지막 항목이 가장 중요하다.** 창원의 "정상"은 **허용치 이내 합격이 아니라 결함 미검출**이다.
판정·허용치 축이 데이터에 없기 때문이다. RIAWELC의 `ND`, LoHi의 무결함도 같다.
**세 데이터셋의 "정상"은 같은 뜻으로 볼 수 있다** — 다만 그것은 "합격"이 아니라 "결함 없음"이다.

## 2-3. (B-3) 통일 후 실효성

3자리 그룹코드로 통일했을 때 (창원 RT + RIAWELC 기준. LoHi는 2-4에서 제외 판정)

| 그룹코드 | 클래스 | 창원 RT/ST | 창원 RT/AL | RIAWELC | 계 |
|---|---|---|---|---|---|

**공통 교집합은 균열·기공·정상 3종뿐이고, 이것이 낯선 데이터 평가를 3클래스로 축소하는 근거다.**

## 2-4. (B-4) 결론 — **부분 통일**

```
① 통일 가능        ✗
② 부분 통일        ✓ 채택
③ 통일 불가        ✗
```

**통일 대상**: 창원 RT + RIAWELC. **3자리 ISO 그룹코드**로 사상하면 1:N이 소멸해 전부 1:1이 된다.

**제외 대상**: **LoHi-WELD.** 4클래스 중 3개(`deposit`·`discontinuity`·`stain`)가 ISO 6520-1에
대응이 없고, 그중 `stain`은 용접 결함도 아니다. 남는 `pore` 하나로는 통일에 기여하지 못한다.

**제외 시 무엇을 잃는가**: LoHi는 **bbox를 가진 유일한 가시광 데이터셋**이다(22,412개).
이를 빼면 우리 실험은 **RT(방사선) 단일 모달**이 된다. 다만 주 실험이 애초에 RT 한정이고
(`실험설계.md` 3-2), LoHi는 가시광 확장 시에만 쓰기로 이미 정해져 있으므로 **주 실험 손실은 없다.**

**창원 VT 취급**: 용입부족·언더컷이 있고 균열·슬래그가 없어 RT와 라벨 공간이 다르다.
사상 자체는 가능하나(전부 1:1) **RT와 섞으면 라벨 공간이 어긋난다.** 주 실험 제외를 유지한다.

### 사상표 초안 — **제안일 뿐이다. `configs/label_map.yaml`은 A 소관이므로 직접 고치지 않았다**

# 3. 결론

## 3-1. 이 데이터로 RQ1이 성립하는가 — **성립한다**

**RQ1**(데이터를 못 모으는 조건에서 공동 모델을 학습할 수 있는가)은 **클라이언트 분할이
실물에 근거하는가**에 걸려 있었다. 판정은 다음과 같다.

**성립한다. 단, 자연 축이 하나뿐이라는 한계를 논문에 명시하는 조건에서다.**

| 근거 | 수치 |
|---|---|
| 자연 축(재질)이 실재한다 | ST 54,053 / AL 8,945 |
| 그 축이 실제로 분포를 가른다 | **TVD 0.183**, 슬래그혼입 **6.05배** |
| 규모 불균형도 실재한다 | **1 : 6.0** |
| 어노테이션 관행 차이까지 있다 | 꼭짓점 14.7 대 9.9, 인스턴스/장 2.34 대 3.27 |
| 묶음 단위 분할이 가능하다 | RT 6,328개 묶음 |
| 클라이언트당 표본이 충분하다 | 최소 C3 7,156장 |

## 3-2. 어떤 분할로

```
RT 62,998
├─ 글로벌 평가셋 20%  12,600   재질×클래스 층화, 묶음(연속 id run) 단위
└─ 학습 풀 80%       50,398
   ├─ C1 강재 2/3    28,828  ┐ 이 둘 사이에만 Dirichlet α=0.5
   ├─ C2 강재 1/3    14,414  ┘ (자연 축이 없어 인위 부여가 필요하다)
   └─ C3 알루미늄     7,156    자연 분할. Dirichlet 미적용
```

**현행 설계와 동일하다. 실물로 검증됐으니 바꿀 이유가 없다.**

## 3-3. 무엇이 부족한가 — 논문에 선언할 한계 3건

1. **자연 분할 축이 재질 하나뿐이다.** C1·C2 분리는 100% 인위적이다. "회사별 분할"이라고
   쓰면 허위가 된다 — **"재질 기반 자연 분할 + 강재 내부 통제 이질성"**으로 정확히 써야 한다.
2. **재질과 어노테이션 시기가 교락돼 있다.** AL 전량이 가장 이른 id 구간에 몰려 있고,
   꼭짓점 평균이 14.7 → 7.1로 단조 감소한다. C3의 이질성에서 재질 물리와 시기 차이를
   분리할 수 없다. **글로벌 평가셋 채점의 공정성 문제로 이어진다.**
3. **클래스 통일이 부분적이다.** LoHi-WELD는 제외해야 하고, 창원↔RIAWELC의 공통
   교집합은 3종(균열·기공·정상)뿐이다.

# 4. 🔴 부수 발견 — `info.id`와 파일명이 어긋나는 파일 10건
