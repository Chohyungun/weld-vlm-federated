# 데이터 분할과 클래스 비교의 근거

이 문서는 창원 AI허브 71761의 RT 이미지가 연합학습 비교에 어떤 분포 차이를 제공하는지, RIAWELC·LoHi-WELD와 어떤 클래스를 비교할 수 있는지 설명한다. 원래 분석은 2026-08-23의 RT 배포분 62,998장을 대상으로 했다. 아래의 분포 수치는 당시 분석 기록이며, 현재 학습·평가에 쓴 동결 분할 수량과 구분한다.

현재 C1·C2·C3는 공개 데이터를 나눈 참여자 역할이다. 실제 회사·사업장별 자료가 아니다. ST·AL도 **명목 재질 라벨**로만 부른다. 후속 확인에서 명목 AL 파노라마에 강 계열 규격이 보였고, 결함 크롭의 재질은 미확인이다. 과거 문서에서 분포 차이를 알루미늄·강재의 물리적 차이로 설명한 부분은 이 근거만으로 뒷받침되지 않는다.

## 1. 어떤 기준으로 나눌 수 있는가

라벨 JSON 129,613개에 있는 분할 후보 필드는 검사 방식(RT/VT)과 명목 재질(ST/AL)이다. 회사·사업장·설비·촬영일·두께·이음형상·작업자 필드는 전수 검색에서 확인되지 않았다. 주 실험은 RT만 사용하므로 원자료가 제공하는 분할 축은 ST·AL 구분 하나다.

두 집단의 크기는 ST 54,053장, AL 8,945장으로 약 6.0:1이다. 클래스 구성에도 차이가 있다.

| RT 클래스 | 명목 AL | 명목 ST | AL/ST 비율의 배수 |
|---|---:|---:|---:|
| 슬래그혼입 | 11.5%(1,032) | 1.9%(1,030) | 6.05× |
| 기공 | 29.3%(2,621) | 45.0%(24,345) | 0.65× |
| 융합불량 | 3.4%(300) | 5.4%(2,928) | 0.62× |
| 균열 | 3.3%(294) | 3.8%(2,054) | 0.86× |
| 정상 | 52.5%(4,698) | 43.8%(23,696) | 1.20× |

분포 차이를 나타내는 총변이거리(TVD)는 0.1831이었다(0은 같은 분포, 1은 완전 분리). 이는 두 명목 집단의 라벨 분포가 다르다는 근거다. 차이의 원인이 재질, 촬영 조건, 수집·라벨링 방식 중 무엇인지는 분리하지 못했다.

## 2. 분포 차이에 섞인 편향

### 이미지 크기

AL은 해상도 332종·평균 1.88 MP(최소 0.92, 최대 5.09), ST는 9,635종·평균 1.84 MP(최소 0.55, 최대 36.17)였다. 결함 이미지만 보면 AL 4,247장은 16종·평균 0.930 MP, ST 30,357장은 한 규격·평균 0.922 MP로 차이가 줄었다.

이 결과에는 정상 파노라마와 결함 크롭의 형식 차이가 크게 섞여 있다. 해상도 차이를 재질별 영상 특성으로 곧바로 설명할 수 없다. RT/ST에서 이미지 크기만으로 정상·결함을 구분한 정확도 96.1%도 이 편향을 보여 준다. 상세는 [AI허브 전수확인](데이터셋_AI허브_전수확인.md)에 있다.

### 폴리곤 작성 방식

숫자 ID 순서로 RT를 다섯 구간으로 나누어 본 기록은 다음과 같다. ID는 촬영일이 아니므로 이 표는 시간에 따른 변화의 직접 측정이 아니다.

| ID 순서 구간 | 이미지 수 | 명목 집단 | 결함 폴리곤 꼭짓점 평균 | 면적 중앙값(px²) | 이미지당 인스턴스 |
|---|---:|---|---:|---:|---:|
| 1 | 12,599 | AL 8,945 + ST 3,654 | 14.7 | 2,568 | 2.34 |
| 2 | 12,599 | ST | 결함 없음 | — | — |
| 3 | 12,599 | ST | 12.3 | 1,185 | 3.53 |
| 4 | 12,599 | ST | 10.8 | 1,152 | 3.73 |
| 5 | 12,602 | ST | 7.1 | 2,544 | 2.73 |

명목 집단별로는 AL의 인스턴스/장 2.34·꼭짓점 평균 14.7·면적 중앙값 2,568 px²·`is_crowd=1` 0.9%, ST는 3.27·9.9·1,510 px²·0.5%였다. AL 전량이 앞쪽 ID 구간에 있다는 점 때문에 출처 구분과 ID 순서의 효과도 겹친다.

꼭짓점 수 차이는 확인했지만 같은 결함을 시간에 따라 더 성기게 표시했다고 확정할 수는 없다. 클래스·형상·수집 배치의 차이가 섞일 수 있다. 재질별 IoU 차이를 해석할 때 모델과 정답 폴리곤의 차이를 구분해야 하며, 실제 촬영 시기나 재질의 효과로 단정하지 않는다.

## 3. 세 참여자 역할을 만든 이유와 현재 규모

설계는 ST·AL이라는 제공 라벨을 먼저 구분하고, ST 내부 C1·C2에만 Dirichlet α=0.5로 클래스 편향을 부여하는 방식이다. C3에는 이를 다시 적용하지 않는다. 따라서 C1·C2의 차이는 실험자가 만든 통제 조건이며, 이 구성을 회사별 자연 분할이라고 부르지 않는다.

8월 분석에서는 평가 20%를 먼저 떼는 계획으로 평가 12,600장·학습 풀 50,398장, C1 28,828장·C2 14,414장·C3 7,156장을 예상했다. **이 값들은 계획 추정치다.** 묶음 단위 처리 후 동결한 실제 규모는 아래와 같다.

| 현재 구분 | 이미지 수 |
|---|---:|
| 전체 | 62,308 |
| 공통 평가셋 | 12,461 |
| 학습 풀 | 49,847 |
| C1(명목 ST) | 26,451 |
| C2(명목 ST) | 16,253 |
| C3(명목 AL) | 7,143 |

원래 RT의 ID 연속 구간은 AL 956개·ST 5,372개, 합계 6,328개였다. 이 수는 분할 단위를 구성하는 데 참고했지만 실제 용접부 수가 아니다. 현행 분할은 바이트 해시와 ID 구간, 지각 해시 일치를 결합한다. 분할 사이 중복 의심을 모두 해소한 것은 아니므로 공통 평가셋 결과는 탐색적이다.

계획 단계의 C3 희소 클래스 추정은 균열 약 235장, 융합불량 약 240장이었다(정상 약 3,758, 기공 약 2,097, 슬래그혼입 약 826). 이를 현재 클라이언트별 확정 개수나 충분한 학습량의 증명으로 쓰지 않는다. α=0.1/0.5/1.0 민감도 분석 역시 C1·C2에 한정한 확장 제안이며 실행 결과가 아니다.

## 4. 서로 다른 데이터셋의 클래스는 어디까지 비교할 수 있는가

창원 RT·VT, RIAWELC, LoHi-WELD의 원본 라벨은 세부 수준이 다르다. 최초 검토한 18개 데이터셋-클래스 쌍에서 직접 대응 8건, 기공 세부종을 나눌 수 없는 1:N 대응 4건, 직접 대응하기 어려운 항목 6건을 구분했다. 마지막 6건은 정상 3건과 LoHi의 `deposit`·`discontinuity`·`stain`이다.

| 결함 개념 | 비교에 사용할 수 있는 ISO 그룹 | 원본의 한계 |
|---|---|---|
| 균열 / CR | 100 | 방향별 세부 구분 없음 |
| 기공 / PO / pore | 201 | 2011·2012·2013·2014 세부 형태를 원본에서 구분하지 않음 |
| 슬래그혼입 | 301 | 창원 RT에 있음 |
| 융합불량 | 401 | 세부 위치 구분 없음 |
| 용입부족 / LP | 402 | 창원 VT·RIAWELC에 있음 |
| 언더컷 | 501 | 창원 VT에 있음, 깊이 기준 미확인 |

위의 3자리 그룹 비교는 분석 제안이다. 현행 `configs/label_map.yaml`은 기공 대표 코드를 `2011`, 대체 코드를 `2012`로 둔다. 이 문서가 설정을 `201`로 변경하거나 세부 형태를 확인한 것으로 해석하지 않는다. 통일된 결함 이름과 ISO 코드는 사상표를 기준으로 사용한다.

RIAWELC 폴더 매핑은 `Difetto1→crack`, `Difetto2→porosity`, `Difetto4→lack_of_penetration`, `NoDifetto→normal`이다. 분포와 형태 판독의 근거는 [실물 확보 보고](데이터셋_실물확보.md)에 있다. RIAWELC 클래스별 7,635·6,320·4,452·6,000이라는 수는 중복 테스트 사본을 포함한 파일 수이므로 창원 이미지 장수와 더해 유효 표본 합계를 만들지 않는다.

| 비교 항목 | 창원 RT | RIAWELC | LoHi-WELD |
|---|---|---|---|
| 균열 | 있음 | 있음 | 없음 |
| 기공 | 있음 | 있음 | `pore` |
| 정상 | 라벨 있음 | `ND` | 빈 라벨 77건의 의미 미확인 |
| 슬래그혼입·융합불량 | 있음 | 없음 | 대응 없음 |
| 용입부족 | 주 클래스에 없음 | 있음 | 없음 |
| 위치 정답 | 폴리곤 | 없음 | bbox |

창원 RT와 RIAWELC의 공통 비교 범위는 **균열·기공·정상 세 클래스의 분류**다. RIAWELC에 위치 정답이 없으므로 이 비교에서 위치 지표를 만들 수 없다. 정상 라벨도 규격상 합격을 뜻한다고 확인된 것은 아니다.

LoHi의 `deposit`은 정의를 확인하지 못했고, `discontinuity`는 특정 결함을 가리키기에는 넓으며, `stain`은 표면 오염이다. 네 클래스 가운데 기공만으로 전체 체계를 통일하기 어려워 현재 공통 비교에서 제외한다. 이는 가시광 확장 후보로서의 보유를 폐기한다는 뜻이 아니다. 창원 VT도 용입부족·언더컷과 RT의 균열·슬래그가 다르므로 주 RT 실험에 섞지 않는다.

## 5. 남아 있는 확인과 해석 범위

제공 라벨 정의, 명목 ST·AL의 실제 의미, ID가 나타내는 수집 단위는 아직 충분히 확인되지 않았다. 원본 `info.id`와 파일명 숫자가 다른 10건도 있었다. 나머지 129,603건은 두 값이 일치했고 두 필드 자체의 중복은 0건이었다. 10건은 정상 ID 대역 밖에 있어 기존 분석에서는 고립 묶음으로 처리될 것으로 보았지만, 이것만으로 해당 이미지의 실제 누수를 배제할 수 없다.

이 데이터로 검토할 수 있는 질문은 **공개 자료를 서로 다른 분포로 나눈 조건에서 공동 모델과 개별 모델의 성능이 어떻게 달라지는가**다. 현장 회사 간 편익, 실제 재질 효과, 누출 방지 보장까지 입증하는 자료는 아니다. 연구 질문의 현재 범위와 사전실험 결과는 [실험설계](실험설계.md), [사전실험 보고](사전실험_보고.md)를 따른다.
