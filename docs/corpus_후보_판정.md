# 규정·설명문 코퍼스 후보 검토

이 문서는 용접 결함의 규정 근거와 설명문을 만들기 위해 수집한 문서 후보를 평가한다. **파일 확보, 텍스트 추출, 사용 조건 확인, 학습·검색 투입, 사람 검증은 서로 다른 단계**다. 추출한 문서가 모두 코퍼스에 들어가는 것은 아니다.

대상은 2026-08-23 조사한 34건(PDF 33 + DOCX 1, 91MB)이다. 파일 해시·쪽수·메타데이터·텍스트 레이어·저작권 문구를 확인하고, 두께·수치 구간·판정·결함 어휘가 같은 쪽에 나타나는 곳을 찾아 본문을 대조했다. 원문 PDF와 추출한 본문 덩어리는 공개 저장소에 넣지 않았다. 이 개정은 기존 조사 기록을 정리한 것으로 자료 사용권을 새로 확인한 결과가 아니다.

## 1. 검토 결과와 현재 활용 범위

이 후보군에서는 사용할 수 있는 두께 구간별 허용치 수치표를 확보하지 못했다. 표가 확인된 유일한 문서는 **API 1104 유료 표준의 합격기준을 옮긴 제3자 요약 기사**였으므로 학습·검색 투입 대상에서 제외했다. 나머지 후보에서 자동 탐색으로 걸린 쪽은 전극 카탈로그·공정 선택표·참고문헌·산업안전 설명 등으로 확인됐다.

규정 원문 경로로 별도 확보한 IACS Rec.47과 한국선급 자료가 허용치 표 파일럿의 근거로 남았다. 그러나 이미지에는 두께와 픽셀-mm 환산값이 없으므로 이 표를 확보했다고 실제 이미지의 합부 정답이 생기지는 않는다. [판정문 생성 가능성](데이터셋_판정생성_가능성.md)에서 이 차이를 설명한다. 규정 수치의 원문 대조와 사람 정답 검증은 아직 완료되지 않았다.

| 단계 | 확인한 결과 | 뜻하지 않는 것 |
|---|---|---|
| 후보 조사 | 34건 분류 | 34건 사용 허가 |
| 중복 제외·추출 | 바이트 동일 2쌍을 제외한 32건, 실패 0 | 저작권 제한 해소 또는 내용 정확성 보장 |
| 권리 기준 분류 | 색인후보 2건, 참고전용 30건 | 색인후보 모두 과업에 적합함 |
| 과업 적합성 검토 | MDPI 논문 1건을 관련연구·보조 색인 후보로 제안 | 승인·색인 투입 완료 |
| 허용치 표 | 별도 KR 파일럿 11행 전사 기록 | 실물 판정 정답이나 본실험용 검증 완료 |

## 3. 추출 결과

초기에는 스캔본의 텍스트 추출을 제한했으나 이후 참고용 추출 범위를 넓혔다. 바이트 동일 2쌍을 제외한 32건 모두 추출했고 스캔본 10건에 OCR을 적용했다. 추출 방식 변경은 사용 조건을 변경하지 않는다.

| 항목 | 당시 추출 결과 |
|---|---:|
| 문서 | 32/32건, 최종 실패 0 |
| 처리 쪽수 | 2,804 |
| 표 | 2,132개, 구조 보존 CSV |
| 그림 | 4,609개, PNG·캡션·쪽번호 동반 |
| 결함 형상 예시로 표시한 그림 | 105개 |
| OCR 적용 | 10건 |

검사 방식 분류는 RT 12·UT 4·VT 1·무관 15건이었다. 저작권 분류는 공개 2·학술지 9·상용출판물 5·유료표준 1·미확인 15건이다. 색인후보 2건은 MDPI와 OSHA이며 나머지 30건은 참고전용이다. OSHA는 권리 분류와 별개로 합격기준 과업에 부적합하다.

추출 과정에서 PDF 31건은 Windows의 한글·공백 경로를 Docling 파서가 읽지 못해 ASCII 임시 경로에서 처리했다. 스캔본 10건에는 EasyOCR의 한국어·영어 지정과 전체 페이지 OCR을 적용했다. 당시 환경에서는 `TORCHDYNAMO_DISABLE=1`도 필요했다. 이는 문서 내용의 결함이 아니라 경로·언어 설정·실행 환경 문제였으며, 추출 성공만으로 인식 결과의 정확성을 보장하지 않는다.

추출 코드와 메타데이터는 `corpus/parse/extract_candidates.py`, `corpus/parse/extracted_manifest.json`에 기록돼 있다. 원문·추출 본문·그림은 별도 저장공간의 약 150MB, 32폴더로 보관한 기록이다. 공개 문서에는 원문이나 개별 추출물을 추가하지 않는다.

7건 모두 처음에는 텍스트 레이어가 없었으나 OCR로 읽을 수 있는 본문을 얻었다. 조사·받침 오식이 남아 있어 사람의 의미 대조가 필요하다. 이들 자료에는 확인된 허용치 수치표가 없다. 원인·조치 설명에 주제가 맞는다는 이유로 권리 미확인 상태를 건너뛰지는 않는다. 발행처·저자·연도가 확인되기 전까지 `참고전용`이다.

캡션으로 표시한 결함 형상 예시 105개도 내부 참고용으로 분류했다. 학위논문 ND 조건, 상용출판물, 출처 미확인 자료가 섞여 있어 현재 기록만으로 논문·발표에 재사용할 수 없다. 이미지 자료나 공개 논문의 그림을 대안으로 쓰더라도 해당 자료의 표시·반출·재사용 조건을 따로 확인해야 한다.

원인·조치 자료를 보강할 경로로 대한용접접합학회지(KCI-JWJ)를 검토했다. 당시에는 수집 착수 전이었으며, 학회지의 공개 열람과 개별 논문의 이용 조건을 함께 확인해야 한다.

## 5. IACS·한국선급 허용치 표 파일럿

| 별도 확보 문서 | 당시 처리 상태 |
|---|---|
| IACS Rec.47 Rev.10 Corr.1(2025), 67쪽 | 원문 확보·Docling 변환, 표 49개, 해시 기록 |
| 한국선급 제2편 재료 및 용접(2025), 362쪽 | 부록 2-7(p316~336) 변환, 표 24개, 해시 기록 |

KR 부록 2-7에서 RT 기준을 `limits_v0_pilot.csv` 11행으로 전사한 기록이 있다. 기공의 크기, 슬래그·융합불량의 합계길이, 균열 판정, 별도 VT 표면 기공 축을 다뤘다. 수치표 원문은 이 공개 안내에 재수록하지 않는다.

당시 알루미늄 조건의 허용치는 0행이었고, 누적 점수제는 용접부·시야 단위 집계 정보가 없어 적용 범위 밖이었다. 이후 명목 AL을 실제 알루미늄이라고 확정할 수 없다는 한계까지 드러났으므로 라벨만 보고 재질별 규정을 자동 적용하지 않는다. 허용치 수치의 원문 대조, 적용 범위 확인, 사람 정답 검증을 완료하기 전까지 파일럿 자료로 취급한다.

## 6. 유료 표준과 과거 공개 문구의 정정

API 1104는 용접 표준의 번호다. 해당 제3자 요약본은 유료 표준 원문이 아니어도 합격기준 수치를 옮긴 자료여서 사용 대상에서 제외했다. 이 문서에 허용치 수치를 다시 싣지 않는다.

2026-10-04 정정에서 앞선 판이 실었던 수치 예시를 제거했다. 당시 본문에는 수치를 옮기지 않았다는 설명과 실제 수치 예시가 함께 있어 서로 어긋났다. 현행 문구의 정정은 이전 게시본이나 저장소 이력을 바꾸지 않는다. 과거 공개 이력의 처리는 별도 확인 사항으로 남아 있으며, 이번 문서 정리로 해결됐다고 표시하지 않는다.
