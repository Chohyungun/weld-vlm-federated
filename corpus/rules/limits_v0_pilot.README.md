# limits_v0_pilot.csv (파일럿 전용 초판, 미검수)

이 파일은 본 CSV가 아니다. 소표본 관통 시험(스펙 §7-6) 전용이다.

- `extraction_path=M`이지만 이중 입력 대조를 하지 않았다. 1인 전사이며, Docling 추출 CSV
  (`corpus/parse/survey/KR-RULES-P2/`)와 원문 markdown 대조로 갈음했다. 스냅샷 비대상이다.
- 본 limits.csv는 스펙 §3의 본 파이프라인(TableExpectation·수용 판정기·이중 검수)으로
  별도 구축하고, 이 파일은 그 시점에 폐기된다.

## 출처

KR-RULES-P2 (2025 선급 및 강선규칙/적용지침 2편, sha256 `46c4ee18…`) 부록 2-7
"선체 용접이음부의 비파괴검사 기준", 방사선투과검사 판정기준 (p327~329):

| clause_id | 원문 | 검사 방법 | 내용 |
|---|---|---|---|
| KRA27-T15 | 표 15 | RT | 제1종(기공 2011) 최대결함크기: 4 / 5 / t/5 / 10 (두께 4구간) |
| KRA27-T16 | 표 16 | RT | 제2종(슬래그 301·융합불량 401) 합계길이: 6 / t/2 / 24 (두께 3구간) |
| KRA27-3D | 본문 (d) | RT | 제3종(균열 100) 전량 불합격 = none_permitted |
| KRA27-S | 표면결함 표 | VT | 표면 기공 d≤0.25t 최대 3mm (active) |

`KRA27-T15`와 `KRA27-S`는 둘 다 결함코드 `2011`이고 두께 구간도 겹친다. 두 행을 가르는
것은 `inspection_method` 하나뿐이다. 이 축이 없으면 표면 행을 배제하는 것 말고는 방법이 없다.

## 전사 규약 적용 내역

- 원문 폐구간 `(a, b]` → 반열림 `[a+0.01, b+0.01)` 환산 (0.01 그리드, 스펙 §1-3).
  원문 표기는 `limit_expr`에 보존. 원문 조판의 `∠`는 `<`의 표기다.
- `t/5` → `prop_t` factor 0.2, `t/2` → factor 0.5.
- `inspection_method`는 원문 절의 검사 방법을 그대로 옮긴다. p327~329는 "방사선투과검사
  판정기준"이라 표 15·16·본문 (d) 유래 행은 전부 `RT`, 표면결함 표 유래 행은 `VT`다.
  추정하지 않는다. 원문이 검사 방법을 특정하지 않는 조항에만 `ALL`을 쓴다(현재 0건).

## CSV 밖에 남긴 것 (건수 보고 대상)

| 항목 | 사유 |
|---|---|
| 표 14+15 결함점수 (1개 1~25점, 시야 내 총합 ≤ 6/12/24/30) | 누적형(F6)으로 적용 범위 밖이다. 판정 단위가 용접부·시야인데 우리 데이터 단위는 이미지 1장이라 집계 단위를 데이터가 주지 못한다(스펙 §4-1). 스케일 메타데이터와 용접부 ID가 확보되면 승격 가능하다 |
| 표 15 비고 무시 하한 (0.5/0.7mm 이하 무시) | 측정 하한 규칙. note에만 보존 |
| (e) 제1종·제2종 혼재 시 각 기준의 반 초과 → 불합격 | 복수 제약 결합 규칙. note에 보존하고 별도 판단 대상으로 둔다 |
| 표 16 군집 간격 규칙 (간격 ≤ 최대 결함 길이 → 합산) | 군집 규칙. note에만 보존 |

`scope=excluded` 행은 0건이다. 표면 기공 행 `KRA27-S-01`은 검사 방법 축이 생기면서
`VT` + `active`로 실린다.

## 유의 사항

- 행 선택 기본 필터는 `{RT, ALL}`이다 (스펙 §1-2 5a). 골격 생성기·커버리지 리포트는
  이 필터를 거쳐야 하며, 걸치지 않으면 VT 행이 RT 격자의 공백을 가린다.
- `KRA27-S-01`은 `thickness_min=0`이라 구간 하단에서 유효 한계 `0.25t`가 0.1mm에 못 미쳐
  실현성 경보(V10)가 뜬다. RT 주 실험의 생성 대상이 아니라 당장 영향은 없다. VT를 생성
  범위에 넣으려면 두께 하한을 원문으로 다시 확인해야 한다.
