# limits_v2_pilot.csv (2 판 — 부분 B, 파일럿 · 미검수)

1 판(`limits_v0_pilot.csv`)의 행 12 개와 31 칸의 값은 **바이트 그대로** 두고, 그 뒤에 칸 넷(`measure` · `aggregation` ·
`defect_class` · `conditions`)을 더한 판이다. 행 · 값 · 구간 · 조항은 바뀌지 않았다. 1 판 파일과 1 판 README 는 그대로 남는다.

- 출처 문서 · 원문 표 · 전사 규약(반열림 환산 · 0.01 격자)은 1 판 README 그대로다. 이 README 는 바뀐 것만 적는다.
- 값은 이 README 에 옮기지 않는다 — 한계값 · 계수 · 상한 · 두께 경계 · 무시 하한 · 결합 규칙의 비율은 표에만 있다.

## 판 대응

파일 이름의 `v2` 는 '2 판' 이다. 1 판 파일 이름이 `v0_pilot` 이라 숫자가 엇갈린다.

| 판 | 표 파일 | 페어 |
|---|---|---|
| 1 판 | `corpus/rules/limits_v0_pilot.csv` | `data/processed/pairs_main_v1/` |
| 2 판 | `corpus/rules/limits_v2_pilot.csv` | `data/processed/pairs_main_v2/`(봉인 뒤) |

페어 메타는 `limits_table.path` 로 표 파일을, `text_contract` 로 정답 서술의 문장 계약 판을 가리킨다.

## 새 칸

| 칸 | 값(닫힌 집합) | 규칙 |
|---|---|---|
| `measure` | `최대결함크기` · `개별길이` · `합계길이` | RT · ALL ∧ active 의 값 한계 행(불허 아님)에 필수. 불허 행 · VT 행은 빈칸 |
| `aggregation` | `개별` · `합계` | `measure` 와 짝 — `합계길이` ⇔ `합계`, 나머지 측정량 ⇒ `개별`. 측정량이 빈칸이면 빈칸 |
| `defect_class` | `제1종` · `제2종` · `제3종` | RT · ALL ∧ active 행에 필수. 같은 (재질, 검사 방식, 코드)는 종별 하나 |
| `conditions` | `군집간격` · `혼재:<종별>` · `구별곤란:<종별>` · `무등급전제` 를 `\|` 로 잇는다 | 문자열 정렬 순 · 겹침 없음. `군집간격` ⇒ `aggregation=합계`. `무등급전제` ⇒ `quality_scheme=none`. 짝 토큰 `X` 는 제 종별과 다르고, 같은 재질 · 검사 방식에 X 종별 행이 있으며, 그 행들이 거꾸로 같은 종류의 토큰을 든다(대칭) |

- 같은 `clause_id` 의 행은 네 칸이 같다. 정답 서술이 조항 단위로 문장을 붙이기 때문이다.
- `개별길이` 는 이 판의 행에 쓰이지 않는다. 측정량 이름 셋을 닫힌 집합으로 두려고 넣었다.
- 로더(`corpus/rules/limits_loader.py`)는 머리에 새 칸이 하나라도 있으면 2 판으로 읽고 넷 모두를 요구한다. 행 규칙은 V12, 행 사이 규칙은
  V13 이다. 1 판 표는 지금 그대로 읽힌다.

- `measure` 는 1 판 행 이름표 머리(`source_row_label`)와 같고, `defect_class` 는 1 판 `note` 의 머리와 같다.
- VT 행(KRA27-S-01)은 부분 B 범위 밖이라 네 칸을 비운다. 로더가 그 사실을 `checks_skipped` 에 적는다.

- 조건이 있을 때만 대응되는 조항(보조 조항)은 행을 더하지 않고 `구별곤란:<종별>` 토큰에서 낸다 — 같은 재질의 그 종별 행의 조항이다
  (`corpus.rules.limit_eval.derive_clause_roles`). 보조 조항은 골격의 `clauses` · `candidate_rules` 에 넣지 않는다.

## 1 판 README 를 고쳐 적은 것

- **(a) 혼재** — 혼재 규칙은 `note` 가 아니라 `conditions` 칸의 `혼재:<종별>` 로 적었다. 결합의 값은 표에 싣지 않는다. 1 판 README 의
  '혼재를 note 에 보존' 은 틀린 설명이었다(검토 192 의 대조 §5).
- **(b) 선언 격자** — 전사 규약(반열림 환산 · 격자)은 1 판 README 「전사 규약 적용 내역」 그대로다. 원문 대조는 구조 필드와 이 격자의
  경계 부호화가 일치한다는 뜻이고, 임의의 실수 두께 전 구간에서 원문과 같은 행을 고른다는 검증은 아니다.
- **(c) 제외 범위** — 결함점수 · 시험시야 결합, VT 맞대기 · 필릿 분모, 실치수 · 합부 계산, 입력 매니페스트 · 분할 · 기하는 이 판의 범위
  밖이다. 용입불량(402)은 이 판에서도 조항이 없다.
- **(d) 적용 전제** — 이 조항들은 품질등급이 지정되지 않은 경우의 기준이다. 자료에 등급 정보가 없다는 사실을 그 전제의 충족으로 읽지
  않는다(`무등급전제` 토큰 — 정답 서술은 '등급 지정 여부를 확인하지 않는다' 고 적는다).
- **(e) 검수 상태** — 원문 대조는 검토 192 · 화면 대조 · 검토 193 의 둘째 확인이다. 사람 이중 검수와 용접 검사 전문가 검수는 없다.
  재수록 수치 사용은 연구 책임자가 결정했다(2026-10-24). 그 결정은 전문가 검수가 아니다. 로더는 이 판도 pilot 모드로 읽는다 — 면제
  목록 · 사유는 1 판과 같고, V12 · V13 은 면제하지 않는다.
